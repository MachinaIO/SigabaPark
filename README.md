# Learning records

Append-only records of the certified curriculum and notebook learning extension, written only by
the `learning` workflow's trusted jobs (and maintainers): one JSONL file per kind
(`certifications.jsonl`, `calibrations.jsonl`, `contracts.jsonl`, `trials.jsonl`,
`comparisons.jsonl`, `activations.jsonl`, `reveals.jsonl`). The format is
`ci/learning/RECORDS.md` on `main`. A record in a pull request or a comment is only a claim.
