The private verifier interface consists of the 128 assignment bits, then 4096 claimed output bits in gate order, then the public statement in its registered `encGates` encoding. There is one claimed bit for each gate. A backend that takes assignment and circuit alone must produce or otherwise supply this trace and account for that work.

The first work tape contains the constant true followed by the full certificate. The second initially contains true and the assignment, followed by blanks. The heads always move together. At the beginning of gate number i, the intended second tape has exactly 129+i occupied cells. A read of a blank produces true, including a self-reference, while a previously verified false wire remains false. The machine checks the claimed bit at 129+i against the computed NAND before writing that value to the history. Hence even an inconsistent future claim cannot supply a wire prematurely. After the last write it checks the end of the input and the final value. Every rejection emits a single false bit. The registered brute-force machine instead has 40 work tapes and enumerates assignments. Its description alone exceeds this component's allowance because every work head contributes a factor of three to the canonical table.

For a gate with indices a,b, the registered frame is four true symbols per unit of a, then true and false, two true symbols per unit of b, and a final false. The parser moves one work cell on every fourth or second true, respectively. The full certificate marks valid addresses and the left boundary at cell -1. The machine rejects an index beyond 4224. The extra true in the first separator requires one symbol of lookahead. The core's simpler `unparse` word uses different separators.

Starting at address zero, the two lookups through entry into the commit phase cost 5a+3b+5 transitions. The first field and separator consume 4a+2, and the rewind costs a+1 because the separator has already moved both heads left. The corresponding quantities for the second field are 2b+1 and b+1. This accounting includes address zero. With f=129+i, the commit scan and write take f+1 transitions. The nonfinal advance and the return to address zero take f+3 further transitions. A final advance takes one transition. A mismatch ends the traversal at the commit position. The initial constant, fixed prefix copy, turn and rewind take 1+4224+1+4225+1=8452 transitions. Thus the proposed clock uses at most 8452+4096(10·4224+10)=173064452 ticks. The run proof composes these phases on the registered inputs before invoking the theorem that a halted deterministic configuration is fixed for the remaining clock.

The two-work-tape description has 4224 loader states and 19 phase states. Both Boolean-valued and blank symbols are charged on every work tape and the input tape, as are both coin values. The table has 6·4243·9 rows of 25 bits each. This gives 5728050 description bits and total declared cost 178792502.

An offline alternative would emit two requests per gate, with a 13-bit source and an occurrence number. Before resolving a source, any gate-wire address at or after its occurrence's availability frontier must return true. Stable binary radix passes on the source could join the remaining requests to the wire table; restoring occurrence order would require a second ordering pass or another routing scheme. The direct walk avoids both sorts because processing each unary field already traverses its address distance. The proposed offline variant has no certified clock here.

The end-to-end theorem states the output law on typed inputs. Its right-hand side checks the entire gate trace and the last output. The local block theorem isolates the part from the first input symbol of a gate through both rewinds, before the history write. The commit-block theorem covers both the matching write and immediate rejection, with the exact physical configuration after f+1 steps. Its induction proof initializes both tapes, connects advance to the next gate or final output, and folds the blocks against the registered evaluation while bounding their sum. A mismatch at the frontier stays a mismatch in the final wire list because each subsequent gate only appends a wire. This component supplies no encryption algorithm or security reduction.
