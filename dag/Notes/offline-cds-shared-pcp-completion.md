## Moving the ambiguity to a single verifier evaluation

Fix a public set U of u coordinates of the PCP proof. Every other proof coordinate belongs to the authenticated core. Change Figure 13 of Döttling, Garg, Goyal and Malavolta, [Laconic Conditional Disclosure of Secrets and Applications](https://eprint.iacr.org/2019/1353), figures 6–13, section 7, as follows. Hash only the core and use ordinary receiver-first OT on each bit of its LOT digest. For r independent verifier tapes, Figure 12 runs LOT.Send only on queried core positions and delivers input-wire labels of a *single* modified Figure 11. Its Boolean circuit, with private payload and tape data and public statement, takes the queried core bits. It returns the payload exactly if **there exists one common assignment to U under which every one of the r PCP tests accepts**. Otherwise it outputs the distinguished failure symbol. Repeated occurrences of a free coordinate, including in different repetitions, are wired to the same existential variable. Do not quantify a different assignment per test. The only labels delivered to this garbling describe one authenticated core input. No receiver obtains alternative labels for its free coordinates: they are internal variables of a deterministic circuit.

For any valid proof, its restriction and its actual free assignment satisfy the new test under perfect completeness. If completeness has marginal error e per tape, use re union bound for the true assignment before accounting for constituent correctness errors. For false x and any core fixed before the verifier tapes, each fixed completion is a fixed proof, so each passes independently repeated tests with probability at most s^r, where s is ordinary PCP soundness. The union over all completions has probability at most min(1,2^u s^r). This remains true for an arbitrary distribution of core strings independent of these fresh tapes. It also permits the chosen completion to depend on all the tapes and the core inputs. The Lean finite-tape counting theorem proves precisely the union step and the second lemma records completeness. The final cryptographic condition is that the core used in this bound is already fixed in the security hybrid. A digest chosen after learning the query schedule has no such guarantee.

To justify the restricted false-statement hybrid, require Figure 13's malicious outer OT with extraction, single-input simulation for each garbled circuit, and context-secure LOT for the substituted core. The proof structure of section 7.4 first extracts one core digest, simulates the Figure 12 circuit on this one digest, and replaces the LOT by a simulator accessing one extracted core database. Run the final garbling simulator on failure. Its output differs from the correct simulated value on at most the bad-tape event above, independently of the plaintext. The inner verifier circuit must have fixed public size (pad its representation for a fixed statement and bounds); its garbling has a single encoded input in each row. This gives a false-statement argument under the stated simulation interfaces; a full new context extractor that outputs a valid NP witness on YES is not asserted or needed for this false-only argument. The paper's proof is classical and includes context extraction. One cannot substitute QPT security for that step from the headline LWE assumption.

## The offline dictionary and its loss

Sample the honest PCP prover and outer OT receiver tapes R publicly; keep verifier tapes, garbling randomness, LOT sender randomness, and OT sender randomness private. Given setup, statement and R, the issuer requires a public algorithm to enumerate K representative **first messages for the core digest**. They can be digests turned into OT messages with the fixed tape. No preimages need be published. On a valid witness the decoder must derive a representative index and a private opening for its core. An exact match uses the ordinary processed core and replays the same OT receiver states. More generally accept a public deterministic transformation of the selected full reply, if it is correct with that opening. Its public auxiliary inputs must be generated by the same sampler in both worlds and available to the reduction without the challenge verifier coins. Sample independent full verifier replies for all K rows under common public setup. Witnesses varying arbitrarily on U but having the same core use the **same** reply and ordinary opening, saving up to 2^u separate proof alternatives. This does not promise K=1 on all inputs.

For false x, let P_j be acceptance on a table with its first j rows encrypting one and the rest zero. A single CDS receiver samples j uniformly, generates all auxiliary data, asks the challenge for row j, and runs independent real senders with known messages for the other K−1 rows. The signed gap of the complete-table adversary is K times the challenge receiver's signed gap: sum P_j−P_(j−1) telescopes. Every public transformation, including arbitrarily many derived evaluations of a row, is postprocessing of this very table. A simulator need not return new independent replies for those transformations. If the constituent simulation errors sum to delta per real-to-ideal endpoint, the simple bound is 2K(delta+2^u s^r) on the table gap, capped at one. Independent uniform indexing is exact with a fixed tape for power-of-two K; arbitrary K may be padded to the next power of two using fresh dummy replies, charging that padded loss, or handled by a stated sampler. This hybrid is black-box with classical messages and a single final QPT adversary execution when the constituent security theorem covers that class with the stated auxiliary input. No such concrete quantum extraction theorem or fixed-registry reduction is provided here.

Issuer cost is common setup/list generation plus K full garblings of both modified circuits and K times the digest-bit count of ordinary OT sends (each row has its own coins). The security reduction pays K−1 of those sender costs and one execution of the table adversary, plus its setup/list, indexing and assembly. Receiver cost is one PCP computation and core LOT hash, digest-bit OT receives/decodes, index search, one Eval of each garbling, and LOT receives for the core queries (at most qr). A constant-size implicit seed for all private row randomness does not by itself implement the required joint table. The generic bound does not exclude aggregation of special independent LWE samples; an OT/garbling context needs its own joint simulation.

Conditional pricing of the shared completion: suppose a public fixed nice tree decomposition of the co-occurrence graph on U has width w, B bags, and contains the scope of each possible local test within a bag. Gate-layout padding may use this tree and a public upper bound on the number of tests. At each bag enumerate at most 2^(w+1) assignments. Evaluate every assigned test on that tuple and the *input labels' underlying core bits* inside the circuit. Forget uses OR, join uses AND on matching assignments, introduce copies the relevant child. This gives O((B+r C_test)2^(w+1)) Boolean table work for fixed routing, plus routing/selection if the schedule is encoded in a universal circuit. A brute-force alternative costs O(2^u r C_test). The latter is exponential. The number of tapes needed at s=1/3, u=128 is 162 to make the single-row bad-tape probability below 2^-128. At s=2/3 it is 438; add the bits for the desired hybrid loss and other errors as needed. At w=2, r=162, charging eight tuple checks per local test gives at most 1296 local predicate instances, before the B bag operations, garbling, hashing, and other cryptography. These are parameter and Boolean-operation counts; there is no measured or verified native Machine clock or 4096-gate bound.

With an empty core the folded verifier can be evaluated directly by the sender. Output the bit if the sampled constraints admit a common assignment and a fixed zero otherwise. This gives an unconditional restricted construction with perfect YES correctness and NO statistical gap at most 2^u s^r, also for quantum distinguishers of classical ciphertexts. Efficiently solvable low-width sampled predicates provide a positive interface but also a randomized decision procedure. For the raw 4096 NAND gates plus final output check, a direct uniformly sampled single-constraint verifier has worst-case per-proof soundness at most 4096/4097; treating 4224 coordinates as free gives r=12,357,406 for the same 128-bit union target. Given this many repetitions there is no general low-width promise, and exact solving the sampled circuit can remain expensive.

## What actual OT response transformations preserve

Figure 6's LWE weak LOT hashes a bit database D to d^(i)=A^(i)D. For a query at L its public response contains b_j=s^T a_j+e_j for j≠L and two dithers t0,t1. With x=D[L], the receiver rounds (-1)^x b·D_without_L + t_x. Suppose D'=D+Delta has the *same bit at L* and the opening knows Delta. Write z=b·Delta_without_L. Set t0'=t0−z and t1'=t1+z, leaving b unchanged. Then the raw phase obtained from D' is exactly the original phase for D for either selected bit, including the realized noise, before any rounding. This is a genuine postprocessing of the same response; it is not a fresh sender execution at d'=A D'. In the Figure 7 key wrapper the same selected key suffices to keep the selected payload pad unchanged. This local identity does not allow recovery of the other arbitrary payload, and does not supply a digest translation for Figure 10's recursively hashed Merkle tree or a way to evaluate the outer garbled circuit at all digests. If all differences are on U, every core query satisfies the bit condition by construction; hashing the common core directly removes the need to transform the outer string OT. For a pair of distinct fixed bit databases independent of the Figure 6 matrices, their weak digests collide with probability exactly q^(-n lambda): condition on every column except a column with difference ±1, which is a unit. A union bound over M such databases gives binom(M,2) q^(-n lambda). Reused tree keys and intermediate hash inputs depending on them in Figure 10 preclude applying this same unconditional formula to its final root without another argument.

## Why publishing arbitrary outer labels does not repair Figure 13

Figure 13 publishes the query locations, both garbled circuits and the per-digest-bit OT sender responses. Figure 3 ideal string OT delivers one of the two strings for a session. If a universal response transform with two known opposite openings yields both independent random strings with probability p in an ordinary one-session experiment, the ideal receiver can guess the other length-l string with probability at most 2^-l, giving an environment gap at least p−2^-l. For weak LOT, Definition 24 lets the first stage choose (digest, location) together and the second stage must output the entire key pair. An opposite-choice transform for arbitrary payloads is a stronger promise than the same-choice phase equality above. Definition 27 is a separate indistinguishability formulation for full LOT.

There is also a direct failure at Figure 11 with no appeal to security games. If a putative factorized reply releases all input labels needed for both the digest of the all-zero database and the digest of the all-one database *for the same* Figure 12 garbling, evaluate at these two complete inputs and open the resulting LOT ciphertexts with both processed databases. By honest evaluation correctness at the two fixed databases this supplies both labels at every one of the qr *occurrence wires* of Figure 11, except for the sum of the two joint error bounds. Knowledge of just those two encoded digest vectors suffices. It is not necessary to release all 2^|d| vectors. At this point assignments to two occurrences of one position need not agree. For a concrete checker, take a false constraint system u=0, v=1, u=v. A single test is chosen uniformly and is identifiable from the query pair (u,u),(v,v),(u,v), respectively. Every fixed database passes at most two of three. With r tapes the true maximum fixed-proof acceptance is (2/3)^r; allowing independent answers at each occurrence yields acceptance on *every* tuple of tapes. With one shared assignment chosen after seeing all queries, the acceptance probability is instead 3(2/3)^r−3(1/3)^r for r≥1 (at least one of the three tests must be absent). Exhaustive enumeration for r=1 through 5 gives 3,9,21,45,93 accepting tape tuples out of 3,9,27,81,243; pooling independently gives all of them. The Lean Boolean lemma checks the underlying local/global disagreement. This public-query local checker is an explicit verifier interface; arbitrary PCP tapes need not be recoverable from the published locations. No claim about breaking the original interactive protocol follows.

## Successor obligation

Find an efficiently generated small list of core digests of a proof for every satisfying witness of a general NAND circuit, together with honest private openings and a manageable shared-completion circuit. A small cardinality alone does not give the issuer the list. Return either a public transformation for the complete multi-level LOT/garbling view or a new full joint reduction with explicit cost. The registered integer-time, assumption-strength and general NAND obligations remain open.
