The fixed-source, message-only router in [task 173](https://github.com/MachinaIO/SigabaPark/pull/173) can be issued and opened by two explicit six-work-tape programs. The programs in the definition include the supplier, both row sweeps, a uniform triple parser and selector, slot manipulation, the whole expansion, framing, and final output. The sum of their registered costs is 4,210,211,861. This is for one local packet on independently authorized sources. General NAND witnesses still need correlated, context-bound source delivery. A declared clock terminates an unfinished machine too. The supporting path ledger and executable replays below justify sufficiency on the stated interface at the algorithm level; the formal theorem checks the numeric machine fields and the strict inequality.

### Interface and physical chronology

Let N=4224. A frame(X) consists of 1 then the payload bit for each bit of X, followed by 0. Enc reads frame(3N mask bits) followed by frame(one message bit). Its output is first the 3N flagged 256-bit opening fields, then 50,672 raw row bodies of 256 bits in the two range/joins order, then the masked bit. An unopened source field consists of a zero flag and 256 zeros. Dec reads frame(a,j,c) followed by frame(the complete encoder output); the indices are three little-endian 13-bit words. It checks a,c differ from j, the indices are in range, and the three selected opening flags. It outputs zero for a denied or invalid triple. This message-only interface has no authenticated test for arbitrary corrupted key strings. For well-framed inputs it consumes the stated prefix. It does not require trailing garbage rejection.

The eight issuer slots at each index each have key, first pad and second pad fields. Every internal field is 256 bits followed by a blank. Enc generates all eight slots per index, including the four absent boundary slots, to avoid a boundary case in its random generation loop. Dummy keys and pads never enter the packet. A fresh bit of the physical transition coin supplies every seed bit. A private terminal word is sampled separately. Eight on-tape role markers track which slots have already been generated, three flags identify the source roles, and a 13-bit decrementing index controls the outer loop. The 256-bit timer and the role/index records use negative work-tape locations below a blank guard. The same positive row cells support the block kernel and, after all calls, the XOR accumulator and terminal replay.

The constant ROM on tape 4 lies left of scratch cell zero. Each of its four 32-bit constant words ends at a blank. Setup costs 267 ticks once. The first forward pass writes row 0's constants, row 1's first key half, and row 3's zeros in parallel. The reverse ROM pass streams the other half into row 2 and restores the preceding heads. Two more traversals rewind the bus. The ten double rounds use the common quarter body with three physical return bits. Two ROM scans at feedforward simultaneously process both carries for rows 0 and 1, then the independent carry for row 2. Addition of the original zero row is the identity on row 3. Every blank at a word boundary resets the relevant carries. The four result rows remain in place; all four heads and scratch return to cell zero. The bus head advances 256. Repeated invocations cost 51,469 ticks including both input reads and all head returns. The bootstrappable in-place core uses 1,497 states including one spare. On already populated row tapes this kernel matched all 512 independent word-reference bits on eight keys. This is a fixed ChaCha20 block with a zero counter and nonce, as specified in [RFC 8439](https://www.rfc-editor.org/rfc/rfc8439#section-2.3).

The issuer interleaves row key and pads over all indices, so moving to each logically adjacent parent still costs physical distance. It compiles each sweep into runs of identical instructions; at N=4224 there are 20 runs. All short displacements are explicit delimiter crossings; two long rewinds find the double blank to the left of the allocation, then move forward the stated number of fields. The emitter reads each field into the XOR accumulator and rewinds the accumulator after every read, emitting the last XOR for each row. At a terminal row its retained word joins that XOR in parallel. Each run count is written as a binary integer; decrement, borrow, rewind and underflow all take physical steps. Each initialization clears the guard above the variable-width counter, including when the block left data there. The last message bit uses the terminal key's low bit.

Dec stores three actual key slots (A,J,C) on tape 5. The selector places the input indices and changing comparison words on the negative halves of tapes 0 and 1. A fourth comparison word stops the current sweep. The row matcher compares little-endian pairs serially, keeping the most significant difference seen. A fourth guard and the first-iteration bit distinguish absent boundary rows. For the increasing unary stages the A or C comparison is to t−1 and J to t; direct is equality to t−1, continuation strict inequality, both requiring j≥t. Reverse stages use t+1 and j≤t. At a join read the left body exactly if j=t and the chosen role index is less than t, or the right if greater. These comparisons operate in the order of actual serialized fields, including unselected ones. The selector writes its four-bit return address next to the first flag; each selected expansion has another four-bit return word below the four comparison answers. No state implicitly holds an uncharged triple, dynamic PC or address. A skipped field uses an initialized 256-bit slot as the clock, so even an input of all zero bits has the correct physical field boundary.

For an accepted unary body replace the A or C slot by its parent incidence pad XOR the input. For a join first expand the J slot, replace it by the required half, then expand A or C and add its range half and the body into J. Thus after the first join J stores the K key, and after the second it stores the terminal key. A direct downward unary edge uses the second source half except at the first downward index. Continuation edges use the first half. A join uses the range's first half at the two boundaries and its second in the interior (its other half went to propagation). It takes the second J/K half only at interior right joins. Every overwrite occurs after consuming the old value. The decoder reads the ciphertext stream monotonically and never uses a random access instruction.

### Cost and checks

The stored definition decodes mixed-radix action tables to genuine tr functions. A lookup uses only the available input/work symbols and fresh coin. Six radix-12 digits encode each tape's optional write (including writing blank) and signed movement; two radix-3 digits encode input movement and output; the remainder encodes a relative next state or halt. The compact data is only the source representation. We charge both full dense tables, namely 6s·729·(28+Nat.size(s)) bits each. The issuer has 365 outer controls, 1,361 sweep controls, and 1,497 core controls. The decoder has 2,463 outer controls including all 1,087 selector controls and 1,497 core controls.

* For Enc the row emitter needs 516,811,627 ticks. Starting on a field boundary, moving d≥0 fields costs 257d. Moving −d with d>0 costs 257d+2. For an absolute rewind from field p use 257p+4 to regain zero before the forward move. Each fold and rewind costs 514, including separators. Initialize an r-bit repetition counter in 2r+2 ticks. If its current positive value has i trailing zeros an iteration costs 2i+2 ticks of countdown control, and underflow costs 2r+2. These formulas were also compared to direct bit-level execution for 42 small width/size cases. The combined bound is 65,536 + 8N·(51,469+1,300) + 516,811,627. The 1,300 local allowance covers 514 sampling/rewind ticks, at most 647 to transfer all four result rows and reset their heads, at most 40 to find and restore the current role, and the indexed-loop setup and countdown (at most 128 per eight slots). The fixed allowance pays the ROM and timer initialization, terminal sampling, guard maintenance, output and frame controls.
* For Dec budget 65,536 + 1,024·(50,672+3N) + 512·(7N+1) + (2N+2)·(51,469+16,384). The first term includes slot/ROM bootstrap, the index prefix, setup of eight comparison configurations, and the three selected opening-slot detours. The field term covers the unselected and common framing cost, with at most 514 input parsing ticks, 262 home ticks from the first slot, and fewer than 100 field-call, return and flag instructions. A sweep iteration has four 13-bit word comparisons and rewind (at most 116 ticks), four 13-bit counter increments/decrements and rewind (at most 116), and fewer than 140 independent selector/branch movements. At most 7N+1 iterations occur including the initial bound check. On a selected expansion every slot is one of three 257-cell fields. At most ten one-way full-span slot seeks/returns (≤775 each), two selected half transfers including bit-pair parsing and row rewind (≤1,056 each), and fewer than 704 remaining return-word, scratch and dispatch steps per expansion suffice. The 16,384 allowance exceeds this total. The two range paths have lengths at most N−1 each and the two binary joins use two expansions each.
* The official fields set Enc time to 2,300,047,211 and Dec time to 653,426,970. Their dense descriptions cost 563,896,080 and 692,841,600 bits. Their sum with both clocks leaves 84,755,434 below the greatest integer strictly smaller than 2^32. The formal theorem computes the cost of the machines actually submitted. A functional refinement theorem proving all honest executions respect these clocks remains open.
* In exhaustive reduced-width integrated fixtures for N=2 through 5, 1,296 requests included valid, repeated-index, out-of-range and denied-source cases with two different authorization masks. The physical selector independently matched all chronological reference flags for N=2 through 6, and for the full-size (0,4223,1) path it emitted 63,344 field decisions in 7,311,115 selector ticks, selecting 8,447 body rows. Full 256-bit tests at N=3 exercised all actual block operations. Decoding the generated action tables directly, two successful paths took 453,456 and 399,356 steps and returned the encrypted one bit. Two invalid paths returned zero in 1,852 and 1,905 steps. The same encoder ran 1,456,732 steps in that fixture. No billions-step production instance was executed.

The predecessor's static hybrid still requires a fixed block pseudorandomness hypothesis at the simulator's cost. Counting these machines does not establish its numerical post-quantum strength. Neither machine compiles an arbitrary 4,096-gate NAND statement into a safe union of source openings across all witnesses. That remains the outstanding integration problem for witness encryption.
