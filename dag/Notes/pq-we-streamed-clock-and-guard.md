### The budget available to a backend

Use the episode target B = 4,294,967,295 for the sum of the two worst-case clocks and both machine descriptions. The registered Capped problem itself has the looser cap 2^100. For *every* correct implementation, the Enc clock is at least **207,643,654** and the Dec clock at least **207,643,910**. Neither security nor any lattice assumption is used.

A gate (a,b) costs 4a+2b+3 bits inside the gate list. Use 4,095 copies of (4224,4224) and one (4224,4223). All prefix gates read the unavailable final wire as true and output false. The last gate reads true and the previous false, hence accepts every assignment. Its gate list has 103,821,310 bits. This is maximal among satisfiable circuits: maximizing all indices would give a false last gate, and decreasing any index costs at least two bits. Only the exhibited length and acceptance are needed in the Lean proof. The outer parameter and statement frames occupy 207,643,652 cells. Message frames first differ in their second cell. A witness frame adds 257 cells before the ciphertext frame. If either clock cannot read the first possible differing cell, both final output laws coincide by input-head locality. Correctness would then assign mass at least 1−2^-128 to each of two disjoint words in that same law.

Write e,d for the two clocks' excesses above the proved floors. For any correct implementation the strict target is equivalent to

    e + d + D_E + D_D ≤ 3,879,679,731.

The description term for one plain machine with k work tapes and s states is exactly 6s·3^k·(4+4k+bitlength(s)). The inequality concerns clocks. Random coins, output and head travel can overlap in one transition. Adding those as disjoint lower bounds without a schedule could overcharge.

### Randomized equality at a gate

Suppose an implementation ties the two input labels of a NAND transition to entire 128-bit contexts. Consider a single scalar bilinear gate test over any field. At seed t its test matrix is A_t(x,y) = u_t(x)^T M_t v_t(y), of rank at most r. Nonzero means match. Require every diagonal nonzero for each seed and at most c accepting seeds for each fixed unequal pair. For n contexts and s equiprobable seeds,

    2 s n ≤ 2 s r + n(n−1)c.

The Lean theorem allows arbitrary matrices with these ranks. For each seed, remove each row index supporting a nonzero below the diagonal and the corresponding columns. The remaining principal matrix is upper triangular with nonzero diagonal. Apply the same reasoning above the diagonal, add, then sum over seeds. If c/s ≤ 1/n and s>0, r ≥ ceil((n+1)/2). For n=2^128 this is **2^127+1**. The illustrated error allocation belongs to the bilinear guard, not to the definition of WE. Rounding an inner product, composing nonlinear gates, or hiding whether a gate matched gives a different model. The direction of the test matters: over a field with at least n elements, encode each context as a distinct scalar and accept on zero of x−y. That matrix has rank at most two and equality is exact. Turning such a public zero test into a hidden message release is a separate task. A dense serialization of even one vector of rank-floor width exceeds B. Rank by itself supplies no bit-length lower bound for a sparse or implicit representation.

**Sharpness with exactly 128 fair coins.** Number contexts 0,...,n−1 and add dummy vertex n in the odd-order cyclic group modulo n+1. Sample u uniformly in 0,...,n−1. Pair v with 2u−v modulo n+1. The fixed vertex u and the partner of the deleted dummy are the two singletons. The other (n−2)/2 pairs each form one bucket. Use the smaller endpoint as a bucket identifier, using the real endpoint for a singleton. Two distinct contexts x,y collide for at most one seed since 2u=x+y has a unique solution in the extended group. Each partition has n/2+1 buckets. Its equality matrix is a direct sum of nonzero all-ones blocks and has exactly that rank over every field. Bucket identifiers can be computed with 129-bit arithmetic. For public u an observer chooses an actual two-element bucket as soon as n≥4. The 2^-128 guarantee for a fixed pair supplies no adaptive full-view hiding. Enumeration checked all n=2,4,8,16,64 seed/pair controls and the width at n=256. The deterministic matrix inequality also passed exhaustive 3-by-3 tests over F2 and F3 and 4-by-4 tests over F2.

### A table-free encryption experiment

PR 36 proves the key-switching ladder collapse and prefix-exposure identities. Its nonlinear processing still needs a cancellation term. PR 83 issues both witness-half XWE tables. PR 109 treats consistency and correlated code noise, with bounded-observation hiding and a full-view gap. PR 117, especially §7 of the hybrid-tool note, already considered a lock obtained from a clear lattice extractor: converting an already unpredictable clear lock to a message does not give the extractor. Its two-query result also rules out decomposable wire-label release. PR 129 seals an ABE issuer but retains the right-hand attribute ciphertext table.

For this experiment we select an external LWE encryption of an independently sampled lock and one program containing a secret decryptor. The evaluator supplies the entire external header to the program. No clear extractor gives the caller the lock, no ABE policy keys are issued, and the real-to-independent secret switch below costs a constant number of hybrid steps regardless of the witness length. It remains a related lockable-obfuscation approach. The specific correlated-header switch, rather than an application of the random-lock theorem to the public view, is the proposed research target.

* **Enc.** Sample a uniform t-bit lock L, a secret s and a t-row pair (A,As+e) from fixed decision-LWE parameters. Publish (A,Y) with Y=As+e+ΔL mod q and Δ=floor(q/2). Define the deterministic fixed-shape circuit P_s(x,A',Y') to evaluate the original NAND statement on the single x, with the registered forward-read rule. On rejection or malformed input it returns 0^t. On acceptance it returns the t nearest-codeword bits for Y'−A's (break ties deterministically). Encrypt the message bit inside the one-bit payload of the Goyal–Koppula–Waters lockable obfuscator for P_s with lock L. Publish all compiled bytes Z with the header. The code accepts caller-supplied header values; the real header stays outside the program. Pad circuit sizes independently of s and the bit. All secrets, coins and compilation are local to Enc. [GKW, FOCS 2017, pp. 612–615](https://ieee-focs.org/FOCS-2017-Papers/3464a612.pdf).
* **Dec.** Parse one witness and the whole ciphertext and run Z(x,A,Y) deterministically. On a satisfying x, the rounded string is L whenever every error lies strictly within Δ/2 of zero on the residue circle. Charge the joint bad-error probability, sampler truncation or bias, and locked-program correctness error to the 2^-128 budget. For L=0 a rejecting input may match the lock; the random-lock game includes this event. No witness-half table, per-witness issuance, or ideal private oracle is supplied.

**Precise unresolved switch.** On each fixed false statement φ, and for each payload β, compare these entire distributions (including params, φ, serialization and all public compiler outputs). In the first draw (s,A,e,L) honestly, form (A,Y) as above, and publish O(P_s,L,β). In the second change only the circuit in O to P_s' for a fresh independent secret s' of the same law. Use the same sampler and padding. The missing step is a concrete reduction for this particular secret replacement, in the presence of the LWE encryption of the very same lock, to an admitted statement-independent registry challenge. Merely declaring this pair indistinguishable would add a premise outside the registry. Circuit behavior agrees even on adversarially chosen headers for a false φ. This fact does not compare the compiled bytes. Giving the raw real program secret and header to a random-lock reduction instead allows recovery of L with the honest rounding probability. Giving only black-box program access omits the compiled bytes. Neither shortcut proves the switch.

After replacement a decision-LWE wrapper knows s' and L. On its single challenge pair (A,b) it builds O(P_s',L,β), adds ΔL to b, frames the full challenge and runs the observer once. With real b this is exactly the replaced game for the ideal samplers. With independent uniform b the translated header is independent of L and s'. Independent-uniform-lock simulation can now replace O by its common simulator. Reverse the steps for the other message. With per-step advantage bounds ε_swap, ε_LWE and ε_lock at wrapper costs, and per-side sampling/view discrepancy η, the full bit gap is at most 2(ε_swap+ε_LWE+ε_lock+η). Certify its square times 2^128 against each observer's cost, admissible strengths k≤H, and exact implementation of the decision challenge. The wrapper uses a single sample and classical postprocessing; quantum-safe bounds for all switches are separate obligations. Neither registry-valid parameters nor the secret replacement have been proved.

**Serialized cost test.** For t=256, lattice dimension 512 and fixed-width 16-bit residues, the raw (A,Y) header costs H=2,101,248 bits. These are accounting dimensions only. Write z for the padded compiled-program length in bits and concatenate it after the fixed header. For a schedule that reads the entire Enc input, writes its entire framed output in a separate phase, and reads the entire Dec input, the uniform upper allowance for those three phases is 207,643,659 + (2(H+z)+1) + (207,643,913+2(H+z)+1) steps at one cell per step. The last number uses maximal statement length even on false inputs. For both machines with at most four work tapes and 4,096 states, reserve 131,383,296 description bits. The schedule is sufficient if

    4z + E_extra + D_extra ≤ 3,739,891,433.

Extra clocks must cover all field sampling, modular arithmetic, unary parsing and compact statement storage, compilation, memory traversal, rewinds, execution, output termination and any overhead beyond the allotted one-cell steps. Use fixed clocks also on malformed inputs; arbitrary ciphertexts can be truncated at the fixed bound. For exactly those description sizes and serial reservations this is the exact remaining allowance. No compiled machine meeting the reservations is known here. Even with no extra work the schedule allows at most 934,972,858 bits for Z. Ordinary asymptotic lockable-obfuscation efficiency does not certify this bound.

### Reducing the open switch to a 256-bit XOR header

The experiment above separates two roles of LWE: implementing the locked program and hiding the lock in a header whose pad the encryptor itself sampled. The second role has a smaller implementation. Draw independent uniform t-bit K and L. Emit h = K XOR L and Z = O(Q_K,L,β), where Q_K(x,y) returns K XOR y on a satisfying x of the registered statement and 0^t otherwise. Decryption runs Z(x,h). There is no row sampler, residue array or numerical rounding in this variant. On every satisfying input the internal comparison is exact for all coins. Only the compiler's correctness failure remains. The lock is still sampled uniformly, including zero.

For false φ the remaining cryptographic experiment compares (h,Z) to (U,Z), with U an independent uniform t-bit string, including the entire machine framing and compiled bytes in each view. Equivalently, keep the header fixed and replace K inside Q by a fresh independent K'. In the independent-header experiment the uniform lock theorem is applicable, since the auxiliary header, circuit and compiler tape are jointly independent of L. The bit gap is bounded by twice the header-switch advantage plus twice the independent-lock simulation advantage, allowing further exact sampler discrepancies if needed. The desired theorem is a concrete reduction of this one correlated auxiliary string for this particular pair of programs to fixed decision-LWE parameters used by the compiler. The marginals already have the correct law: replacing the joint view with two independently sampled marginals loses exactly the correlation at issue. Given the raw K and the header, L is recovered with t XORs; revealing only j distinct header bits to someone with K leaves exactly t−j bits of conditional min-entropy. This pinpoints the limit of an argument that hands the real plain program to the uniform-lock reduction.

With t=256 and the same phase and description reservations, the sufficient inequality becomes **4z + E_extra + D_extra ≤ 3,748,295,401**. It saves 8,403,968 reserved serialized steps relative to the LWE header. The new circuit has 384 input bits and performs the original NAND evaluation, a 256-bit XOR and output selection. An actual compiled length, tape count, state count, clocks and registry reduction for the header switch remain open. This is the preferred experiment under the 32-bit budget. The bilinear-rank theorem motivates keeping the entire witness inside the program; it supplies no security for its compiled bytes.
