### The operands that require fusion

In Brakerski–Komargodski–Segev, *From Single-Input to Multi-Input Functional Encryption in the Private-Key Setting*, Appendix A.2, specialize the recursive construction to two inputs. Write M_out,M_in for the independent outer and inner masters. A first-slot encryption at i publishes O_i (encodes the freshly generated child master M_i and PRF key K_i under M_out) and A_i (an inner aggregation function key with x_i,M_i,K_i). A second-slot encryption Y_j encodes y_j and its fresh tag t_j under M_in. A function key H_f encodes the constructor with f and its fresh tag z_f under M_out. Dec(H_f,O_i) generates the child key k_fi under M_i, using the tape derived with K_i,z_f. Dec(A_i,Y_j) generates the child ciphertext c_ij under the same M_i using the tape derived with K_i,t_j. The starred/absent alternate fields and branch-zero control are those of the honest algorithms. Dec(k_fi,c_ij) is public code. Its first operand varies with (f,i) and its second with (i,j). Retaining only the currently selected garbled row lowers evaluation workspace but leaves the serialized producer that supplies the other operand. Sending Q-independent output labels without binding them to that operand does not establish equivalent joint views. The fiber theorem tests when one output alone admits a fixed postprocessor; its converse supplies no efficiency bound.

### A restricted fused rank for a public witness table

Use a publicly checkable factorization of the registered verifier
`φ(x,y)=G(L(x),P(x,y))`. Its address map onto a rectangle K×V must cover every issued key/attribute pair, or the encryptor must supply a distinct proof that each extra pair is unauthorized on every false statement. It suffices that L is onto K and every P(x,·) is onto V. In particular, different x can index the same policy key even when their truth tables on the *original* y disagree: a row-dependent public permutation can move the matching column. No right inverse is required by Enc or Dec. Independent surjectivity of the two *marginals* fails: address (x,x) hits only the diagonal of a Boolean square. A residual accepting one off-diagonal cell makes the original relation false but authorizes a published decryption. The Lean coverage equivalence establishes necessity when soundness is required for every residual test; a particular residual may reject a missing cell.

This construction uses the public-key policy-ABE split of Brakerski–Jain–Komargodski–Passelègue–Wichs, *Non-Trivial Witness Encryption and Null-iO from Standard Assumptions*, §3, with the new public address map. The public key classes and attributes are fixed by the statement before setup. One fresh policy-ABE setup issues a policy key for each z∈K; in zero-acceptance notation the key's circuit is f_z(v)=1−G(z,v). Place the class keys in canonical order. Independently sample a secret pad r. The private function-side issuer receives r and β and outputs the single header h=r⊕β. The ciphertext-side issuer receives r and the ABE public key and publishes independently randomized encryptions of r at all canonical attributes v∈V. It never needs β. The issuer generating policy keys needs the ABE trapdoor, public G and the class order. A centralized WE encryptor implements these three roles. Pad r and trapdoor are never released. An evaluator checks the public relation if a total Boolean answer including rejection is wanted, computes (z,v) from the supplied witness, and on acceptance returns h XOR the recovered bit. ABE error for that selected pair is the per-witness correctness error. This exposes no secret interactive row-generation service, no child key and no child ciphertext.

Only one private bit function parameter is issued under this pad. Reusing it in two header bits leaks their XOR even on a false statement. Do not share the setup across separate WE encryptions. Both original witness-coordinate tables in WE list known values in a public order. The restricted primitive allows these public address choices and an honest secret setup shared by the two issuing roles. It gives no function-hiding guarantee for secret residual predicates and no hiding for arbitrary private input tables or varying address patterns in a full BKS LR game. The guards on all non-accepting inputs reproduce the Boolean answer β AND φ, including false outputs. Repeated public evaluation is covered by giving the distinguisher the entire static frame.

### Full joint view and reduction cost

For a fixed false φ, let R=|K| and M=|V|. Every issued f_z is nonzero on every published attribute by joint coverage and verifier equality. For hybrid j choose h uniformly before ABE setup, commit to public v_j in the selective-attribute game before seeing its public key, obtain all R policy keys from the same key oracle, and challenge on one-bit messages h⊕β₀ and h⊕β₁. Generate all preceding ciphertexts using independent coins and h⊕β₁, and all following ciphertexts using independent coins and h⊕β₀ under the actual challenge public key. Order and project the frame exactly as specified, including h and all public circuit/class information. At j=0 and M the **joint** distributions are the two honest transcript laws, since h is uniform independently of the setup and r=h⊕β. Adjacent hybrids are the two possible ABE responses. This argument works for a quantum distinguisher if the underlying selective game is secure against that distinguisher and the classically scheduled wrapper is accounted for. Evaluation on any number of witnesses or on the distinguisher's own quantum computation is postprocessing.

With absolute acceptance-probability gap ε per hop the end-to-end gap is at most Mε. Each single adversary calls the R key queries, one challenge, and M−1 ordinary public encryptions, assembles the whole frame and runs the original adversary once. Include enumeration, oracle simulation/key generation inside the ABE reduction and the cost of handling that frame. The squared-gap registry accounting incurs 2 log₂ M bits before relative reduction cost (see the split-witness note); a proof in the registered machine model and concrete LWE hardness remain open. Setup and full joint false-instance privacy here are those of the new ABE frame. We prove a fresh reduction, not byte equality with the BKS frame.

### A checkable raw NAND family

Configure k,b in advance with k+2b≤128. Let z be the first k raw witness bits, t the next b, and y the final b. A recognizer checks that gates 0 through 4b−1 compute the b masks t_j XOR y_j using the consecutive four-NAND macro d=NAND(t_j,y_j), e=NAND(t_j,d), f=NAND(y_j,d), v_j=NAND(e,f). The suffix must read only the true wire, z, v, and previous suffix gates. At each raw gate replace self/forward reads by true, as in the registered evaluator, before testing wire membership. Relabel the permitted wires and emit the reduced NAND suffix G. Reject this mode on any escape from the permitted wire set; a complete scheme for general φ would need a separate fallback. The address (z,y XOR t) is jointly onto. Gate-by-gate evaluation on the relabeled suffix is identical. A fixed parser can recover G without enumerating truth tables or solving SAT. A flat-array implementation needs O(s) indexed operations after decoding; a tape implementation scanning a table of at most n+s entries per gate takes O(s(n+s)log(n+s)) bit-cell operations for the indexing in addition to reading the unary input, with constant heads and straightforward sequential records. This is an asymptotic implementation sketch.

For k=1,b=3, take G(0,·) to accept {0} and G(1,·) to accept {0,1,2} in the 3-bit cube. The sixteen choices of (z,t) have sixteen different raw rows but use two ABE keys and eight ciphertexts. The two shapes have different cardinalities; a nonzero translation preserves no odd-cardinality subset of this elementary abelian 2-group, so both translation orbits have size eight. Check also a zero residual and the orphan-cell counterexample. A finite enumeration for k=1,b=2 covered all 256 residual truth tables and both β,pad values at every raw witness. An independent raw-NAND implementation compared all 128 witnesses on each of 50 deterministically seeded seven-input circuits (6,400 comparisons), and exercised a 128-input 4,096-gate positive parse, forbidden mask-wire access and forward default. An idealized secret-key sanity check with four independent one-time attribute pads enumerated all 32 equally likely NO frames (h and four masked ciphertext bits) under each β. This last check tests pad bookkeeping only.

Public SAT is an essential comparison. Running through K×V gives a cleartext SAT test after RM residual evaluations, followed by an ordinary one-bit WE output. For one class all rows are reindexed versions of one row; even the public ABE encryptor enumerates M attributes and the direct scan can often win. Both illustrative easy residuals above are directly decidable. Conversely, **any** (k+b)-input NAND list with at most 4096−4b gates can occupy the suffix (with padding preserving its output when possible), and the resulting raw statement is satisfiable iff that arbitrary residual is. This is a preservation construction, not a SAT running-time lower bound. With k=20,b=24 there are 2^44 candidate pairs, 2^20 keys and 2^24 ciphertexts. A solver may still beat enumeration. Nor do additive object counts by themselves establish an advantage over public SAT.

### Physical objects for the BGG+ matrix ABE

Use the public-key matrix construction of Boneh–Gentry–Gorbunov–Halevi–Nikolaenko–Segev–Vaikuntanathan–Vinayagamurthy, *Fully Key-Homomorphic Encryption, Arithmetic Circuit ABE, and Compact Garbled Circuits*, §§2.2, 4.4, Theorem 4.8. Let n,m be the LWE dimension and column width, d=ceil(log₂ q) the fixed residue width, and ℓ the actual number of attribute wires. Include a fixed unit wire when implementing Boolean NAND by 1−ab, so ℓ=b+1 in our ledger. Profiles and framed parameters are fixed or recovered from φ. Section 4.4 publishes A,D,B₁,…,B_ℓ, each n×m, samples a 2m×m low-norm key matrix S_z with (A|B_f)S_z=D, and outputs per attribute (c_in,c₁,…,c_ℓ,c_out), each block of m residues. Its decryption on a zero policy rounds c_out−S_zᵀ(c_in|c_f) coordinatewise.

Only one plaintext bit is used. Set the other m−1 bits to zero. In the issued key keep only the first column of S_z, represented modulo q with fixed d bits per residue. In c_out keep only its first coordinate. Keep every input block needed by Evalct. That selected rounded coordinate is exactly the first output of the full decryptor for the same tapes. Public projection from the original ABE key and message-challenge ciphertext is deterministic, so a single-index reduction can request the original full keys and challenge on (r,0,…,0). The evaluator only uses B₁,…,B_ℓ, the public function, publicly reconstructed attribute and the public gadget. A and D are needed by the original setup and encryptor but are absent from the serialized WE output. All parameters/circuit templates are fixed or publicly reconstructed; fixed-length order supplies class/attribute identifiers. No extra challenge handles are released.

| Retained field | Bits in this fixed encoding |
|---|---:|
| Shared evaluator matrices | ℓ n m d |
| One indexed policy key | 2m d |
| One attribute ciphertext | ((ℓ+1)m+1)d |
| Pad header | 1 |
| Entire frame | 1+ℓnmd+R·2md+M·((ℓ+1)m+1)d |

If the external serialization sends a mode selector, profile, attribute or policy description, add those fields. Sharing public matrices once prevents charging them in each key. Generating the full objects then projecting gives exact honest distributions and a conservative clock: one TrapGen and all setup matrix sampling; R times Evalpk, ExtendRight, and multi-column SampleD; M times original encryption, each with ℓ independent m×m sign matrices, two error vectors, secret s and the matrix-vector arithmetic. Initial projections and frame writing also cost time. Output projection alone saves no sampling time. A direct sampler can generate just one public target column and sample one preimage vector using the common extended basis; Lemma 2.6 admits one target column. Its ideal Gaussian is the column marginal because the fiber constraints and Gaussian weights factor by column. A finite sampler with error δ per key needs joint error accounting (at most the sum of the original and replacement deviations, summed over R keys). It requires no full D or other target coordinates to compute a projected ciphertext. We do not rely on this optimization for an exact finite machine bound.

In a dense implementation, after key projection the one selected Dec computes one Evalct on the public residual, its 2m-term modular dot product and one rounding. The sequential input head may traverse the entire WE frame to select the two records. There are no encrypted child tables, and no cryptographic producer gates or live GC labels at this rank. Honest Enc still reads the original φ, constructs each arithmetic policy, runs all lattice algorithms, writes the table, and pays for randomness. No verified Turing bound follows from the physical-field ledger.

At illustrative n=256,m=4096,d=16 (field geometry only), k=14,b=10 gives R=16384,M=1024, ℓ=11. The evaluator header matrices occupy 184,549,376 bits, one key 131,072 bits, and one ciphertext 786,448 bits. The projected total is **3,137,355,777 bits** including h. Section 4.4's *literal* independent sign draws alone consume **188,978,561,024 random bits** over these 1,024 ciphertexts, beyond 2^32 on a machine reading at most one fair bit per step. The raw residual search uses 16,777,216 candidate pairs. For k=20,b=24 the projected field total is **28,725,429,141,505 bits** and sign draws are 7,036,874,417,766,400. These geometries are not valid security or noise parameter claims. In particular Section 4's setup and error constraints must be checked for the actual depth, and sampling cost and reduction strength matter separately. Neither example certifies the registered 2^100 goal or a strict 2^32 optimized clock.

### Comparison and open interface

PR #140's issuer tree still requires compatible child key and ciphertext capabilities. PRs #142/#143 extract concrete descendants with linked randomness and keep those objects' marginal laws. PR #148 scopes terminal public outputs. This specialization instead exposes a new fixed ABE frame with a dedicated proof and public reindexing, and retains only one decryption coordinate. It neither extracts nor grants a reusable BKS secret row producer. For a general private rank, the missing primitive must form compatible selected output-label material from a hidden policy and a hidden input joint transcript without disclosing counterfactual inputs, under all allowed cross-pair/repeated evaluations. Joint coverage solves only the restricted public policy/address problem. Arbitrary NAND statements, an end-to-end concrete ABE-to-registry reduction, concrete noise and sampler choices, and a certified honest machine clock remain open.
