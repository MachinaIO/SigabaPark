Consider the fixed-template, independently keyed garbling of [PR 144](https://github.com/MachinaIO/SigabaPark/pull/144) and the public active data labels of [PR 145](https://github.com/MachinaIO/SigabaPark/pull/145). Enc knows the override word v in its own data, but does not know the actual private key parameter or the resulting ordinary output y. A control wire has one label for each physical point bit p=0,1. The garbler knows which physical control selects the normal value and which selects the override. For each possible normal semantic bit b define D_p(b) accordingly, so one D is the identity and the other is constant v_i. The evaluation receives one control key and one selected normal-wire label at each coordinate. It may replay that same input, not obtain a second normal or control opening. All helper PRF calls use explicit role, slot, row and coordinate domains. Padding, computation of the ordinary child ciphertext, and the control test still belong to the actual template. [BKS, Appendix A.2, Figure 6](https://eprint.iacr.org/2015/158.pdf)

### What rejection sampling does

For arbitrary one-bit functions H_0,H_1, selecting the first label meeting both output constraints need not have the law of selecting under the active constraint only. With a fixed public active key, an ordinary secret-key PRF assumption does not even promise balance. A family may always return zero for the all-zero key and still differ from a secure family at only one uniformly sampled secret key. For an active target one, there may then be no label at all. In a finite test with two candidate addresses, independent ideal truth tables for the active and hidden keys, targets zero and a uniform random ordering, the real full search succeeds with probability 7/16 versus 3/4 for the one-constraint simulator. Enumeration of the visible active table, selected address and failure symbol gives total variation 5/16; conditional on success on both sides the variation is still 2/21. In particular conditioning on success biases the distribution of the visible key/table. This refutes an exact one-constraint simulator for the raw proposal.

A balanced alternative makes the label (point,R,t), with point distinct from the programmed bit t. Decode t XOR F_p(slot,row,i,point,R). For each trial set t from one of the two target equations and test whether F_0 XOR F_1 equals D_0 XOR D_1. A successful label is correct under *both* real keys, including a publicly known active key. Give each physical output color an independent uniform start S in a cyclic R domain of size N; on its j-th trial use R=S+j modulo N. Use both colors with opposite normal-wire points. If the global cutoff T<=N, all queried addresses are distinct at a fixed color; all other colors, outputs and rows have disjoint domains. The starts and rejected candidates are private. Under an independent random function for the hidden control role, each fresh answer is uniformly random even conditional on the entire active-key function, these starts and previous trials. Hence the success bits are independent fair bits. Conditional on any completed waiting-time vector, the accepted R for each label is a fixed translate of its independent uniform start. The vector of accepted R's is uniform, also conditional on global success. The active t is its prescribed output XOR the true active PRF bit. This justifies simulation of the active labels without assuming balance of a disclosed PRF key. Repeating candidate inputs with replacement would require accounting for repeat answers; independent fair coins per repeat are incorrect.

Process 2L labels with a pooled cap T. The ideal failure probability is exactly 2^(-T) times the sum of binomial(T,j) for 0<=j<2L. The pooled_cutoff node counts these tapes. The exact minimum T for an ideal per-word failure <=2^-128 is 136, 262, 896, 5018 and 18141 respectively for L=1,16,128,1024 and 4096. These figures were checked by integer comparison at T and T-1, updating binomial(T,j+1)=binomial(T,j)(T-j)/(j+1). Set a smaller per-word error when accounting for many words, PRF hops and other correctness failures. A global abort uses a fixed failure symbol and an explicit default return. The maximum sampler cost includes 2T one-bit PRF evaluations, start sampling, counter/address arithmetic and labels, plus the garbling. If runtime is observable, pad the loops; the registered machines always require a worst-case clock. A four-cell fallback would revive that worst-case layout. The observer should not receive rejected trials or openings of both labels. The cutoff for a real hidden key needs a PRF replacement at the full bounded clock and with a valid embedding (below); an ideal tail bound alone is not a correctness theorem for real PRFs. A direct exact encoder avoids this issue completely.

### Two-bit dedicated sink without grinding

At one output i compute P_p=F_{K_p}(slot,row,i,terminal) for the two physical control keys; the address intentionally omits b. For both candidate b form

    A_b = D_0(b) XOR P_0;    B_b = D_1(b) XOR P_1;
    Y_b = (point=A_b XOR B_b, token=A_b).

A receiver holding control point p, its key, and active Y reads

    token XOR (p AND point) XOR P_p.

The identity and opposite-color guarantee are checked by two_bit_decode. Exactly one D_p(b) flips when b flips, so the two points are opposite even if the PRF keys are equal, biased or public. No PRF or random oracle is assumed for correctness. The normal orientation is deliberately programmed; never publish it. Both bits are carried by the normal computation's last garbled row, not in a separate mux table. These tiny terminal labels must never be used as PRF keys. If a normal value has other consumers, retain the original wide wire and use a copy or the existing-label gadget below.

For the active physical side, let a be the permitted bit XOR the known active pad. In the inactive-control random-function hybrid the opposite token is an independent uniform bit even conditioned on that entire active key. Thus the active point is uniform and the companion token equals a XOR (p AND point). This holds jointly for the whole output vector and any fixed test, with arbitrary inactive truths and active values (vector_law). The simulator needs the physical active control point and permitted output, not the semantic branch, normal bit or override. Reusing the two pads across the two possible normal-label values is intentional: only one such label survives the inactive-gate masking argument. An equivalent three-bit version carries an independently oriented point and the two separate masked tokens, and includes that point in the control-pad address. It costs more in a producing gate. Opening both two-bit labels in the same garbling identifies the normal physical branch from which token changes, even if the intended observer was only entitled to a single output. Reusing one mask across different output indices can leak the XOR of two hidden normal bits on the override path. Neither exposure is covered.

For one dedicated binary NAND with no other use, put its two-bit selected Y directly in each of the four garbled rows, masking each cell by two domain-separated two-bit pads of its predecessor keys. With w=129 the previous normal gate plus the four-bit return cost 4w+4=520 bits; the new gate costs eight bits (one packed byte), saving 64 bytes per such output. Enc uses eight two-bit cell-pad evaluations and two one-bit control evaluations; Dec uses two two-bit evaluations and one one-bit evaluation. The three-bit variant uses twelve stored bits. A fused three-input truth table using the two ordinary gate operands and the control also writes eight one-bit rows, with 24 one-bit input pads to build them and three to read a cell in the straightforward separate-domain implementation. These are field/call counts, not equal machine clocks. For a shared wide normal wire, one unary copy into a two-bit sink instead writes two two-bit cells: four additional bits, the same payload as PR 145's separate return. Removing a return table does not remove the producer.

### Three cells for existing unmodified labels

When the ordinary y wire already exists, write u for its physical point and let pi be its hidden semantic orientation. D(p,u) is either u XOR pi or v_i. Mask it with one control-row bit R_p and one normal-column bit S_u derived at disjoint terminal domains under the respective wire keys. The XOR of the four cells D(p,u) XOR R_p XOR S_u is always one, since the normal row has odd parity and the override row has even parity. Publish three of the four one-bit cells. The fourth is determined by parity_three. This uses three extra bits, four one-bit pads at Enc and two at Dec; the existing gate cost remains. The active cell is the output XOR the two known pads. Given it, the two neighboring cells are independent uniform bits after switching the hidden row and column pads. The remaining cell follows from the fixed parity, so any three stored entries have the required joint law. Each hidden pad may mask two cells in this specific gadget; independently randomizing those two cells would invalidate their parity. For a single coordinate with externally fixed labels, universal correctness for both orientations and either override gives eight possible truth matrices. A fixed decoder reading only those labels and a fixed-length terminal header needs at least three bits if it must realize all eight. Programming the source labels or sharing one orientation across a word changes those hypotheses.

### Two cells per coordinate and one bit per word

A common control permits another trade when the label format of each distinct normal carrier can be chosen in advance. For u=0,1 assign an extra column bit g_i(u)=S_i XOR (u AND Gamma), with fresh independent S_i per wire and one fresh uniform Gamma per word. Keep ordinary gate PRF keys independently sampled and separate from g_i. The active g values are jointly uniform independent of Gamma for every fixed active color vector. Let h equal one when physical row zero is the normal row (equivalently h is the physical override row). Then D(p,u)=D(p,0) XOR (u AND (h XOR p)). Publish C=h XOR Gamma once, and two headers per coordinate,

    E[p,i] = D(p,0) XOR F_{K_p}(slot,row,i,word) XOR S_i.

The active result is E[p,i] XOR (u AND (C XOR p)) XOR F_{K_p}(slot,row,i,word) XOR g_i(u). The word_decode theorem verifies this for all underlying bits. For joint simulation choose C uniform, preserve the active g_i values, set each active header from this equation using the permitted output and actual active pad, and choose the other headers independently uniform in the hidden-control random-function game. This preserves the common bit correlation across the word. Never identify Gamma across unrelated words or S_i across wires. A fixed public active message label with no private mask component cannot be reprogrammed by this rule. When an existing wire is needed elsewhere, its outgoing pads must use only its independent key part. If one bit is carved out of a fixed-width suffix the security parameter of that key is reduced by one; retaining its original key width costs a new bit in every producing cell. Independent masked seeds and incoming gates must cover these roles as well. Reusing a single ordinary wire at multiple output positions requires dedicated carriers, or a proof for a different correlated mask scheme.

The header has 2L+1 bits rather than 4L, with 2L control-pad evaluations at Enc and L at Dec. The g_i are genuine label material. At a binary producer the extra carrier bit raises its four cells by four bits unless there was spare space. If a dedicated short producer emits (u,g_i(u)), its cells alone cost 8L bits, in addition to this header. The two-bit dedicated-sink design above is better in this case. For unmodified wide carriers the three-cell layout avoids a new column bit. These choices do not share nonterminal gate keys or presume zero-cost generation.

### From one ideal word to the public transcript

Use the independent-label, known-one-path proof of PRs 144/145. Fix a valid batch pair with its active rows/slots selected. First randomize any unissued input-seed derivations so a target inactive parameter/control key is uniform at its row while all selected seeds, public active data labels (including zero) and shared shapes are retained. In topological order replace the ordinary outgoing gate pads keyed by each inactive wire using a secret-key PRF oracle. An incoming cell that would write the unknown inactive control or normal suffix had an inactive predecessor; its entire ciphertext is already uniform. The fixed active predecessor row never writes that unknown suffix. Thus the reduction can carry the oracle key without knowing its bytes. For the challenged inactive control use the *same* oracle on all its outgoing ordinary domains and its separate terminal addresses, including every rejected trial in the grinding version. When challenging another inactive wire, sample the control keys locally, except for earlier switched roles, whose answers can be simulated by consistent lazy tables. Programmed sink labels are data and have no outgoing key use. The real wire assignment can be sampled before filling any cells. Unknown suffixes are only needed where an already uniform cell hid them. This argument also applies when the normal computation uses the control as an earlier wire, provided no programmed output is a predecessor. A control aliased with a publicly supplied or subsequently opened *inactive* secret is outside the hybrid; use independent roles or supply a fresh-copy argument. Numerical coincidences with independently sampled keys can be charged by a birthday bound including publicly fixed suffixes. The proof does not switch a disclosed key, or appeal to ideal random behavior at the public zero key.

At the end, ordinary inactive gate cells are uniform; the one active cell per gate is reconstructed from the selected labels, using the actual known PRFs. Handle the special terminal cells via their joint kernels above. For the word variant the active extra mask bits and the common C are drawn in the stated order independently of the active PRF-key parts. If both alternatives for one wire were available the transcript argument would fail. Fresh independent slot/row garblings and distinct addresses allow many words, preserving all correlations of a selected seed. A conservative two-world loss sums the per-inactive-key PRF gaps at their actual full clocks, plus any input-seed/ABE comparisons, collisions and finite abort errors; the terminal calls enlarge the same hidden-key query lists rather than requiring one independent assumption per bit. Tests may have quantum auxiliary state under appropriately proved quantum security with classical challenge queries. Adaptive opening to a different input after the same ciphertext, exposing unclamped key material, coherent oracle access to hidden keys, or a dependent target seed that must be written in a clear record, is not justified by this static argument. A static-list scheduling proof or a separately quantified adaptive reduction is still needed for each enclosing FE comparison. The elementary Lean facts certify ideal finite identities, not the full cryptographic reduction. [Bellare, Hoang and Rogaway, *Foundations of Garbled Circuits*](https://doi.org/10.1145/2382196.2382279)

### The strict cost target

When every opaque AGG output costs at least three bits from individually stored cells (including the actual final producer if it is charged there), the folded PR 145 recurrence gives at least 3^(2^(r-1)-1) bits per unit ordinary output at arity r. This follows by composing the factor-three AGG map 2^(r-1)-1 times. With at least 64 bits per prefix-key or slot entry, strict cost below 2^32 forces every table width <=25. The node ternary_floor proves no partition works: at r=5, if terminal width b>=9 the terminal table suffices; otherwise the other five widths total at least 120 and their 64-bit entries already exceed the target. Higher ranks need at least 31 AGG leaves. The four-row two-bit normal producer costs eight bits per output, so melting the old four-cell mux into that isolated producer does not by itself invalidate this lower bound. These claims concern the stipulated bitwise output interface, not all garbling.

Considering *only* the 2z+1 word header and one bit per ordinary base output, the formal scalar composition instead gives (z+1)·2^(2^(r-1)-1)-1. At r=5,z=1 this is 65,535. Five front widths of 23 and a final width of 13 cover 128 bits. The sum of minimal front fields and the terminal header bound is 5·2^23·64 + 2^13·65,535 = 3,221,217,280 bits, below 2^32. This is a surviving necessary ledger, not an upper bound. At the same partition increasing all front fields to 96 bits gives 4,563,394,560 bits before other work. Counting the dedicated output producers can restore the three-bit floor, and the prefix/slot objects also contain their actual ordinary circuitry and key records. No complete parameter choice below 2^32 or the registered 2^100 cap has been verified. A positive construction still needs a source of cheap existing carrier data for the normal word, concrete secure PRFs and any ABE layer from the registry at the composed loss, and complete registered Enc/Dec machine clocks and description lengths.
