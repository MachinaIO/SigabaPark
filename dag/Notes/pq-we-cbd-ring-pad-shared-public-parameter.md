## One expansion

Fix degree N a positive power of two, q=256, rank=m=1, secret=error=CBD(1). Issue one uniformly random public polynomial A with independent eight-bit coefficients per WE ciphertext. A private root has K=4N bits. Per coefficient, read two disjoint bits for s and two for e, taking first minus second in Z/256. This is exactly the registered coefficient law, with masses 1/4,1/2,1/4 at -1,0,1. The coefficient samplers in ModuleLWE.secretLaw and errorLaw are independent products, and the two samplers are independent. Evaluate b=As+e in the negacyclic ring and serialize canonical coefficients little-endian in eight bits each. The output has 8N=2K bits. Given uniform independent A and an independent uniform root, the joint real sample is the compact registered pair; ideal b gives an independent uniform 2K-bit string by the byte bijection. The claim averages over uniform public A. No claim is made for each fixed adversarial A (at A=0 the output is visibly sparse).

The pinned core's rank-one decision problem uses ModuleLWE.encodeSample on both sides. It encodes the first member of the pair by expanding multiplication by A into an N-by-N negacyclic matrix M, then applying SIS.encodeMatrix to M. The outer pair frames only its matrix member. Each row and each natural-number coefficient are separately framed by encList, using the minimal Nat.bits representation (zero has empty digits). The unframed response suffix is an encList of b coefficients. The executable converter in WE_CBDWirePad peels the outer frame, extracts the first encoded coefficient of each decoded row, separately decodes the response, pads each word with high zeros and emits two packed strings. Column zero of the multiplication matrix is A, since multiplying by the constant monomial leaves A unchanged. Flattening the one response polynomial preserves coefficient order. The transport solution proves the bounded converter pushforward statement for *any* law on typed pairs, including the registered real and ideal laws, without assuming that the challenge already contains packed coefficients.

If L denotes the sum of minimal coefficient bitlengths over M, the b suffix starts at 8L+4N²+2N+1. Its own length is at most 17N; the full input fits 68N²+19N+1 bits. For malformed words the bounded variant truncates input at that bound and each output at 8N; the companion Lean proof shows that neither input nor output clipping changes a valid pair. A streaming converter can peel the marker/value streams in three finite-state layers, emit only each row's first coefficient, pad to eight bits, and scan onward to b. Bounded scanning, writing the two outputs, local simulation, and description lengths belong to the *reduction* clock. No formal coefficient on this multitape cost is claimed. At N=512 the deterministic maximum start position is 17,826,817, attained by all A coefficients equal to 128. The uniform mean is 15,737,857 since each signed matrix coefficient is marginally uniform and its expected minimal length is 1793/256. The honest public header remains 4,096 bits.

## Shared A, hidden roots and trie addresses

Assign distinct physical input-port, gate-cell, row and role addresses to *intervals of leaves* in a predetermined binary tree per wire key. Expand a seed with G_A, split into two K-bit child seeds, and use only disjoint terminal slices as masks. A fixed finite use list can simply concatenate an agreed collection of terminal leaves and take disjoint slices. Neither release an internal seed and then count its descendants as fresh random pads, nor reuse a pad at two addresses. Repeated queries to a single address return the same slice. An input gate consuming the same wire twice has distinct port roles. A one-use, short output word may use one direct G_A evaluation without a long address path. Public addresses here select paths; they are not extra input bits to the ring challenge. All garblings must use the same declared layout independently of hidden challenge seeds.

Take a fixed evaluation path with known active roots and an externally indexed collection of hidden roots. The conditional hidden-wire PRF argument needs the incoming root independently uniform *and unobservable*: upstream inactive records that would disclose it must already be masked by separate uniform pads, or the input transfer distribution must permit removing the unused alternative. Erase the unused root in that representation. For the deterministic fixed trie, replace expansions in parent-before-child order. At the target the root was sampled uniformly or is one half of a predecessor's independently sampled 2K-bit ideal output. Insert the challenger's packed b as its two children, and use the challenger's public A as the common system A everywhere. The target seed bits themselves are unavailable in the embedding. Independently sample its sibling seed if its parent was idealized, and simulate every other root and unaltered descendant by real multiplication with this same A; earlier replaced parents receive fresh uniform two-child words. This gives the neighboring joint games. Fresh independent public A per hop of the proof is permitted because each separate reduction samples one transcript; resampling A *within* a transcript would change the experiment. Mark equal addresses as one trie node. Active message-side zero labels and deliberately exposed keys are evaluated with the real generator on that same A, preserving what anybody can recompute. Never replace their outgoing pads. A root passed as data or routed later to the adversary needs a different argument.

For W eligible distinct node expansions let C_j include the full clock plus description length of the j-th one-challenge tester. The signed probability gaps telescope; each absolute gap is at most sqrt(C_j/2^H) under the registry's decision HardAt convention. If C_j ≤ rho*C for the attacker's cost C, their total is at most W sqrt(rho*C/2^H), giving W² rho loss in normalized squared gap before other hybrids. Count the actual union of queried prefixes, not merely the number of terminal wires. In the fixed occurrence-indexed hybrid one need not condition on distinct random roots: unaltered computations on coincident sampled seeds already agree under real G_A, and idealized occurrences are defined by their indices. If a surrounding proof instead excludes accidental equality among U independent ideal K-bit seeds or Q independent guesses, an additional union bound U(U-1)/2^(K+1)+UQ/2^K applies under those independence conditions. Repeated authorized handles must be consistent. This does not justify selective revelation of an earlier hidden root after seeing the transcript, coherent challenge queries, or adaptive circuits that alias their private seed material.

Independent evaluation of the pinned RingLWE.H yielded (N,H)=(256,87),(512,166),(1024,332),(2048,676) at q=256,m=1. At N=512,m=1 and q=2^k for k=9,10,11,12 it gave 148,136,127,118. With N=256, (m,k)=(4,5),(2,6),(2,7) gave 118,105,96. These are outputs of the registered classical estimator, not proofs of quantum hardness. At N=512, W²rho must fit 2^38 for a 128-bit normalized implication if all other losses vanish; W≤2^19 only at rho=1. A post-quantum interpretation requires a matching concrete assumption against quantum distinguishers receiving classical samples and a valid quantum lifting of the whole reduction.

## Physical example and cost window

For one ordinary two-input NAND returning a normal carrier usable downstream in the zero-header selector, give each physical ordinary label an independent K-bit outbound key, point bit u, and programmed terminal bit g. Four issuer cells cost 4(K+2) payload bits. Each of four physical input roots supplies two disjoint pads of length K+2. Expand once to L and R, expand R to two children, then slice the three terminal leaves L,R0,R1. The incoming root and R are never returned as pads. This uses eight ring products on issue and four to reconstruct both active parents' streams on evaluation. The two physical control keys supply one selector bit each by one dedicated expansion per key, with one expansion on evaluation. Thus 10+5 ring products implement this isolated example, plus writing 8N public A bits and the four cells, six possible input/control root keys over the two alternatives and two output roots to sample, three selected input/control labels to deliver, output-root generation, and the real arithmetic, pad XOR, GGM wiring and selector bit work. At N=512 the four cells alone are 8,200 bits; the two input openings and control opening with one point bit each cost 6,147 bits when physically delivered. Output and input keys are charged at their actual component boundary, not double counted when an existing producer already provides one. This is a shared-A registered primitive inside a gate layout, not a full WE encryption.

For a four-row, G-gate ordinary circuit with I primary inputs, suppose each of its four cell payloads is masked independently at both ports with at least K bits, and the only source consists of disjoint terminal leaves in the above trie. Let R≤2(I+G) be the number of available independent physical wire roots, excluding separately supplied secret entropy. Expanding one leaf replaces K available bits with 2K, a net gain of K. After T expansions at most (R+T)K bits are available. Hence 8GK≤(R+T)K implies T≥6G-2I (as a natural inequality, 6G≤T+2I). This counts issuer products only. With I=128,G=4096, T≥24,320 even before extra point bits or selector operations. A fixed double loop visiting all N² coefficient pairs per product consequently exceeds 2^32 visits at N=512. For the fixed-pass signed-window method with width w, 3^(w-1) full table vectors, and a full separate accumulator scan for each of ceil(512/w) windows, the ledger 4096[3^(w-1)+24320 ceil(512/w)] is at least 4,923,756,544 for every positive integer w. Equality is attained at w=11. This excludes that issuer implementation at the exploratory strict cap by itself when writes and updates are separate serial passes. It neither excludes the registered 2^100 cap nor different circuits, correlated row masks, table reuse across separate implementations, or compressed/overlapped arithmetic.

A direct alternative uses integer convolution. Put e.g. n=512, u=s+1 coefficientwise, digit radix B=2^18. Coefficients of ordinary A*u are nonnegative and at most 510n=261120<B. Pack A and u as base-B integers and multiply once, extracting all ordinary convolution digits without carry between coefficients. Subtract the coefficient at j+n from the coefficient at j to reduce modulo X^n+1. Subtract the precomputed A times the all-ones polynomial (its j-th negacyclic coefficient is twice the inclusive prefix sum of A minus the total), add e, then reduce modulo 256. The integer operands have at most 9216 bits. This circumvents the count of a fixed N² coefficient-pair loop and the full-window dictionary assumption; its actual multiplication, multi-tape movements, and integration clock still need to be bounded. The integer route matched direct negacyclic convolution on 6,674 cases (all ternary secrets at degrees 1, 2, 4 and 8 for one sampled public polynomial per degree, and ten samples each at degrees 32 and 512). The 9,192 direct/window comparison cases were also rerun. These tests address only the ring arithmetic. No end-to-end WE implementation, concrete composed hardness margin, or canonical upper clock has been certified.
