Fix a public full-row-rank binary matrix H of size k by n depending only on the security/size class. The search challenger samples uniform s and independent Bernoulli(p) noise e and gives A=H^T s+e. It accepts the planted s, checked using its coins. Quantum hardness of this fixed-code search game would be a falsifiable assumption, distinct from standard random-matrix LPN. No target y is in the game. Encrypt one bit as (A,s.y+mu). For any witness Hx=y of weight <=w, the parity decoder has bias at least (1-2p)^w for 0<=p<1/2. Fresh repetitions give polynomial size and honest times if this bias is inverse polynomial. Both hardness at the selected noise and an encoding of general NP into targets of a fixed code remain to be established.

**A sufficient NO-side condition.** For a target y suppose a publicly computable random index i gives a coordinate permutation Pi_i and invertible binary M_i with H Pi_i=M_i H. The family need only be available to the reduction, with polynomial advice if security is stated nonuniformly. Define r_i=M_i y. Suppose one can oracle-list-decode s from predictions of r_i.s with inverse-polynomial signed correlation on uniform indices, in time and list size polynomial in the size and inverse correlation (take both signs if needed). This suffices for message hiding on that target. The indices need not cover a dense fraction of all k-bit directions.

Indeed use any one-sample message distinguisher on the permuted header Pi_i^T A. The transformed secret is M_i^T s, and the noise still has the native law for each fixed i. For example, given a uniform bit c, run the test on (Pi_i^T A,c); output c if it accepts, and 1-c otherwise. Its signed correlation with s.r_i equals the difference of the acceptance probabilities for messages zero and one, averaged over original coins. For a gap gamma>0 at least a gamma/2 fraction of planted samples have conditional correlation >=gamma/2, by boundedness. Fix such a sample; the reduction supplies independent fresh runs of the test to the local list decoder on this same header. Choose a uniformly random list element, giving inverse-polynomial planted-secret recovery. This applies to quantum tests run on classical inputs with freshly preparable computation. A T-sample distinguisher for repeated encryption incurs a T-hybrid loss, since all other samples with specified messages can be generated directly. This reduction uses the supplied permutations; assuming point prediction hard for each NO target would evade the fixed-game requirement.

**A sparse family of directions that suffices for the decoding step.** Identify secrets with coefficients of a degree-<d polynomial P over F=GF(2^m), so k=dm. Suppose for each uniform a,b in F with b nonzero the available action maps y to the binary functional Tr(b P(a)) (interpreted in dual coordinates). This has at most |F|² directions in a binary ambient space of size |F|^d. The following decoding argument does not require enumerating F when m grows. Assign the known correct zero bit on b=0; this preserves positive correlation. If the prediction has overall correlation alpha, at least alpha/2 of the a's have conditional correlation >=alpha/2. At each sampled a, binary [Goldreich-Levin list decoding](https://www.wisdom.weizmann.ac.il/~oded/X/gl.pdf) on b returns a list of size O(1/alpha²) containing P(a) at such good points with probability at least 3/4. Convert trace-dual bits to field elements. Use independently sampled distinct a's and fresh decoder coins. With high constant probability the true polynomial hits at least alpha N/8 lists among N samples (hypergeometric concentration followed by independent trials).

For clarity, choose N a sufficiently large constant times d/alpha^4, with |F|>=N and d>=2. Find a nonzero bivariate polynomial Q(X,Y) of weighted degree <alpha N/8, weights (1,d-1), vanishing at all sampled list pairs. The number of monomials is Omega((alpha N)^2/d), exceeding O(N/alpha²) constraints by the choice of constant. On the preceding hit event Q(X,P(X)) has more roots than its degree, so Y-P(X) divides Q. Extract the linear-in-Y factors of this form by randomized finite-field polynomial factorization, with verification, and return their candidates. All computation is polynomial in m,d,1/alpha (using an explicit irreducible field modulus). An exponentially large field allows any inverse-polynomial alpha asymptotically. This demonstrates a specific sufficient geometry for the reduction; it does not provide H or its required coordinate permutations.

**A structural test on candidate fixed codes.** Every available M_i must permute the multiset of H's columns, including multiplicities. Conversely this condition suffices to build Pi_i by matching equal columns. Thus an explicit proposed family of syndrome actions can be tested at the column level. In particular, a group acting on syndrome space cannot be realized by a spanning H of polynomial length if all nonzero column orbits under that group are superpolynomial: every used orbit must occur in full. For the most direct field construction, requiring every scalar multiplication by b in F* on F^d as a syndrome action forces the orbit of every nonzero column to have |F|-1 elements. This rules out that implementation with exponential |F|. Having r_i equal the desired functional only constrains M_i on y; it does not force the whole scalar action. The outstanding design problem is a short invariant column set and enough list-decodable directions on NO targets, compatible with short witnesses on YES targets and hard fixed-code search. If a YES target with a known short witness also had the stated decoding family, its parity decoder would itself contradict search hardness at inverse-polynomial correctness bias.

**Gap necessary before searching for an orbit.** In this Bernoulli-noise construction any representation Hx=y, including an overweight one, predicts the pad with bias rho^|x|, rho=1-2p. Under nonuniform security an adversary on a specified NO sequence can hardwire one such representation per length. Thus if rho^w >= lambda^(-C) for correctness and 1<=w, a NO representation of weight <=D w for constant D gives bias >=lambda^(-CD), excluding security. In fact, whenever some attainable syndrome has minimum weight >w, there is an attainable syndrome of minimum weight exactly w+1: walk from zero along the columns of a representation for the distant syndrome; the minimum weight changes by at most one per step. Therefore the unrestricted threshold language on *all* syndromes of such a fixed H cannot use this Bernoulli construction with polynomially amplified worst-boundary correctness and nonuniform WE security. This includes the repetition scheme: one challenge component already suffices to distinguish. A general NP compiler would have to map NO statements into a promise region avoiding all near-boundary syndromes, with minimum distance growing beyond every constant multiple of the YES threshold under the stated bias condition, or change the encryption/decoding law. Such a gap is only necessary; it does not by itself give list-decodable actions or hiding.
