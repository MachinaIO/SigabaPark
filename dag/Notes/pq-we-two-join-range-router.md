## The two-join interface

There are opaque source objects A_i, J_j, C_k for 1≤i,j,k≤N. The A and C roles are positive and the J role is negative. A statically specified collection of sources is opened by giving its actual secret strings. Both joins have public rows, and a public checker verifies a proposed label for each addressed source, router, intermediate and terminal vertex. A common first-join label K_j represents “J_j is open and some open A_i has i≠j.” The terminal T is derivable if some such K_j and some open C_k have k≠j. In particular i=k is allowed. The input objects are uniformly random independently generated labels until their authorized opening. A public wrapper consists of the typed vertex identifier and its checker string. Upstream code can use the same label as its outgoing plaintext in a protected issuance row. The experiment charges the public wrappers; it does not give all their hidden openings.

These are actual bit strings consumed by the second gate. The evaluator never supplies a support list, a numerical moment or a separate proof that it computed a comparison. It can mix every available string, propose arbitrary openings, evaluate the public expansion coherently and inspect the entire classical challenge. The security claim below is relative to the closure of the union of the opened sources. When a true context needs the original i after the second gate, replace K_j by individually checked K_ij for i≠j. Issue each K_ij from A_i,J_j, and the terminal from K_ij and either side of the range of C excluding j. This exact-pair version takes O(N²) rows. The O(N) version forgets i because every allowed future test in this experiment only compares k to j.

## Exact symmetric update

A row has one destination vertex v and one or two parent vertices p. All keys are independent uniform κ-bit strings, one per vertex. There is one fresh pad purpose for every parent incidence of every row, including repeated placements of the same child key. Given the key for p, its deterministic expansion provides its pad for that incidence. Store one κ-bit body, the XOR of the actual destination key and all incidence pads of that row. Knowing its parents reconstructs the actual next key. Multiple ways of obtaining one child reconstruct the same key. OR is implemented by several one-parent rows sharing a destination. AND is one two-parent row.

Construct strict prefix and suffix OR keys for A: L_j for j=2,…,N is reachable from A_(j−1), and for j>2 also from L_(j−1). R_j for j=1,…,N−1 is reachable from A_(j+1), and when j<N−1 also from R_(j+1). All A range rows use 4N−6 bodies. Each K_j receives at most two rows, from J_j with L_j or R_j for the existing sides. Repeat the range construction on C. The terminal has rows from K_j with respective C range keys. Induction up and down the scans gives the claimed strict ranges. The theorem `two_join_closure` identifies the two semantic joins with exactly the compatible triples. The implementation need not scan through unopened branches at decryption; the public graph fixes every address and an honest compatible triple has an explicit route. Both scans can alternatively be balanced using a rerooted binary range tree and a different ledger.

At fixed p, order its outgoing incidence purposes by public row order; append a checker-seed purpose, and for T alone also a message-pad purpose. Every vertex has at least two purposes for N≥2. Expand its root down a fixed binary tree with one leaf per purpose, splitting a list in half recursively with the first block on the left. A single length-doubling generator call supplies the two child strings. For checker seed u publish the full 2κ-bit G_A(u). A proposed vertex string is tested by redoing its tree and checker expansion and comparing with the public string. Publish β XOR one fixed bit of the terminal pad. This second expansion for the checker is essential for the simple statistical image bound. Every checker and the message body feature in the game.

## Fixed falsifiable assumption and finite honest randomness

One possible generator uses just ordinary decision LWE. Independently for this public packet sample A uniformly in (Z/2^16)^(4096×1024) and publish it. A κ=32768-bit vertex/tree seed supplies 1024 uniform 16-bit secret coordinates s and four independent bits per error coordinate. Set e_i to the first two bits' sum minus the last two bits' sum (CBD(2)). Form b=A s+e mod 2^16. Its 4096 little-endian words are exactly 65536 bits. Their concatenation supplies G_A(seed), split into halves. Thus a real single fixed challenge is (A,b) with a fresh uniform seed, and the alternative is (A,U) with U independently uniform in that full body space. No challenge parameter or sampler depends on any gate, tag, opening list or statement. The same matrix is used with fresh independent seeds and can be freshly chosen by encryption itself. All samples are finite fair-bit samplers.

The core LWE parameters support uniform secret, m=4096, n=1024, q=65536 and error `.cbd 2`. Transposition or re-encoding between the core matrix convention and the row-vector serialization is public and must be charged in a compiled reduction. We do not claim any numerical advantage bound or estimator certification for those exact parameters, or a quantum security theorem about LWE. The conditional reduction holds against a quantum observer with a classical challenge whenever the stated fixed LWE pair is quantum-indistinguishable. More generally the identical packet proof applies to any concrete fixed public-parameter doubling PRG with that quantum property.

## One-challenge full-view reduction

Fix the opened source set before issuance, or publicly generate it independently of all secrets. Its monotone graph closure is efficiently computable, without any cryptographic secret. Call vertices in the closure live. Never switch a live key or expose a dead root. In topological order over dead vertices, replace their root expansion trees by random strings, switching internal evaluations parent-before-child. Also switch the final checker expansion on the independent dead checker leaf. Each individual switch uses a single copy of exactly the fixed decision sample above. The reduction knows the shared A and evaluates all ordinary expansions of known seeds with that A. Other already-switched calls simply receive independent uniform pairs. At an internal tree challenge its incoming seed was supplied by a previously idealized parent and is neither printed nor needed again. The current leaf indices and all outgoing uses of the LWE challenge's two halves are known even though the source secret and error coins of that sample are unknown.

At a dead vertex root, every incoming row contains at least one dead parent, already switched by topological order. That parent supplied an independent pad specific to this row; it also supplied a distinct leaf for its own public checker. Integrate out one such pad per row. All those incoming bodies are then independently uniform conditional on the child's actual root, on the other parent pads, and on all remaining data before their evaluation, even when the same child occurs in many rows. The complete-frame translation in `hidden_incidence_frame` gives the bijection. The simulator can consequently generate these rows without knowing the challenge root. Rows into live vertices from a dead alternative are also well-defined: the reduction knows the live destination and uses the challenge output for any unswitched incidence from the present vertex. Distinct incident leaves, including those on two sides of the same OR, are never reused. Live sources are opened by printing their actual keys, and source wrappers and all intermediate checkers are generated in their corresponding hybrids. This reasoning uses no secret key from the LWE input. It continues to hold for public functions of the complete packet, including all candidate-checking queries; there is no ideal evaluation oracle.

In the final ideal experiment every dead check string is independent uniform over 2κ bits conditional on A. A fixed addressed verifier, run on all 2^κ candidate keys, has an image of cardinality at most 2^κ independent of that ideal string. Thus the probability that *any* candidate passes any one of D_dead dead-vertex testers is at most D_dead/2^κ even allowing unbounded search in the ideal game. The finite counting step is `public_check_image`. In the real experiment the same publicly checkable success has probability at most this plus H_dead·ε, where H_dead counts switched expansions and ε bounds the relevant one-challenge distinguishing advantage at the simulator's cost. For bit-message indistinguishability when T is dead, the ideal pad bit is uniform independently of all public rows, openings and tags. The real difference between the two bit-conditioned views is at most 2H_dead·ε by two hybrid paths. Equivalently one can sample β and analyze success over half via a single path. Without a time-uniform bound for ε, sum the actual hybrid advantages. Every individual hybrid reduction receives one sample; there is no joint challenge of H_dead unknown secrets. A uniformly random hop can also telescope signed advantages, with finite hop sampling or averaging dealt with explicitly in the clock.

If the whole opened union admits a compatible triple, the key is intentionally derivable. E.g. separately open (A₁,J₁,C₂) and (A₂,J₂,C₂) in two intended contexts. Both individual triples conflict, while pooling gives (A₂,J₁,C₂), a legal derivation. Isolation by independent keys and packets per context addresses a fixed list of contexts at proportional cost. Showing that all witness evaluations of an arbitrary false circuit cannot pool into an authorized closure remains necessary for WE.

## Relation to moments and to the actual switched source

For two positives and one negative in a field of odd characteristic above N, r=i+k−j and d=i²+k²−j² obey r²−d=2(i−j)(k−j). The formal factorization detects the two conflicts including when i=k. For example (+3,−2,+4) and (+1,−1,+5) have r=5 but d=21 and 25. At the degree M in the product of source polynomials with signed exponents i and M−j and positive unit coefficients, the coefficient is exactly the size of the positive/negative overlap for sets. The formal `overlap_coefficient` sums the actual matching pairs. With multiplicities it counts the product of multiplicities at each tag. Reduce in a characteristic exceeding the possible count if zero must test emptiness.

For h positive tags a and m negative tags b the common-root test also has a signed-moment expression. Swap polarities when needed so h≥m. For nonempty lists write P(t)=prod(1−a_i t)/prod(1−b_j t)=sum c_l t^l. Logarithmic differentiation gives l c_l=sum_{k=1}^l (sum b_j^k−sum a_i^k)c_{l−k}. Use characteristic greater than h+m, c_0=1, and indices up through h+m−1. The determinant with entries c_(h+i−j) for 0≤i,j<m equals prod_{i,j}(b_j−a_i). For distinct nonzero b, the coefficient at each used index comes only from the simple fractions, because the polynomial part has degree h−m. Their residues are b_j^(m−1−h) prod_i(b_j−a_i)/prod_(k≠j)(b_j−b_k). Factoring the coefficient matrix with ascending and descending Vandermonde matrices cancels the residue denominators and powers of b exactly. This rational-variable identity specializes as a polynomial identity to repeated or zero tags. Empty sides use product one. This is an algebraic check, not a separate mechanism for issuing authenticated labels. Our router computes its two-join authorization content by opaque-key transitions, with no evaluator-chosen field claims.

The [native switching bank](https://github.com/MachinaIO/SigabaPark/pull/168) gives public source bodies c_i=m_i−τ^i at unit slope. If an opened native positive tag of degree one reveals m_1, then τ=m_1−c_1 and all other native monomial labels become publicly computable from their wrappers, exactly, before consulting the LWE bank. The theorem `opened_native_source` checks the recovery identity for every degree. For N≥2 a source-opening game giving just A₁ and withholding all J,C has empty authorized closure. If the missing router keys are publicly derivable from the corresponding native m labels (including encrypting independent router keys under pads publicly computable from those m values), the receiver obtains every key and can open the message with probability one. Independent simulator-generated native side data does not create a cryptographic connection. The present positive result gives a new native key type for the two joins; it does not prove that the old switched product token can deliver these new labels without extra opens. In particular an adaptive, correlated upstream leak about a dead key is outside the reduction.

## Concrete accounting

For N≥2 there are 3N source keys, 4N−4 range keys, N intermediate keys and one terminal: V=8N−3. The two sets of scans take 8N−12 unary rows, and the two joins take 4N−4 binary rows, in total E=12N−16. They contain P=16N−20 parent incidences. A nonterminal with d outgoing incidences uses d internal expansions to produce d pads plus one checker seed, and one additional checker expansion. The terminal uses one split and one checker expansion. Across all vertices this gives H=P+V+1 calls. All source and gate checkers are included. In this fixed order the logical packet contains the A matrix, E·κ row bits, 2V·κ checker bits, and one message bit; source secrets are external opening objects with κ bits per authorized source. This total excludes any upstream wrapper that must deliver those secret strings, external packet framing, and finite machine descriptions. Honest key generation additionally samples Vκ fresh fair bits besides the public A.

Direct generation exceeds 2^32 modular products already at N=128, even though this packet's published fields remain below 2^32 bits at N=4224. Proof simulation also charges generation of all known-key material and public output, matrix re-encoding, and the adversary's clock. No finite-tape or registered-strength bound follows from the field ledger. The companion replay implements both wrapped joins and every public tester using a smaller CBD-LWE stretch for functionality only. Checking all 64, 512 and 4096 source-set triples for N=2,3,4 produced 15, 298 and 3247 reachable terminals, respectively, all equal to the explicit compatibility predicate. None of the tiny instances is a claimed security parameter.
