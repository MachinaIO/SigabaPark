A public list of four-by-four residue matrices fixes the emitter's finite control. Each field element is represented by nine output bits, least significant bit first. Unused projected rows can be padded by zeros. The input consists of one message bit and 713 symbols per lane: one splitting coin, four blocks of 160 fresh bits and 72 dummy symbols for output. The last splitting coin is ignored. Each earlier splitting coin provides the next share and updates the remaining parity. The final lane emits the remaining share. For each matrix row the machine emits the linear field value followed by the squared shifted field value. It uses no work tapes. public_run proves equality of its entire output to this specified concatenation for every assignment of the input bits, using the same public opcode list for all assignments.

At 4096 gates and 129 lanes per gate, the machine reads 376737793 input symbols, with a clock of 753475589. Its state count is 39444179406312849456. Its charged transition table takes 16566555350651396771520 bits, for a total registered Machine cost of 16566555350652150247109, below 2⁷⁴. The theorem covers this static emitter at fixed matrices. Generating the fair operand tape, parsing the original circuit, deriving its matrices, addressing the decryption rows and the two registered tuple wrappers still require separate implementations and charges. Hard-wiring different matrices for different statements cannot supply a single all-circuit encryption algorithm.

The residue_counts theorem proves the exact preimage count at each residue of the 160-bit sample space. The zero residue has one extra preimage. The complete fixed-packet coupling loss and the non-singleton line distance fit below the requested 128-bit threshold by line_budget. In the separate line module, inverse_header and nonzero_chart exhibit the reversible change of coordinates on the entire nonzero-slope packet. zero_chart and zeroChange give the product residual and an invertible seed parametrization on the zero-slope packet. difference_count and square_overlap count differences of two squares and the exact histogram overlap under a nonzero translation over every odd finite field. The final stratified total-variation formula is derived in the preceding note.
