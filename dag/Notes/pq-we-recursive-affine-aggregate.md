### Which ciphertext is being produced?

In Brakerski–Komargodski–Segev Appendix A.2, Figure 5 produces a **child function key** and Figure 6 produces a **tuple of child ciphertexts** under the same starred master. The full rank-t first-slot ciphertext itself contains an outer unary ciphertext O and an inner aggregation key A. At rank two, the normal Figure 6 result is the native unary encryption of (x₁,x₂). It is not the affine Figure 5 packet from PR #153. The affine packet occurs in the first component O′ of the *first-slot rank-two child ciphertext* when Figure 6 is called at rank three. The rest of that returned pair includes the inner native unary AGG key A′. The returned ciphertext for the third input is a separate native unary Enc under the same inner child master as A′. Dropping A′ or the third-input ciphertext changes the private interface. [BKS Appendix A.2, Figures 5–6](https://eprint.iacr.org/2015/158.pdf) · [PR #153](https://github.com/MachinaIO/SigabaPark/pull/153)

For an outer AGG key at row i, x₁⁰,x₁¹, selection bit a, target tag s, starred child master and outer PRF key K are key-side. Each input encoder holds its own two candidate payloads, randomness tag τ_j, override tag s_j and override word v_j. If all override tags match s, Figure 6 returns the entire override tuple. Otherwise it selects all x_j^a and uses tapes PRF(K,τ_j). Equality of several message tags is local to a *grouped* message party, not automatically to the individual Enc_j parties. A private equality target has an identity communication matrix on unrestricted distinct equal-length tags: fix other tags appropriately (or restrict them to a common column-side value). A table indexed by a public ordinal is a different variant; collision conditioning and exposed K-containing components cannot be discarded without a joint proof.

Write π_0,π_1,π_{2,k},r_{k,0},r_{k,1},r_{k,2},s_k for the ordinary affine child master fields at its configured slot and row. In each returned bit position k, the four transmitted bits of O′ are
```
D_l = A_l + r_l  (l=0,1,2)
E   = c + π_0 A_0 + π_1 A_1 + π_{2,k} A_2
        + (π_0 r_0 + π_1 r_1 + π_{2,k} r_2 + s_k).
```
The parenthesized value is owner-local for a fixed public row ordinal. The relative owner of A,c is decisive. The honest O′ plaintext is (new grandchild master, new PRF key,0); it does not yet contain the selected (x₁,x₂). Those are used by A′. For the concrete selected-seed grandchild KG of #153, let b⁰_k,b¹_k be the two freshly generated suffix bits at position k. On an ordinary suffix position c=b⁰_k, A₀=b⁰_k+b¹_k, A₁=A₂=0. At the output point position c is the fresh grandchild orientation o and the slopes are (1,0,0). If the inner record selects its second payload branch exchange the first two slopes. In a genuine inner dummy master encoding the intercept and the first two slopes vanish and A₂=1. These are fixed-shape alternatives of the Figure 5 affine interface. An enclosing Figure 6 bypass instead returns the full supplied v_j bytes, with no obligation for those bytes to form a fresh honest affine ciphertext.

Grandchild Setup consumes part of PRF(K,τ₂) in the original Figure 6. Its b and o fields therefore need not belong wholly to either side. In particular the ordinary point baseline is o(K,τ₂) plus a pure starred-master offset; the point-coordinate Lean lemma checks that literal identity. There is no x₁ or x₂ in that one output field. Choosing a fixed public message ordinal makes the indexed r,s offset independent of the private randomness tag, but does not make the tag public.

For a pseudorandom finite-tape generator whose uniform tape supplies an unbiased orientation, exact small-width separated features for this *specific intermediate field* face a quantitative obstruction. Fix an ordinary, nonoverride row ordinal. Take t independent keys and t+1 fixed, distinct randomness tags, queried at that same logical ordinal in **counterfactual evaluations of its function**. Difference the first column into each other column. This cancels any row-specific additive offset. An exact width ≤t−1 representation of the point bit on the entire private input domain forces the t×t difference matrix to be singular. For independent random-function rows the orientation bits at distinct tags are independent fair bits, and differencing a common first bit leaves t independent fair bits per row. The nonsingularity probability is ∏_{j=1}^t(1−2^(−j))>1/4. A hybrid over the t keys would give a single-key PRF gap >1/(4t), using t+1 ordinary queries to its challenger and local simulation of the other rows. Include generation and rank-testing time. If only an average per-cell approximation of error ε is known, charge at most t(t+1)ε before the key hybrid. This is a test of the unrestricted truth table of the literal program. It neither grants multiple queries at one ordinal in the static FE game nor prohibits a new WE implementation having the same final functionality. If an implementation expands a short seed instead of sampling a genuine setup tape, the balanced-marginal assumption for ideal tapes or the extra expansion reduction must be checked.

In the independently preallocated, public-ordinal tape variant, the owner can instead generate all O′ fields locally for a scheduled suffix row. For A′, the native KG returns one selected seed plus color per secret parameter bit. A selected word has form W⁰+(W¹+W⁰)b. If b=x₂^a, it is W⁰+((1+a)ΔW)x₂⁰+(aΔW)x₂¹: both products forming the coefficient words belong to the owner. Parameters drawn solely from the fresh local tape or from x₁ are local. The native *unabsorbed* garbler's third-slot ciphertext contains gate rows fixed by the template, master and tape, plus active data labels each affine in one selected input bit. This accounting does not apply unchanged to an optimized garbler that folds the private input into different table contents. For a grouped suffix message and a public target ordinal, a message-local override e can multiply each message feature by 1+e and contribute e·v_j as an intercept. A cross-slot AND of tag tests in the original Figure 6 is still a joint private operation. [Fixed-table variant](https://github.com/MachinaIO/SigabaPark/pull/142) · [Native format](https://github.com/MachinaIO/SigabaPark/pull/144)

A useful batch identity for a genuinely separated word is Y_o=c_o(m)+∑_l θ_{o,l} b_l(m). The same message feature b_l may occur in many outputs. Per key slot sample independent masks π_{o,l}. Per slot/row sample one shared vector r_l and independent s_o. Issue α_{o,l}=θ_{o,l}+π_{o,l} and all T_o=s_o+〈θ_o,r〉 in the key; send one D_l=b_l(m)+r_l per feature and E_o=c_o(m)+〈π_o,D〉+s_o per output in the ciphertext. Decode E_o+〈α_o,D〉+T_o. For fixed private data the α,D,T arrays are jointly uniform by triangular inversion and E is forced by all Y and those arrays. For Q slots, M rows, h common features and L outputs the private setup uses QLh+QM(h+L) bits, the keys QLh+QML and the row packets QM(h+L). Row-varying θ must be allocated as distinct parameters, or generated from a proven smaller public feature space. This avoids duplicating D for the same feature across L outputs. It requires independence across different slots/rows as stated.

### A new all-rank construction for a fixed, fully issued batch

The following construction dispenses with the original private-tag switches. Its security follows from a different complete-frame simulation. It handles arbitrary fixed public function templates, including raw NAND CircuitSAT with a single accepting witness; its physical cost below rules out the target for the literal encoding.

Fix positive row counts n₁,…,n_r, Q immutable function slots, a public template F_θ, fixed bit widths and canonical slots/rows before setup. One private input per ordinal is issued, with exact replay returning the same record. The LR condition compares every authorized function on every cross-tuple. For the unary base require static, function-and-message-private FE with exact correctness (or charge the selected child's error) and **affine-in-plaintext encryption for fixed master, tape and row ordinal**. The unabsorbed native base of #144 has this property: every gate-table byte is independent of the private data bits, and each active input-label word is word⁰+(word⁰+word¹)m_l. Such an encryption can implement a nonlinear F through its *decoder*. No assumption of affine decoding, independence among bytes of a child token, or secret key linearity is needed for the lift. Native selected-label KG happens also to be affine in fixed-template private parameter bits.

For r≥2, set a=n₁. Allocate one independent rank-(r−1) child per first-row index i, with the remaining row counts n₂,…,n_r and function template F'_θ((x,y),z,…)=F_θ(x,y,z,…). Preallocate independent ordinary encryption tapes for every logical child record. Preserve each tape across all evaluations that synthesize shares for that record. Write L′₁ for the child first-slot token width; sample one independent L′₁-bit pad p_ij per i and row j of the second slot. Setup is shared privately by the issuing algorithms, and its generation is charged inside WE Enc. It does not receive any future input or θ.

* KG(θ) returns the concatenation of the slot-appropriate child keys (one per first row i, for the requested θ slot). This eager issuer does not need x_i. Other θ slots have the same fixed schedule.
* For each i,j let E_ij(x,y) be the **whole** first-slot child Enc at j on the concatenation x||y, using that child's master and preallocated tape. The first-slot record at i contains p_ij+E_ij(x_i,0) for all j. The second-slot record at j contains p_ij+E_ij(0,y_j)+E_ij(0,0) for all i. The issuer of each sees only its own input and the private setup. Calculating E(0,0) can be moved into setup by storing the result; it is never free. This finite-difference method needs no derivation of a matrix of private coefficients.
* For a later slot h≥3, its record at u contains the ordinary child (h−1)-st record under each of the a masters on its own input at u and its reserved tape. There is no first-input dependence there.
* At evaluation select i,j and XOR the corresponding two shares to obtain E_ij(x_i,y_j), exactly by affineness. Select the matching i-th components of all later records and the key, then call child Dec once. Affineness holds for each new input encoder, being a concatenation of affine child maps restricted to (x,0), (0,y), or its own ordinary slot, and fixed offsets. This closes the induction at every arity. The first Lean theorem proves the split identity over any additive group, with signs specialized to XOR here.

Condition on *all* child masters, inputs, tokens, keys and tapes. The first shares are independent uniform strings across (i,j), and the second shares are these same strings XOR the true child outputs. All other transmitted fields are known rearrangements of the independent-child frames. Thus an assembler given complete child transcripts samples fresh first shares, computes second shares by XOR, and copies the other components. It never receives intermediate private master bytes. The complete-fiber bijection is proved in Lean. Allowed coefficient fields can be arbitrarily correlated inside a child. For each i, validity of the child LR batch follows by fixing this first input in every cross tuple; different i have independent masters and coins. One hybrid per first-row index suffices. The wrapper can commit all challenged child query pairs before that child's first response in the static game, generate companion children with their own tapes and assemble the public frame. When the request order within the predetermined batch changes, the current first or second share is uniform while its mate is pending; couple the other upon learning the child output. A key-first issuer has the needed master but needs no future message. This is finite precommitted-batch privacy, not a proof of adaptive LR key selection, corruption security, or variable-length program privacy. All public outputs may be postprocessed or evaluated arbitrarily by a quantum observer with independent auxiliary state.

### Exact size recursion, reduction and raw WE

Let K_r be the bits in one whole function key and L_{r,h} those in one record of slot h; omit fixed ordinal/packing headers. Let K′,L′ be the recursively configured child widths. Then
```
K_r       = n₁ K′
L_{r,1}   = n₂ L′₁
L_{r,2}   = n₁ L′₁
L_{r,h}   = n₁ L′_{h−1}       (h ≥ 3).
```
For base row width C and key width K, putting N=∏ n_h and P=∏_{h<r}n_h gives K_r=P K and L_{r,h}=N C/n_h. All r publicly issued tables total **r N C** bits, plus Q P K key bits. These are actual emitted fields of this whole-word opposite-pad algorithm. For three slots a,b,c the key is abK and the input-record widths are bcC,acC,abC. For two they are bC,aC with key aK. The pads alone take n₁ n₂ L′₁ bits at a node in addition to n₁ child setups, reserved tapes and any cached offsets. Under this layout the total pad bits over the hierarchy are (r−1)NC. One first-slot record runs n₂ child first encryptions; one second-slot record naively runs 2n₁ such encryptions, and a later record runs n₁ child encryptions. Charge full child invocation, zero-input generation, read/write of the pads/keys, and tape traversal. Decryption reads the selected subrecords (possibly scanning preceding entries on sequential tapes), XORs L′₁ bits and executes child Dec once. No constant-time indexing bound on the registered tapes is implied.

For unmodified classical 128-bit witnesses split into all codewords in each chunk, N=2^128. If the last chunk has b bits, P=2^(128−b) genuine key components are emitted per function, and there are 2^b actually issued last-slot records. Nonempty records therefore give max(P,2^b)≥2^64 even before charging their widths. In fact the literal input tables have r·2^128·C bits. Implicitly reconstructible zero fields and alternative samplers do not inherit this lower bound. At the base encode the given public 4,096 NANDs including the registered true result of unavailable reads, followed by two NANDs implementing β AND φ. In the unoptimized four-row representation with label width w, one slot and 128 private witness bits, C≥(4·4098+128)w=16,520w bits, even before the output orientation and any true-wire label or framing. At w=2,049 that is 33,849,480 bits per Cartesian row. This is field geometry, not a concrete PRF hardness setting. The unary key includes the selected label seed and color for β. The reasoning applies to all false φ, and correctness does not depend on finding or sampling witnesses.

A distinct flattened option uses a **single unary master**, Q function keys and N unary rows indexed by the full tuple. Preallocate independent garbling tapes per tuple. Native gate tables are data-independent for fixed tapes; each active input label depends on just one party's bit. Assign each whole data-label word to that input owner and assign all constant/table bytes to a designated issuing role, e.g. the last slot. Each party sends the fragments for all tuples containing its ordinal. Evaluation concatenates the fragments in their fixed order and uses the unary key. The full public frame is a bijective public rearrangement of the complete unary batch. This removes the P repeated unary keys and r-fold duplicated full records, but still emits **N C** bits across the input parties when C is the fixed native packet width. No single issuer needs a full private tuple during actual generation. Public evaluation of the resulting labels can be nonlinear. Sharing the *same* garbling on different tuple rows instead is unsafe in general: for the fixed public predicate w AND NOT w, giving both labels for w permits combining the true input wire label with the true negated-wire label from another evaluation. The evaluator can reach the normally impossible true predicate wire and test the β gate, even though the public predicate is false on every witness. Fresh row-dependent tables prevent this particular cross-row mixing.

The eager proof uses P unary ordinary gaps via the recursion. The flattened proof uses one unary gap on a batch of N rows, with an adapter that handles the entire transcript and constructs its pairs/identifiers. For the explicit static native base, a conservative two-sided PRF hybrid count at one master with m rows is 2(Qd+Qm(d+s+g)), where d is the number of private parameter wires, s the supplied data/constant wires, and g the actual gate count including output normalization. See #144 for the order of replacing inactive keys only, domain separation, and either accounting for coinciding keys explicitly or charging a birthday term. With fully issued slots one can take d=1 here; g≥4098 and s≥128 in the displayed geometry. In the eager comparison m=n_r at each of P leaves; in the flat comparison m=N at one master. For per-comparison acceptance gap δ and aggregate statistical error η this yields an upper bound Hδ+η with the corresponding total hybrid count H. A single ordinary challenger can have m input-seed queries or all outgoing-row queries of a wire; its online work includes simulation of the remaining native fields, the adapter and the final distinguisher. A registry squared-gap bound therefore needs at least 2 log₂ H additional bits before relative time/description inflation and η. Post-quantum security is conditional on a sufficiently secure, statement-independent PRF under classical oracle queries against a quantum distinguisher. A concrete PRF-to-registered-LWE implementation with these times, advantages and finite parameters has not been supplied. Even perfect base privacy would not cure the honest table-size excess.

### Scope for compression and reproducibility

For known future *public* linear tests T, storing a packet modulo their common kernel preserves the answers. Computing a public basis, its change of coordinates, and the cost of the projected encoder are additional. For the literal affine packet with every possible future α, testing E+〈α,D〉 at α=0 and at the standard unit vectors recovers E and every D bit. The future-rows Lean theorem states this for a whole vector. A basis depending on a private orientation, selected key, hidden master or LR world cannot simply be appended as a public header. At a fixed first row in the eager lift, if the concatenated left contributions across all j always lie in one inexpensive **public** subspace U (allow a known public offset), one may sample the first pad uniformly in U and issue the first share in U-coordinates once. It is uniformly independent of every hidden child transcript, and the second shares are computed using the expanded public coordinates and the true outputs as before. For the actual issuers to use this they must share the pad, evaluate the correct E, and access the needed coordinate efficiently. For the unabsorbed native base, fix a single data input bit and one data-label suffix coordinate. Toggle that input away from zero and subtract the all-zero packet, cancelling every intercept. Across distinct row ordinals the resulting suffix differences are XORs of two independently sampled suffix bits per row. Their vector has full support on the entire binary row-index space. Consequently no fixed proper public row-index subspace contains even this one family of differences for all the actual tapes. Certain deterministic point differences and header constants can be compressed; affine dependence on the data within a fixed row does not give affine dependence on row ordinal across independent tapes. A new correlated tape generator requires a new joint privacy proof.

Small exact controls used a one-row information-theoretic unary base for the nonlinear test β(x XOR z)y. Setup bits t,X₀,X₁,Y,R₀,R₁,P₀,P₁ are independent. The key is h=t+β and P_h. For u=x+z and v=y send A_k=(k+t)u+X_k, S_k=(k+t)uY+R_k for k=0,1, B=v+Y and C_k=X_k B+R_k+P_k. Open A_h B+S_h+C_h+P_h. These seven ciphertext bits are affine in (x,y,z) at fixed setup. On all 16 input/function worlds, enumerating all 256 setup tapes verified decryption and equal full joint multiplicities within each output class. Independent copies per unary row give the bounded logical base. The three-slot two-row-per-slot eager lift had 16 key bits and 28 bits per input record, and returned all 8,192 expected cross outputs over eight sampled masters, both function bits and all input lists. Completeness of general private-frame privacy uses the conditional simulation, not these sampled replays.
