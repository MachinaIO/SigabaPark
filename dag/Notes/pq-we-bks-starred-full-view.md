### The reduction for Claim A.11

Fix a rank t at least two, first-row index j, outer bit b, a false statement, and publicly ordered tables of n_i inputs in each slot i. There are q function pairs. Write a=n_1 and G=sum_(i=2)^t n_i. For the payload-folded WE, the left and right inputs are identical public chunks, q=1 and g_d(w)=d AND phi(w). This note uses the selective-message game with the ciphertext returned at its requested slot. Definition A.4 step 3 prints index 1 for every slot; literal use of that index cannot even type-check for heterogeneous slot domains. Figures 5 and 6, the encryption algorithm and the game notation give the intended slot. Several hybrid displays use FE1 where the keys have child arity. [Brakerski, Komargodski and Segev, ePrint 2015/158, Appendix A.1–A.2, Figures 5–6 and Claims A.8–A.14; Appendix B.1, proof of Claim 3.7](https://eprint.iacr.org/2015/158.pdf).

The reduction chooses b before the child setup. For child slot 1 it commits to all n_2 pairs ((x^b_{1,j},x^b_{2,i}),(x^1_{1,j},x^1_{2,i})). For child slots s=2,...,t−1 it commits to the n_(s+1) pairs (x^b_{s+1,i},x^1_{s+1,i}). Child ciphertexts returned in the same slots and row order are gamma_(s,i). After commitment it requests q key pairs (C_(f^b_h), C_(f^1_h)) for delta_h. In this application even the key list is fixed before setup. C decodes the pair in its first argument and passes all t decoded values to f. Each Cartesian product of child queries corresponds to an original tuple with first-row index j, so equality of the original function outputs proves child validity. On a false statement both gated outputs are zero for all these tuples. There are exactly G ciphertext replies and q key replies under one child master. The paper's rectangular equal-T display can be implemented by syntactic repeated-pair padding only when the concrete challenger requires rectangular lists; extra replies have to be counted in that implementation.

To wrap the replies, independently sample the ordinary outer single-input master, the inner rank-(t−1) master, and independent child masters and PRF keys for the a−1 other first rows. For index i<j set the two flags in its first outer ciphertext and aggregator to one; for i>j set both to zero. In row j set both flags to zero and use dummy master/PRF-key fields in both algorithms. Sample each row tag s_i once and reuse it consistently. For every suffix row invoke the inner encryption at its own slot on (x^b,x^1,tau,s_j,gamma), with its fresh outer coins and independently sampled tau. For every h issue the ordinary outer key on D_(f^b_h,f^1_h,z_h,delta_h) with the sampled z_h and outer key coins. Deliver all a ordered pairs, all G wrapped suffix ciphertexts, q outer functional keys and the original public context to the observer. The wrapper has no starred master and uses no parsing shortcut. The work beyond one run of the observer includes one outer and one inner setup, a−1 child setups and PRF key generations, a outer encryptions, a inner aggregator key generations, G inner encryptions, q outer key generations, all tags, encodings, framing and reading/writing the replies. These routines run at their actual function and message lengths; the count is not a Turing-machine clock.

At child bit zero the same starred master encrypts the b-side plaintexts and issues keys for C_(f^b_h). At child bit one the same starred master encrypts the 1-side plaintexts and issues keys for C_(f^1_h). All outer fields continue using b in both worlds. The formal model samples direct local and child tapes in one order and a challenge plus an independent local wrapper in the other order. The assembler accepts only the gamma and delta arrays. The full_view_switch theorem commutes the independent draws and proves exact equality of the resulting ordered views for each bit. Words model encoded classical strings; the operations are arbitrary deterministic algorithms with explicit random tapes. For the independent-coins H6/H7, instantiate child tapes with a real child setup plus independently sampled per-call randomness, and local tapes as specified above. The theorem does not formalize FE security or a concrete circuit-to-machine translation.

A.10 and A.12 require an additional distinction. A uniform random *function* of the printed tau and z tags returns identical coins on a repeated tag, whereas H6/H7 display fresh coins per call. Conditioned on two equal tags, two one-bit coins have equality probability one in the function experiment and one half in the fresh experiment. This already falsifies a universal exact sampler identity across these interfaces. Coupling until the first repeat costs at most 1−(M)_N/M^N per passage, where M=2^lambda, N=G+q, and the falling factorial is zero when N>M. The birthday union bound is N(N−1)/(2M). This is separate from first-row s-tag collisions in routing comparisons. No collision correction belongs to the fresh H6-to-fresh H7 identity itself. Any domain separation or sampling without replacement must also be used in the implemented endpoints or separately justified.

For any observer on the classical strings, let u and v be its probabilities of output one at fixed outer bit zero on H6 and H7. The probability at outer bit one is the same c on both sides, since the two child challenge queries are then identical. Thus the absolute difference in the original averaged outer success probabilities is |(1−u+c)/2−(1−v+c)/2|=|v−u|/2. Fixing outer b=0 in the child reduction and returning the observer bit unchanged gives a child guessing bias exactly |v−u|/2, or an ordinary output gap |v−u|. No factor for running the observer twice or observing its estimate is required. A quantum observer with fixed auxiliary state independent of the fresh challenge coins acts on exactly one sample; conditional on a classical transcript its output probability is a number in [0,1]. Equality of transcript laws therefore transfers directly. Finite quantum hardness and the wrapper clocks are still required to bound that probability difference. The algebraic equality is fixed_bit_normalization.

### Direct endpoints for the one-payload case

An encoder specialized to WE can hardwire both g_0 and g_1 in the same issuer D, write x in both plaintext positions, and set every first-row flag to the payload bit d. These are precisely the fixed-b=0 endpoints H(3,1) and H(3,a+1). At each endpoint Figures 5 and 6 decode the chosen labels and apply g_d. This changes the encoding algorithm, and removes the four start/end normalizations of the original proof. Its ordinary distinguishing gap telescopes directly across the a internal blocks. Arbitrary payload/statement-dependent auxiliary strings would need their own treatment.

There is a shorter direct variant related to the public-decryption transformation of [task PR 141](https://github.com/MachinaIO/SigabaPark/pull/141). Publish one independent real child function key delta_j for C_(g_d) per first row under its own fresh child master, the a private shared-inner aggregator keys, and the G shared-inner encrypted suffix records. In Figure 5 public decryption of a D key at row j returns such a child key computed with PRF(K_j,z). Accurate emulation of this *particular* postprocessing keeps the same coins and can charge each side's probability of any wrong outer decryption by at most the sum of its a q per-evaluation error bounds. Starting with freshly generated keys defines a separate endpoint construction; its proof below does not assume that PRF-derived and fresh keys are identically distributed. One selected witness decrypts the shared aggregator on its suffix ciphertexts to get a child ciphertext tuple, then decrypts that tuple with delta_j. If correctness of each per-tuple evaluation is bounded uniformly for all admissible keys/inputs, their two failure bounds add; the actual primitive parameters and quantifiers must be checked.

For a transparent coins implementation, build a table of independent child encryption tapes for each j and suffix slot/row. Each public suffix plaintext includes its slot-specific row label. The fallback of AGG_j knows the jth child master and tapes and computes exactly its child encryption on the indexed row (with first label prepended in the first suffix slot). Use distinct, fixed public identifiers for first rows. For one switched row j, the left shared-inner message is an ordinary suffix record; the right record has the same label plus override identifier j and gamma_(j,s,i) computed from precisely the fallback tape. The left shared-inner key for j is real and the right key has a dummy fallback; all other real keys remain unchanged. All-tuple shared-inner admissibility follows: the target aggregator returns its original tuple on the left and the matching overrides on the right; other aggregators see distinct identifiers and use their same fallback. The shared_inner_admissible lemma proves this for every tuple and every key, with at least one suffix slot. The reduction knows all child masters and coins in this comparison, so both message lists can be committed before shared-inner setup. The public delta keys are independently computed under those child masters.

Once j uses a dummy, transition its override gamma list and public delta_j with exactly one rank-(t−1) selective child game as above. The other child masters are independent and remain known to the wrapper; the shared-inner master is generated locally. Then undo the override using a second shared-inner game at the new delta. For a>=1 this gives a child comparisons plus 2a shared-inner comparisons; the direct encoder and reduction use no outer single-input FE. Each shared-inner challenge has n_i rows at child slot i−1 and a aggregator key pairs. Each starred child receives n_i rows at slot i−1 and q=1 function-key pair. A fixed-size, common encoding for real and dummy keys, payloads and overrides must be used where FE leaks length. The honest tape variant's a aggregators together contain a times the sum of suffix-row tape lengths before FE encoding.

A compact version adds an independent PRF seed to each starred child master and derives encryption coins from an injective encoding of the operation, slot and public row identifier. Direct delta key generation can use fresh coins independently; if key coins are derived as well, give each functional query a disjoint type and unique index. The supported API fixes both left/right inputs for every nonce before use. An exact repeat returns the cached response. Reusing a nonce with a different query pair is outside this API. Masters are independent across first rows; merging their nonce spaces without adding row identifiers and proving a new joint game is invalid. For nested uses, allocate a fresh seed per logical master and disjoint encodings for every API and output block, with lengths set before the query. Truncate independent uniform blocks to each algorithm's exact tape width.

For either fixed child bit, a PRF challenger can locally sample the underlying ordinary FE master and compute all child replies with its oracle for these coins. Unique tags give exactly the independent coin law in the random-function case. The middle random-function left/right comparison is one ordinary selective child challenge; its coins can be cached on exact repeats. In this starred comparison the target aggregator has a dummy fallback, so its unknown seed or master is never embedded by the wrapper; other masters have independent local seeds. The hide/unhide reductions know all starred seeds and can legitimately place them in their private aggregator keys. Thus the compact child's ordinary gap is bounded by the ordinary randomized child gap plus one PRF ordinary gap on each side. Each PRF reduction makes exactly G encryption-coin queries for one-block tapes (plus q if routing key coins), or the sum of block counts at the actual widths. Only classical PRF queries with quantum postprocessing are used. The honest aggregator pays for the PRF circuit, seed and tape expansion. For correctness with PRF-derived tapes, perfect correctness on all used tapes suffices; if correctness is only average over uniform coins, account separately for replacing the PRF by a random function in the efficient correctness test at the selected tuple, or prove the requisite joint distribution of the derived tapes. This is a computational comparison of the compact switch against the independent-tape switch after hiding the affected aggregator; it grants no standalone indistinguishability between exposed code representations of different sizes.

One may batch B distinct first rows per pair of shared-inner comparisons by using padded suffix records with room for B override ciphertexts tagged with distinct row identifiers. Each targeted dummy routes to its own exact entry; all nontargeted keys fall back. Hide and restore each block together, switching its independent child masters one at a time in between. The counts become 2 ceil(a/B) shared-inner and a starred-child ordinary gaps, with the same per-game query lists. This requires fixed B-wide payload and circuit domains at honest endpoints, and up to B G overrides when the reduction builds one challenge. It does not remove the a child switches or imply a free multi-user bound. Bringing B to a can move the product aG into ciphertext width, proof-simulation time, or both. No native compact encoding with a proven finite registry advantage or clock is supplied. The machine and the registered lattice reductions remain open.
