### An exact YES certificate on arbitrary input syntax

The issuer takes the registered statement and one message bit, without a witness, seed hint or structural certificate. On success it constructs an input assignment on its work tapes and emits the framed message. On failure it emits a fixed framed zero. A false circuit can never supply an accepting certificate. This gives perfect equality of the two public distributions on every NO. Correctness holds on all YES statements on which the deterministic policy succeeds. The decoder skips the three framed variables (parameters, statement and witness) and copies the framed ciphertext.

First compute an overapproximation of every wire's Boolean range. At a NAND, zero remains possible if both abstract operands allow one; one remains possible if at least one allows zero. This stays sound under sharing, repeated operands and correlation. Start with constant true at wire zero, both values at each input, and true for any not-yet-written address. The forward theorem is an induction over the actual registered estep, including getD on unmatched indices.

Demand true at the terminal and process gates in descending order. Demanding a gate false requests both parents true. Demanding it true keeps an existing false parent request if present, then prefers a forced-false available parent, and otherwise uses an unconstrained operand allowing zero, preferring the left. Conflicts reject. Successful demands refer only to earlier normalized wires. Assign each input true if requested true and false otherwise. The original theorem proves that consistent parent demands, including a compatible initial assignment, give terminal true under the registered fold. It uses the default-true semantics of both values and unavailable parent requests. In the machine, unavailable parents are physically normalized to zero, whose range is fixed true.

The complementary guided policy takes the right operand optionally when both operands are distinct, both unrequested and both abstract ranges allow either value. Given an accepting valuation, every request can be kept compatible with that valuation: an already-false or provably false choice agrees; in a genuinely free tie at least one child is actually false. The guidedSparse theorem proves existence of a sparse choice tape of length at most the number of gates which keeps requests compatible throughout the reverse fold, starting with any compatible demand map. The implementation of sparse consumes no choice on repeated operands. Together with descending topological order and the certificate implication this gives a residual witness relation. Supplying those choices publicly for arbitrary statements, or hiding a bit while allowing only an actual witness to provide them, remains open.

### Clocked four-work-tape implementation

DemandRole.enc consists of 4818 states. Four aligned work heads at coordinate j hold a presence marker, a possible-value trit, a demand trit and a temporary right-parent mark. The input tape supplies the gate list in both directions; no copy of the references and no adviser are needed. At zero the marker is distinguishable from an ordinary live wire. Live mixed ranges and unrequested demands use the blank trit on their respective tapes. A blank presence marker represents an unavailable wire independently of those trits.

The registered physical chunk for gate (a,b) is 1^(8a+3) 0 1^(4b+1) 0, following the checked parameter frame. In the forward scan, each eight- or four-symbol group moves aligned work heads by one to address its operand. Rewind to the marked origin between lookups. Append the output range to the first unallocated coordinate and return to zero. At the statement terminator, check the one-bit message framing and final blank, store the message in control, and seek back to the last gate. In reverse, locate and remove the last live wire, keeping its demand in control. Thus a reference to the current gate or any future wire now has an absent marker, exactly as at forward evaluation time. Decode the right parent first, normalize if needed, and mark its coordinate. Read the left parent, resolve or reject the requests, update it and then find the marked right parent, update it if required and clear its mark. This also works when both parents are the same. After decoding the first operand backwards, the preceding zero belongs to the previous gate or to the parameter frame. Its left neighbor is one in the former case (the last parent run is nonempty) and zero in the latter case. On successful exit the 128 input demand trits give the actual witness. No trits or intermediate states appear in the ciphertext.

For all registered inputs the two directional physical body scans cost at most 2·2·4096(6·4224+3), plus O(1) per gate for delimiters, control and loop entrances. Address-group motion overlaps scanning the input. In the forward pass, each gate additionally has at most two rewinds from parent addresses, one scan from home to the end and one return. In the backward pass, locating the end, returning home, normalizing either absent parent, returning home from a parent, looking up the right mark and preparing the next iteration are bounded by eight full 4226-cell traversals. Work heads always move together. Even allowing twelve full traversals and 64 additional constant steps per gate **across the two passes**, and 10,000 steps for setup, framing and terminal control, the total is below 1,000,000,000 ticks. The decoder's 210,000,000-tick clock covers the largest registered statement, both role frames, the 128-bit witness and single-bit ciphertext. These are machine clocks and table lengths, not RAM operation counts.

The encoder's four work tapes and 4818 states give a 77,271,084-bit canonical table. The decoder costs 294 bits to describe. Both registered roles together cost **1,287,271,378**, including both clocks. The costs theorem checks these numbers on the supplied machines. The mathematical soundness and guided-completeness theorems are separate from an all-input bisimulation for the finite controls, which is still open.

### Coverage, counterexample and actual role replay

For every 128-bit planted word, start each term with the corresponding literal in the left branch of an OR and x AND NOT x on the right. Conjoin all terms and insert unused gates immediately before the final gate to preserve its operands. Only the planted word satisfies the equation, even though every primary has both polarities among the syntactic paths. All conjunctions demand both children. In the disjunction, the separate contradictory branch has an unconstrained range under the coarse abstraction, and the left branch is available and chosen. This recursively forces the literal true on its own primary. There are no cross-term input collisions. This explains all 2^128 plantings without treating a fixed collection of probe assignments as a solver.

The full role transition table was extracted directly from enc.machine.tr (coin independent), checked for alignment of all four heads, and executed with independent tape storage. On two independently generated mixed planted words the recovered 128 input bits matched all planted bits. Times were 50,494,516 and 50,665,760 steps; the all-zero and all-one planted words took 52,553,176 and 48,925,400. The latter included a zero message. An extreme forward/self-reference case took 520,168,744 steps and returned one. A fixed-false instance returned zero. Independently calling the core's parameter encoder, registered encStmt and outer encodeTuple on two planted cases and the conflict case gave exactly the physical bytes used in the tests.

For the conflict family, make each term NAND(NAND(x,NOT x),NOT x), with NOT x=NAND(true,x), then conjoin the 128 terms. Each equals x. Both operands of each outer NAND appear available in the abstract range, though only the right one can actually be false when x=true. The left-first policy emitted fixed zero on this positive 4096-gate input in 40,421,036 steps, even with message one. The right-guided residual takes 128 bits; flipping any one of the 128 decisions fails the replay. The exact count concerns this abstraction and branch order. No universally shorter residual, all-YES correctness, fixed hardness reduction or universal sub-cap fallback follows.
