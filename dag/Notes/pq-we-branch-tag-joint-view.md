## Two evaluations of one Peikert–Waters input

Consider using the branches of one public LWE all-but-one key as gate tags. Let the encryptor sample a uniform binary seed x, keep the inversion key private, and publish two branch images on x, or data from which both images can be computed. An endpoint bit masked by a publicly specified function of x then requires x to remain hidden. This reuse already fails with two distinct known tags, even if neither is the lossy branch.

In the notation of Peikert and Waters, Gen picks a distinguished branch v*, samples A,S,E and publishes (A,B'), with B' = ASᵀ + E − r(v*). Evaluation at v returns (xA, x(B' + r(v))). Subtract the right components at u and v. The result is x(r(u) − r(v)) modulo q, including cancellation of the *same* error E. This statement concerns two evaluations on one secret input. Public evaluation on inputs chosen by the evaluator is part of the ordinary primitive. [Peikert and Waters, full version, §6.4, pp. 37–39, Theorem 6.5](https://sites.cc.gatech.edu/fac/cpeikert/pubs/lossy_tdf.pdf)

Here is the recovery calculation including rounding. Set p' = 2pw, n = w log₂ p. Before rounding, the integer matrix behind r(v) is the anti-cyclic expansion S(v) with each row expanded by binary place values. Use consistent integer lifts of its rounded coefficients, adding multiples of q when necessary. Each coefficient differs from q/p' times its integer target by at most 1/2. Thus a coordinate d of the lifted difference satisfies |p'd − q t| ≤ np', where t is the corresponding coordinate of the integer row of packed digits times S(u − v). The observer obtains d modulo q. Since q ≥ 8p'n, nearest rounding of p'd/q recovers t modulo p'. Each digit is at most p−1 and each coefficient of S(u−v) is 0 or ±1. Hence |t| ≤ w(p−1) < p'/2 and the centered representative gives t over the integers. S(u−v) is nonsingular over the rationals for distinct branches, since w is a power of two and X^w+1 is irreducible. Solve the known linear system and unpack its digits to recover x. The Lean theorem rounded_branch_unique proves the modular uniqueness step. The application to the published matrices and the linear-system algorithm are paper arguments.

The finite check enumerated every pair of distinct branches and every binary input at (w,p,q) = (2,2,131), (2,4,521), (4,2,521), (4,4,2053). All maps from x to the public difference were injective. This experiment tests the rounding convention on small instances.

## A complete local mask test and an explicit failed circuit construction

Take G to be 128-bit strings under XOR, or write the gate equations additively over any abelian group. Gen samples two labels per wire, independently. Publish both labels at each input and the true label of the constant. Normalize every forward reference to the constant at its read position as required by the registered relation. For a gate with parents i,j and output o, emit four records

    C[a,b] = K[o,NAND(a,b)] − K[i,a] − K[j,b].

Publish the bit β XOR firstBit(K[last,1]). Eval takes the witness, computes its trace in topological order and adds the two active labels to the selected record. This derives the correct output label even with repeated parents. A satisfying witness recovers β exactly. The four-record layout uses 2,130,049 payload bits at 4,096 gates, including input labels, the constant label and the endpoint. This figure counts literal payload writes only.

For any four records define D(C) = C[0,0] − C[0,1] − C[1,0] + C[1,1]. Theorem nand_rectangle_quotient proves that two four-entry tables have equal D exactly when they differ by row and column offsets. Independent uniform row and column masks therefore reveal precisely D as a coset label for **one table**. In the displayed construction D(C) = K[o,0] − K[o,1]. On any false circuit an arbitrary assignment derives K[last,0], so the last rectangle gives K[last,1] and the message. On the particular registered allNand00 circuit even the last rejecting row is opened with the public constant label. More entropy in separable input masks cannot fix this identity.

A concrete repair attempt adds ab·U_o to the record (ab is the Boolean AND, acting as zero or one). A fresh uniform U_o masks the rectangle perfectly in isolation. If the correction ab·U_o is carried merely by relabeling the rejecting output, the new rejecting label is K[o,0]+U_o and the same public rectangle again translates that rejecting label into the accepting label. A genuine interaction correction needs an opening bound to both incoming derivations.

There is a second obstacle even for perfect opaque pairwise gate operations. Set u=NAND(x,x), v=NAND(x,u), z=NAND(v,v). The output is always false. With reusable labels indexed solely by wire and value, one evaluation on x=1 supplies the left value 1, while another on x=0 supplies u=1. Applying the authorized (1,1) row of gate v yields a label for v=0. Duplicating it gives z=1. Padding before the three gates embeds this example in the registered size with the remaining input bits unused. An arbitrary pair of attainable labels need not be jointly attainable.

## A trace-sensitive route with two separate tests

Let S and T be the original input supports of the two parent functions. Theorem joint_wire_values proves that values a,b occur on one assignment if and only if there are local openings for a and b whose assignments agree on S ∩ T. One glues the left assignment on S to the right one off S. Constant and normalized forward wires have empty support. Inductively, labels bound to assignments on the union can enforce every NAND merge. Agreement only on the overlap is sufficient for a *single merge* if the output binding also preserves the glued assignment for future merges.

A possible interface to target is a compressed lattice label for (wire, value, assignment restricted to support). Gen would create two input labels and one transition descriptor per gate, independent of the eventual witness. Eval would combine two labels with matching support openings and derive a label bound to their union. Only an accepting terminal label would release an endpoint pad shared by all satisfying assignments. The three-gate example supplies an immediate test for a new algebraic translator. A public equality check on caller-supplied assignments is insufficient if a caller can copy the public translation data and apply the label operation directly. The missing cryptographic operation is a compact transition authenticating the *actual* labels and retaining the binding in its output, together with an accepting-only conversion to the common pad. Listing the assignments of a support can require 2^128 labels. Listing them on a separator can also exceed the budget. The semantic glue lemma avoids assuming that either list is present.

For a proposed hybrid with additive corrections there is a stronger full-transcript test. Condition on a public index with a message-independent distribution. Let X be a uniform finite seed space (it can be binary and need not be a group), let f_b(x) be the entire deterministic vector for message b, and let the independent uniform mask coins r enter this view through one group homomorphism M. Include every correlated helper, terminal component and exposed key in the vector, or justify the conditioning on it. Theorem masked_view_count proves

    #{(x,r) : f_b(x) + M(r) = y}
      = |ker M| · #{x : y − f_b(x) belongs to im M}.

For nonempty X and finite mask group, the two classical views have identical laws exactly when the counts of seeds coincide in every coset. More generally put n_b(C) = #{x : f_b(x) belongs to C}. Their total variation distance is the sum of |n_0(C)−n_1(C)| over distinct cosets C divided by 2|X|. This follows by summing over all representatives and using that the mask is uniform on its image. This distance also bounds every quantum measurement on the classical output with independent ancillas. Correlated quantum side information would require a joint state argument. Independent one-gate checks can miss shared-mask constraints. For example (r,r XOR b) has two uniform marginals and disjoint joint supports. The formula gives a falsification test and a sufficient target for the *last* hybrid. It supplies no real-to-hybrid lattice reduction.

## Cumulative lossiness and write budgets

Libert, Nguyen and Passelègue give a relevant alternative with a common compression of evaluations at losing tags. Their LWE construction has one injective tag and an inversion trapdoor. The relaxed guarantee bounds an error averaged over losing tags. A circuit chooses tags via its traces and exposes an entire reusable ciphertext. One needs a compiler that makes all satisfying witnesses reach the injective endpoint, makes the trapdoor capability available there, and controls error for the complete false-statement view. Choosing the literal bit C(w) as the public tag lets anyone select the accepting tag directly. The paper's equality circuit tests agreement with one hidden string. [Libert, Nguyen and Passelègue, ePrint 2022/1229, revision of January 2024, §§2.1 and 3.1, Theorem 1](https://opencryptology.org/2022/1229/versions/20240114T061334Z.pdf)

Two resource screens apply to the literal fixed-width serializations considered here.

* For Peikert–Waters, take d ≥ 128 as an explicit parameter screen. It does not assert any particular security strength. To certify positive loss via the residual leakage bound of Theorem 6.5, its right-hand side must be smaller than n, hence w > d from its d/w term. Since w is a power of two, w ≥ 256, n ≥ 256, and q ≥ 16w²p log₂ p ≥ 2^21. Even rounding the bit width down to 21, issuing one full index per gate costs at least 4096·256·384·21 = **8,455,716,864** writes. The dense_gate_write_floor theorem checks the arithmetic conditional on these lower bounds. Reusing one index changes the write calculation but exposes the two-image issue if the same secret input is used at distinct visible branches.
* For the literal LWE cumulative construction at λ=128, §3.1 sets t=log₂ λ=7 and includes 2t matrices of shape n by n'=⌈n log₂ q⌉. Its rounding and compression conditions give q/p > 2^128 and n ≥ 2ℓ log₂ q with ℓ ≥ 1. Thus n ≥ 256, n' ≥ 32768, and each fixed-width coefficient needs at least 128 bits. The 14 matrices of **one key** already cost at least **15,032,385,536** bit writes. This omits both A and B. The calbo_key_write_floor theorem checks this integer bound. A seed-compressed distribution or a ring representation would require separate sampling, expansion, security and cost proofs.

For a prospective ring layout, 4,096 gates with four rows and two degree-1,024 polynomials per row at 32 bits per coefficient require exactly 1,073,741,824 writes. More generally 32 such polynomials per gate already cost 2^32 bits. Eight per gate leave 3,221,225,471 steps for excess encryption time, all decryption time, and both descriptions, before any other ciphertext fields are charged. These sizes are a serialization example. They carry no estimate of quantum Ring-LWE hardness or sampler runtime.

The strict screen is Enc.time + Dec.time + Enc.descLen + Dec.descLen ≤ 4,294,967,295. Each literal layout above fails from Enc writes alone. Neither result excludes a different compact layout or implies failure of the registered 2^100 cap. PR 130 prices a dense issuer conversion, while PR 131 investigates compulsory head movement on long unary statements. Reads and writes on different tapes can overlap, so adding either write floor to the prefix floor would require a scheduling argument. The zero-entry note treats exposed GGH15 preimages, while the rank-gap note treats a restriction to linear tests. The two-branch cancellation and rectangle calculation here use publicly available outputs directly. [PR 130](https://github.com/MachinaIO/SigabaPark/pull/130) · [PR 131](https://github.com/MachinaIO/SigabaPark/pull/131)

A positive submission still needs concrete fixed registry parameters and strengths, the support-bound translator and terminal algorithms, a full-view quantum reduction with concrete loss, correctness error at most 2^−128, and machine clocks and descriptions within the strict screen. The algebraic counting and resource bounds do not instantiate these obligations.
