### Removing every selected data-label field

In the fixed-template garbling of [task 144](https://github.com/MachinaIO/SigabaPark/pull/144), encryption knows its own message m when producing each garbling. This asymmetry with the key issuer's private parameters matters. For each data-input wire i, give its actually selected semantic value m_i the public label (zero κ-bit suffix, color 0). Give 1−m_i an independent uniform secret suffix and color 1. Enc writes neither selected labels nor a public seed. Every receiver can start every data wire at the public label. The garbler uses m to construct the gate truth tables; the public template and its gate order are independent of m. A variant transmits one public random row seed to derive different active suffixes/colors for each (slot,wire), assigns the complementary color to the inactive label, and retains the seed and all these exact derivations in the simulator. Fixed public zero is sufficient in the explicit construction below.

This is an encoding for one fixed encrypted message per garbling, with one active data path per issued parameter slot. Re-evaluating the same garbling on both semantic data values, opening a row to fresh data, free-XOR correlations, or reusing a private inactive label across garblings needs a different proof. Reserve distinct terminal wires or explicit terminal return tables when an output could alias an input. Do not expose the semantic-to-color orientation for intermediate data wires. The procedure still reads the entire plaintext, including wrapped override values, and constructs all garbled gates. A bypass bit inside a child key's private parameters is outside Enc's knowledge; apply the following optimization for known data only.

### The finite lookup for parameter labels

At a fixed master level choose Q issuance slots, d private bits per slot, and M public row identifiers; pad shapes and allocate replay rules before setup. For each (j,i), sample an independent bit pi and two independent κ-bit branch seeds S[j,i,u]. Generate independent masks even for repeated bits of a parameter. Run one collusion-resistant, selectively secure public key-policy ABE setup for attributes (role,j,i,u). Publish both encryptions of the two seeds at their respective attributes. A private issuer for theta_j publishes alpha[j,i]=theta[j,i] XOR pi[j,i] and the ABE key for the *public* predicate that accepts the chosen role and slot and u=alpha[j,i] on valid i. The holder knows which records to decrypt from clear alpha and derives selected labels for every row from the opened seeds. The off-branch seed remains unavailable even to all other-slot keys, since every such predicate rejects the slot. For one slot the master can be independent; true multi-key ABE allows a single same-level setup and 2Qd encrypted seeds without giving any issuing authority to the observer.

Enc labels its private parameter wire at semantic b by (PRF of S[j,i,b XOR pi] at a distinct input-label domain containing (j,i,row), b XOR pi). Enc uses its secret mask pi and both seeds to create the garbling without access to theta. The holder has the correct color alpha and suffix. If a setup is transient inside the BKS issuer or aggregator, the algorithms that garble, issue and evaluate must obtain their full appropriate public parameters and private authority. Scoped delegation across child masters would need a precise restricted-issuing construction and security proof. Ordinary sharing of a master with private material exposed to an evaluator cannot justify it. Internal PP bytes must be carried or rederived in their actual representation and charged, even if a top-level PP can be shared among many slots.

For static left/right query schedules, on each side choose pi and compute the inaccessible address (j,i,1−alpha[j,i]) before any ABE setup. The reduction can instead choose alpha uniformly and define pi from that side's committed theta. Other- and same-slot issued keys all reject this challenge attribute. Locally sample the target seed S and challenge on encryptions of (S,zero) while still using that same known S in all its garbling labels and gate calculations. After the encryption is replaced, use a multi-query PRF challenger at the unavailable seed and replace only its derived suffixes by independent random values, keeping the encrypted dummy fixed. The two replacements in this order preserve all correlations the simulations need. Publicly known other seeds, all selected evaluations and the actual public ABE key are retained. A receiver may evaluate opened seeds at arbitrary additional points. Reusing one slot for a distinct theta, allowing a semantic-branch remapping after the challenge, or obtaining another key decrypting a challenged attribute invalidates this schedule. No adaptive-key claim is made. One multi-challenge ABE game can batch the seed encryptions only if charged at its actual loss and capacity.

Use the explicit four-row garbling with independent suffixes and separate PRF domains for gate masking and input-label derivation. Each physical gate-pad call includes (role,slot,row,gate-id,physical-row,left/right,block). In topological order replace outgoing masks keyed by each inactive wire with uniform pads. An earlier incoming row writing an inactive suffix necessarily had an inactive predecessor and has already been randomized, including inconsistent rows at a gate with repeated input wires. Thus a challenger need never disclose its embedded secret suffix for such earlier rows. The active data labels are public constants: calculate every pad under those keys normally, even at unselected physical rows. No replacement uses the PRF security of a known key. A row other than the active one has at least one inactive input. Its fresh hidden mask suffices; distinct role domains also separate two uses of one label at the same gate. A conservative finite proof may condition on distinct fresh inactive suffixes and absence of collisions with the fixed public suffix and all independently sampled or previously fixed known keys. For H independent uniform inactive keys and at most J fixed/independent known keys, per side the union bound is (HJ+H(H−1)/2)/2^κ. Include any additional collisions where independence is obtained only after PRF replacement. Genuinely correlated roles must be separated at construction time.

The final simulator keeps the public zero data labels, samples uniform alpha and active parameter seeds, produces real keys for those public policies, encrypts active seeds and dummy inactive seeds, and preserves every active seed's dependency across all M rows. Choose active internal labels independently, fill each active gate cell consistently with the active successor, choose the other cells uniformly, and apply the authorized output matrix in the terminal decoder. Optional unissued slots must be disabled with a fixed zero output as in task 144. The mask lemma proves measure preservation of theta XOR pi for an arbitrary joint test of the resulting ideal kernel (the finite sums become expectations after dividing by their common cardinality). Uniformity of alpha by itself makes no claim about a real garbling.

If the ABE encrypts h seed bits per ciphertext, let t=ceil(κ/h). With ordinary gap bounds per comparison, a conservative total over two sides is 2Qdt times the maximum single-challenge ABE gap, plus 2Qd input-seed PRF gaps with up to M queries each, plus the sum over both sides of the inactive gate-key PRF gaps, plus the stated statistical bad-event terms. One inactive-key reduction can cover all its outgoing physical cells with all required output blocks. Charge the full transcript simulation and one final observer to each reduction. An arbitrary observer with independent quantum advice receives classical strings; the reductions only need classical query access to their PRF/ABE games but require security against quantum computation. Union-bound failed ABE seed decryptions by Qdt times per-record correctness error when correctness of all issued slots is required, or dt per used slot; include trapdoor and parameter failure probabilities. Deterministic PRF equality with identical keys, domains and lengths ensures exact label agreement thereafter. This argument does not give a registry strength or a finite loss for the underlying lattice algorithms.

### Literal BGG+ and BV setup and key costs

For the nondelegated BGG+ ordinary matrix construction, Section 4's FKHE encrypts an m-bit block under an attribute of length ell. Let L=ceil(log2 q). Its public fields (A,D,B_1,...,B_ell) are (ell+2) matrices in Z_q^(n by m), and its ciphertext contains (ell+2)m residues. The low-norm R_f is a 2m by m integer matrix, in addition to its predicate/description and any referenced PP. Thus one shared setup writes (ell+2)nmL literal matrix bits. The seed records cost 2Qdt(ell+2)mL bits before their attribute/framing fields. Q key matrices, their encodings and Qd alpha bits are additional. The lookup circuit costs O(d) binary muxes and depth O(log d), plus role/slot bounds and checks; if sent as a circuit, count its encoding, or send alpha with a fixed public compiler and charge expansion. A row reuses the seed ciphertexts. Honest encryption per seed block samples a vector s, error vectors and ell sign matrices of dimension m by m and performs the corresponding matrix-vector operations. Evaluation uses Evalct and the product by R_f; pay key generation, sampling, modular arithmetic, storage and sequential lookup. Keys are charged once per issued slot and evaluations once per selected seed block if cached. A fresh independent master pays another setup. As a field ledger example with Q=16, d=256, κ=128, ell=14 (including role), n=256, m=4096 and L=16, setup has 268,435,456 bits and the 8,192 one-block records have 8,589,934,592 bits. These dimensions illustrate a rejected ledger; they do not certify correctness or LWE hardness. Concrete parameter choices must satisfy the construction's noise inequalities, distributions and a reduction to the registry at the required quantum strength. [Boneh et al., ePrint 2014/356, Section 4, Theorem 4.2](https://eprint.iacr.org/2014/356.pdf).

Brakerski and Vaikuntanathan's bounded-description CPRF offers a different conditional interface. In its formal Section 3, authorized points have C=0 and hidden points C=1. The security experiment commits the constraint before setup; honest use needs computational functionality, not an unconditional equality on every point. Count the error over every required authorized lookup or provide a finite multi-point reduction. For one constrained key per independent master, exposing other authorized values is allowed by the game, whereas replacing multiple hidden points requires a hybrid with distinct, non-requeried points and a bounded query count. For the printed Section 5 family, PP contains z+2ell_H+3 n-by-m matrices, m=n ceil(log q), and a hash description; O(log d) lookup depth does not eliminate cost of the z description matrices. Section 6's short key adds ABE.PP and two ABE ciphertexts per description bit, encrypting LWE sample vectors, and its underlying public fields are still required for constrained evaluation. Theorems 5.1 and 5.2 require DLWE and 1D-SIS-R (and the security theorem uses admissible hashing). The WE registry contains decision LWE and its three ring/module variants, with no 1D-SIS premise. A worst-case lattice implication does not identify the required directed finite reduction. The direct finite ABE/PRF route avoids importing 1D-SIS, but still needs matched finite LWE and PRF parameters. [Brakerski and Vaikuntanathan, ePrint 2015/032, Sections 3, 5 and 6](https://eprint.iacr.org/2015/032.pdf).

### A native batched terminal mux and the remaining output-width recurrence

For an actual terminal AGG return with a common private control t, an ordinary output vector y of length z, and bypass v known to Enc as a plaintext field, avoid first constructing z new w-bit output labels. Garble the ordinary computation producing private labels for y_i and a label for t. For each i directly garble four *one-bit* return cells indexed by the two physical colors. Cell (c_t,c_y) carries v_i when the semantic control means bypass and the corresponding semantic y_i otherwise, XORed with one PRF bit under each corresponding input-label suffix. Include output index, physical row and operand position in both domains. Evaluation sees exactly one return bit per i, which is the final plaintext bit. It obtains neither a control decoder nor a translation table for the other possible y_i color. This batches z bits with one control wire, 4z emitted cell bits, 8z one-bit pad evaluations at encryption and 2z at evaluation before any valid batched PRF expansion; it does not issue z new private output-label pairs. The ordinary ciphertext generator, private control test (including tag comparisons), and all its nonterminal gates still run. For g ordinary four-row gates of width w=κ+1, these cost 4wg further table bits and 8g width-w pads per garbling. The terminal_law lemma checks the joint distribution of all cells after the inactive masks are idealized, conditional on any fixed active-cell values and any joint output-probability test. The garbling hybrids, rather than this ideal finite identity alone, justify idealizing the masks. If an unnormalized output is forwarded into another *gate* in the same garbling, use a full label there; the one-bit table applies only to a plaintext output of that base FE decryption.

Removing input-label transmission invalidates the old input-width lower bound. A different bound remains for this **particular** literal output construction. Let O_h(z) and A_h(z) be uniform lower bounds on terminal ciphertext length at depth h (arity h+1) for respectively an ordinary functionality with at least z output bits and an aggregator-derived functionality with at least z output bits. Include the re-parsing C_f of Figures 5–6 in the same role as f. A base ordinary garbling physically writes at least one decoder bit per output. A base aggregator garbling using these four cells per output independently writes at least 4z. At positive depth the terminal outer ciphertext is a child encryption under the shared inner scheme for the aggregator family. Some issued aggregator returns a tuple including a starred terminal ciphertext under C_f. Taking fixed maximal widths on all supported row inputs and nonempty issuance slots gives O_(h+1)(z) ≥ A_h(O_h(z)) and A_(h+1)(z) ≥ A_h(A_h(z)). This counts the output shape of local algorithms regardless of whether the witness evaluator will visit each possible output. It applies when the complete serialized tuple and conditional return are supported and do not use a special external encoding. The mixed_output_floor lemma gives O_h(z) ≥ 4^(2^h−1) z. In the expansion there is one original-function leaf, while each other leaf implements an aggregator or its argument re-parsing. At arities 4, 5 and 6 this costs respectively 2^14, 2^30 and 2^62 bits per unit final output per terminal entry.

For an explicit prefix with one serialized key per prefix value, assume each raw table entry (including each prefix key and each chunk ciphertext) has at least 64 bits, and all tables fit strictly below 2^32. Every bit width is then at most 25. Let front contain the prefix width and all widths preceding the terminal slot; its length is the arity r, and b is the terminal width. The lengths sum to 128. Arity ≤4 cannot cover 128 bits. At r=5 one has b≥3, yielding at least 8 times 2^30 terminal bits for even a one-bit final output. Arity ≥6 already exceeds the cap at a single terminal entry. The table_budget lemma checks the arithmetic for every partition. The 64-bit entry floor is an implementation condition, not a consequence of public active labels; test it on physical key/ct fields of the chosen concrete implementation. This finding concerns the stricter 2^32 machine target and the four-cell terminal ABI. Output-wide conditional decoding with fewer independent cells, an altered recursive aggregator interface, scoped setup sharing and a finite registry-backed realization remain open.
