The source-power dictionary in [the preceding task](https://github.com/MachinaIO/SigabaPark/pull/168) makes many wire labels functions of one root. We give an explicit statement-independent candidate game and a complete eight-row view with genuine intermediate payloads. For a bounded output length the latter needs no pad hardness assumption. The result concerns the rows available to an observer without exposed source labels. Initialization of a witness evaluator and the final cycle test still require new arguments.

### A fixed experiment

Here is a growing, bounded public-coin parameter algorithm. At integer security parameter λ≥8 take N=λ², M=4N+2 and b=2λ+24. Generate an odd b-bit prime by at most b³ independent uniformly sampled odd candidates and deterministic polynomial-time primality testing. Return a common abort symbol on failure. The prime number theorem gives negligible asymptotic abort probability. Draw the scalar root uniformly in the nonzero field elements. For an exactly bounded implementation of finite uniform draws use rejection with polynomial trial caps, returning the same abort on overflow. The standard exact-sampling experiment below instead allows expected polynomial sampling. For each literal (i,sign), 1≤i≤N, take positive exponent 2i−1 or negative exponent M−(2i−1). Publish independent a_i≠0 and c_i uniform for **each signed index**. Its implicit key is m_i=c_i+a_i τ^e. Distinct exponents, fixed-width residues in [0,p), and signed indices in lexicographic order make the addresses unambiguous. Two exponents sum to M precisely for opposite signs on the same coordinate. All product degrees are less than p−1. Neither labels nor the missing power τ^M are challenger outputs.

Fix the following common oracle and encoding. Allow at most λ⁴ distinct classical queries (u,v,g,r,s,j) with two valid ordered signed indices, 0≤g,j<λ⁴, 0≤r<4 and 0≤s<4, injectively encoded in fixed widths with an experiment version prefix. Repetitions return cached records. The challenger chooses a bit. For the finite SHAKE256 instantiation, in the real branch return the designated bit of SHAKE256 on the prefix, encoded tweak, and both fixed-width secret residues in order (use the first output bit for each distinct j). In the ideal branch return an independent fair bit at each distinct encoded occurrence. The claimant receives classical answers, makes arbitrary quantum polynomial-time computations and guesses the bit. The challenger checks equality. The hypothesis bounds the difference of output-one probabilities; guessing success over half is half this advantage. No quantum superposition access. No adaptive label reveals, encrypted terminal tests, circuits, acceptance hints or unknown-oracle programming in either branch. A reduction can pick queries based on its circuit because the challenger does not. At a fixed concrete size this defines a falsifiable standard-model hardness claim, with an explicit time budget. It cannot support an unrestricted asymptotic security claim with a fixed sponge width. For a fixed pair, all prefixes have equal length, so the sponge state and any pending partial block before the common secret suffix have constant total width. Once the number of allowed public tweaks exceeds the number of prefix states, two tweaks lead to the same completed real output on that pair, while their ideal answers are independent. The growing computational hypothesis below instead uses a growing-dimensional rounded field projection. Source-dependent challenge plaintexts are outside this pad-only game. Quantum exhaustive search provides an upper benchmark of order √(p−1) candidate checks when enough independent output tests identify the root; b and the number and cost of checks matter. This is no security lower bound.

For the growing candidate use the same bounded oracle, changing only the following sampling and evaluation rules. Use a vector root in F_p^d (d=λ, exclude only the all-zero vector), componentwise powers, fresh nonzero diagonal entries and uniform c per coordinate. On every occurrence publish independent h uniform in F_p^(3d) and b₀ uniform in F_p, and return Round(b₀+〈h,(x,y,x∘y)〉) in the real branch; Round(z)=floor(2[z]/p). In the ideal branch publish the same header and an independent fair bit. Repeated addresses cache the whole pair. The product block supplies a genuine cross term. For comparison, the separate, undithered unary projection uses only x and a fresh h of length d. The pair game uses a public dither; no reduction of dithered LWR to ordinary LWR is assumed. For a safe prime p=2r+1 with r prime and r>2M, all exponents are odd and less than r, so all are permutations of the whole field, including zero. Then each tag on a uniform *unconditioned* vector root is exactly an ordinary uniform-secret LWR marginal for the unary projection. Removing zero costs at most p^(-d) for the whole experiment. Rounding uniform residues differs from a balanced bit by 1/(2p), giving at most J/(2p) error for J independent ideal bits. Neither the joint related-key game nor the triple-address projection follows from this marginal. For arbitrary growing primes some exponents can share a divisor with p−1; their power marginals need not be uniform. The generic computational game makes no safe-prime claim. A fixed safe-prime example is the 2048-bit prime of RFC 3526 §3; the safe-prime instance does not require an asymptotic safe-prime density conjecture. LWR here has uniform fresh headers generated by the challenger. Chosen projection vectors or reusing headers are different games.

Bellare and Cash's related-key PRF framework and later polynomial-related-key constructions motivate comparing allowed key transformations and the exact ideal game. The polynomial-key result analyzes a Naor–Reingold variant under decisional degree-d Diffie–Hellman inversion, and an affine variant under DDH. Their assumptions and transformations do not prove our public-salted polynomial power schedule with two-input overlap against quantum algorithms. See [Bellare–Cash](https://iacr.org/archive/crypto2010/62230663/62230663.pdf), [polynomial RKA work](https://eprint.iacr.org/2014/488), and [RFC 3526](https://www.rfc-editor.org/rfc/rfc3526#section-3).

A permutation-only growing extractor profile avoids safe-prime generation: use the finite field of size 3^k for a prime k>2M, with a public polynomial-basis representation (fix k as the least prime above 2M, and sample a degree-k monic irreducible polynomial by bounded independent trials with a common abort). For any odd prime ℓ dividing a scheduled exponent, ℓ=3 cannot divide 3^k−1. Otherwise the order of 3 modulo ℓ would have to divide k and ℓ−1<k, so would be one; then ℓ would divide 2. Thus every scheduled exponent permutes the full field. The entropy argument works with canonical injective binary encodings of its coefficients, with no LWR or DLWE implication for this extension-field profile. The prime-field game above remains separately specified.

### One-bank computational switch

In a simulator for independent destination LWE banks, process sinks first. At the current independent target-secret challenge, sample the source root, the complete nonchallenge state and independent target-public metadata. For each issued monomial degree add its known source-dependent shift to the supplied challenge bodies; do not sample a substitute target secret. Form all rows whose addresses depend on the sampled source, and all corrections computable from the available state. A uniform challenge body remains uniform after its shift, independently for fresh records. The reverse induction requires every further observation involving the unknown target secret to be either one of those supplied challenge samples or simulable from already switched data: a raw hidden target key, or a cycle back into a live bank, breaks this premise. Exact sample counts, ordinary assumption matching and reduction time are charged per bank.

After the target switch, suppose the remaining state (including all destination keys or payloads needed by the simulator) is sampled efficiently given the public coefficients, independently of the unknown source conditional on those coefficients. Query each distinct occurrence once, xor its answer with the sampled row payload and publish the real auxiliary distribution. With real answers this is the honest view; with ideal answers independent masks hide the entire joint list, including repeated *payloads*. If the same occurrence is used twice its answers are identical, hence it cannot be treated as two independent masks. This single reduction loses no factor for the number of records; its running time includes all queries and the original observer. With independent layer roots the simulator may sample future roots before switching the current layer only when earlier ideal rows no longer require the current secret and no source-dependent public data remains. A same-root destination payload is generally unavailable. Pseudorandomness of a value alone cannot justify masking an unknown correlated value (the two can coincide). Classical postprocessing gives no automatic simulation of a hidden cycle relation.

There is also a standard-PRF comparison when every literal has its own independent uniform root and its label is c_i+a_i s_i. Conditional on public rows these source keys are independent uniform. Use independent, compatible PRF key encodings (or use uniform binary secrets as the source keys); mapping uniform field symbols to binary keys may cost statistical error. For a two-input pad, compute two PRF values under the corresponding source keys on disjoint row/side domains, xor these derived strings to form a row key, then apply an outer PRF under that row key on its output domains. Replace inner functions one independent wire at a time. Unique occurrences give independent uniform derived row keys, even when the same literal occurs on both sides. Replace the outer functions one independent row at a time. Each reduction samples other keys/functions and all available payloads; standard key-collision effects are already covered by the multi-key hybrid when keys are independently sampled. Charge one single-key advantage per switch and actual evaluations. This proves pad privacy on the stated interface only. Independent literal roots can require four distinct bilinear cross monomials per pair of distinct coordinates (32,512 at N=128; plus unaries, same-coordinate terms when admissible and constants). A scalar exponent schedule uses at most 2N unary and 4N+1 even-degree positions before deleting forbidden or unused positions. A vector-coordinate bank can multiply the number of degree samples by d.

### A statistical switch with true same-root payloads

Let Ω be a finite uniform root set. Condition on any independent public data, including all coefficients, and on independent payload coins. For each published occurrence j fix an injective n_j-bit address E_j on Ω, an arbitrary t_j-bit message P_j(τ), and a fresh public binary Toeplitz matrix H_j of shape t_j by n_j. Messages and addresses may depend on τ but must be fixed before these independent hash seeds. Publish all seeds and words C_j=H_j E_j(τ) xor P_j(τ). Let T be the total output width. The joint distribution has total variation distance at most (1/2)√((2^T−1)/|Ω|) from the same seeds and T fresh bits.

Indeed for distinct roots each difference of addresses is nonzero. For a nonzero n-bit vector, the first nonzero coordinate selects a different pivot diagonal bit in each Toeplitz output row; after ordering the rows the minor is triangular with unit diagonal. Thus its random image is uniform, even at a specified payload difference. Across records the simultaneous collision probability equals 2^(-T). For seed h and bucket z write C_h(z) for its root occupancy. Then E_h sum_z C_h(z)^2=|Ω|+|Ω|(|Ω|−1)2^(-T) by counting ordered pairs. Subtract |Ω|²/2^T to get the centered second moment. Cauchy-Schwarz over seeds and buckets, and division by twice the occupancy normalization, give the stated bound. The attached Lean nodes verify the finite energy and absolute-deviation algebra, source address injection and a scalar affine version of the shifted collision argument. Toeplitz universality and the eight-row interpretation are mathematical arguments here. A finite executable audit enumerated 480 nonzero-difference Toeplitz distributions, 128 complete small shifted joint laws and 800 selected two-gate evaluations. These are finite fixtures. The result continues to hold for mixtures over independent conditioned coins and quantum postprocessing of the final classical view. For deterministic pre-header leakage L(τ) with at most B values, condition on each leakage fiber. Averaging the displayed bound and applying Cauchy-Schwarz to the square roots of the fiber sizes gives (1/2)√((2^T−1)B/|Ω|), relative to (L,headers,U_T). This does not yield secrecy after giving away a complete correlated source label.

For an explicit two-gate interface take g=NAND(X,Y), out=NAND(g,W), assigning two distinct signed tagged labels to each logical source input (unique literal index per variable/sign). Use the safe-prime scalar bank so each full source label as a function of τ is injective. For g choose Z_0(τ),Z_1(τ) as true κ-bit downstream keys, e.g. canonical truncations of two more tagged residues, with the first bit overwritten by their respective distinct color bits; select κ≥2. Fixed public row order can use semantic bits here; hiding topology, truth tables or witness bits from the evaluator is not a claim. For each of four input pairs of the first gate, hash E=enc(X_a,Y_b,X_aY_b) into κ bits and xor the true Z_NAND(a,b). For each of four second-gate rows hash E=enc(Z_z,W_c,[Z_z] W_c) to one bit, masking β·NAND(z,c). Here [Z] denotes the integer string embedded into the field, with 2^κ≤p; use canonical widths. This address is injective in the root even if Z truncates, by its full W component. Each header is sampled independently. Given the selected three full source labels and their colors, an honest evaluator recovers the exact Z, selects the next row, and obtains the specified terminal bit for all eight assignments. The law of the **complete eight rows without input labels** is within the stated distance of uniform bodies, with T=4κ+4 for either β. No replacement of unknown same-root plaintexts is required. β-worlds differ by at most twice this bound. This does not describe a public witness-label delivery mechanism.

With p of bit length 2048, κ=256, d=1, first input addresses cost 6144 bits, second addresses 4352 bits. Independently transmitted Toeplitz headers cost 4(6144+256−1)+4(4352+1−1)=43,004 bits, and the bodies cost 1028 bits, exclusive of public coefficients, framing and source delivery. The bound is <2^-510 (|Ω|=p−1≥2^2047). General parameter choices must pay for the root and the headers. Full-field intermediate payloads in the same architecture cost four full field lengths, already beyond the statistical entropy budget. A single revealed full source label permits reconstruction of τ on a permutation profile by inverting the affine and power maps. Conditional on such a reveal the remaining true rows can be recomputed for known β, unlike independent random rows. The row proof cannot include an initializer that publishes even one such label. For the asymptotic arbitrary-prime profile this inversion/entropy theorem needs injectivity checked separately.

The growing rounded-projection candidate itself also has a finite-entropy theorem for fixed occurrences with injective pair addresses. For two distinct roots, the two pre-rounded residues at the same occurrence are exactly independent uniform field elements: h dotted with their nonzero address difference is uniform, and the independent public dither b₀ supplies the other independent residue when averaging over headers. For either relative xor of the two true payload bits the probability of a collision of rounded bodies is at most (1+p^(-2))/2. Different bit headers are independent. The same ordered-pair count and centered-energy argument give TV ≤ (1/2)√((2^T−1)/|Ω| + (1−1/|Ω|)((1+p^(-2))^T−1)). This proof handles actual same-root messages fixed before headers, including the same two gates on the permutation profile. The growing game's adaptive or expanding-transcript claim is still new. For the numerical example this dithered version needs 1028·4·2048 = 8,421,376 public header bits and 1028 body bits. The Toeplitz word headers amortize across output bits much better.

For arbitrary growing primes the same rounded proof tolerates noninjective power tags. Choose one full tagged operand i(j) per row. For any fixed root, its address can coincide at a given row with that of at most gcd(e_i,p−1)^d roots including itself, because each coordinate power has at most that many scalar preimages with the exponent factor taken before the d-th power. The fraction of ordered root pairs equal at any row is therefore at most δ=min(1,[1+sum_j(gcd(e_i(j),p−1)^d−1)]/(p^d−1)). Bound these pairs' collision probability by one and apply the independent rounded bound to every other pair. The resulting TV estimate replaces 1/|Ω| in the previous display by δ. It still assumes fixed pre-header messages and occurrences.

### Two gates with every input label short

The preceding full-operand injectivity requirement can be removed in this two-gate graph by accounting for the true intermediate payload in colliding rows. Start with eight full injective signed tag addresses, one for each of X₀,X₁,Y₀,Y₁,W₀,W₁,Z₀,Z₁ on a permutation profile. Publish eight independent Toeplitz compression seeds, producing κ-bit X,Y,W labels and κ−1-bit suffixes for Z₀,Z₁; prefix each Z with its own color. Keep the same truth tables and independent outer row hash headers but use the 3κ-bit ordered address (x,y,x AND y) at every gate, with bitwise AND. It is equal on two roots precisely when both input labels are equal. The evaluator uses the witness input bits as primary row colors, and the decoded Z color for the second gate. It recovers the exact output as before. This is a claim about the row law with all compression and outer seeds public, before supplying input labels.

Fix distinct roots and let X,Y,W,Z each denote a vector of two equality indicators, comparing their labels on these roots. The six indicators in X,Y,W are independent Bernoulli(q), q=2^(-κ); the two in Z are independent Bernoulli(2q) and independent of the first six. The separate public compressor seeds imply these laws even though all labels use the same two roots. Write |X| etc. for indicator counts. With T=4κ+4, the probability of collision of *all eight bodies*, averaged over all public seeds, is exactly 2^(-T) F(q), where

    F(q)=E[ q^(-|X||Y|) 2^(|Z||W|) I ],
    I=1 iff Z_NAND(a,b)=1 for all a,b with X_a=Y_b=1.

An outer row with different addresses gives the usual independent hash-difference match. A colliding first-gate address requires equality of its actual Z payload and saves κ bits of hash collision cost. A colliding second-gate address saves one bit, since its output payload is fixed across the two roots. The stated expectation follows. For a reproducible expansion enumerate the 256 binary patterns. For each with I=1 add q^(n−|X||Y|)(1−q)^(6−n)(2q)^k(1−2q)^(2−k)2^(k|W|), where n=|X|+|Y|+|W| and k=|Z|. This gives

    F(q)−1 = 20q²+52q³+147q⁴+36q⁵−392q⁶+228q⁷−28q⁸.

For κ≥2, q≤1/4, dropping negative terms and bounding each positive power after q² by its value at 1/4 gives F(q)−1≤44q². For equal roots the entire table collides surely. The same second-moment argument yields TV ≤ (1/2)√((2^T−1)/|Ω| + (1−1/|Ω|)44q²). This proof relies on the exact structure of the destination labels and permits neither arbitrary same-root plaintexts nor arbitrary reuse of seeds.

At κ=256 and a 2048-bit prime, all 8 public compression seeds use 6(2048+256−1)+2(2048+255−1)=18,422 bits. The four κ-bit and four one-bit outer headers use 4(4κ−1)+4(3κ)=7,164 bits, for 25,586 public seed bits plus 1,028 body bits and the source coefficients/framing. This example retains genuine intermediate keys and reduces both label and header sizes. A specific partial initialization can be included. Publish the true short labels X₀,W₀,W₁ together with all headers and all eight bodies. Compare these 3κ+T fields bitwise to independent uniform bits, keeping the same public-seed law; the total number of target bits is T′=7κ+4. Distinct roots give the same disclosed strings with probability q³. In the joint collision calculation this exactly cancels the additional 2^(3κ) normalization: fix the three indicated flags to one and use the same expression for F over the five remaining independent indicators. Explicit enumeration gives F_disclosed−1=106q+221q²−396q³+132q⁴≤164q for q≤1/4. Thus total variation distance is at most (1/2)√((2^T′−1)/|Ω|+(1−1/|Ω|)164q). At the displayed sizes this is below 2^(-125), and the issuance includes 768 actual disclosed bits. With X₀ alone the polynomial is 10q+41q²+104q³+52q⁴−236q⁵+92q⁶. This proves a complete two-gate distribution with real labels known on one partial input and both labels of another. The remaining Y labels are withheld. Giving all three required active input labels permits evaluation, and its output when accepting depends on β. No uniform-body approximation for that full interface is asserted.

### An entire honest input path with a simulator given only its output

There is a stronger variant with all three active input labels supplied. Give X and Y labels length 2κ each, W and Z labels length κ, retaining one fixed color bit per Z. Each label still has its own public compressor from its injective full signed tag, and each outer address is the same ordered concatenation of equal-length operands and their bitwise AND. Fix any input (a,b,c) independently of the seeds, set k=NAND(a,b), and let o=β NAND(k,c). The simulator, given (a,b,c,o), samples the honest law of all public coefficients and headers. Independently sample X_a,Y_b,W_c uniformly, and Z_k with its correct color and uniform suffix. Set the visited first row to Z_k xor its actual evaluated public hash, and the visited second row to o xor its hash. Fill the other six bodies independently uniformly. Output all headers, bodies, and the three active input labels. The honest evaluator follows both real rows and obtains o exactly, including in the simulated view.

To compare the laws it suffices to replace the three active labels, the implied active Z suffix, and the *six unvisited* bodies together by uniform bits. The number of compared bits is L=4κ+κ+(κ−1)+3κ+3=9κ+2. Program the two visited rows afterward by identical deterministic postprocessing. For two distinct roots, agreement on the active labels and Z suffix gives the exact uniform collision factor for those four strings. Condition on these agreements. The four unused-label equality flags U,V,R,S for the other X,Y,Z,W remain independent, with probabilities q²,q²,2q,q respectively for q=2^(−κ). Among the three remaining first rows, U+V+UV now have equal addresses. Among the three remaining second rows, R+S+RS have equal addresses. Upper-bound all equal-address payload consistency indicators by one. The normalized collision contribution from distinct roots is at most

    E[2^(κ(U+V+UV))] E[2^(R+S+RS)]
      ≤ (1+2q²·2^κ+q⁴·2^(3κ))(1+3q+10q²)
      = (1+3q)(1+3q+10q²) ≤ 1+13q   for κ≥2.

The first inequality enumerates the two binary flags in each factor. Noncolliding addresses have independent full hash-difference costs even after conditioning on the compressed labels. The diagonal root pairs have collision probability one. This gives TV ≤ (1/2)√((2^L−1)/|Ω|+(1−1/|Ω|)13q). We additionally checked the exact conditional collision sum for all eight paths at integer κ from 2 through 19 (144 rational inequalities). A rejecting path therefore hides β from its entire initialized two-gate view, and for an accepting path the simulator needs only the specified decoded bit.

At the 3072-bit safe prime in RFC 3526 §4 and κ=264 the bound is below 2^(-131). The eight compression seeds cost 8·3072+12κ−10 bits; the eight row headers cost 40κ−4. This totals 38,290 public seed bits, 1,060 body bits and 1,320 bits for the three supplied source labels, apart from coefficients and framing. The argument is selective for a single path. A party handed alternative input labels, a global source issuance mechanism, or a cycle tester obtains a different joint distribution. A generic circuit can fan out those labels and incur many output-width hash constraints on a single hidden label; the two-gate count does not pay for those.

For an acyclic binary circuit there is a coarse sufficient width condition for the same single-input simulator. Use a fresh tagged full address and public compressor per wire/value and independent outer headers. Concatenate both input labels injectively (and optionally a cross term) with canonical widths. Put the color bit in internal labels; primary active colors can be supplied by the selected input. Compare all active label random bits and all unvisited bodies to uniform, and construct all visited rows afterward using the public semantics and the given final output. Let k_i be each full short-label width, s_i the number of fixed color bits, t_g the output width of gate g (one for a final payload), and D_i twice the sum of t_g over all input *occurrences* of i. An unvisited colliding row contains an inactive input whose labels coincide on two roots. Each inactive input occurrence is present in exactly two rows. Charging every colliding row to one such occurrence gives total saved hash width at most sum_i D_i F_i, for independent flags F_i with probabilities 2^(−k_i+s_i) conditional on agreement of the active label pair at every wire. The off-diagonal collision factor is therefore at most the product over i of 1+2^(−k_i+s_i)(2^D_i−1). This also accounts for repeated inputs by charging occurrences. If k_i≥D_i+s_i+2λ+ceil(log₂(number of wires))+2 then the product is at most exp(2^(−2λ−2)). The same centered-count bound includes the diagonal term (2^L−1)/|Ω| where L is the sum of all active-label random widths plus the three unvisited output widths per gate. Choose an injective root bank with sufficient entropy and charge all these widths. This is a backwards width recurrence, potentially exponential in depth even for fanout one. The single-path simulator does not allow a public choice among many inputs or prove general WE.

### Cost and terminal boundary

In the LWR two-label version each output bit carries 3d+1 field elements in its header, plus its body, and the evaluator uses d cross products, a 3d-term modular inner product and one comparison. The cross product can be reused across bits on a fixed pair. Headers for different bits/occurrences are independent. Padding a fresh encrypted row requires modular arithmetic, canonical bit decomposition, and comparison under the actual FHE, including noise, relinearization and ciphertext serialization where applicable. Binary Toeplitz arithmetic is linear on encrypted bits given public headers, but forming/canonically encoding a field product is not free. SHAKE on encrypted labels incurs its full Boolean permutation and input/output cost. No machine clock or capped WE certificate follows.

A full-field pad polynomial in a scalar τ of public degree at most D has outputs in the publicly specified evaluation coefficient matrix applied to (1,τ,...,τ^D). With more than D+1 outputs its left nullspace contains a nonzero relation; independent uniform field outputs satisfy that relation with probability 1/p. This calculation concerns exact full-field outputs with fixed known coefficients; it gives no linear relation for rounded bits or SHAKE. The bit-entropy construction trades expansion for an unconditional result.

Row confidentiality does not establish that derived labels have the provenance claimed by a cycle/annihilation tester. In particular a separated xor of two unary KDF outputs can interact with the allowed affine operations; see the discussion following p.19 of [Kluczniak](https://eprint.iacr.org/2020/1502). Our cross-input encoding and nested PRF do not prove authenticity or annihilation either. A terminal record depending on τ^M, source-derived ciphertexts, or a consistency opening beyond the supplied target samples cannot be generated by either reduction above. A WE construction still needs a source delivery and terminal simulation for the full public transcript, a quantum advantage/time accounting, and the registered concrete machine bounds. Adopting the new computational experiment would need a separately reviewed assumption submission; the frozen WE assumption registry is unchanged.
