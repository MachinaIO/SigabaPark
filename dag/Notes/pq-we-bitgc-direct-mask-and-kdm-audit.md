## Conditional row construction

Fix a public Boolean circuit T with I input bits, G gates and O output bits. A row computes T(theta,x), with private slot parameters theta and message input x. Figure 3 of Liu, Wang, Yang and Yu, [BitGC](https://eprint.iacr.org/2024/1988), gives private, one-evaluation garbling. Each row generates independent (s,t), where s is its global label offset and t is an auxiliary SWHE key, as well as the encrypted seed bank and fresh label coins. The garbler knows both labels and their semantic ordering. For a semantic bit h the external input label is W0+(-1)^pi h s in Rp, pi=LSB(W0). Public data comprise switching and conversion hints, the encrypted seed, the public correctness-PRF key, masked wire bits, output decode bits and the selected labels. Only the selected label for each private input should be delivered. For example, use an authorized selector for a theta wire, with the data encryptor providing the selected x label. Figure 3 alone gives no such selector or common setup between independent generators. Neither the zero labels nor the input point bits are public on private inputs. Seeing both labels of a wire recovers the offset up to sign (and the known semantic ordering resolves it). Applying this formula to independent rows is safe only under the separate transfer and transcript hypotheses. Each row needs a proof for its *whole* view. The source simulator takes one fixed input/output pair after the template is fixed. An adaptive key query after seeing the row, cross-slot auxiliary data or the master encoding information requires further work.

**Direct variant.** Delete the low-depth PRG. Independently sample r_i for each of I+G wires, put fresh ordinary GSW encryptions of these bits under s in the public bank, and use them directly wherever Figure 3 homomorphically expands the seed. Keep the unoptimized input stitches. One can also sample independent public R_g in Rp, once per gate, in place of PRF(K,g). The latter is precisely the ideal randomness used for the correctness analysis in Appendix A.1. All parties and simulators use the same public table. For privacy, adapt Appendix A.2 Hybrid 1 with the same real selected labels sampled in the alternative order. In Hybrid 2 a reduction samples the r_i itself and submits (r_i,0) challenges under the common params, with a hybrid per ciphertext if using single-challenge CPA. The wire masks are now independent of the dummy ciphertexts: the paper's seed-to-uniform Hybrid 3 is unnecessary. The replacement of successive masked stitches by uniform in Hybrid 4 works as before, with a fresh pad for each wire. The output simulator computes its decoding bits from the known output and simulated labels. This conditional argument saves the private PRG assumption and homomorphic PRG circuit, and the optional public table saves the PRF assumption. It still needs joint-parameter CPA with the appropriate distributed-decryption correctness, concrete losses, and a time-bounded machine implementation. For NAND the required HE multiplication depth falls from d_PRG+2 to two. Propagating gates use freshly supplied encrypted r_i, so this depth counts operations within each gate template, not the depth of T.

## Which key-dependent distributions remain

Write c=q/p, h=2^j, n for ring degree, ell=floor(log2(q))+1, D=2 ell. Section 5.2 draws independent small s,t with first coefficient exactly 1. Errors are fresh small ring elements from the bounded distribution, without that condition. Two fresh independent uniform ring samples a,a' give (a,as+e+c t), (a',a't+e'+c s). The conversion table draws one more uniform D-vector A and independent D-vectors E1,E2,E3, and publishes
(A,B1=A s+E1,B2=A t+E2,B3=B1 t+E3+Powersof2([-s,1])t).
Products with secrets here are componentwise ring products. Its first ell shifts are -h s t and its last ell shifts are h t. B1 is also a base for B3, while A is used for both B1 and B2. Appendix C, Hybrid 0 to 1, explicitly assumes the *joint* replacement of these three hints by encryptions of zero, in a view containing the challenge ciphertext. In the zero world B3 still uses B1 t. Section 5 requires p even, p dividing q, large p and q/p^2 growing faster than polynomial times (D+1)^L n^L as specified there. The two secret laws, fixed first coefficient and noise widths must be reconciled with the registry's i.i.d. coefficient law. A reduction that conditions on a coefficient needs its success probability and patched ideal law, too.

CircularRingLWE.sampleLaw in the pinned core instead gives independent uniform row bases A_i, one secret z, and shifts -2^j aut_k(z) under z; plain RLWE uses zero shift. No second independent t, shared base, or dependent B1 base is supplied directly. In particular, changing both keys by u,v changes the mixed difference of st by uv, whereas a separable affine expression in s and t has zero mixed difference. The directions can respect fixed first coefficients: in degree n≥2 take u=v=X; X^2 is nonzero modulo X^n+1 (at n=2 it is -1). This tests the formal shift identity, not the probability of all four points under a given secret law. This eliminates a direct affine matching of that shift; it does not rule out randomized embeddings, noise transformations, extensions of the ring, or a new proof.

A fresh pair per depth alone retains s_j→t_j and t_j→s_j inside *one* correlated decryption (switch a share, decrypt in the auxiliary basis, switch the output share back). A topological order for both strict directions does not exist. Switching the output to s_(j+1) instead changes the base of the label difference while the ordinary summands in the same Eval step still have offset s_j. A repair must switch every summand consistently, make a compatible encrypted wire-mask bank, preserve the lifting/rounding laws, and simulate the shared-base product hint; a directed edge list does not prove any of these. Taking t to be an automorphic image of s changes their product law and leaves a quadratic shift. For arbitrary NAND masks u,v the mixed coefficient g00+g11-g10-g01 of the masked truth table is -(1-2u)(1-2v), always a signed unit. Public sign corrections preserve this. Therefore the mixed correlated-decryption summand does not vanish by fixing the NAND template; this is a local obstruction to deleting that call, not a lower bound on alternate implementations.

## Expanded honest cost

In the uncompressed fixed-width Figure 3/§5 encoding, let Q=ceil(log2 q), P=ceil(log2 p). Two two-element switches and one four-vector conversion table cost (4+4D)nQ bits per fresh row. A flattened GSW ciphertext in R2^(D×D) costs nD^2 bits, not a single bit or ring element. The seed bank costs lambda nD^2 bits. Add the lambda-bit public PRF key, I+G stitch bits (or G using the paper's separate input optimization), O output bits, and I nP bits of selected input labels across whichever transport carries them. Public shape, table indices and serialization can add cost. If using the direct variant, substitute (I+G)nD^2 for the encrypted bank; if using independent public R_g, substitute G nP for the PRF key. Unrelated rows each need their own key-dependent hints. Public parameters independent of secrets can be shared; reusing a row offset requires a joint-view proof. The raw seed bank alone reaches 2^32 bits at lambda=128, n=512, ell=128, and grows monotonically in those dimensions. No inference is made that these bounds are forced by 128-bit hardness. Even the direct bank for one I=128,G=4096 row contains 4224 ciphertexts. Bit length alone lower-bounds a fresh single-bit-output-tape serialization time when each output bit is written individually; it is not a measured machine time.

Each side evaluates the homomorphic PRG in the seeded variant plus a constant number of HE operations per gate. A literal flattened multiplication uses a D-by-D polynomial matrix product and bit decomposition; naive multiplication uses D^3 ring products before flattening. There are two ordinary and one correlated distributed decryptions per evaluated gate; the garbler computes both provisional and signed label sums. Correlated decryption performs two share switches, a bit-decomposition-driven conversion using four length-D ring inner products, ring products for the bilinear share expression and rounding. There is no constant cost per ring operation in the registered Turing machine. Bounds on all lifting/rounding errors must be accumulated across all gates, rows and evaluations (Appendix C and Lemma 1). The source's negligible asymptotic error does not supply the finite target.

The compact gate stitches help transport a fixed large circuit with relatively few input bits when its one-time setup can be charged. In recursive WE, the sizes of D/AGG must include generation/encoding of child objects, key material, evaluation and outputs. Each input bit represented by a literal wire label costs nP bits in its next encoding. Reusing the 4096 original predicate gates as the size of these derived circuits would omit that work. No concrete registered KDM reduction, end-to-end false-instance hybrid, finite correctness margin, or canonical-machine upper bound was established, either at the exploratory 2^32 mark or the registered 2^100 cap.

Three companion Lean results check the expanded seed-bank inequality, the mixed finite-difference identities and the signed-unit NAND calculation. The distribution and simulation arguments above are paper audits or conditional designs.
