### Raw products and their quotient

The odd residues modulo eight carry two additive characters, the sign bit S and hiding bit H. Pairing signs a,-a,b,-b on the four legal NAND rows gives H = [a differs from b] times the NAND discrepancy. The sign bit is sign(a) xor y xor ([a differs from b] and x). The character code is multiplicative on all odd residues. For any nonempty all-NAND(true,true) circuit, the two traces with all claimed outputs zero except for an optional flip of the last output give a deterministic public decoder: recover the message as H at the first trace xor the complement of the change in S. This includes 4096 gates. For the H quotient, simultaneously flipping one sign at the last gate and one at the terminal test translates between messages at all traces, even when the claimed prefix varies. Both assertions concern the joint public view.

### The native coefficient bank

For every NAND gate, emit its canonical square-free residual h=1+z+xy and the three products xh, yh and zh. Append the final accepting-output residual. The empty program has zero terminal residual. Constant wire zero and every unavailable operand evaluate to true. An accepting witness opens every coefficient packet to the message. Under independent fair coins the number of preimages of every public packet is identical for both messages exactly when the constant lies in the binary span. Outside that span a public linear functional recovers the message from the complete coefficient vector on every coin choice. Keeping private factorization syntax changes those public laws. More generally, a semantic equality after linear interpretation allows a residual in the kernel of interpretation; exact coefficient equality allows only the zero residual. Randomizing a span of provably null representations repairs precisely the residuals it contains.

For 4096 gates the specified local bank has 16385 coin bits and a conservative dictionary bound of 49155 coefficient bits before framing. A checked NO fixture escapes this bank: its 4118-coordinate packet admits a twelve-position separating parity. Adding producer residuals times sibling operands repairs that fixture and raises the conservative bound to 73731 coordinates. A different padded NO fixture with an eleven-gate core then gives a sixteen-position separator among 4128 coordinates. The latter two counterexamples and the one-step fanout bank are computational experiments. The Lean coefficient theorems prove the general coset criterion and native correctness of the four-row bank.

### Aggregate the reverse refutation before choosing a representation

Using a sparse table of wire weights, the reverse pass removes each output weight and adds two contributions at its parents, including both contributions when the parent is repeated. On any claimed trace, the output constraint plus the weighted sum of all residuals equals one minus the authentic output on the same primary input. The theorem uses the native evaluator and quantifies over arbitrary nonempty gate lists, input bits, forward references and claimed gate bits. It proves the whole telescope. The weights are evaluation-dependent; exhibiting them as an arithmetic circuit does not hide the coefficients used to publish that circuit.

The aggregate on the right depends only on the original inputs. NANDPrimaryMask constructs the canonical algebraic normal form C on these inputs by symbolic execution, without expanding any claimed-trace variables or separately publishing the reverse multipliers. Its global generator is 1-C. Encrypt by publishing the full square-free coefficient table of m+r(1-C), for uniform r in GF(2). Evaluating at an accepting witness recovers m. For every NO statement, canonicality gives literal C=0, and the translation r to r-1 preserves the entire ciphertext when m is changed by one. Canonicality follows by testing an inclusion-minimal nonzero monomial on its own indicator assignment. This is an all-statement mathematical baseline. It requires exact symbolic evaluation of the circuit, and the dictionary computation, machine description, output framing and clock are unpriced.

Translating input coordinates by any circuit-dependent public bit vector preserves this argument and can shorten particular expressions. It cannot give a uniform small explicit ANF. A four-bit EXACTLY-TWO block has ten or eleven nonzero coefficients at each of its sixteen possible centers. For 32 disjoint blocks joined by AND the supports multiply, with each term uniquely specified by its tuple of disjoint local subsets. Every one of the 2^128 input centers gives at least 10^32 terms. Complementing the constant removes at most one, so one coin branch of the explicit dictionary exceeds 2^106 term positions. The support and count are proved in Lean. Lean also checks the 55-gate native four-input block on all sixteen inputs. A native test assembled six four-literal minterms per block, reusing four NOT gates, with 55 NANDs per block and 62 more for conjunction. This gives 1822 gates and 2274 padding gates up to 4096. The test checked every single-block truth table in context and randomized accepting and rejecting inputs. Factored and decision-diagram representations have different sizes and require their own public-law argument.

### Exact black-box query boundary

Consider a classical encoder that accesses an arbitrary Boolean predicate only by value queries. For each message and coin outcome keep the positions queried on the zero predicate. The transcript remains fixed when all those answers remain zero, also for adaptive encoders. Suppose every singleton predicate decrypts perfectly for its witness and the entire public zero-predicate law is identical for both messages. Take a common zero-predicate ciphertext and its two coin preimages. Their query sets cover the domain: a missing position defines a singleton predicate on which both runs have the same ciphertext, contradicting correctness. Thus any uniform worst-case limit q obeys 2q at least the domain size.

The lower bound is attained exactly. Split inputs into equal parts by the first bit. For message b search its half. If any satisfying witness is found return an explicit tag b; otherwise return a common sentinel. From the sentinel and any valid witness the recipient recovers the side opposite that witness. On NO the sentinel is certain. For 128 input bits each half has 2^127 positions. These are predicate queries, not registered machine steps. Explicit public gate structure, non-black-box preprocessing, computational hiding and approximation fall outside this lower bound. No capped registered WE machine is established.
