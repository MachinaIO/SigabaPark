### The residual computation

For gate z=NAND(x,y) insert (not x or not y or not z), (x or z), (y or z), and require the final output. The constant wire and forward references read true as in the registered evaluator. Remove duplicates, tautologies, and satisfied constant clauses. A core hitting each surviving ternary clause gives, conditional on its bits, a genuine 2-CNF even when the core enables a binary edge *between* hidden variables. PR 93 handled the special case of unconditional hidden binary constraints and guarded units. PR 227 studies a generic shared-completion route; we give a concrete way to process, merge and release its guarded residual on a width-dependent class. No assumption about the adversary following a fixed honest evaluation is needed for the explicit graph below.

There is also an exact relative encoding. Partition coordinates into blocks, choose one anchor per block, fix its relative bit to zero, and transmit the other relative bits r_i=w_i XOR w_anchor. Hidden orientation y_B gives w_i=y_B XOR r_i. The Lean theorem relativeFiber proves the exact existential equivalence for every predicate on the entire trace. Hence if each gate involves at most two blocks, evaluate the predicate on each of up to four orientation pairs and exclude every invalid pair with a guarded binary clause. Pin constants/output in the same way, with units. Only the guards on the transmitted relative bits enter the public schedule. The term 'transmit' describes input to the verifier; publishing both choices of a cryptographic authenticator requires a security argument.

For any fixed guard assignment the binary graph contains a contradictory SCC exactly when a complementary pair is mutually reachable (also reject an empty clause). If a complement-closed terminal set T meets every directed cycle of the possible edge graph, every contradictory SCC intersects T, and an intersecting terminal's complement belongs to that SCC by contraposition of paths. Propagating possible paths through the acyclic nonteminals for each source terminal and then closing the terminal graph costs O(|T|(V+E)+|T|^3+E) Boolean operations, with fixed layout. The terminals select an implication graph test; they do not store guard bits that must be reused later.

We instead stream constraints in a fixed public incidence order; read each core bit once, when first required, and keep it until its final use. Add each enabled binary clause to a finite presence table. At the last occurrence of a hidden variable x, eliminate it. For all present clauses (x or p),(not x or n) add (p or n), including the case in which p or n is the constantly false empty disjunct of a unit. Signs p,n range over remaining live literals. Discard tautologies, merge repeated literals into units and duplicates into one presence bit. Remove all clauses mentioning x. Keep an empty clause as a rejecting flag. Every unprocessed clause mentioning a variable has to be accounted for before that variable can be forgotten; the schedule is public. Equivalence with existential completion follows by induction from the Lean theorem eliminate, which preserves an arbitrary future constraint independent of x. Its predicates include inactive-guard placeholders equal to true. This subsumes paths that pass through many previously forgotten variables. A future edge can make a cycle through forgotten variables, which is why dropping all their incident edges without the resolvents is incorrect.

With f live hidden variables, there are at most 1+2f+2f(f-1)=1+2f² distinct non-tautological clauses of size at most two. A pivot update considers at most (2f+1)^2 pairs. With c live core bits, at most 2^(c+1+2f²) different summaries occur in a layer. The constants and the public layer index need no state bits; if a rejecting flag is set it may immediately merge with the rejecting state. Nodes with identical summaries merge even if the prefixes differ. Advance through deterministic updates between successive first reads. The resulting ordered branching program has two outgoing transitions per nonterminal node. Construct reachable nodes by memoizing the exact successor summaries, at the cost of emitting and comparing those states. This worst-case upper bound can be enormous. With a fixed protected terminal set one may instead maintain the boundary/terminal clauses until a chosen layer and release the remaining fixed small SCC predicate; protected variables count in f. Secret-dependent traversal of the host graph is unnecessary in the explicit-program construction.

### What happens to 2^63 different accepting cores

For the 64 disjoint NANDs followed by a left-associated XOR of their 64 outputs, choose the 64 first outputs and the 252 XOR-gadget outputs as core bits. Hide the primary inputs. For any fixed first output its two private inputs exist (for zero use 11; for one use 00), and immediately eliminate them together, without conditioning other gates. Read first outputs in sequence, checking each four-NAND XOR as soon as the new first output is read. The first output initializes the accumulator. On later blocks one retains the previous accumulator, new output and at most four local gadget bits, checks all four NANDs and retains only the updated accumulator. The optional 1890 double-negation padding pairs preserve the final value and can be verified by their binary constraints or contracted by explicit NOT composition. Each of the 2^63 odd 64-bit patterns still supplies a distinct, valid core (the other core bits are determined). All of them pass this same layered verifier. This preserves the meaning of the core even for supplied invalid XOR intermediate bits, which must be rejected. A conservative explicit representation uses at most 64 live bit states plus a rejecting state at each of 316 core reads, at most 20540 nonterminal nodes, no table of all possible core words. The local-elimination and scheduling argument works independently of the parity simplification whenever the indicated frontier stays bounded.

### A ciphertext for the public layered read-once graph

Use the registered rank-one Module-LWE distribution in a power-of-two negacyclic ring of degree N. Let q=2^w, w at least three, error coefficients independent CBD(1), all node secrets independent uniform ring elements. Associate a different secret s_v to every node including the single accepting endpoint, even when two layers describe the same state. Add a rejecting endpoint as needed. The statement-independent challenge has m=2w ring rows. Draw the same vector A of m independent uniform ring elements for all node headers. Send A, the initial key, and each nonterminal's m responses

    b_v = A s_v + e_v + (q/2) EncBits(s_child0 || s_child1).

EncBits writes the w binary bit planes of each child's N coefficients to w ring elements with coefficients zero or one. Repeated child targets within or across nodes use the same child key. At the single accepting endpoint publish the first response only under its key, shifting coefficient zero by (q/2) times the payload. Other coordinates encrypt zero. No public decryption key for that endpoint is released. On an accepting core, starting with the public root key, select the w appropriate rows, subtract the A s_v products and round each coefficient. The absolute error is at most one, strictly below q/4, so the child key is recovered exactly. Noise restarts at each transition. At the terminal recover the payload the same way. A valid registered witness produces a core by evaluating its NAND trace and reading the scheduled coordinates or relative parities. Distinct witness inputs may take different paths and recover the same bit.

On a NO graph the accepting endpoint is unreachable from the root when both outgoing bits are allowed at every read. Replace outgoing responses of unreachable nodes, including the terminal row, by independent uniform bodies in increasing layer order. A target node's own secret is never sent as the root. Every incoming edge carrying its key was emitted by an unreachable *earlier* predecessor and the entire predecessor row body is already independent uniform. A reduction can therefore embed the unknown challenge secret as this target, use the challenge A as the common A, sample all other keys/errors, and compute the target response by adding its known children encoding (or the bit) to the challenge body. In an ideal challenge, adding a known shift to uniform bodies gives exactly the next hybrid. For the one terminal row simply discard unused challenge rows. No secret is reused for a different node. This accounts for every public header even if the evaluator opens or combines many branches. In the final hybrid the message only affected the now-uniform terminal, hence the two final distributions coincide. A nonuniform reduction may fix a hybrid index or a uniform reduction may select a random index; charge graph reachability, sampling and full formatting. For U replaced nodes a conservative per-world sum bounds the distinguishing gap by 2U times the maximum single-challenge gap. With squared advantage and simulator/attacker cost ratio K, the corresponding bit loss is 2 log2(2U)+log2 K. The classical registry has no quantum Machine certificate; on classical challenge strings the same distribution argument is valid for quantum distinguishers subject to an appropriate quantum assumption.

The honest raw accounting is mNw bits for A, Nw for the initial key, mNw for each of V nonterminal rows and Nw bits for the terminal. Also pay for topology serialization or its deterministic reconstruction and the original unary circuit parser. For N=512,q=128,w=7 this is 50176(V+1)+7168 bits, before that overhead. The simple issuer performs mV plus one ring multiplication, and a decoder on a path of d edges uses wd plus one; small-error generation, key bits, key indexing, and arithmetic are also charged. For the 20540-node upper bound the raw bank is below 1.04 billion bits, which is not a machine clock bound. The concrete estimator strength, full reduction cost and total time must be certified for any claimed cap. The public graph admits an even cheaper O(V+E) reachability decision, after which the issuer may send the message on YES and a fixed zero on NO. Thus the encrypted graph gives a reduction-preserving reference and does not establish a cryptographic advantage over clear processing of the same graph.

A graph with repeated, independently selectable reads of the same bit has a different semantics: a width-two test can accept exactly when the first value is true and the second false. It rejects every consistent word yet has an accepting path whose terminal key is delivered by the headers. The read-once construction pays for every bit kept across such an interval. Issuing rows for a succinct transition circuit without enumerating the states and preventing inconsistent rereads inside its public transcript are the missing steps. Neither row marginals nor garbling both labels under ordinary single-execution simulation closes these obligations.
