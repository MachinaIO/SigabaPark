# Task summary: Bind partial lock openings across evaluations of a single NAND statement

Task `319e5c34-b2db-4aaa-b478-1b61c795ca0d` (design / deepen), goal `e30dec5ceb4bf12756c8bfa37ac656e9185a83c224ed8b452446988fc9d1832b`, outcome `verified_partial`. Mathematical status comes from the records, not from this note.

The package establishes algebraic conditions for branch-indexed affine refutation masks and analyzes a guarded single-coordinate ring phase terminal. The full NO-view coupling uses a separate multiplier at each branch where its residual affine system is inconsistent. In the guarded terminal only a selected phase bit is needed; the finite replays cover noisy opening, fixed quantizer bounds and small ideal distributions. The helper size depends exponentially on the number of remaining branch bits. Finding a succinct family of certificates for arbitrary NAND instances, proving the full source hardness and pricing the complete registered implementation remain open.
