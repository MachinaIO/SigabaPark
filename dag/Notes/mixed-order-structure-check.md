For 124 data bits and four public selector bits, decode the encoded gate list and run the public compiler on all sixteen selector values. Each pass starts with symbolic data inputs and constant selectors. The fold implements the registered constant wire, default-true forward references and last-gate convention. An equal-wire NAND is a Boolean negation. Constants simplify before a general NAND is formed. The size-limited version rejects an intermediate tree larger than its chosen budget and checks that data leaves in the final cofactor have distinct names. The variable order is the leaf order of that branch. No claimed branching program, witness, or advice accompanies the gate word.

Theorem compile_sound proves agreement with evalGates for every gate list, address and assignment. A successful decideWire supplies a valid read-once tree for every address by checked_all. Theorems whole_cube, whole_data_affine and whole_addr_affine prove that the address interpolation agrees with the complete circuit on Boolean points and is affine in every coordinate over any commutative ring. Thus over a field this is its multilinear extension. This remains valid when different branches use different leaf orders. Products on overlapping supports can produce a square in a named variable and fail the check. Complementing a repeated NAND operand before extension avoids this error.

A read-once tree also has an exact Boolean range, computed without a field operation. Disjoint supports let two independently attainable values be realized on one assignment. Theorems decideWire_sound and split_witness connect this test to the full-length Boolean witness. On the recognized class, encryptWire_yes releases the message as one bit and encryptWire_no always releases zero. Identity decoding suffices on all satisfying witnesses. Recognition and failure depend only on the statement. This decision route uses no packet, random probes or cryptographic assumption.

A separate direct evaluator keeps four kinds of wire records: unknown, fixed false, fixed true and nonconstant on a stored support. For a nonconstant record the invariant provides both a locality proof and a witness for each output value. Disjoint live operands can therefore be combined. An inconclusive overlap becomes unknown, which a later false NAND operand can mask. The theorem decideWord_sound proves that an accepted direct decision is exact. The direct evaluator only computes the decision and can forget the expression needed for a field evaluation.

An executable check shifted the 2993-gate matching-bank example into the registered wire convention, padded before its last gate to 4096, and round-tripped its 19916750-bit nested-frame encoding. The compiler reconstructed the sixteen distinct branch orders of that bank. Its largest intermediate had 308 nodes, below the chosen 512-node limit. This does not certify a common-order lower bound for that particular bank. In 400 random small cofactors, exhaustive Boolean evaluation and exact field interpolation agreed with every accepted case. The outcomes were 55 NO, 318 YES and 27 inconclusive. A repeated-variable tautology and an oversized intermediate exercised both rejection paths. In the earlier point-predicate example a 384-coordinate span packet exists. Deciding the range directly removes that packet whenever this structural recognizer accepts. Acceptance of all circuits with a small branching program remains open.

For the direct evaluator a record can use two tag bits and 124 support bits, or 532350 logical bits for all 4225 wires. With operands already interleaved, machine_run and run_finsets implement their support union and disjointness by a 36-state, zero-work-tape machine. On 124 coordinates its clock is 499, its transition table costs 2160, and its total cost is 2659. One use per gate and address would account for 32702464 local steps. The table can be shared by a single dispatcher only after supplying its construction. The pure nested-frame decoder inverts the registered encoding. The gate-word upper bound is 103821312 bits before its outer tuple frame.

A sequential layout using four full traversals of the record tape per gate and address would traverse at most 139552358400 record bits in those traversals. This is a conditional layout count. The actual machine for locating both records by the decoded unary indices, copying and interleaving them, restoring head positions, parsing the outer parameter and input frames, resetting per-address storage, issuing framed output and decoding it still requires construction. Its worst-case clock and transition table, and any all-circuit fallback, must be charged before asserting the registered cap. Returning the message on an inconclusive false statement leaks it, while always issuing zero loses correctness for inconclusive true statements.
