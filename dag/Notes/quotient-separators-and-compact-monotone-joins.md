### Which quotients actually glue

A separator summary q is safe if subtree extension depends only on its value: any extension from one representative can be transported to every representative (quotientLift). It suffices that each summary class be an orbit of an action on the subtree satisfying assignments inducing a transitive action on its separator class. Coarser summaries also work given the same extension proof. Generate local signatures from an actual bag tuple, retaining the output summary and the projected summaries for all children. When compatible child summaries are reachable, fix that one tuple, transport each child extension independently to the requested concrete boundary, and paste. Output-summary reachability must in turn lift to every parent-requested representative. Passing a hash that agrees on only some representatives does not prove either property. To avoid enumerating all bag tuples just to create the quotient, supply a constructive generator of exactly the feasible local signatures, for example by fixed representatives of count classes or disjoint Boolean group summaries. The honest machine must validate the public grammar or cover for its input circuit.

There is an additional opportunity when the signature relation is itself dense. For parent state p its reachability is the monotone Boolean function OR over rows producing p of the AND of their required child-state availability bits. Any equivalent public monotone circuit on these availability bits suffices. Give each internal true signal a fresh label, implementing AND by one grant needing all inputs and OR by a separate one-input grant per incoming signal. The same topological hybrid applies to a shared acyclic circuit; number every outgoing use of a label distinctly. For example a node accepting some pair i<j from left/right sets on M ordered labels naively emits M(M-1)/2 pair rows. Form the prefix OR of available left labels using a chain, then AND its (j-1)th prefix with the jth right label and OR all these outputs. This uses O(M) grants and input labels. It works even with many simultaneously reachable labels. General nonmonotone tests on which labels are 'absent' do not follow from possession of individual true labels.

### A 4096-gate instance with distinct overlapping 88-bit separators

Divide the 128 primary bits into disjoint ordered groups A,B,C of sizes 40,48,40. Let a,b,c be their respective ORs. The two child bags test a != b on A union B and b != c on B union C. Their parent uses all three summaries and a one-bit public root predicate. Two fixtures use (a≤c) and ((a!=c) OR (a=b=c)), respectively. Both have six locally allowed root triples. The former has two globally allowed triples; the latter has none. OR is surjective on every nonempty group and each leaf depends only on two ORs. Any representative of its 88-bit separator having the specified summary therefore works, including arbitrary positive weights. This is a four-state quotient per edge. Enumerate only the eight group triples and the four pairs per leaf. The real issuer selects its root predicate from syntax, with no query asking whether the conjunction is satisfiable. NAND implementations use conventional two-input AND, OR, XOR and NOT macros, pad with NAND(1,1) before a final output-preserving gate, and contain exactly 4096 gates. A syntactic recognizer can limit this specialization to these macros; broader semantic equivalences require proof.

Both layouts use nine independent labels (four per child, one root), four published leaf keys, six root grants and one terminal bit. There are twelve child-pad usages across the six root grants. Each side has two states of fanout two and two of fanout one, so real encryption uses four doublings (eight native ring rows). Thus the packet, excluding public circuit/format descriptors, has 10*12288+24576+1=147457 bits. Uniform coin demand is 9*12288+24576=135168 bits. In the false fixture all four expanded state keys are unreachable; the h bound here is four. In the true fixture every correct witness uses one expansion for one of its two child keys, and the other pad is the one-use key itself. Conventional schoolbook negacyclic arithmetic uses exactly 8*N²=33554432 coefficient product/add terms on encryption and 2*N²=8388608 on true decryption, plus error additions, XOR, parsing, tape movement, label allocation, and serialization. Signed ternary secret coefficients permit add/sub/skip specializations. These are static elementary terms and exact serialized field bits, not measured multitape clocks. The companion replay checks every OR-state combination, multiple representatives, both payloads and an actual two-row N=2048 seeded expansion.

In general let J denote all bag-state labels, L all published rows, U the total child slots across those rows, and f_s an individual fanout. With implicit public numbering, raw bits are (L+2)*lambda+1, random bits (J+2)*lambda and source calls sum_s max(f_s-1,0) ≤ U. A candidate algorithm may branch on k crossing bits, construct fresh independent labels/pads for every restricted problem, encrypt the same bit across all 2^k branches and let the witness select its branch. All branches are false on a false statement. Charge their sum of sizes and hybrids; a common independent public A is permissible under the top-down proof with all other banks simulated using that A. For very wide separators with no certified quotient, or when the local monotone matrix lacks a small circuit, explicit 2^width dictionaries or Cartesian rows exceed budget. A single all-encompassing bag or exhaustive branching can give exact logical coverage at excessive cost. Public finite tables of the claimed size already permit a bottom-up Boolean reachability SAT decision; the cryptographic contribution here removes such tests from honest issuance and provides joint simulation. Neither a universal small decomposition/quotient nor a registered full-machine clock was established.
