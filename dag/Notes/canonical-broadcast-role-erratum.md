### Correction to the published role claim

The machine and cost in [PR 192](https://github.com/MachinaIO/SigabaPark/pull/192), including the note “Exact constrained broadcast separators on the all-live K91 NAND circuit”, used an outer frame around Gates.unparse. The registered relation's encStmt uses encGates. The old cost of 1,286,883,714 is the actual cost of that old machine. Its claimed correctness on canonical encodings of the recognized YES statements is false. The arbitrary-boundary count, five-state scan and semantic separator arguments do not depend on this serialization mistake.

For a parent pair (a,b), encUnary(a) is a ones. The registered encGate is encPair(encUnary,encUnary), which frames the first operand and leaves the second unframed. The encGates list frames each pair; the machine then receives encodeTuple of paramsWord and the role variables, framing the whole statement once more. Excluding the last outer terminator, a physical gate chunk is exactly

    1^(8a+3) 0 1^(4b+1) 0.

The frameCircuit theorem proves the concatenation of these chunks followed by zero equals frame((relation n s).encStmt φ) for every actual circuit φ, without any validity or topological assumption. In contrast, the old expected chunk was 1^(2a+1) 0 1^(2b+1) 0. Its first unordered K91 pair (1,3) allowed just the ordered physical run lengths (3,7) and (7,3). No registered pair has either shape, as oldDisjoint proves. Thus the old matcher even rejects the entire nonempty canonical statement domain on the registered parameters. On a full-size satisfying K91 test with bit one, the old transition returned the zero ciphertext frame in 1171 ticks. The old machine's privacy on false statements is consistent with this behavior, but its claimed decryption on recognized positive canonical inputs is not.

### Canonical K91 replacement

CanonBroadcastRoles defines the CanonicalBroadcast and CanonicalTaggedBroadcast namespaces, each with arbitrary-clock registered Machine values enc, dec and the entire control program. The K91 replacement compares both physical parent orders, charging the distinct lengths of the first and second runs. Swapping an unordered pair now generally changes the number of input bits. The second-stage role skips three actual framed variables (parameters, statement, witness), then copies the last framed ciphertext. For the canonical 91-slot schedule, every assignment obtained by using primary bits 1 and 3 true and the other 126 false gives acceptance, independent of the parent swaps. The swapping theorem proves invariance of the registered evalGates under arbitrary local parent permutations. The complement of this matching family gets a fixed zero ciphertext. Thus all NO ciphertext distributions agree, and the stated YES family decrypts correctly for every satisfying witness. Unrecognized YES inputs remain outside this correctness guarantee.

The encoder checks the complete 1031-bit parameter frame against its four zero positions; a physical gate mismatch, a premature blank, a malformed message frame or a trailing symbol after the matched word goes to fixed zero. The final bit is buffered until the payload terminator and end of input have both been checked. On honest inputs a two-mark work tape checks a chunk of 128 consecutive ones by moving out 64 cells and returning, which costs 129 ticks. At most one branch jump is charged per pair. The largest possible 4096-gate K91 body among all orientations is 102,089,712 bits, obtained by placing the larger reference first independently at each gate. Charging the ruler's return tests, setup, parameter frame, payload and terminal states stays below 105,000,000 ticks even on an early mismatch. For either role's decoder the fixed upper bound on encGates length is 4096(6·4224+3) bits. Framing it, adding parameters, the 128-bit witness frame, ciphertext and final blank fits 210,000,000 ticks. The declared clocks also cap arbitrary malformed inputs.

The K91 encoder has 4,241,718 states, one work tape and a 2,366,878,644-bit canonical transition table. The decoder has seven states, zero work tapes and a 294-bit table. Their combined cost is **2,681,878,938**. This includes matching the actual circuit statement, both clocks and both machine descriptions.

### A canonical family containing both satisfying and unsatisfying instances

A separate K90 machine handles 4096 gates: the first is (0,0), yielding a false wire F at index 129. The next 90 slot gates are NAND(t_j,t_j) with t_j chosen among 0,129 and j (1≤j≤90). The slot value is respectively fixed zero, fixed one or free (the complement of the corresponding primary). The remaining 4005 gates are the broadcast/combine schedule on these slots, omitting the final inverter. Their parent pairs may be reversed independently. Thus there are 3^90·2^4005 such statements. Unlike the K91 orbit of a single positive fixture, fixed tags can force either terminal bit; with free tags the same class includes instances whose acceptance depends on their witnesses.

The tag prefix is read from the actual gate encoding. Even repeated ports require different lengths: each t has a first run of 8t+3 and a second of 4t+1. On the negative side of the ruler tape, marks at −4 and −2 permit groups of eight and four respectively without enumerating every position in the control. Check equality of the two parent values before continuing. Store a bit mask of possible five-state scan states. For each free slot take the union of both bit successors, and for a fixed slot take the prescribed successor. These are exactly the reachable states by induction on the slots, since free tags designate distinct primaries. For the final tag accept the profile if at least one reachable state has final accumulator one. A negative mask decision can immediately emit zero even on a later malformed body. A positive decision checks every remaining gate pair before releasing the message. An off-template statement therefore cannot trigger a message-dependent output unless it is precisely a recognized YES member. The decoder copies the ciphertext as before.

The K90 body has at most 102,112,374 physical bits and the tag prefix (excluding parameters) costs at most 6+90·(12·129+6) bits. Before returning to the body ruler there are at most 2·90·129 additional return checks. These and the body chunk/jump overhead fit the same 105,000,000-tick clock. There are 6,845,112 encoder states, one work tape and 3,819,572,496 description bits. With the decoder, registered cost is **4,134,572,790**, under 2^32. The costs theorem verifies these figures for the explicit Machine values. It does not formalize the complete run law for every tag string; the described control invariant and independent transition tests support the scoped functionality. Neither replacement supplies general WE correctness or an all-circuit fallback at this cost.
