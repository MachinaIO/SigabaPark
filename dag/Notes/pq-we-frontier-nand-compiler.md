### Input and choice of masks

Work in the Boolean ring on the 4224 nonconstant tableau wires, with xor for addition and x²=x. For gate output c (absolute wire number, 129 through 4224), normalize an operand to constant one if it is wire 0 or its index is ≥c, in accordance with the registered evaluator. On a legal tableau, c=h where h=1+ab; repeated operands use the same variable. The output wire is o. Start residual polynomial P=o and accumulated polynomial B=beta+r★(1+o), with fresh uniform bit r★. Process gates in descending order, keeping a public structural bag L initially {o}. Skip any gate whose output c is absent. For each visited gate replace c in L by its distinct nonconstant normalized operands, retaining previous live variables other than c. The schedule, all bags and the ciphertext layout depend only on the input statement. Let w be the largest before/after bag size, including the final primary bag. Old bag plus both parents has at most w+2 variables. In particular do not remove a primary from this accounting just because it ceases to occur in P; previous masks may still depend on it.

Split P=U+cV, B=B₀+cB₁. Put S=hV on the next bag. Draw **one independent bit per visited gate**, r. Finalize the complete block of coefficients containing c: write the ANF coefficient array of B₁+rV over L minus c in increasing subset order. Carry P←U+S and B←B₀+rS. At the end write the primary coefficients of B. Decode by reproducing the schedule, evaluating the original tableau from the given witness, and XORing the offered coefficients whose monomials are true. All output positions have fixed public indices: each monomial with internal wires belongs to its greatest such wire, and the primary block comes last. A coefficient is accumulated before exactly one emission. No local P or S arrays, separate mask bits, branch-by-coefficient decisions or other intermediate descriptions are transmitted. The logical coefficient field has ∑_visited 2^(|L_before|−1)+2^|L_final| bits, and uses 1+#visited random bits. The single output-field framing doubles its bits and adds one terminal bit on the machine output tape. A sparse serialization of this same final function must normalize equal monomials *across* stages.

This computes the canonical coefficients of the ordinary single polynomial beta+r★(1+o)+∑r_c(P_before+P_after). Its sum of unmasked differences plus 1+o is 1+C(witness). Each difference vanishes on a legal tableau, and the terminal difference vanishes when o=1. The output bit on valid witnesses is exactly beta. More locally, evaluate at c=h. The masked c block and the new carry combine to the old accumulated value on every such tableau; correct proves this Boolean identity. In the opposite-message world complement r★ and all r. The initial difference of B is o=P. If the two accumulators differ by P before a step, their c-block difference is V+V=0, and the carry difference is exactly U+S=P_after. Theorem carry proves both updates pointwise. Multilinear Boolean ANFs are unique, so the finalized coefficient blocks agree bit-for-bit. At the end the difference on primary variables is C. On every false circuit this is identically zero, yielding a uniform coin bijection with identical complete ciphertext. The argument also covers dead gates, constants and duplicated parents. This is perfect statistical hiding for this static compiler, with no hardness premise.

### Registered entry and tape ledger

The definition contains a closed oracle-free **SigabaNeo.Machine** for the statement-reading first stage. It has zero work tapes, 475136 states, description 65568768 bits and clock 2^28 (theorem budget). It skips the first parameter frame and decodes the statement frame, recognizing that encGates is a list of framed pairs, each pair being frame(unary first) followed by unary second. It emits two raw 13-bit little-endian operands per gate. A second, mathematical decoder decodeWirePairs inverts the actual SigabaNeo.encGates on every gate list (theorem decode). The packed stream occupies 106496 bits at 4096 gates. Computing the bound uses at most 4096(6·4224+3) raw statement bits; doubled outer statement framing and the two 128-bit parameter counters with the small remaining framing, plus 106496 emission-only ticks, fit 2^28. Noncanonical inputs are outside the registered domain; the stage halts on several invalid forms but is not a total syntax validator. For inclusion in a full reader, replace its end-of-statement halt by a continuation onto the remaining frame(s), and direct its output to storage. The proved dense description is for the standalone parser only. No independent dense-table charge for that parser may be used as the description of a larger machine after increasing the work-tape count.

A concrete, deliberately slow sequential implementation plan for the frontier table uses globally indexed 4224-bit monomial masks as scratch keys; they are not part of the ciphertext. Maintain two old/new ping-pong work tapes, each recording a fixed-width key plus the P,B coefficient bits per row, ordered by increasing subset index of the current sorted bag. During a stage only c and the two parent positions require marking on additional address-aligned tapes. For emission, scan the old c-containing half, streaming B+rP from each row. For construction of a given next-bag target key m, scan the entire old tape. An old key t without c contributes its old P and B if t=m. An old key containing c has stripped key d=t minus c. It contributes its old P once for each of d=m and (d union the normalized parent set)=m; the same two indicators contribute r·oldP to the new B. If the indicators coincide they cancel, as required for a constant gate. A mask for constant one is empty. Build both comparison indicators during one simultaneous fixed-key comparison and then reset the target/marker heads. Iterate every next-bag subset, append both carries, and rewind the old tape on each new target. Bag changes, both operand lookups and the transcript order are independent of all coins. This costs at most 2^(2w) old/new record comparisons per visited gate; only two adjacent tables plus a constant number of 4224-bit masks and the stored gate list are needed. Decryption can evaluate the canonical coefficient stream with the original tableau and a current subset mask, without constructing P,B.

One conservative layout allowance is 2^18 bit-head ticks per record comparison, including writing/rewinding a 4224-cell target, old/next record framing, mask comparisons, subset increment and amortized old-tape return. For example use a delimiter per mask and fixed tail cells for P,B, budget eight complete back-and-forth traversals of a 2·4224+16-cell framed record plus a further four such traversals for any carries and reset. Accumulate equality flags while streaming; use binary wire counters on a separate tape when positioning the three markers once per gate, outside the inner loop. At most two further sweeps per row emit the finalized block and construct next keys. A deliberately loose arithmetic envelope per algorithm is 2^45+2^(2w+32) ticks (4096 stages, packing, framing and output included). The small-term allowance also covers repeated scans of the 106496-bit packed gates and 4224-cell tableau. For example w≤32 gives <2^97 ticks per algorithm in that envelope. This is a paper schedule, including explicit record comparisons, not a compiled clock bound for the whole wrapper. If a proposed implementation has ≤18 work tapes and ≤2^34 states, its dense description is <2^74 bits under the registered formula; this is a design allowance, not a theorem that the missing wrapper meets it. For w=32 two such descriptions and clocks together would be within 2^100. The exact proven cost available here is that of the actual closed parsing stage. Exhausting a width, clock, or state allowance must leave an unsupported input or switch to another correct branch.

### Adaptive coverage and the obstruction to arbitrary orders

A front end can test publicly derived candidate witnesses by running the actual original circuit and directly output beta on a verified YES. It can also soundly intern commutative Boolean ANDs using signed literals, representing NAND as a complemented AND, folding constants, duplicates and complements. Hash-consing only reuses equal normalized children; deterministic full-key comparisons suffice in place of a hash table. The output literal can certify false/true without SAT search when it is constant. On a recognized conjunction of input literals, assemble a consistent candidate and verify it in the original evaluator. These steps have fixed public behavior on a given statement. An unclassified statement can use the raw normalized-index frontier above. In particular the early x AND NOT x factor in the 387-gate zero fixture folds to zero. The two identically built branches in the 4096-gate XOR-of-identical-products fixture acquire identical names, so its XOR tail folds to zero. Neither example gives a universal efficient ordering.

A second fallback on an explicitly bounded class is Shannon splitting. Select s primary indices publicly, issue the same beta independently for **all** cofactors that pass a preflight width check, requiring that every cofactor be supported before this mode is chosen. Use literal constant propagation (both zero and one) before rebuilding the active bags; an edge into a zero operand makes its NAND equal one. The witness selects its cofactor and extends its legal trace by evaluating that cofactor. Every cofactor of a NO statement is NO, hence all coin translations apply simultaneously, subject to independent issuance and statement-only layout including lengths. The resource multiplier is up to 2^s; with the illustrative paper ledger, s=12 and per-cofactor w≤26 gives a 2^96 leading time term. This does not solve arbitrary inputs if all cofactors remain wide. A certified false case can issue a fixed message-independent dummy. A verified accepting assignment can issue beta openly. No failure mode may silently return either dummy on a possibly true statement or clear beta on a possibly false statement.

There is an **order-independent ciphertext-size limit**, even when an order reduces intermediate work. On the YES point function F=∏_(j=1)^128(1+x_j), its canonical ANF contains all 2^128 primary monomials (one choice of 1 or x_j per factor). Negations and an AND chain realize F within 4096 NANDs. In the literal atom protocol at *fixed beta*, complementing all public-layout-independent masking coins toggles the full polynomial by 1+F, regardless of the sequence of substitutions if it reaches the pure witness polynomial. All nonconstant primary coefficients therefore have marginal one half individually. Expected nonzero primary coefficients alone are (2^128−1)/2 or larger. For each pair of complementary coin tapes at least one member has ≥2^127 such terms, by the elementary covering count in theorem point. The representation that emits each nonzero monomial separately cannot meet 2^100 on all coin tapes; a dense primary table writes 2^128 bits. The clear-YES or conjunction front end specifically handles this elementary point. This argument constrains literal normalization, not every encryption or compressed function representation.

Even a statement-chosen invertible affine basis for the 128 primary variables cannot uniformly make that representation cheap at a smaller local 2^32 cap. Consider F=e_k(x₁x₂,...,x₁₂₇x₁₂₈) at k=16 or k=51. Lucas parity identifies e_k with the predicate that the popcount of the true pairs has all bits of k set. Ripple counters implement the two examples in 1923 and 2313 NAND gates. In the Boolean ring's degree filtration the top homogeneous vector transforms by the exterior power under linear changes (repeated variables lower the degree); translations preserve it. For e_j on 64 disjoint pairs, the contraction from exterior degree j to degree j contains a permutation submatrix of size binom(64,j)·2^j: choose one endpoint from each of j distinct pairs as row and the opposite endpoints of exactly the same pairs as the unique nonzero column in this submatrix. A single top coordinate monomial has contraction rank binom(2j,j). Thus the top support is at least the ceiling of the ratio of these quantities, in every invertible affine primary basis. For k=51 apply the volume dual of the top degree 102 vector to get e_13 on dual pairs; coordinate monomials remain coordinate monomials under this duality and arbitrary basis changes act contragrediently. The support lower bounds are 53,264,258,627 for k=16 and 10,347,205,680 for k=51. The fixed-beta coin translation consequently gives expected ≥5,173,602,840 nonzero primary terms even for the latter example; it has 20,944,938,235,259,110,656 accepting assignments among 2^128. These bounds address a fixed basis per circuit and explicit monomial issuance, not mixing internal and primary coordinates, coin-dependent representations or certifying YES by a publicly found witness. They exceed 2^32, not 2^100.

For the rare-YES family an actual public-witness extractor can recognize affine/XOR preprocessing leading into pairs, solve a 128-variable affine system selecting exactly 51 products and verify the assignment in the original NAND circuit before exposing beta. Forty 2857-gate fixtures with random permutations, 128 invertible shears and 32 complementations admitted such a witness. A mutated false final gate was rejected. No coverage claim is made for arbitrary circuits or a decoder that trusts an unverified pattern match.

### Evidence and open scope

On 256 arbitrary mixed nine-gate DAGs, including forward and repeated operands, a separate full-polynomial accumulation and the streamed coefficient array agreed exactly, and complementary output worlds differed on exactly the final primary ANF. All 4096 primary assignments were checked across those fixtures. The closed parser action was separately replayed on the actual framed statement encoding: a three-gate pair test using indices 0,128,129,4095,4224 and a full 4096-gate fixture both produced every expected bit of the packed operands. The method is statement-dependent and the size obstruction is unrelated to the fixed-pair machine of [PR 186](https://github.com/MachinaIO/SigabaPark/pull/186). Its full residual C is a canonical witness ANF: testing whether it is zero decides the given circuit's satisfiability, which explains why universal cheap completion would be substantial. The exact frontier operations, supported-class privacy and literal lower bounds are available; a registered general end-to-end Machine implementation, a worst-case cap and an independent offline cryptographic fallback for the remaining circuits are open.
