The external decryption word contains framed parameters, statement, 128 witness bits and ciphertext in that order. PR #132 starts with a supplied 4096-bit certificate on a different private interface. Here a deterministic three-work-tape transducer produces that certificate itself. It spools the decoded statement onto tape zero, writes true and the witness on tape one, and uses tape two to mark history address zero. Both work heads return to zero. Throughout gate evaluation, the input head remains at the ciphertext frame and never inspects its payload. The component's output is the frame of the 4096 computed gate bits (8193 output symbols). Inlining the component in a full decryptor still requires an internal output tape or an equivalent wiring argument.

For parameter, statement and witness field lengths P,S,W, the input adapter takes exactly 2P+3S+3W+7 physical ticks. Each NAND with unary indices a,b and current history length f takes 5a+3b+2f+8 more ticks. Each previously computed false wire remains false. A self or forward reference hits blank history and reads true. The output delimiter takes one final tick. For this instance P=515, W=128, S≤103821312, a,b≤4224 and f≤4224 before each gate. The declared clock is 484513167 and the exact 26-state canonical table uses 88452 bits. The component cost is 484601619 (time plus description), independently of ciphertext length. The run theorem proves the clock suffices on all typed inputs. Malformed inputs are clocked but carry no functional promise.

For a fixed statement the candidate lock predicate may read a witness and an internal trace. Hardwire each selector to the constant true, a witness input, or an earlier trace input according to the registered rule. Gate i contributes the flag t_i XOR (a_i AND b_i). Conjoin its 4096 flags in a perfect binary tree and require the last t_i. The compiled expression is certified in TraceLock.check_shape. Induction over the gate order identifies the accepting trace with the generated trace and requires the registered output to be true; this is the uniqueness condition already treated in PR #136. The emitted frame has a known fixed layout, so the unframed t_i can be wired to its data coordinates when inputs are typed. On an interface offering arbitrary encodings, decoding or rejecting malformed frames is a separate cost.

In the two-input AND/XOR basis with freely shared wires, this predicate uses 8192 flag gates, 4095 tree ANDs and one final AND, with depth at most 15. Unbounded fan-out here includes the same witness or trace literal reused by multiple gates. In the AND/OR/NOT basis let d=a_i AND b_i and use (t_i OR d) AND NOT(t_i AND d). This is five gates per flag and local depth four, or 24576 gates in total and depth at most 17. A formula with no shared internal nodes duplicates d once per flag, giving at most 28672 gates and the same depth (literal occurrences may repeat). The generic width-five permutation-program proof for fan-in-two formulas gives an upper bound of 4^17 instructions under its binary Boolean basis after pushing negations to leaves; this is a general combinatorial bound, not a compiled lock implementation or ciphertext length.

The checked machine is a private component for a candidate construction. The stated gate/depth counts describe the trace predicate alone, not the XOR header calculation or the lock. Neither the full-view setup switch nor a compact compiler has been proved. In particular, reducing the circuit depth does not remove the base-field cost lower bound for the literal GKW parameter schedule discussed in PR #136.
