### Compile the graph before inspecting either party's data

Fix the template, public sizes and slot/row schedule. A wire descriptor is (base, unary map). The base is a public source identifier or null; the two truth values of the unary map are garbler-local. An Enc-known message bit is null with its constant map. A secret parameter bit starts at its own wire with the identity map and a pair of labels available to the garbler. With zero or one distinct non-null parent, evaluate the new map pointwise and keep the parent base (or null). With two distinct bases allocate a fresh base and garble the binary truth table NAND(f(x),g(y)) on the two *original* base labels. Start the new map at identity. Allocate even if f or g happens to be constant. Whether to emit a node, its parents, the identity of every alias, output references, padding, physical row order and packet lengths all depend only on public structural references. A data-dependent table-elimination decision can leak a known bit. Do not publish the local unary maps. The whole_graph lemma proves public projection commutes with a gate list of arbitrary length. The local_value lemma proves each gate's semantics when its allocated fresh base takes the computed value. In a well-formed topological list with unique fresh output identifiers these local equations determine all allocated values in order. An independent finite test checked 3,600 three-gate graphs and 28,800 evaluations, including repeated inputs and fan-out.

Known-only computations run in clear inside Enc; they still consume time. A clear output may be released only when the interface authorizes it, e.g. inside a representation private to an issued slot. A final unary truth map has two masked one-bit rows under the two base labels at fresh output coordinates. Releasing its two semantic bits can distinguish a constant from a permutation. Terminal public visibility must also handle unissued columns, for example with a private disable input and a fixed dummy output. Four-row binary cells use independent parents' PRF masks and full labels of w=κ+1 bits. Each retained binary gate costs 4w bits and eight width-w pads at issuance and two pads during evaluation. An ordinary absorbed gate costs zero table bits and zero evaluator pads. Fan-out of a descriptor reuses its selected base label at *different* gate/physical-row/operand domains. For a fixed valid static query schedule, idealize the inactive keys in topological order as in [task 144](https://github.com/MachinaIO/SigabaPark/pull/144). The one active cell is computed consistently and all other cells have an exclusive hidden pad. Never idealize a publicly known active key. No global XOR relation among independent label suffixes is used.

When an independent full output label must be materialized from a unary parent, sample per-color width-w pads P0,P1, and set the label of the result at physical row zero to P0. The opposite semantic value gets the opposite point and an independent uniform κ-bit suffix. Emit only P1 XOR the label of the result at row one. With zero active, the opened label is the real active pad and the single cell is uniform after idealizing the inactive pad. With one active, the output label is uniform and the cell is its XOR with the real active pad. If the two truth values agree it is P0; otherwise use the opposite point of P0 and an independent suffix. The involution (point,first suffix,second suffix) ↔ (opposite point,second suffix,first suffix) proves the latter joint opening law, including any deterministic function of the opened label. This charges two issuance pads and one evaluator pad (output zero uses its computed pad directly). In the nonconstant row-one case the inactive child suffix equals the previously idealized row-zero pad, which has no other use or exposed numeric value. Its independently chosen point fixes the opposite active point. One can defer that hidden suffix when embedding an outgoing challenge. In the constant case the child opposite suffix is independently sampled. A programmed row-zero label cannot simultaneously be assigned an independently imposed point. Use two full masked rows with freely selectable output labels where required. PR 150's zero-header selector needs separately programmable normal output colors and auxiliary bits; a unary alias, duplicated terminal occurrence, or fixed public label does not provide them. [Task 150](https://github.com/MachinaIO/SigabaPark/pull/150).

For comparison, Zahur, Rosulek and Evans combine a garbler half gate and an evaluator half gate with a common label difference to realize AND in two ciphertexts with free XOR. Their correlation/security conditions are different from independent-key PRFs. The unary absorption above uses public base identities and hidden rewrites; it provides no free XOR of two independently based labels. If the specific GGM generator starts at public zero, the exact CBD sampler decodes zero secret and error and G_A(0)=0, hence every descendant of that root is zero for that exact unsigned packing and layout. Such a known-key pad may be evaluated by the public zero convention. For a generic PRF the known-key call must be computed and charged. [Zahur, Rosulek and Evans, EUROCRYPT 2015](https://www.cs.virginia.edu/~evans/mightbeevil/halfgates/).

### A concrete Fig. 5 that needs no garbling or PRF of its own

Use the child private single-input fixed-template base of task 144 with a statically allocated key slot. Its deterministic KG for a one-bit private parameter θ returns a κ-bit selected seed and its physical color θ XOR orientation. The child master contains two independent seeds and that orientation; its size for this coordinate is 2κ+1 bits, before framing and other setup. The public gated function has a common public circuit template and only its payload bit varies. C_f repacks the input; it does not change this private parameter. For BKS D_(f0,f1,z,u) the garbler's data record contains the real or dummy child master, K and w. Its private key parameters include θ0,θ1 and the L=κ+1 bits u_k of the child-key override. Use the same shape at every step including A.8/A.11, with fixed-size dummy fields. In the ordinary branch D derives the selected child key for θ_w; in the dummy branch it returns u. The specified static KG ignores the passed randomness, so a compiler may eliminate the unused PRF(K,z) in this instantiation. If a different KG uses the coins, K is still Enc-known but z is a private key parameter in the original construction. Making z a public, domain-separated fixed slot nonce is a different construction requiring the corresponding PRF/query audit. [BKS, Appendix A.2, Figures 5–6](https://eprint.iacr.org/2015/158.pdf).

For every k the exact output has the affine form over F₂

    Y_k = c_k(m) + A0_k(m) θ0 + A1_k(m) θ1 + A2_k(m) u_k .

In dummy mode c=A0=A1=0 and A2=1. In ordinary mode A2=0 and the correct one of A0,A1 is the XOR of the k-th stored bits for the two semantic values. The intercept is the bit for semantic zero. For the point bit the intercept is the child orientation and the slope is one. Thus all coefficients and intercepts are computed by Enc alone, using the actual child-key kernel, with zero cryptographic pads and no unknown-unknown NAND. One constant-shape implementation forms two normal selector flags per row and computes difference, two flag-masked slopes and a normal-masked intercept in at most one XOR and three ANDs per returned bit after reading the two candidate fields. The override coefficient is the common dummy bit. A generic wire compiler can have mixed and genuinely joined gates for this mux; recognizing the public Fig. 5 template as a sparse affine macro removes those private gates for every m. Do not do this based on the observed input values. Other child KG algorithms or varying circuit encodings can be nonlinear and need a new analysis.

Here is a bounded private-key FE for this **whole** affine macro, including its multiple queries. It applies to any fixed public support map. In each slot choose independent secret mask bits π_i for its private parameters. For every possible (slot,row,output k) sample fresh slope mask vector r on its fixed support and a fresh bit s. A slot is opened for at most one θ; a row identifier denotes at most one message per master. Write α=θ+π in the key once. For each allowed row and output include T=s+〈θ,r〉 in that slot key. Encrypt a row by publishing, for each slot and k,

    D=A(m)+r,      E=c(m)+〈π,D〉+s.

The receiver returns E+〈α,D〉+T. This equals Y. Across all Q slots and all M distinct rows, α, D and T are jointly independent uniform fields: subtract θ to recover π, subtract A to recover r, then subtract 〈θ,r〉 to recover s. The baseline E is exactly Y+〈α,D〉+T. Hence sample those three visible arrays and derive E from the authorized outputs. The joint_affine_setup and affine_decode proofs verify the finite change of variables and reconstruction. This is information-theoretic; neither PRF nor ABE is needed for this affine base. A quantum observer on the same classical transcript obtains the identical state distribution for independent auxiliary advice. For an online ordering with preallocated sizes, one may choose the first of E,T to be exposed at a cell uniformly and set the other from Y once both its row and slot exist. Sample its D uniformly when its row arrives and the slot's α once. A key issued first includes all its future T bits; if a row precedes the key the hidden T can still be programmed. The fixed-batch bijection establishes the conditional distributions underlying this deferred-decision argument. Globally valid adaptive query pairs and immutable row/slot allocation remain required; a general interactive FE theorem was not formalized.

For one D slot let d=L+2. The private master has d+4ML independent bits, the function key has d+ML bits, and each ciphertext row has 4L bits. For Q independent slots multiply those counts by Q when opening all slots; one row contains a separate packet for every configured slot. Framing, public indices and template descriptions are additional. Setup samples and stores every master bit. Per key, constructing α and all T uses d+6ML elementary XOR/AND operations under the literal three-entry dot product. Encrypting all rows uses 9ML operations for D,E after generation of the clear coefficients; decryption uses 7L per selected row/slot. These count bit operations: the real tape must also read candidate seeds, masks, θ and row-dependent key and ciphertext records and write them. A streaming ordering makes each row's mask records contiguous; a decoder seeking a later row in a sequential key must pay for preceding records. Do not assume constant-time random access or persistent state between WE Enc and Dec.

At κ=2048, L=2049, Q=1 and M=4, the private setup is 34,835 bits; the key is 10,247 bits (1,281 bytes separately rounded), each row 8,196 bits (1,025 rounded bytes). One key plus four row packets have 43,031 bits before packing/alignment. Key generation takes 51,227 listed Boolean operations, row formation 73,764 before the coefficient work and decryption 14,343. There are no gate-pad or input-label PRF calls in this construction. By contrast, the literal selected-seed mechanism for those d private parameters writes 4,202,499 key bits at the same κ before garbling. If one uses separate independent one-time pad vectors at each source rather than the joint affine setup, the single-use override coordinates only require M bits per branch (one per row) and a selected color. Any sharing beyond those positions requires fresh pads for additional fan-outs. Actual byte packing, duplicated setup inside transient plaintexts and transfer of all private material are part of the enclosing cost. For r=2 and one prefix plus two private tables with entries ≥64 bits, widths ≤25 cover at most 75 witness bits under the strict cap. Deeper ranks use broader child key interfaces. One local D does not implement the 128-bit primitive, and an eager optimization that already eliminated a D cannot save it again.

A separate three-bit ciphertext alternative trades key size for row width. At each cell select j among the four candidates (0,θ0,θ1,u_k) and a known complement c; this represents all modes above. Sample a two-bit hidden permutation shift p and four independent bits r[z]. The key table is T[z]=candidate[z XOR p]+r[z]. The ciphertext releases z=j XOR p and e=c+r[z]. The selected output is T[z]+e. Its ideal view is a uniform table and uniform z with e=Y+T[z]. Per cell the master/key/ciphertext cost is 6/4/3 bits. Across M rows of the same (slot,k), the parity of the four candidate bits is identical, even after translating by p. Represent r as a two-variable algebraic-normal-form polynomial. Share a single uniform quadratic coefficient only within that (slot,k), with fresh p and three fresh lower coefficients per row. The parity of T is then one masked common bit; the lower three coefficients of T and z are independent uniform conditional on it. Sampling that common bit, the lower coefficients and z reconstructs all e from Y. Costs per slot become 5ML+L master bits, 3ML+L key bits, and 3L ciphertext bits per row. Never reuse that highest coefficient when the parity can vary. Compared to the four-bit row design, the key is longer by 2ML+L−d bits, the M ciphertexts are shorter by ML, and the master is longer by ML+L−d. Whether these widths help at a given BKS rank depends on which serialized outputs recur and how often. A subsequent algorithm can no longer treat an arbitrary many-row key as a κ+1-bit seed.

### Reusable labels, private preprocessing and the remaining AGG

For an affine terminal on existing ordinary labels, independently pad the intercept at the all-zero physical tuple, and send one correction per input equal to its physical affine slope plus the two independent per-color pads for that input. Specifically B=F(0)+sum P_i,0 and D_i=slope_i+P_i,0+P_i,1. Eval uses B+sum x_i D_i+sum P_i,x_i. Compared with the public active colors and their actual pads, idealizing the unheld pads gives independent uniform D_i; B is determined by the authorized answer. The affine_view proof checks every joint test of this full packet. This costs four bits for the three-parent D terminal and six one-bit pads at issuance, three at evaluation, if applied using preexisting labels. Domains include slot,row,output,operand and gate purpose. With fresh internal pad vectors this must not be confused with the preceding affine-only FE.

If many positions actually share one selected parent bit from the same θ0,θ1 pair, a private selector label can be produced once. For physical input colors a,b take domain-separated independent (κ+1)-bit pads P_a,Q_b. Set c=1 XOR ΔP_point XOR ΔQ_point for the respective row differences. Correct Q_b only in its point by b·c. Let H be the corrected difference of the **unselected** input role. Emit H and c (κ+2 bits). The physical output word is P_a XOR correctedQ_b XOR ((a XOR b)·H); its suffix changes only with the selected physical bit, by ΔP_suffix XOR ΔQ_suffix, and its point changes with slope one. Set the secret semantic orientation accordingly. Conditional on both active input pads, the two inactive pads are independent in the hidden-pad hybrid. Their differences are in bijection with (H,c,opposite-suffix difference) for either selector choice: per suffix coordinate retain the unselected difference and the XOR of both; for points retain ΔP_point or its complement and 1 XOR both differences. The selector_word lemma checks the decoder and both coordinate bijections. H,c are uniform, the active label is then calculated with the known pads, and the inactive suffix is independent uniform conditional on it. This allows an outgoing inactive-key challenge after idealizing the two inactive parent pads; the selector must not publish the original differences or reuse the private pad domains. Accidental numeric collisions need the same independent-key handling as other gates. Its emitted hint costs four full pad calls at issuance and two at evaluation. A shared selector followed by two-operand affine outputs costs 3L+κ+2 bits instead of 4L. For a single seed-plus-point word L=κ+1 it costs one bit more. It can pay off with more than κ+2 genuine output uses of the identical parent pair and choice. Every output use takes different masks, while the common selector label is charged once. This ordinary label alone cannot satisfy PR 150's independently prescribed terminal orientation. Public low-rank correlations can be used only when the fixed image and the resulting full-view pad law are proved; the differences of two private child seeds cannot be published as a public basis.

On the key side, a public-template subnet depending only on θ can be evaluated by the issuer and promoted to a new parameter column h(θ). Provide selected seed/one-time material for that column exactly as for other private inputs, never h(θ) in clear. The public replacement frontier and retained sharing must be independent of θ. The reduced function's value is equal for every requested m. Charge the issuer's evaluation of h, master and key columns, per-row derivations and any expanded query sizes. For fixed additive promotion and retained-node prices, a cut formulation has source-connected boundary demands, demand(v)→compute(v) at the promotion price, compute(v)→sink at its gate price, and infinite compute(v)→demand(parent) arcs; raw parameters can be bought at demand(v)→sink. A cut retains a computation only with all parent demands covered and bills a shared node once. Overlapping preprocessing or a common variable-size encipherment needs a separate nonadditive cost model.

Fig. 6 gives a different boundary. The message supplies all received tags; compute whether they are equal and well-formed at Enc. For a secret target t-bit tag compare one representative tag to the t independent private target bits with t local unary maps (zero garbled tables), combine by t−1 binary masked gates, and absorb the all-equal flag into the last unary map. A one-bit target needs no binary gate. A publicly fixed target makes the Boolean condition entirely Enc-known; its branch identity must still be hidden by the output encoding. This does not compute the normal child encryptions, which use a private starred master and K. If a public row ordinal really fixes a PRF input independently of the private query values, its pad can be precomputed by the key issuer, at the expense of one separate private result per required ordinal, its issuance work and its protected input columns. Original random message tags are not independently predictable by that issuer. Thus the sparse-affine D kernel does not instantiate the general AGG base: its private-unknown encryption/key operations, shape-compatible overrides, clock, and finite registry reductions remain open. The information-theoretic identities and literal ledgers above concern the enumerated static interfaces and do not certify a complete WE machine.
