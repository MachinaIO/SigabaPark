**Complete address.** Let z contain the 128 witness bits and all 4096 claimed gate bits. In gate i, read wire zero as one, an input from its witness position, a prior output from its claimed position, and all current/future gate references as one. The ith predicate checks the claimed output against this NAND. A final predicate asserts the last output. In gate order induction on the local checks gives exactly the registered evaluation for the supplied witness. Conversely a valid witness supplies this unique trace. With m=4097 checks, D_i(z)=(1-P_i(z)) product_{h<i} P_h(z) selects exactly the first failed check when there is one and selects none on a valid tableau. Each prefix conjunction has fan-in-two depth at most 12 for up to 4096 preceding check bits, plus one level to join the failing bit. A shared balanced parallel prefix network can use O(m log m) Boolean gates at O(log m) depth; gate addressing and the evaluation of individual checks are extra. This construction needs no algebraic refutation. Converting such Boolean prefixes into low-degree arithmetic ideal certificates would be a further requirement.

**Full function law.** Independently sample a uniform bit R_i(z) at every pair of check index and complete tableau. Define Y_b(z)=b xor the parity of the R_i(z) at failed checks. It returns b on valid z. On a false statement, flip the R bit at the first failure separately at each z, and flip b. This involution preserves the public predicate columns, the fair random-bit law, and every output simultaneously. More strongly the output truth table is uniform: condition on all entries except one fixed first-failure entry per z. The remaining entries are mutually independent fair coins, each xored into a single output. Consequently even coherent oracle evaluation of the entire sampled Y has the same law in both message worlds. A full independent truth-table bank costs 4097 times 2^4224 bits and is only an ideal model. Oracle-only substitution of pseudorandom functions requires exactly the applicable PRF interface: an oracle simulator with the other keys can route the Y queries to a challenged R_i. Quantum superposition queries require coherent access and reversible masking, with query and uncomputation charges. Neither calculation provides a compact public executable representation.

**Pooling test.** Put y=NAND(x,x), t=NAND(x,y), z=NAND(t,t), and assert z. Exhausting the 16 possible four-bit tableaux yields no context supporting all four checks when the full tuple is retained. With either the single witness bit or total parity as the context, both bins support all four local checks by pooling. On removing each check, the numbers of assignments satisfying the remaining three are respectively 1,2,2,2. More generally, for a false instance, let a safe partition mean that every occupied bin omits at least one locally achievable check. Choosing one such check per bin gives an unsatisfiable subset: a trace satisfying all chosen checks could not belong to any bin. Conversely label each trace by the first failed member of any unsatisfiable subset. Thus its minimum possible number of occupied bins equals the minimum unsatisfiable subset size when the partition is unrestricted. Efficient construction of small bins or their complete achievable-check lists is an additional condition. If the partition and exact lists are computable in polynomial time for arbitrary instances, safe on every NO and covering every trace, testing whether any bin attains all checks decides SAT.

The minimum-core criterion is attained by all 4097 checks of a full-size instance. Take an odd chain of 4093 NOT gates from the first witness bit x to y, followed by a=NAND(x,y), c=NAND(y,x), and out=NAND(a,c). Both honest evaluations reject. Fix x=1. If a chosen chain check alone is violated, propagate the flipped value honestly thereafter: y=1, a=c=0 and out=1. If the chosen violation is instead one of the final three gate checks or the asserted output, honestly evaluate all preceding gates, flip only the chosen gate when applicable, and finish honestly. Thus all singleton failure patterns occur. Two distinct singleton patterns in one bin would jointly cover every check. Every safe partition needs 4097 occupied bins, hence at least 13 label bits at fixed length; first failure achieves the count.

Pin x=y=out=1, a=c=0 and all unused witness bits; all final checks pass. There are 4092 free interior chain bits u. The failure bitmap on the 4093 chain edges is an affine bijection onto the odd-parity masks: the first endpoint and specified failures determine the entire chain, and odd failure parity preserves the chosen last endpoint. Changing u by a nonzero bit vector d toggles the edge vector by the nonzero even vector delta=d xor (d shifted left by one position), with zero padding. Pick a singleton edge e in the support of delta. The two interiors with failure patterns e and e xor delta have disjoint failures and differ by d. An affine full-tableau label whose restriction to this slice has rank below 4092 has some such nonzero kernel direction, so it necessarily allows pooling just two tableaux on this instance. The 13-bit nonlinear first-failure label avoids this restriction. All 4097 singleton patterns were checked computationally, as were all nonzero directions at lengths 3,5,7,9 and three directions at full size. The arbitrary-direction conclusion is the algebraic argument above.

**A one-key hypothesis and a two-key question.** Abstract exact shifted evaluation returns F+H. The proposed public pair would implement F+b and F+W, where W is the failed-check parity mask. Their difference yields the desired bit function in XOR arithmetic. The hypothesis to be transferred gives one fixed shift chosen independently of the freshly sampled hidden master, one returned encoding plus public parameters, and a simulator independent of that shift except for its padded size. It supplies no oracle reading the underlying master and no second same-master key. Consider modifying any such representation with an independently uniform master bit r and appending r xor (H(z0) AND H(z1)) to its derived key for two fixed distinct inputs. Under one issuance, the tag is independent uniform conditional on every original public field, the adversary's chosen shift and its coins. The old simulator extends by one independent fair bit. Evaluation ignores the tag. For the pair of shifts b and W under one master, the xor of the two tags equals b xor (W(z0) AND W(z1)). In the ideal false-tableau model the two values of W are independent fair bits: the acceptance probabilities are 1/4 and 3/4. Even the full evaluated pair (F+b,F+W) for F and W independent uniform functions has identical joint law across b; the extra distinction resides in representation fields. Generalizing the AND to k distinct addresses gives gap 1-2^(1-k). The modification is semantic and survives normalizing descriptions. This countermodel is to a proposed implication between interfaces. It makes no claim about a concrete published key distribution. If a security game also publishes related auxiliary encodings, repeated same-master keys, or the new master bit, the single-tag simulation premises require rechecking.

**Independent-master alternative.** A separate restriction applies if only evaluated functions are disclosed. Let G be the finite additive group of full output functions. Sample n mutually independent uniform baselines F_i in G. Issue each exactly once as F_i+S_i(F_0,...,F_{i-1},b), permitting arbitrary earlier whole functions as input to the shift. Fix b and any independent public information or coins selecting the shifts. Each output history has exactly one input history: recursively recover its last baseline by subtracting the shift computed from the already recovered prefix. The Lean definition constructs this equivalence at arbitrary n. Therefore the whole issued history is uniform for both bits, even on a YES statement. If the decoder at a fixed valid witness sees just these functions, its correctness errors across the two bits sum to at least one. Independent baseline substitution of this particular acyclic form cannot provide correct recovery. Encodings correlated with baselines, repeated masters, biased baselines, restricted codomains and additional correlated auxiliary data lie outside this lemma.

A candidate outside that restriction uses an actual dependency cycle with independent masters. With F0,F1 from separate setups, choose shifts H0=V_C*(encode(b)-F1) and H1=-V_C*F0 in an additive commutative group. Summing both shifted evaluations gives encode(b) on a valid point and F0+F1 otherwise, under exact shift correctness. Each shift is independent of its own freshly generated secret (use independent public parameters and a supported padded circuit). But its counterpart's issued bytes now depend on that secret. The required joint simulation is circular; proving one marginal with a separately sampled opposite master does not sample the correlated second encoding. In Peikert–Shiehian the master evaluation at a fixed public point is linear in the hidden master vector. Converting this pointwise affinity into a concrete reduction for both full headers including their encrypted shift circuits and correlated vectors is open.

**Original-source interfaces.** Peikert and Shiehian's Lemma 3.2/Figure 1 fixes the circuit before sampling the public setup and master secret and returns one shifted key (ct,a,c). The simulator samples the public matrices and the corresponding canonical vectors, with a GSW encryption of a dummy circuit. Construction 5.18 programs an explicit list of distinct addresses. Theorem 5.10 splits values between independently set-up instances; it does not supply a second key under the first master. The underlying evaluation in Lemma 3.8 is approximate over a modular vector space. Translating exact Boolean cancellation into that scheme needs encoding, a rounding margin across the actual evaluated use cases, and its error and parameter costs. With m'=nL, L=ceil(log2 q), literally serializing the two public matrices of Construction 3.1 at L bits per entry costs n^2 L^2 (zbar+1+tau) bits. At (n,L,zbar,tau)=(64,16,4095,1) this is 4296015872 bits before any shifted key. That exceeds a local 2^32-bit target; it does not exceed the registered 2^100 cost cap by itself. This example establishes no security level or general lower bound. [Peikert–Shiehian, §§3,5](https://eprint.iacr.org/2017/1094.pdf)

Abram–Malavolta–Roy's Tree Encodings I, §4.4 p.37, puts C(alpha)-Eval(K,alpha) in a key-dependent constraint. The laconic master evaluator permits describing this circuit; Lemma 14, p.34, compares a key shifted with a **fixed** constraint to its simulated distribution under decomposed LWE. Its simulation includes TreeSetup/LFE public data and fresh remaining canonical fields. The authors explicitly leave key-dependent hiding open. In our narrower proposal H(z)=V_C(z)*(encode(b)-Eval(K,z)); this cancels the baseline on valid z. On false C the function H is extensionally zero but its description still contains K,b. No fixed-constraint theorem supplied here simulates this correlation. Nondeterministic authentication for truth tables in the paper does not turn this correlation into an assumption already registered for WE. **A guarded black-box issuer.** Fix the circuit, issuer coins and any message-independent public input. Suppose all message dependence is confined to oracle answers, equal to a common simulatable response wherever V_C rejects. Replay the issuer on that simulator and record its first accepting query. On a miss both real artifact strings equal the simulated artifact. Given the same valid witness and reader coins, at least one of the two real answers is wrong. Coupling identical issuer/reader randomness and summing the two marginal correctness error bounds gives success at least 1-2 epsilon for this witness-finding procedure. This remains true when the code reads the explicit circuit while selecting queries. For a circuit-blind issuer given only membership in a hidden uniform singleton of a size-2^128 universe, a common all-negative path of length T hits that singleton with probability at most T/2^128. With epsilon=2^-128 this forces T>=2^128-2. Singleton circuits themselves fit the registered format by negating mismatch literals and accumulating AND by paired NANDs, padding before two final NOTs. Only the point-query bound requires a circuit-blind issuer. Ordinary WE encryption may inspect the circuit and use message-dependent operations throughout.

The DAG proofs check the simultaneous involution, the semantic tag counts, the guarded replay implication, and the triangular evaluation bijection. The existence of sufficiently small, jointly simulatable public encodings under a fixed falsifiable post-quantum premise remains open, including the cost of setup, serialization, every evaluation, clock, description and reduction loss.
