## A bounded batch interface

Fix a public NAND template F(theta,m), including its wiring, its fixed input and output lengths, and any common padding. The inputs theta and m are both private. An encryptor and key issuer share symmetric master material. Allow Q key slots and M distinct ciphertext row identifiers per master. The static game commits both lists of left/right messages and key parameters, their public row/slot identities and their shapes before setup and before seeing any transcript. It requires F(theta0_i,m0_j)=F(theta1_i,m1_j) for every issued slot and row. All ciphertexts and keys then go to an arbitrary observer. There is one parameter per issued slot; repeating an identical static handle can reuse it. The public template must be identical across the two experiments. This is a narrower interface than adaptively issuing private function keys after ciphertexts are observed.

A generic implementation garbles the same public template anew at each (slot,row). Independently at each (slot,parameter wire) sample secret PRF seeds for the two semantic values. Give a holder just the selected seed. For each pair of possible garbled input labels encrypt the two labels by XOR with seed-derived pads, include domain-separated lookup tags, and shuffle the two records. For the data input publish the *one selected random garbling label* per bit. The template wiring does not disclose the data: neither the plaintext message nor a map from those input labels to semantic values is published. Hardwiring a varying message into an observable unpadded circuit is a different construction. In a static batch the unissued seed at each wire can be pseudorandomized once across all distinct row domains. Its records then carry uniform pads and independent tags. With h-bit tags a false match in any of QMd positions has ideal probability at most QMd/2^h, plus PRF distinguishing losses; ambiguous records must be handled. This is avoidable.

Instead choose a uniform secret orientation per (slot,parameter bit) and place the two masked records in physical positions b XOR orientation. Include the selected position in the key alongside its seed. One disclosed position is a uniform bit independent of the private parameter. This removes tags and makes lookup exact. Independently permuting or masking each position with a *public* per-row offset gives no additional security here. Using the same slot for incompatible parameters could yield both seeds and neither security argument applies.

## Direct input labels and four-row garbling

The following explicit version removes both masked theta records. Write k for the PRF-key length and w=k+1 for a label's length. Each label consists of a k-bit secret key and a color bit. Use separate PRF domains and output lengths for input-label generation and gate-row masking (or an explicitly costed expansion). For parameter wire i, row identifier j and slot q, set its semantic-b label to

    (PRF(S[q,i,b], "input" || q || i || j), b XOR orientation[q,i]).

All fields are unambiguously encoded, and only the k-bit PRF output is used as the suffix key. KG returns (S[q,i,theta_i], theta_i XOR orientation[q,i]) for each i and the public slot identifier. Thus the holder recreates its input labels for each row. It never sees the other seeds. Every slot/row garbling samples independent suffix keys for the wires carrying m and for internal wires, two per wire, with independent secret wire orientations. Enc sends the active m-label vector for each slot and keeps the value-to-color association secret. Keys and garblings use no cross-slot seed or internal-label sharing. Shared topology may be described once or supplied by the public statement.

At a gate with wire labels A and B, each pair of input colors indexes one row. To encode the desired output label, XOR it with PRF under A's suffix at (gate-domain,q,j,gate-ID,physical-row,L) and PRF under B's suffix at the corresponding R domain. Each mask has width w. If the same wire supplies both operands, L and R domains remain distinct. Encode all four rows, including logically inconsistent input combinations for repeated wires. The holder evaluates only the row indicated by its two labels, recovering the next complete label. At each output reveal just its orientation to decode the active color. Reserve distinct terminal wires via fixed copy gates if an output would alias an input or another output. Constants can be treated as public fixed inputs with only an active label. No global free-XOR offset or circular key is used. Correctness is exact for correctly indexed deterministic PRFs, even if two suffix strings happen to coincide, because their point bits and domains are handled explicitly.

**Fixed-batch privacy argument.** Normalize the template to include one additional private enable bit per slot: the enabled circuit returns F, the disabled circuit returns a fixed zero output. All genuine keys set enable=1. For an unused slot the proof uses a virtual enable=0 and fixed dummy theta, and gives the observer no dummy key. This avoids charging leakage F(dummy,m) for unissued slots. A fully issued, publicly fixed-size batch needs no enable branch.

1. For a fixed side and each parameter bit choose as active the semantic bit provided to the real or virtual holder. Keep its seed and all derived labels exactly. Replace the *other* seed's label derivations with independent uniform k-bit suffixes at the distinct row inputs using an ordinary multi-query PRF challenge. The adversary may locally evaluate PRFs under any keys it knows. The reduction never hands out the hidden challenge seed.
2. In each slot/row, classify each data, parameter and internal wire label as active or inactive by honest evaluation on that batch pair. Replace the outgoing gate masks generated by the inactive suffix key of each wire with random-function values, in topological wire order. Any incoming row writing that inactive label had at least one inactive predecessor, since the two active predecessors necessarily yield the active output. Such incoming rows are already uniform, including inconsistent rows of repeated-wire gates. The reduction can therefore embed an unknown uniform PRF key as the inactive suffix without having to write that suffix as plaintext into a previous row. Every physical row selected by an inactive input uses a distinct mask domain, so one random pad makes the entire row uniform, independently of remaining masks. If both operands use the embedded key, query the oracle at the two separate domains. Output translations contain no suffix keys.
3. In the resulting transcript generate the active parameter seeds and colors uniformly per slot/bit, active data labels uniformly per slot/row, and active internal labels uniformly per slot/row. Fill exactly the active physical row at each gate using the prescribed PRF masks and the chosen next label; sample the other three rows independently. For each terminal wire the decoding bit is its active color XOR the allowed output bit. This simulator uses only the shapes, public schedule and matrix of permitted outputs. It preserves the correlation across rows of each disclosed seed and position. In particular no coherent evaluation oracle for the *hidden* master is given to the observer; the reductions query their PRF challengers classically and permit a quantum final observer with admissible auxiliary state.

This is a construction-specific hybrid argument, independent of a black-box garbling guarantee for adversarially chosen label seeds. For a common per-comparison ordinary PRF gap δ, with uniform coin generation, one conservative two-sided loss is 2(Qd + QM(d+s+g))δ for d private key wires including the optional enable bit, s independently supplied input wires and g gates including output normalization. Count any extra constant input wires in s. This overcounts labels with no outgoing uses. Bound the actual query count and work of each distinguisher; an input seed can have M label queries, and the inactive wire challenge covers all its incident outgoing physical rows. The argument uses independent wire roles and domain separation; PRF evaluations under the same numeric key caused by chance equality can be simulated with the known other-role keys. Alternatively condition on no collision between uniform inactive challenge keys and other individually simulated suffixes, and include the corresponding birthday loss. Random nonces in place of distinct row identifiers require their own per-master collision bound. Fresh garblings with repeated row domains do not satisfy this simulation. [Bellare, Hoang and Rogaway, *Foundations of Garbled Circuits*, Garble1 and its privacy proof](https://doi.org/10.1145/2382196.2382279)

**Allocation and security gap.** Each ordinary row under a master uses its unique public ordinal. A key slot is allocated to a single distinct parameter, before the batch. Replays of a deterministic call reproduce the same object. In the honest serial BKS layout the keys for a shared inner master are indexed by first-coordinate row and keys for the independently starred child can inherit function ordinals. Distinct later-coordinate entries carry their own row ordinals. A nested implementation must carry these identifiers inside the evaluator and prove injectivity separately for each master, including programmed hybrid calls. Sampling a lambda-bit key tag does not entitle one to enumerate a slot for every possible tag.

The fixed initial witness tables make both lists known to the WE encryptor, yet do not by themselves establish a black-box static-game reduction at every node. BKS Appendix A.2 Definition A.4 permits adaptive function queries after receipt of ciphertexts. Theorem A.5 uses a fully secure one-input base, with a selective-*message* relaxation discussed immediately below it. In particular Figs. 5–6 and hybrid A.11 install challenge-derived keys and ciphertexts inside subsequent query descriptions. To use the static base one must give a query-order invariant, independently for each comparison, proving *both* lists for its challenge master can be chosen before its first response; a value supplied by an independent challenger can sometimes be generated beforehand, so the prose requirement alone is no proof that a specialized schedule is impossible. In a genuinely adaptive game the proof's first step already needs to know which seed may later be revealed, and a previously filled uniform row may have to become a consistent PRF opening. No adaptive simulator has been demonstrated. This is an unclosed security step, not a distinguishing algorithm. [BKS, Appendix A.1–A.2](https://eprint.iacr.org/2015/158.pdf), [Bellare, Hoang and Rogaway, *Adaptively Secure Garbling*](https://eprint.iacr.org/2012/564)

## Honest cost and the terminal ciphertext

A base encryption emits per slot 4wg garbled gate bits, at least ws active data-label bits and one decoding bit per dedicated output; add row addressing and framing. The key emits wd bits of selected seeds/colors plus its slot index. One base decryption reads the chosen slot and computes at least two PRF pads per evaluated gate in this implementation. Encryption evaluates both pads for each of its four physical rows. At Q=32, M=32, k=128, g=4096, s=64, a one-bit output, the gate, active-data and output fields occupy 2,172,716,032 bits in total. This is a single-level shape illustration. It excludes setup, key records, fresh randomness, uniform generation from the public circuit, PRF work, tape head motion and descriptions; it supplies no full WE parameter row. A PRF itself is not a hardness assumption in the registered lattice instance. Concrete LWE-based PRF parameters, a quantum reduction at the amplified strength, finite errors and machine costs are missing.

There is a second recurrence independent of whether derived *function keys* are compact. Assume the fixed-width later-coordinate plaintext reserves its full programmed bypass field in every row, encodes every bit as a separate data input, and explicitly supplies one w-bit active label per data bit in at least one slot. Let the base be depth d=0 (arity one). A terminal coordinate representing an s-bit underlying message has width at least w s. For arity above one the terminal ciphertext in Appendix A.2 is an encryption one rank lower of an augmented message including v_t. In Figure 6 that field can be returned as a starred child terminal ciphertext with the underlying x_t. At arity two the starred child takes (x1,x2), which is at least as wide as x2. Thus if a lower bound L_d applies *uniformly to every supported depth-d family in these two roles*, the bypass field has width at least L_d(s) and the outer child encryption has width at least L_d(L_d(s)). The table masters may be different; the two applications use the same conservative lower function, not identical distributions. Taking L_0(s)=ws and composing gives

    terminal bits at arity r ≥ w^(2^(r−1)) · s.

The theorem terminal_ciphertext_composition verifies the abstract arithmetic induction. The cryptographic hypotheses come from the literal message/input layouts above. Falsification included the w=1 and s=1 boundary controls and finite exact recurrences before the proof. This count originates in an encrypted input field, even when every garbling encodes all output bits natively.

Under the strict 2^32 run target let p be the public key-table prefix width and b1,...,br the remaining nonnegative chunk widths, totaling 128 with p. Whenever the prefix table and each slot table fit below 2^32 their widths are at most 31, so r≤3 covers at most 124 witness bits. For r≥4 even one terminal entry with s≥1 and w≥16 reaches 16^8=2^32. The theorem terminal_ciphertext_floor formalizes the partition implication. For a zero-width final chunk one can use effective width s=1 in this layout: every terminal function returns at least one bit (a final bit or a serialized object), and the fresh terminal-copy gate alone emits at least w bits even with an empty data vector. Thus the base map is bounded below by w·max(1,s), which composes exactly as above from effective width one. Omitting empty slots altogether yields an ordinary smaller-arity partition. In the one-rank eager header transformation the original encrypted suffix tables are kept. Its header has 2^(p+b1) nonempty keys at rank r≥2, so a subcap header forces both p and b1 individually ≤31. The same conclusion follows for retained terminal ciphertexts. Rank-one direct expansion of an eager output per full witness itself has 2^128 entries. This covers every partition of all 128 witness bits and every publicly compiled circuit shape under the listed layout hypotheses, rather than an average circuit. The registered primitive has the distinct 2^100 cap; the argument establishes rejection at the stricter run target only.

A fixed-width literal issuer also carries the independently supplied key override u in its private parameter. A key issuing one seed per private bit consequently can regrow with the child key length, even though this direct garbling has no IBE or per-parameter label records in its ciphertext. Compact private masters alone change neither override. An alternative representation could move v to a public field H=v XOR Expand(seed), encoding only the seed with labels. For a conditional return of v versus y, the evaluator could produce Expand(seed) in the passthrough branch and H XOR y in the ordinary branch, with the external decoder always XORing H. The bit identity holds in both branches. The public-field simulation, padding and later use of H in programmed challenges must be proved, and the literal bitwise mux and pad computation still cost gates proportional to the return length. A secure word-wide bypass, compact encrypted input representation, or proof with genuinely different hybrid fields is needed to avoid the current recurrence. No general lower bound on garbling or WE follows.
