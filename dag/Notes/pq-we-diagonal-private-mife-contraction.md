## A separable output in the original public package

Consider the selective serial construction of Brakerski, Komargodski and Segev, *Multi-Input Functional Encryption in the Private-Key Setting: Stronger Security from Weaker Assumptions*, Appendix A.2, pp. 41–42, Figures 5–6. A private WE ciphertext contains t function keys (possibly a table for a public witness prefix), and one nonempty ordered list of n_i ciphertexts for each rank-r coordinate. Let F_f be the key's function. All key functions in the two WE worlds agree on every allowed tuple for a false statement. We assume fixed, typed, injective serializations throughout. [BKS, ePrint 2015/158](https://eprint.iacr.org/2015/158.pdf)

PR #141 computed only the outer D key entries from this transcript. The complementary AGG output has a special property on the honest lifted inputs. For row j in the first coordinate, the underlying master M_j and PRF key K_j are shared across a tuple; the seed address tau_i(u) is fixed by the selected public input in coordinate i. Thus its output is exactly the tuple with entries

    V[j,2,u] = E_(r-1)(M_j,(x_1[j],x_2[u]),1; PRF(K_j,tau_2[u]))
    V[j,i,u] = E_(r-1)(M_j,x_i[u],i-1; PRF(K_j,tau_i[u]))   for i >= 3.

In the same row the key output is H[f,j]=KG_(r-1)(M_j,C_Ff; PRF(K_j,z_f)), with C implementing BKS's re-association of the first two inputs. Later-coordinate input frames in this honest table have absent override tags. Consequently Fig. 6 never takes the bypass branch. Its bypass condition depends on all coordinates and we do not assert separability for hybrid programs or arbitrary forged ciphertexts.

For each j, run the public common-inner rank-(r-1) decryption with its published AGG key at just q=max_{i>=2} n_i tuples. On run a=0,...,q-1 choose item a mod n_i in coordinate i. Record output field i at this index the first time it occurs. On the joint correctness event all repeats give the same serialized ciphertext. Thus these calls recover **every** V[j,i,u]. For the interface which must cover every slot index, q is optimal because a single call selects only one item of each slot. This is not a lower bound on algebraic ways to synthesize fields. The theorem diagonal_cover proves both the dependent-type extraction formula and this cover bound.

Once these tables are materialized, drop the common AGG key for each j and the entire common suffix transcript. With H from the eager key transform, a witness evaluator selects H[f,j] and V[j,i,u_i] and makes one rank-(r-1) decryption. Each returned field is public postprocessing of the original WE challenge; the transform can serialize default values if a raw return does not parse. No security game is asked to allow two functions that merely agree after decryption.

## Precisely the second contraction

Let r>=3 and write k for the selected second-coordinate row. The virtual first ciphertext V[j,2,k] is a **pair** (O[j,k],A[j,k]). Its outer component O is a base ciphertext under the outer submaster of M_j. Its component A is a rank-(r-2) AGG key under the inner submaster of M_j. The V[j,i,u] with i>=3 are rank-(r-2) ciphertexts under that **same inner submaster**, addressed to its appropriate slots. H[f,j] is a base key under M_j's outer submaster. The original tail evaluation therefore computes

    G[f,j,k] = base.Dec(H[f,j],O[j,k])
    W[j,k,*] = Dec_(r-2)(A[j,k], (V[j,i,u_i])_(i>=3))
    output = Dec_(r-2)(G[f,j,k],W[j,k,*]).

The output of A is again coordinatewise on its real lifted inputs. Cycle through their indices to obtain the complete W[j,k,i,u] table. The first plaintext there is ((x_1[j],x_2[k]),x_3[u]); later plaintexts are x_i[u]. G implements C_(C_Ff), which consumes exactly this nested type. The second_contraction theorem gives the deterministic equality on the local correctness event allowing all output types to depend on the row and coordinate. It models the typed decryption boundary; the identification with Figure 6 and the distribution coupling are paper arguments.

Direct generation must reproduce the tape correlations. At the root sample independent z_f, tau_i[u] and independent row master/PRF material as in the original scheme. At the second cut, the tape PRF(K_j,z_f) for KG_(r-1) determines the tag z'[f,j] of the next D key. The tape PRF(K_j,tau_2[k]) for first-slot encryption determines the fresh starred M[j,k] and K[j,k] and the other first-slot issuance coins. Each PRF(K_j,tau_i[u]) for i>=3 determines the inner tag tau'[j,i,u] used by the second AGG. Issue the final G with master M[j,k] using PRF(K[j,k],z'[f,j]); issue W under that master and the exact PRF(K[j,k],tau'[j,i,u]) tape. Repeated seed labels are evaluated consistently, including coincidences between a key tag and a slot tag. The source z and tau lists are shared across all rows, while K_j is row-specific. Independently resampling all second-cut masters and tags gives a different distribution in general. To get a strictly matched generator, split each original finite tape into its original named fixed-length subcalls; if the implementation consumes variable numbers of coins, charge and reproduce that sampling. Dropped operations can be skipped when their outputs and their coin offsets are unused.

When both sides are cut eagerly for two successive layers the intermediate M_j itself is unused: the new M[j,k],K[j,k] are sampled by the *first-slot encryption tape*, and neither those samples nor the downstream tags depend on the discarded M_j. Keep its K_j, which actually selects the tapes. Generate the surviving terminal masters. This saves real intermediate setup and issuance, subject to fixed tape boundaries. If an outer ciphertext is retained instead, its plaintext still carries the complete child-master representation of Figure 5. Charge it, or supply a separate proof of a shorter child representation.

In a deterministic typed functional test of Figures 5–6 with ideal one-input key/ciphertext objects, base Dec checked the master tag before applying the recorded function; all PRF labels were truncated to two bits to force reuse. Three seeds for each of the lists (2,3,5), (2,3,2,5), (2,3,2,2,3), each with two function keys, gave identical full key and ciphertext representations at both cuts for direct generation and public extraction. All 972 selected final evaluations agreed with the original serial evaluator. This tests the addressing and serialization logic; the ideal base contains function descriptions and has no cryptographic hiding property.

## Arbitrary depth and selective key contraction

Put P_0=1 and P_d=product_{i=1}^d n_i. Choose 1<=h<r. Sweep h successive AGG branches as above, and choose 0<=e<=h. Contract only the first e outer key issuers and leave the remaining h-e issuers in the decoder. The resulting ordered package has the following non-overlapping **indexed entries**:

| Kind | Count | Master and type |
| --- | ---: | --- |
| Key headers at depth e | t P_e | Functional keys of the rank-(r-e) instance at that prefix; base outer keys when e<h |
| Retained issuer ciphertexts | sum of P_d for d=e+1,...,h | One base outer ciphertext for each prefix at those depths |
| Remaining slot ciphertexts | P_h times sum of n_i for i>h | Coordinate-typed rank-(r-h) ciphertexts for each terminal prefix |

Use the prefix indices to fetch the selected header, descend its retained base ciphertext chain, and decrypt the selected terminal tuple. With D_s=2^s-1 direct base decryptions for the original BKS decoder the transformed count is (h-e)+D_(r-h). Eagerly advancing e by one removes tP_e current headers and P_(e+1) outer ciphertexts, adds tP_(e+1) next-rank headers, and saves one selected base decryption. These are logical opaque objects, not equal-size words or a byte estimate. No deduplication of accidentally equal strings is assumed. Given a concrete width/call-cost table, compare each e using the *actual* key, ciphertext and decryption costs for that rank; the optimum is a minimum over h,e and the input splits.

The public postprocessor needs, in direct base-decryption calls,

    sum_(d=0..h-1) P_(d+1) [ max_(i>d+1) n_i * D_(r-d-1) + t * 1_{d<e} ].

Leaf fetching and serializing the stored intermediate tuples also take time. For delayed issuers the postprocessor keeps each base outer ciphertext from its returned first-slot pair intact; it does not require the still-dynamic function key as an operand. If the goal is to remove only *D* from the common-inner side after the original eager outer step (rank r>=3), leave the starred computation untouched. The common-inner game has n_1 AGG keys and n_2 first ciphertexts. Its own one-layer eager transform produces n_1 n_2 headers; it retains n_2 inner aggregator keys, and the shared slot tables for i>=3. Together with t n_1 starred headers this is t n_1+n_1 n_2+n_2+sum_{i>=3} n_i objects. It uses 2D_(r-2)+D_(r-1)=2^r-3 direct base decryptions. This cheaper cut saves one extra base call while avoiding the per-prefix terminal ciphertext arrays.

For any challenge side let epsilonKey_d and epsilonAgg_d bound the marginal probability of the exact output mismatch for each eager issuer and each full cyclic AGG invocation at depth d, on its *ideal coupled input distribution*. The sum of P_(d+1)[t·1_{d<e}·epsilonKey_d + max_(i>d+1)n_i·epsilonAgg_d] over d bounds the probability that the transformed public and direct transcripts differ. No independence across cells is needed; repeated labels must continue to coincide. Perfect correctness makes the distributions identical. Standard correctness only for independent random tapes must be applied after establishing that marginal for the actual derived coins, or by a quantified PRF hybrid with repeated points and tag collisions handled explicitly. Assuming fresh tapes for each cell independently is unjustified. At ordinary output-gap normalization, add one such error for each WE world to the original transcript gap, and charge the public transform to the adversary. This guarantee uses public postprocessing of the completed BKS game and does not claim new security for correlated cross-instance keys. Registered per-witness correctness additionally charges the remaining honest selected decryptions; unconditional joint-transcript bounds are sufficient, often loose. In a coupling to the original selected evaluation, charge the original correctness error plus transformed-package deviation and any public transformation failure affecting that path.

For honest runtime, at depth d compute the necessary PRF addresses under each of P_d contexts: up to t+sum_{i>d}n_i distinct key/slot tags per context on a fully eager pass. Generate the surviving key/slot objects exactly once per retained index, with their actual rank-dependent issuance costs. Wire framing, writes, computation of child masters/PRF keys and tags, and reads when selecting a row all count. A simple sequential-tape method scans the indexed sections once in order with length-prefixed bounds, storing the selected fields for decryption. Its cost includes reading the serialized sections and maintaining row counters; a constant-time random-access table lookup does not certify the registered clock. Honest Gen need not execute the exhaustive real-to-ideal proof transform. The dynamic lower boundary is the terminal rank-(r-h) evaluation on a selected tuple and any retained D chain. To remove the next terminal AGG branch by the same method adds the next row dimension P_(h+1), except for fields still independent of that coordinate as explicitly tabulated above. It cannot simply relabel A[j,k] as a key under another row's master. An ordinary FE can attach a fresh independent setup identifier to each key/ciphertext and reject mismatched identifiers without losing single-instance hiding. Thus universally interoperable cross-master ciphertexts are not part of the ordinary interface.

## Equal-rank comparisons and a separately secure grouped alternative

For t=1 with r=16 and widths (1,1,9,...,9) with fourteen nines, taking e=h=2 leaves 4 keys and 4·14·512 ciphertexts: 28,676 entries and 16,383 direct base decryptions, versus 65,535 decryptions originally. The two public contraction stages use respectively 33,553,410 and 33,552,388 base calls, totaling 67,105,798, before handling bit lengths. With widths (8,...,8) at the same rank and cuts one instead has 65,536·(1+14·256)=234,946,560 entries with the same remaining decryptions. For an unweighted screening proxy of fully eager P_h(1+sum n_i)+D_s, s=r-h, no prefix keys and positive slot widths, fix q>=h bits in the contracted prefix. Convexity minimizes the remaining sum by giving the s residual slots widths floor((128-q)/s) and ceil((128-q)/s) in the unique required multiplicities. Enumerating q=h,...,127 and s=1,...,128-q gives minima 20,480 (h=0), 31,745 (h=1), 45,059 (h=2), 71,687 (h=3). The h=2 row above attains the third minimum. These units mix objects and calls and are deliberately a screening proxy, separate from the WE cost function.

There is a new proof choice if the exact original joint law is unnecessary. Partition the P_h prefix rows into groups of sizes L_g. Sample an independent ordinary rank-s master per group. Under each master issue t keys for the restricted/re-associated function, one first-slot ciphertext for each pair of a group row and a value of coordinate h+1, and one independent ciphertext per value for each of the other slots. A common prefix of the group's rows may be wired into its function and omitted from its plaintext. A satisfying witness selects its group and decrypts once. In the uniform power-of-two case, this is independent ordinary prefix peeling for the group-identifying bits, with the remaining intra-group bits folded into the first encrypted slot. One group is exactly an ordinary chunk merge. This is not a product-law claim about the BKS recursive tapes. Distinct group masters preclude evaluating ciphertexts across groups in the stipulated algorithm; privacy covers arbitrary processing by the recipient by the following independent-game hybrid.

For every false original statement, each restricted key pair agrees on every within-group rectangle. In a hybrid switching just group g, locally generate all earlier groups in one world and all later groups in the other, and obtain group g's entire package from its normal selective rank-s game. The ordinary gap sums over the groups. Each game has at most t key queries and at most max(L_g n_(h+1),max_{i>h+1}n_i) messages per coordinate. The reduction clock includes generating the other groups. If all group bounds satisfy gap²<=rho·cost(A)/2^B, a sufficient strength before additive errors is B>=128+ceil(2log2(number of groups))+ceil(log2 rho); prove the relative-cost and underlying registry bounds separately. This argument does not need an indistinguishability claim for revealing an additional issuer or a shareable parent master. For a fixed witness only the selected group's honest correctness is needed.

The fully grouped construction retains sum_g [t+L_g a+R] objects, with a=n_(h+1) and R=sum_{i>h+1}n_i. With the (1,1,9,...,9) schedule, groups of size 1,2,4 retain 28,676, 15,362 and 8,705 objects respectively. Their largest first-coordinate query list is 512, 1024 and 2048 respectively. The same number of direct base decryptions remains. Converting this trade into a clock needs setup, key and slot-encryption prices for each group's actual bounds; reducing the item count can increase a bounded-FE parameter.

In particular, under the direct transposed BS/AMVY layout discussed in PR #141, a base ciphertext explicitly writes 2QNh IBE ciphertext fields. Here h in the AMVY notation is the encoded key-input width, separate from tree depth; write U for a uniform lower bound on N times this width times IBE-field bit width. For s>=2 let b=n_(h+2). In each group BKS first-slot encryption issues L_g a distinct *indexed* rank-(s-1) AGG key queries against one shared inner master. The inner base (outer submaster if s-1>=2) must support Q>=L_g a; the b second slots each write one base ciphertext under it. Thus across all groups the contribution of this one charged adjacency alone is at least 2 P_h a b U bits, for any grouping. The theorem shard_capacity proves the sum inequality even for unequal per-group U values. In the 1,1,9,...,9 example it is 2^21 U, which reaches 2^32 when U>=2048. In the sixteen-eights example the single adjacency already reaches 2^33 bits for U=1. These are conditional **honest output** lower bounds for this explicit layout, not for every private FE, and do not exceed the registered 2^100 cap in general. [AMVY, §3, Equation 3.2](https://eprint.iacr.org/2021/848.pdf)

The two physical charges can also rule out the strict target across **all partitions** in this terminal-layout class. Let the original function-key prefix width be p, let the consumed q bits form P=2^q rows, and let a_1,...,a_s be the remaining widths. The full sum of adjacent ciphertext charges over any grouping is bounded below by 2U times the adjacent-power sum F of the single path of widths (p,q+a_1,a_2,...,a_s). Indeed the first edge charges P·2^p·2^a_1 summed across all groups, the next edge (if present) charges P·2^a_1·2^a_2, and later edges have at least one copy. This charges the actual exposed rank-s terminal ciphertexts and their required key capacities. Perfectly aligned tape reuse does not lower these explicit field counts. If hyperparameters vary, take the minimum U over the charged ciphertext instances.

The original remaining rank-s decoder has I(1)=0 and I(s)=1+2I(s-1) **issuer** decryptions that return a serialized child function key, hence I(s)=2^(s-1)-1. Charge the writing of that key once per such call. With U>=32768 and at least 2048 bits in every such child key, the honest Enc output and these honest Dec writes alone cost at least

    65536 F + 1024 (2^s - 2) >= 2^32.

The last inequality for every 128-bit path is theorem joint_native_floor. Briefly, for s>=2, F bounds the sum of powers of the two endpoint widths, using the two distinct endpoint edges. If F<65536 the endpoint widths total at most 29. Summing 2^v>=2048v-20480 over all edges counts the 128 bits twice except for those endpoints. The four cases s<=19, s=20, s=21 and s>=22 complete the inequality; a single edge already covers 128 bits. One sufficient explicit AMVY layout has at least one server, encoded key-input width at least 256, IBE ciphertext field width at least 128 and at least 256 written secret-key fields of at least 8 bits for every required child key. These are conditional uniform width requirements, not inferred concrete parameters. The result includes the fully eager exact terminal package and independent unequal shards having these ordinary per-master key capacities. It does not rule out fused generation/evaluation without materialized subroutine outputs, other FE realizations, or the 2^100 registered cap.

A concrete uniform Machine implementation, a complete finite security-strength calculation for the permitted registry, and a native string-output base with suitable widths and clocks remain open. In particular, improving postprocessing cannot by itself establish post-quantum security for the cited classical theorem.
