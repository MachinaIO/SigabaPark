**Setting.** Take the independent secret-key slots and per-row fixed-template garblings of the referenced construction. Each distinct key slot can be opened once; future references to the identical issued key can replay it. All encryption queries are public, unique row ordinals under this master. Each query pair of messages is classical and returns an independently garbled column entry per slot. Function-key queries may now be chosen adaptively after ciphertexts, and future ciphertext queries may in turn depend on the revealed keys. The joint left/right game requires equality of every queried function/message output on the two sides. For the reduction assume this validity on all reachable mixed transcripts (or globally valid algorithms); do not assume a key can be issued twice with fresh parameters to one slot. The template, valid shapes and declared maxima remain public.

**One preselected key slot supports online rows.** Fix its two candidate parameters before issuing any entry. That stronger commitment of the *key pair* is enough for the topological wire argument, even when messages arrive adaptively. Sample the selected seed vector and its color bits once. Generate one fresh garbling per row, using that query's active inputs and the fixed selected parameters. After the unselected-seed switch, different rows have independent unselected input-label suffixes at distinct row domains. The wire hybrids can be ordered first by row ordinal of arrival and then by topological wire ID. For a challenge wire occurring in a chosen row, simulate prior rows in their already switched form and later rows in the unswitched form; answers to the observer only need its classical queries and the reduction's own coins. The simulator can answer each entry from the common output then available, and reveal the already chosen seed vector whenever the key is requested. Abort before answering a row on which the fixed pair has unequal outputs. Quantum auxiliary state is carried along by the straight-line reduction; the finite PRF advantage is evaluated at its full clock and oracle usage. This gives one-slot message-adaptive privacy with a key pair fixed in advance, without predicting all messages. It still does not explain how to equivocate a key chosen after the ciphertexts are sent.

**Guess only the target slot's future opening.** Use Q intermediate steps, changing the entire transcript of just one column from left to right at each step. The other columns are independent, and can be answered honestly on their prescribed sides, including when their query parameters are adaptively chosen. For the target column there are at most A possible ordered function-parameter pairs plus one case for a slot that is never opened. A parameter of width d permits A=2^(2d); a smaller publicly specified set of legal pairs improves this bound. Use a uniform h-bit guess for h=ceil(log2(A+1)), with unused codes immediately returning an independent fair bit. Each of the A+1 cases has probability exactly 2^(-h) with bounded sampling time.

When guessing a pair, preselect that pair with the one-slot challenger and withhold its key until the observer asks for the slot. Check each arriving message pair against the guessed pair; abort to a fair bit upon mismatch of outputs. Check the two parameters when the slot is opened; abort if they differ. If it remains unopened and the guess was a pair, abort at the end. For the unused-slot guess, run the disabled virtual column with constant common output and abort on a key request. The real marginal of an unopened honest column is exactly its ordinary encryption regardless of which input labels are called active in the proof. The enable bit and hidden orientation preserve this property even in the unused case.

For each fixed hybrid side, consider the honest mixed transcript before the random guess is checked. The target's encryption does not inspect the target key request or the guess. When the guess is correct the whole run is exactly this transcript: the issued key, if any, uses its actual side's parameter, and universal validity guarantees that no preliminary output check aborts. On every other guess the final result is unbiased, whether the mismatch occurs immediately or at the end. This can be coupled with an independent guess and the full honest experiment until the first discrepancy. Exactly one of the 2^h codes yields the corresponding honest transcript result. Thus the simulator's output probability is one half plus 2^(-h) times the deviation of the honest hybrid probability from one half. The factor is the same on both sides, including when the probability of never opening a slot differs. Telescoping gives

    adaptive batch gap ≤ Q · 2^h · (one-column preselected-pair adaptive-message gap).

The unused case uses the same two-sided real-to-ideal garbling comparison, with no disclosure. Equivalently sample a single target column uniformly and sum the per-column maxima; handle non-power-of-two column counts by exact bounds on the sum rather than assuming a biased sampler. Failure probability of an unverified finite simulation adds with the same amplification. The reduction must also construct the other Q−1 columns, perform validity tests and handle the observer's computation.

**Scope and cost.** This bounds adaptive *indistinguishability* at a fixed finite parameter length. It gives no general polynomial-security adaptive simulation theorem for arbitrary growing parameter circuits. For a fixed 1-bit selector there are at most four ordered pairs, so h=3 and the loss is at most 8Q times the one-column bound. If the two parameter alternatives come from a public list of L possible ordered pairs, use h=ceil(log2(L+1)) and charge the algorithm to enumerate/sample/test that list. A lower bound on the width of an injective code for all keys is not automatically a lower bound on the entropy or guessing space of the *specific* pairs requested by one WE reduction. Conversely, fixing the challenge message bit does not fix the child master randomness or a programmed opaque response.

Applied to the serial construction, this supplies a route to non-selective key queries under an explicit *finite* guessing loss, where slot uniqueness and validity hold. If the amplified reduction weight is W and single-primitive security satisfies squared gap ≤ρ cost(A)/2^P, then the sufficient comparison condition P≥128+ceil(2 log2 W)+ceil(log2 ρ) must include this 2^h factor at each relevant use. With literal wide override parameters, no finite registry certificate covering that strength and clock is known here. This change affects only the strength analysis; it does not save a bit in the terminal ciphertext. The argument assumes independently generated slot columns. Sharing correlated garbled gates across slots would invalidate their honest simulation in the target-slot reduction and needs separate justification.

**A separate query-order specialization for fixed WE batches.** A static-list reduction consists of a locally sampled list of *both* message pairs and function pairs, independent of the one designated target master's responses, and a postprocessor that may use these responses arbitrarily. In the WE endpoint the witness table and possible prefix functions have exactly this form; the final observation can be quantum. At one rank the printed BKS selective hybrid schedule preserves this invariant as follows.

* Claims A.6, A.8, A.14 and A.16 use the shared inner child as target. Its key inputs are the row aggregator programs, and its slot messages contain the original values, tags and in the programmed cases a child ciphertext gamma. All starred masters needed to generate gamma, their PRF keys and the selector flags are locally generated independently of this shared inner child. Compute every query description first.
* Claims A.7, A.9, A.13 and A.15 target the outer one-input master. Its messages are the starred-master tuples or their dummy replacements. Its keys use D with the supplied original function pair, tags and either dummy u or a programmed delta. Delta is generated with a locally available starred master, independent of the outer target. These lists likewise precede any response.
* At A.11 use the independently starred child at its actual arity r−1. The function pairs for that target are the merged-input circuits C_f. The message pairs comprise the joined first two plaintexts and the remaining coordinate values from the parent lists. The challenge responses are the values delta and gamma that will be hardwired into the outer and shared-inner ciphertexts or keys. Those wrappers use *different*, locally available masters, and can be constructed after the starred-child responses. No opaque delta or gamma is needed as input to that same starred child's batch. The type of the starred master at r>2 must be respected even where the printed bound uses single-input notation. Claims A.10 and A.12 are PRF comparisons.

Consequently descending any such fixed-rank comparison branch again yields a list sampled without consulting its own designated challenge master. Induction preserves query order even when the postprocessor at the previous level builds keys from the responses. This observation supports using static security for this fixed WE transcript on this particular schedule, without paying the adaptive guess factor, provided all lists are admissible on *every* cross product, their public shapes and slot identities match and every required local generation uses the genuine distribution. It does not prove a stronger general BKS theorem, eliminate tag collisions, or complete the typed security and concrete strength calculation. The opaque override values still occupy the padded data fields whenever they occur as inputs under a different master, so this scheduling improvement leaves the ciphertext lower bound intact.
