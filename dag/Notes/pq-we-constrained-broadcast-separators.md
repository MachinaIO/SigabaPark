### From a dense factor graph to a small exact state

Number primary groups 0 through k−1, assigning each a distinct registered primary wire. First update column j by NAND(y_i,current_j) for every i<j−1, row-major, where y_i is the current value of column i. Then compute a₀=y₀ and a_j=NAND(a_{j−1},y_j) along adjacent columns. Output NOT a_{k−1}. At k=91 this uses all 4096 gates. Every intermediate value reaches the terminal. In the bipartite incidence graph, put each new factor and its output in the branch set of the second group (in the adjacent chain use the group of the updated column). Each new factor attaches to that group's previous representative and touches the first group. All pairs are covered once. This gives a K91 minor after deleting the inverter. In the primal graph the same contraction uses only wire vertices. A full binary table on 91 variables has at least 2^91 rows; an incidence factor vertex is not inherently a binary variable.

For an arbitrary carrier and binary operator op, write shape(f,g,x::xs)=f(x)::map(g,xs). One row of the literal broadcast semantics reads u, leaves the next column intact, and maps op(u,·) on the remaining columns. The streamed version instead reads f(x) and updates (f,g) to (g,op(f(x),·) composed with g). The general theorem proves equivalence of the entire emitted list to literal broadcast rows, for every input and both initial maps. This supplies all y_i before the same adjacent fold and inverter. On Booleans each unary map is its two-bit truth table. For NAND the post-initial reachable sets have sizes 1,2,4,5 and thereafter lie in alternating five-element sets. The stable theorem checks each possible successor for both symbol values. The first four layers and the two invariant sets are explicit. For a fixed split of an input word, deterministic state q after its prefix defines one rectangle of prefix and suffix words. The cut theorem gives a unique q and proves disjointness of these rectangles. Exact backward minimization of the fixed 91-layer accepting predicate by equality of the two child signatures gives maximal residual width four. This last count is a replay result.

### Internal boundary pins require additional information

For any original wire, the template builder records its origin. After r broadcast rows have updated column j, its value is P_r(x_j), where P_r applies the first r maps in their issue order. An arbitrary boundary may prescribe many such intermediate wire values, as well as primary values, adjacent-fold values or the final inverter. Identical final states of the unrestricted five-state scan need not answer such a query.

Let h be the first i at which y_i=0 or h=k if none. On this branch every P_r for r≤h is precisely r flips. For r>h it is constant: row h sets it to one, and subsequent rows update that constant. The pinSplit theorem proves the two exact formulas, including r=0 and the first reset. For the all-true branch, elementary iteration of NAND(true,·) gives only flips. Thus process each intermediate pin P_r(x_j)=b once per branch. If r≤h impose x_j=b XOR (r mod 2) at time j. Otherwise require the constant P_r(false)=b just after time r−1. At each step impose the guessed first-zero schedule, all compiled masks and every adjacent accumulator pin. Propagate numbers of partial assignments by adding along both allowed input transitions, or use Boolean OR for extension feasibility. Inactive physical primary inputs multiply the counts by their number of free assignments. The branch h is unique for each complete word. Summing its answers therefore gives exactly the number of satisfying assignments extending all specified boundary values. This is a query representation for any fixed assignment to a graph separator, including arbitrary internal wires. It does not assert a low-rank explicit tensor simultaneously listing every assignment of a general graph bag.

For k=91 the bound is 92 branches, 91 layers, at most five states per layer (initial layer included) and two possible transitions per state. This is at most 83,720 transition attempts, plus preprocessing O(k²+(k+1)(k+number of pins)). Counters need at most 129 bits for 128 free primaries. The circuit dictionary is polynomial, with one entry per original gate. Testing 360 fixed-seed random masked/substituted circuits of sizes 2 through 9 against exhaustive assignment counts found exact agreement. The full fixture accepts exactly 72,917,650,054,486,813,599,294,558,676,476,493,824 registered 128-bit witnesses. For nine different wires the two conditioned counts sum to this number, including the final inverter and internal gates. Ordinary bucket elimination remains an exact fallback: multiply/join all factors containing the next variable, existentially project it and retain the resulting relation. Boolean values on future or out-of-range parents must be read as true. The fallback need not be cheap.

The recognizer extends the family by a supplied list of k primary ports or constant-zero-index ports (wire zero denotes true) and independently swapped parents at every gate. Every nonconstant slot must be distinct. Check port bounds and uniqueness, reconstruct the schedule, compare each unordered parent pair and its length, then use the pin algorithm. The checker takes O(k²+n) word operations with a membership array and O(k²+n) storage including the dictionary. The supplied assignment of slots is a recognition certificate, not an assumption that the registered input contains it. For the standard ordered slot list the checker needs only the actual gate list. If two slots name the same primary, unconditioned DP paths would double-count inconsistent inputs, hence the injectivity check.

### Actual registered roles on an explicitly recognized subfamily

The SemSepRole definition gives both finite controls, their clocks, and their fixed representations; there is no setup, hash, oracle, or external selector. The encoder reads the primitive's actual encodeTuple of parameters, registered unary gate indices, and framed message. It checks the unordered parent pair at *every* gate against the full K91 schedule with the canonical 91 primary slots. All 4095 two-distinct-parent gates may be independently reversed, so exactly 2^4095 registered statements match. They all accept the primary assignment with numerical value 5 (low bit is input 1). On a match issue the message bit; otherwise issue the constant zero, always as a framed one-bit word. The decoder skips the three frames for parameters, statement and witness, then copies the ciphertext frame. All NO inputs generate identical ciphertext bytes for either message. Every matching YES input decrypts correctly for every satisfying witness. Correctness for other YES inputs is open for this branch. The richer pin counter above is not run by these machines.

For a parent a the physical frame contains 2a+1 consecutive ones followed by zero. For unequal numbers compare the common smaller run, branch on its delimiter, then check the remaining exact run lengths on the chosen order. A single work tape holds two marks 64 cells apart. Its head makes a round trip while checking precisely 128 ones in 129 steps, including the final marker test. Remainders use literal control states. The preparation phase consumes 1031 parameter-frame bits. The 4096 canonical pairs use exactly 16,856,012 statement bits before framing. Swapping parents preserves that length. On either successful route each gate consumes its two exact runs and delimiters and at most one jump. An early mismatch halts after three output bits. The number of 128-bit round trips is at most 33,712,024/128; including ruler setup, all jumps, parameters, terminator and payload fits the 35,000,000-tick encoder clock. The largest registered circuit uses at most 4096(2·4224+2) unary bits. Its outer frame plus parameters, witness and ciphertext fits the 70,000,000-tick decoder clock on honest runs. A decoder whose adversarial input is malformed still stops at its declared clock. Its six skip states and final copy state use no work tape.

The roleCost theorem checks the declared clocks plus canonical transition-table description lengths. The encoder has 2,188,673 states and one work tape; its description costs 1,181,883,420 bits. The decoder has seven states and costs 294 bits to describe. Their combined registered cost is 1,286,883,714. The Lean theorem covers these exact costs; the matching language and role behavior are justified by the control invariant above and executable checks. The hard-coded gate schedule, program counter, tuple framing, scanning and both roles are charged. No full-circuit encryption theorem, or upper bound for an encoder combining this branch with unrestricted fallback, follows.
