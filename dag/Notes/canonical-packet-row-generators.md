## The scalar and its complete NO transcript

Work over R_q=(Z/q)[X]/(X^N+1), q=p Delta, with N and S powers of two, S dividing N, p prime and 2S dividing p-1. The S roots of Y^S+1 in F_p are alpha times the powers of a primitive S-th root omega. For a polynomial of degree <S summing its evaluations on these S points gives S times its constant coefficient. Each positive monomial below degree S has zero geometric sum. Embedding by Y=X^(N/S) preserves coefficient zero. A Boolean packet with J accepting slots therefore has coefficient zero J/S in F_p. Since S<p, J/S=0 exactly when J=0. The orbit identity is proved by the attached Lean solution for every field and shifted primitive orbit. These slot values refer to a single public packet; validity at one slot is enough for decoding.

Write A for a common r-by-m public matrix of ring elements (independent uniform entries; no rank test). Pin the first secret ring element to the constant Delta b, with the bottom r-1 sampled uniformly. The one public response is c=A^T s+e with m ring entries, e having independent coefficient errors (CBD1 in the examples). Use a gadget G containing a column selecting the first secret component with weight one. Each packed input profile y_i(z) at packet index z uses B_i=A-y_i(z)G and the same c. NAND(x,y) uses R_x=BD(-B_x) with GR_x=-B_x, B_new=-B_y R_x-G and c_new=-R_x^T c_y-y c_x. Over the commutative ring this carries plaintext Y_new=1-xy. The initial slot bits can have arbitrary lifts; it is their residues modulo p that evaluate a true Boolean circuit at the slots. Keeping the unreduced q-lifts is necessary in this version. Forward references on the original register circuit are normalized to the fixed true wire.

For the selected output column and its constant coefficient, write D_z for the resulting base-ring linear functional on the shared input vector. Its coefficients depend only on public A, the circuit and packet. Put j_z=coeff0(Y_out) in Z_q, whose residue modulo p is J_z/S. Then the noiseless reference is D_z(A^T s)-Delta b j_z. An independently flooded flat reference adds scalar U_z. Conditional on the whole common input challenge, changing from this reference to D_z(c)+U_z on NO translates the independent scalar floods by -D_z(e). For width-L uniform intervals the joint variation is at most sum_z min(1,|D_z(e)|/L), using any fixed integer lifts that bound the shifts. The input challenge is one common matrix-response pair even though the list can have exponentially many scalars.

A different honest issuer draws one common base vector u whose D=Nm coefficient noises are uniform on consecutive dyadic intervals of length L. Set w=A^T s+u and publish a canonical description of V(z)=D_z(w)-Delta b j_z, as well as A,c. The receiver computes D_z(c)-V(z)=Delta b j_z+D_z(e-u). If |D_z(e-u)|<Delta/2, nearest-multiple-of-Delta rounding modulo q yields b J_z/S modulo p. It outputs one exactly for a nonzero rounded residue. At a valid witness this decodes b for either message. If K bounds the integer row l1 norms, |e|_infty<=E and |u|_infty<=L/2, the sufficient simultaneous error bound is K(E+L/2)<Delta/2.

On NO, Delta j_z vanishes in Z_q at every packet. Conditional on A,s,e, the real function values then coincide with the simulator D_z(c+u') at u'=u-e. Crucially, equivalent functions must induce the *same entire description*, with the same public basis and padding. Replacing u-e by a fresh u' costs at most min(1,DE/L), independent of the number of packets, coefficients emitted, or the size of D_z. An error tail is charged separately. To simulate from the registered rank-(r-1) decision challenge, append an independent top public row and add its pinned Delta b contribution to the given response. In the uniform-response world, c is independent of A and b, and the simulator's entire description depends only on A,c, the circuit and its own u'. This costs one Module-LWE comparison per endpoint plus the smoothing distance per endpoint, charged at the full adapter clock. In the honest public description no executable closure may contain s or b. The equality for the coupled noises is exact; the fresh independent noise comparison is statistical.

## An explicit canonical compiler

Consider a circuit supplied with a public decomposition into a skew NAND chain. The previously computed value is the heavy input. The other input is a local subcircuit using the current small packet-index block and public slot profiles only. Different blocks are disjoint and the chain reads them in order. The initial heavy wire is a constant or a fixed public slot profile. This includes chains depending on every index block. Local tables can be computed exhaustively at cost exponential in the *local block size*. The same argument extends to a bounded bank of live registers with local-heavy gates. This is an identified class, not a decomposition of every NAND DAG.

For each local value x compute its clear q-lift X, R=BD(-B_x), and its public input-response map D_x on ring vectors. For the heavy register write Y for its q-lift and D_h for its vector response map (before selecting an output column). For a fixed base vector w and scalar d=Delta b, track the five registers

    w,   a=D_h w,   y=Y w,   d,   t=Y d .

The update for NAND(local,heavy) is exactly

    w'=w,   a'=-R^T a-D_x(y),   y'=w-X y,   d'=d,   t'=d-X t .

The local response map is ring-linear, so D_x(Y w)=Y D_x(w). The final public linear observation takes coefficient zero of the selected a entry minus coefficient zero of t. Thus every letter has a public linear transition after expanding N polynomial coefficients, of width W=N(3m+2) using full ring storage for d. The initial injection E takes Nm+1 scalar coordinates (w,b) into this state: d is the constant Delta b, Y is the known initial phase, and the initial response is the publicly prescribed map applied to w. The simulator uses parameter (c+u',0). The legal input contains only the projected 128-bit witness address, the common bank, and the compressed residue vector.

Start from the terminal observation row and work backwards. At each block multiply the current row generators by each allowed letter matrix of that block, then keep generators for the module of the results. Independence of the allowed letters across the remaining blocks makes the row-span recurrence exact. After the initial injection, reduce once more. If H denotes this final generator matrix, the honest publication is just H times (w,b), in a public order and fixed-width residue encoding. The rows depend only on the public circuit, parameters, and A. Any packet row r(z) is a linear combination of the rows of H. The decoder computes these combination coefficients using the stored/recomputed public elimination, obtaining V(z) by combining the released scalar residues. Conversely every H row lies in the span of actual packet rows. Thus pointwise function equality is equivalent to bit-identical canonical outputs for fixed public data. The attached general theorem proves both directions over every commutative ring. No real witness need appear among the virtual generators.

Here is a deterministic generator algorithm for q=p times a power of two, with p odd. Reduce separately over F_p and Z/(2^a). In a remaining rectangular block pick a nonzero entry of smallest prime valuation, using fixed position tie breaking. Swap its row and column to the pivot position, and divide its unit factor out by scaling the row by a unit. The pivot is P^v for the local prime P. Every entry in the pivot column and row is divisible by P^v. Use invertible row and column subtractions to clear that column and row and continue. Carry a copy of the original rows through only the row operations, or store the column operations and their inverses. After elimination the zero rows contribute nothing and the remaining original-coordinate rows generate exactly the initial module. Retain at most the number of columns; this argument does not require the module to be free. Pad with zero generators and CRT-combine the two lists slot by slot: multiplication by the two public CRT idempotents recovers each factor's generator component. Output at most Nm+1 residues after the final injection. This fixed algorithm suffices for canonicity within the two bit experiments; it does not promise identical bases across different circuit encodings.

For B local letters per layer, at most BW rows of width W reach a reduction. Dense matrix application takes O(BW^3) ring-residue multiply/add operations per layer. Pivot search, row/column updates, and carrying original coordinates use O(BW^3) additional elementary residue operations and O(BW^2) storage per prime factor. The final solve takes polynomial time in W and log q, with modular inverses and recorded pivot valuations. Dec also computes the selected clear packet and its linear transition row for each layer, or recomputes the basis if omitted from the header. These are algorithmic counts with sequential memory, sampler, integer arithmetic and lookup costs still to be translated to the registered Machine. The whole basis matrix should be recomputed from public inputs or costed if transmitted.

Repeated reads of a block must preserve its value. For example, independently branching two occurrences of x inside x AND NOT x creates spurious accepted paths. Noncrossing rereads admit a precise extension: for a subinterval with transition product P, take the module of all its attainable matrices; independent concatenation spans pairwise products of generators by bilinearity, and wrapping by two occurrences of one letter uses the union over the **same** b of A_b P B_b. Flatten into at most W^2 coordinates for this computation. The skew transition products also lie in the smaller linear family w'=lambda w, y'=alpha w+gamma y, a'=K w+M y+L a, d'=lambda d, t'=alpha d+gamma t, with three ring scalars and three ring matrices. Closure follows by substitution, including arbitrary linear combinations. A fixed number of repeated full scans in the same or reverse variable order can instead tensor the per-letter transitions across scans, transposing reverse scans. Contract the final tensor of scan products with the fixed chain of boundary indices. Keeping the whole tensor of matrices may require W^(2 times the scan count) base coordinates. None of these rules allows arbitrary repeated-read correlations to be discarded.

## Interpretation

In a common ideal variant correlating u=e+u' makes the real expression D_z(c+u')-Delta b j_z. Taking u'=0 gives zero reference-subtracted noise and exact NO equality to D_z(c). For this algebraic compiler, one can even select A,c independently of b and publish the canonically compiled b times the slot-count signal under a sign convention. This case removes the need for hardness on this restricted circuit family. It is distinct from the independent-noise LWE calculation above.

An efficient canonical honest compiler and an efficient canonical simulator also yield a SAT decision procedure: set noise zero and compare the real b=1 description to its D_z(A^T s) description on the same public header. Equality is precisely J_z=0 at every packet. The simulator may cost more than the honest budget. If the honest compiler works correctly for every valid choice of its algebraic inputs, take A_top=0, bottom secrets zero and u=0. Comparing the honest compiler's descriptions for the two bits already decides SAT in two honest compiler calls; this specialization is not justified by correctness only with high probability on random headers. On the proven skew class SAT is decidable and there is no contradiction. Another special case, choosing actual sample addresses to hit a unique accepting packet using a statement-independent sample of Q addresses, has coverage at most Q/T on average over T possible locations. Circuit-dependent successful sampling gives a search procedure by testing its selected packets. Neither statement rules out computationally hiding randomized, noncanonical descriptions with their own complete joint law.

A flat emitter still needs one scalar per packet and at least one explicit full ring word. At 128 witness bits and disjoint S-slot packets this gives at least S+2^128/S >=2^65 bits even at one bit per word. This lower bound alone does not exceed 2^100. The stronger domain-specific accounting below is for particular implementations. It is not an impossibility theorem for the registered goal.

## Finite audit

For the noise calculation in the following examples initialize the heavy wire with a single fixed slot profile and use h further scalar retained literals as the local inputs. A heavy phase then always belongs to {0,1,Y_0,1-Y_0}. With centered plaintext coefficient representatives its integer coefficient l1 norm is at most 1+N floor(p/2). For radix 2^b, w=ceil(log2 q), m=r ceil(w/b) and D=Nm, use K_0=1 and K_next=D(2^b-1)K+1+N floor(p/2). This is a sufficient row-norm envelope; it is not an observed noise or lower bound. Put L=2^(130+ceil(log2 D)), bounding one endpoint variation by 2^-130 for CBD1. Choose Delta=2^a such that 2K(1+L/2)<Delta. Public A sampling modulo p 2^a needs either a bounded statistical approximation with its own error budget, or a separate exact-sampling implementation; the dyadic noise is exact with fixed fair coins.

All entries are compatible with 2S dividing p-1 for the listed full slot choice. The header includes A and c. The exact registered call is ModuleLWE.H with degree N, rank r-1, m ring samples (one shared response), modulus p*2^a, uniform secret, and CBD1 error. It returns **2** for the first row. This demonstrably fails 128-bit strength. Actual estimator answers at other parameters are separate from the size estimates; none of these bit counts certifies that the reduction overhead or security target fits. For the 4096/242 row the naive dense core width is 106,496, so even applying two dense letter matrices to a full basis accounts for 2,415,627,046,223,872 multiply/add positions. At the first backward step one instead has only one observation row. For given h retaining min(2^h,W) possible generators or storing all living small rows reduces work substantially. A polynomial complexity classification is not a measured clock.

Numerical checks covered 41,472 four-slot terminal evaluations modulo 544 with all Boolean input profiles for one NAND and all chosen centered error corners. Over modulus 12, independent row-generator extraction mod 3 and mod 4 preserved zero of every one of the 144 parameter differences on all 128 index strings for both a seven-layer chain and a version with an identically-zero output. The latter still has varying D_z rows. Its virtual generators in the two-coordinate example were (1,0),(0,0); the other example gave (1,1),(0,1). The translated shared-noise experiment matched pointwise across the enumerated real and simulated inputs. A separate full-transcript count with two coefficient inputs, three packets and noise interval length four had variation 15/64 for shared fresh flooding and 51/128 for independent fresh reference floods, compared to the exactly coupled law.

The restriction to a local left operand in the linear transition is material. At an unrestricted gate the radix digits of the varying public heavy-side matrix would be needed. At even q, extraction of a non-lowest binary digit on all residue values is not a polynomial function over Z/q: 0 and 2^j are congruent modulo 2, whereas their j-th bits are not (1<=j and 2^j<q). Mere tensor powers and linear combinations over that ring cannot supply all such digit maps. Specific limited ranges or an explicit public finite-state compilation may still work. General capped WE, its registered reduction and complete resource certification remain open.
