# Lean proofs of the lattice estimator's attacks: status

The goal is a Lean proof, without `sorry` or `axiom`, of every LWE attack the lattice estimator
considers, and of close variants. Each proof is an explicit algorithm with a proven success
probability and operation count. This page tracks progress per attack. Details and bit gaps are
in [PROOF_GAP.md](PROOF_GAP.md); the cost models are in [LWE_ESTIMATOR.md](LWE_ESTIMATOR.md).

Status marks:

* **proved**: a Lean theorem whose remaining premises are only standard facts that are also
  proved;
* **proved given H**: a Lean theorem with the explicit hypotheses `H` as premises;
* **paper**: an audited paper proof, not yet in Lean;
* **open**: no proof.

| Estimator attack | What a proof needs | Status |
| --- | --- | --- |
| `exhaustive_search` | enumerate the secret's support, check `b − As` short; uniqueness w.h.p. | **proved** (`Attacks/Guess/Collision.lean`). `Guess.ambiguity_probability`: for prime `q`, `n > 0`, a secret in a support of size `S` and any fixed error in `[−B, B]^m`, the scan fails to return exactly the secret with probability `≤ (S−1)(2B+1)^m/q^m` over uniform `A`. `Guess.scan_singleton_iff` identifies the failure event. `Guess.scanMultiplications_eq` counts exactly `S·m·n` ring multiplications; additions and tests are not counted |
| `mitm` | split the secret, hash or round `A₁s₁`, collision search | correctness **proved**: `Mitm.matches_eq_scan`, so the join returns the scan's candidates and inherits the bound above. Cost: `Mitm.balanced_tableOperations` counts `k(1+|E|)` modelled table operations. `Mitm.integerBox_card`: the error box has exactly `(2B+1)^m` guesses. `IndexedLookup.Tree.filter_probe_eq_scan` (bucket filtering equals a full scan for a partitioned tree) and `comparisons_le_depth` (one pivot comparison per level). `filterCount_spec` (bucket filtering: one equality test per row). `leaf_miss` (counterexample: depth alone does not bound lookup cost, so bucket sizes must be bounded too). **End-to-end theorem for the flat-bucket join** (`Mitm/FlatJoin.lean`, `flatJoin_end_to_end`): the output equals `exactJoin`; the singleton-recovery probability is `≥ 1 − (|S|−1)(2B+1)^m/q^m`; exactly `|R|·|E|·|L|` key equality tests. This variant costs about `S`, like exhaustive search. **End-to-end theorem for the sorted-table join** (`Mitm/Sorted.lean`, `sortedMitm_end_to_end`, built on `Algorithms/PairJoin.lean` `pairJoin_spec`): the left table is sorted once by an injective code of `A x`, each right vector and error guess issues one binary-search query carrying `y`; the output equals `exactJoin`, recovery `≥ 1 − (|S|−1)(2B+1)^m/q^m`, and the comparison count is `≤ |L|⌈log₂(|L|+1)⌉ + |R||E|(⌈log₂(|L|+1)⌉+1) + #hits`. With `|L| = |R| = √S` this is the `√S·|E|·log S` runtime, plus the number of hits (its average over `A` is bounded in `Mitm/Hits.lean`: `expected_hits_le` gives `≤ |L||R||E|/q^m + #{(x,y,z): x+y = s}`, and `expected_comparisons_le` the full average comparison count) |
| `arora-gb` | Arora–Ge linearization: full rank of the linearized system w.h.p. (the Gröbner variant needs semi-regularity, Fröberg's open conjecture) | components: `AroraGe.boundedErrorEquation`; `AroraGe.homogeneous_not_injective` shows the homogeneous form keeping the constant monomial is never injective, so the constant must move to the right-hand side; that rank question, success and cost are open. **Counterexample to the naive full-rank claim** (`AroraGe/Rank.lean`): with `s = 0`, `e = 0`, `n = 1`, `B = 1`, `q = 5`, the sample polynomial is odd (`aX − a³X³`), so every linearized matrix has a kernel (`fullRankCount_mod_five`: 0 of `5^m`). Shifting the secret does not help either (`AroraGe/Shifted.lean`, `shiftedFullRankCount`: with all errors zero, 0 matrix–secret pairs have full rank, kernel witness `(0, 1, 3s)`). Full support alone does not help either (`AroraGe/RandomErrors.lean`, `rankFailureCount`): if the error is 0 with probability `k/(k+2)`, rank fails with probability `≥ (k/(k+2))^m`. **Proved by enumerating consistent assignments**: `consistentScan_failure` gives failure `≤ (q^n − 1)((2B+1)/q)^m`, and `consistentScan_multiplications` counts exactly `q^n m n` multiplications. This is exhaustive search through the Arora–Ge equations, not the polynomial-time linearization. `uniformTranslation_zero_count`: under a uniform error, each fixed coefficient of degree `k ≥ 1` survives with probability `≥ k/D`. **End-to-end for one instance** (`AroraGe/CubicSolver.lean`, `uniform_recovery`): one secret coordinate over `F_5`, 3 samples, uniform errors in `{−1,0,1}`; success probability `≥ 32/3375`, exactly 45 multiplications. `translatedFailure_probability` (`AroraGe/Solve.lean`): for `n = 1`, any prime `q`, error alphabet of size `D < q` and any fixed secret, the public coefficient matrix is rank-deficient with probability `≤ (q^D − 1)(1 − 1/(Dq))^m`. `AroraGe/Multi.lean` (`failure_probability`): for `n` variables, rank deficiency has probability `≤ (q^M − 1)(1 − 1/(D q^n))^m`. `Algorithms/LinearSolve.lean` (`existsUnique_mulVec`) gives unique solvability. **End-to-end for `n` variables** (`AroraGe/Recover.lean`): `Identity.lean` proves the true monomial vector solves the linearized system (`mulVec_monomialValues`) and its degree-one coordinates are `s` (`monomialValues_single`); `Algorithms/Gauss.lean` is an executable Gaussian elimination with soundness, completeness under trivial kernel (`Gauss.complete`) and `≤ 5·m·M·(M+1)` field operations (`Gauss.fieldOps_le`). `recover_correct`: outside the rank-deficient tuples the attack, run on the public samples `(a_i, b_i)`, outputs exactly `s`; `recover_failure_probability`: over uniform `(e_i, a_i) ∈ E × F_q^n` it fails on a fraction `≤ (q^M − 1)(1 − 1/(|E| q^n))^m`; `recover_fieldOps`: `≤ 5·m·M·(M+1)` elimination operations (expanding the `m` products into coefficients is not charged). **Gröbner/XL** ([research/arora_gb.md](research/arora_gb.md)): on paper, if the sample directions span `F_q^n`, the degree of regularity is `≤ n(d−1)+1` and one affine XL matrix of degree `n(d−1)+d` gives a Gröbner basis, with elimination cost `O(R N min(R, N))`. The many-sample probability is `≤ (q^H−1)/(q−1)·(d/q)^m`. Lean: `xl_has_unit_row`, `xl_socle_zero_column`; `XLSpan.powerRow_spanFailures_card` proves the many-sample span-failure count `≤ (q^H − 1) d^m q^{(n−1)m}` (probability `(q^H−1)(d/q)^m`). The XL elimination cost and the Gröbner-basis certificate are not yet in Lean |
| `bkw` (coded) | plain BKW with fresh samples: bias of summed errors, Chernoff test; coded/LMS variants | components: `Bkw.blockDifference` (subtraction zeroes a block), `Bkw.ErrorTree.residual_bounds` (`|e| ≤ 2^a B`), `Bkw.errorMean_norm` (Fourier bias of a depth-`a` tree is exactly `β^{2^a}` for a finite base law). `Bkw.matchedMass_conditional` (one fresh pair conditioned on a block match factors into a uniform remaining difference and the difference of two independent errors), `errorMean_difference_re` (after one difference the real character mean is `|mean|² ≥ 0`), `zeroStage_negative_mean` (at depth 0 the cosine mean can be −1, so test after ≥ 1 difference). `errorMean_leaves` (depth-`a` expectation as a sum over `2^a` leaf assignments with product weights) and `errorMean_succ` (for `d ≥ 1` the character mean is exactly `|β|^{2^d} ≥ 0`). `retry_mass_eq_filter` (geometric retry weights equal the filtered law). **End-to-end for one-stage binary BKW with a majority vote** (`Bkw/BinaryVote.lean`, `binaryMajority`; build with `lake build SigabaNeoStd.Lattices.Attacks.Bkw.BinaryVote`): each vote draws two fresh rows (law `votePMF`), so one vote succeeds with probability exactly `1/2 + (1−2p)²/(4|B|)`; the strict majority of `N` independent votes recovers the secret bit except with probability `exp(−2Nγ²)`, `γ = (1−2p)²/(4|B|)`, with `≤ 5` charged operations per vote (Hoeffding: `Probability.iid_majority_count`). Also proved: `Bkw/Stages.lean` (`stages_eq`, `stages_iid`: after `a` stages the remaining coordinates are uniform and independent of a signed sum of `2^a` i.i.d. errors, and batches factor exactly; `freshCost_eq`: expected base samples `(2 q^b)^a`); `Bkw/QAry.lean` (`matched_difference_card`, `qary_difference_mean_norm`). Open: assembling the `q`-ary final test into one theorem, an executable sampler equivalence, and coded/LMS BKW **Multi-stage q-ary BKW, end to end** (`Bkw/Recover.lean`, `bkw_end_to_end`; non-module, build its target directly): `a+1` reduction stages with fresh retries give iid outputs with a uniform suffix and error law `signedLaw p (a+1)` (`stages_iid`, `stagePMF_toMeasure`); its real character mean is exactly `c = ‖p̂(1)‖^(2^(a+1))` (`FourierTest.signedLaw_real_mean`); the final Fourier score test keeps exactly `{s}` except with probability `≤ q^k exp(−(Nc/2)²/(2N)) = q^k exp(−Nc²/8)` (`bkwFinal_recovery`, Hoeffding + union bound). Cost: `(2|B|)^a` expected attempts per output (`freshCost_eq`) and `scoreOpCount N q k = N q^k (k+1)` for the test. Coded/LMS variants (lattice codes in the reduction) are not formalized |
| `dual`, `dual_hybrid` | rigorous dual distinguisher; short dual directions are the costly part | **Proved end to end with an explicit sampler** (`Dual/Sampler.lean`, `BinarySampler.binaryDualTest`). If `q^n < 2^m`, binary syndrome collisions give nonzero dual directions of norm `≤ √m` for every `A` (`valid`); with bounded errors and `√2 π m B < q`, `N` fresh trials give acceptance gap `≥ 1 − 2δ`, using `2^m n m + N m` multiplications (`multiplications`). The sampler is exponential time, not the estimator's BKZ-produced dual vectors. Also proved: `boundedDualTest` for any sampler of norm `≤ W₀`; `gaussianDualTest` for errors with a coordinate tail bound (`truncated_dual_bias`, `outsideBox_prob`); `shared_dual_test` with one shared right-hand side under pairwise sum/difference conditions (`shared_variance`). Open: the cheap BKZ-produced dual vectors (walls 1 and 2), and connecting `discreteGaussian_tail` to an explicit Gaussian product measure |
| `usvp`, `bdd`, hybrids | uniqueness (stage 2) + a solver for the planted shortest vector | uniqueness **proved** (`Planted.badMatrices_probability`). **Close variant proved end to end: the LLL primal attack** (`Attacks/Primal/LLL.lean`, `lll_attack`): explicit integer basis of the embedding lattice from public `(A, b)` (`QAry/Basis.lean`), verified LLL with proven termination fuel and swap bound `(4/3)^swaps ≤ potential` (`Reduction/LLL/Algorithm.lean`, `Reduction/LLL/Termination.lean`), approximation `2^((d−1)/2)` (`run_approx`), and recovery `±(e,s,1)` whenever `2^((d−1)/2)‖(e,s,1)‖ < R` and `A ∉ badMatrices` (`reduced_finds_planted`). The gap condition holds only in small dimension, so this gives no Kyber cost. `LLL.bkz_unique_shortest` gives the same recovery for any `BKZ.Reduced` basis; producing one in time `2^{O(β)}` with an average-case profile is walls 1–2 |
| — full-dimension sieve on the embedding (the route around walls 1 and 2) | sieve correctness (T1) + the static statistics S1–S3′ for the planted lattice at polynomial `q` | T1 **proved given S1–S4, S3′ and `IdealUniformLeaves`** (`Sieve.prescribedScan_T1`); statistics: paper for random `q`-ary lattices (T4/T4b, audited), obstruction at thin shells and `q = 3329`, wide-shell redesign in progress |
| — rigorous worst-case block reduction (slide reduction) | exact block solvers, termination, approximation factor | **proved** (`Reduction/Slide/*.lean`): exact projected primal/dual block SVP by bounded search (`solveAt_spec`, `dualSolveAt`); boundary potential invariant under block-internal operations and contraction by `(1+ε)²` per dual update; `slide_reduce_eps`: for every independent integer basis the pass terminates with explicit fuel, preserves the lattice and passes `slideCheck`; `checked_approx`: `‖b_0‖ ≤ ((1+ε)(β+4)/π)^{(k−1)β/(β−1)} λ1(L)` for `n = kβ`; `checked_unique_shortest` gives recovery of a uniquely short vector under this factor. Obstruction recorded: naive relaxed BKZ insertion can increase a prefix-product potential (`Reduction/Slide/Tour.lean`, `completion_changes_prefix`). Worst-case factor only: no Kyber cost |
| — BKZ-based (estimator's cheapest) | wall 1 (average BKZ profile) and wall 2 (sieve on BKZ blocks) | open. Parts 1–3 of wall 1 gave an exact pre-BKZ law and two obstructions; part 4 (Gaussian selection) in progress. Worst-case BKZ gives no cost for Kyber |
