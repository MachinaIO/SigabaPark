For the nonlinear template β(x XOR z)y of [task 161](https://github.com/MachinaIO/SigabaPark/pull/161), one function key and three separate input issuers suffice, with exact joint privacy on the full static Cartesian batch. For n independently chosen private bits per input owner, the total published length is quadratic in n, including every row and the key. The implementation changes the native setup and proves its full-view distribution afresh. The construction is unconditional for this template; this result does not establish an unrestricted cryptographic backend.

### Keys with eager row corrections

For a private binary vector θ, preallocate one immutable function slot. Independently sample π_i and two PRF seeds for each i, and publish the selected seed in a single unlabelled position and α_i=θ_i+π_i. Never include the semantic branch as metadata. Let f_ib denote the evaluations of the two functions on the fixed addressed coordinates; encode slot, row, output, feature and purpose injectively, using each repeated occurrence consistently. Define r_i=f_i0+f_i1, s=Σ f_i0 and T=Σ f_iθi. A row holding public-domain functions c,A_i on its private input sends D_i=A_i+r_i and E=c+Σ π_i D_i+s. Opening E+Σ α_i D_i+T gives Y=c+Σ θ_i A_i. All additions are binary. T is computed from the selected seeds. For m scalar addresses of common support size h and seed length λ, one unframed key has h(λ+1) bits rather than h+m for the eager orientation-plus-T key; this contracts for m>hλ. Each eager row still costs h+1 bits per address. Honest formation must read the row data and compute up to 2hm PRF evaluations, and opening one address up to h more. Shapes with varying public support can skip vacant cells identically in both worlds.

For static θ chosen independently of its reserved masks, replace only the h unexposed functions, not the disclosed seeds. Conditional on selected seeds their evaluations at the chosen addresses are known. In the pseudorandom hybrid each D_i is fresh uniform on distinct addresses; α, selected seeds and D can be sampled before setting E=Y+Σα_i D_i+T. Replays return the same records. Include independent reserves/corrections per distinct function-key slot. Comparing two worlds costs at most twice the sum of the inactive-key PRF advantages at these fixed classical query lists. A quantum distinguisher can run any operation on the published classical coefficients and seeds. A sufficiently secure PRF against quantum algorithms with classical oracle queries suffices for this static reduction, charging all simulated PRF calls, records, final circuit and key-collision effects in the concrete instantiation. No such finite registered PRF reduction is proved here. Two different selections under the same pair can reveal both siblings, and the equality pattern of the published orientations even distinguishes same vs opposite selections when Y is constant. Two-sided exposure below means key plus ciphertext in the same transcript, not both branches of one logical slot.

If c and every A_i lie in one known d-dimensional space V of functions on the authorized addresses, independently sample the paired masks as uniform canonical V-coordinates instead. The entire addressed algorithm works directly on d-bit coordinates. Conditional on the selected coordinates, D_i is independent uniform in V and E is forced as above. Exact equality of all reachable Ys determines their canonical coordinates. Unlabelled selected-key length is h(d+1), and the single correction object is (h+1)d bits. Another exact option of [task 153](https://github.com/MachinaIO/SigabaPark/pull/153) in this space uses π_i, uniform r_i and an independent s in V; it publishes one d-bit T plus h orientations rather than h selected d-bit functions. One may contract the actual rows only when efficient local issuers for these coordinates exist. If a representation has coefficient kernel on reachable points, quotient by the kernel before publication. For duplicate basis functions, coefficients (0,0) and (1,1) have equal evaluations but unequal encodings, and the opening equation on full coordinates would expose that difference. Public basis, framing, correlations with all auxiliary outputs and the full reachable batch must be fixed.

### Changing the actual native tape

Write addresses (i,j,k) with positive row counts a,b,c, respectively. The issuers privately own arbitrary bits x_i, v_j, z_k. They need not know anyone else's values, or the values at their own other ordinals when issuing a row. The function key holds a single hidden bit β. The authorized results are Y(i,j,k)=β(x_i+z_k)v_j. Fix the full Cartesian static batch and one function slot. Extra slots can use entirely independent copies.

Use three public binary spaces of actual functions:
* U={f(i)+g(k)}, dimension u=a+c−1.
* V={v(j)}, dimension b.
* W={f(i,j)+g(j,k)}, dimension w=b u. It contains the pointwise products of U and V.
Set u_m=x_i+z_k and v_m=v_j. An anchored U chart stores values at k₀ for each i and increments away from k₀ for each k≠k₀ at a fixed i₀; the increments do not depend on i. W uses this chart at every j. The anchored_chart Lean proof gives uniqueness for additive abelian groups. Products of U and V in these charts require at most w bitwise ANDs (each U coefficient at slice j is gated by v(j)). No hidden change of basis is published.

In setup draw t as a single uniform bit, X₀,X₁ independently in U, M in V, and R₀,R₁,P₀,P₁ independently in W. At each address use exactly the seven native packet equations with these masks evaluated there. The fixed-tape packet O has fields
* A_e=(e+t)u_m+X_e and J_e=(e+t)u_m M+R_e for e=0,1;
* B=v_m+M and C_e=X_e B+R_e+P_e.
Here a binary e+t gates the whole function. The key is (h=t+β,P_h), with one orientation and w canonical bits. At each address decode A_h B+J_h+C_h+P_h=Y. The proof native_coordinate verifies the coordinate identity. Our setup retains the per-address equations but intentionally replaces the original independent ordinal tapes. Fixed data, independent original tapes give each seven-bit packet full support (choose X₀,X₁,M,R₀,R₁ and then P₀,P₁ to realize any seven output bits). M_ord independent such packets therefore cannot be encoded losslessly in fewer than 7 M_ord fixed-length bits without side information. A compressed independent-tape claim would not follow from affineness in the message.

Condition on h. The two physical rows can be reordered as selected and opposite; their identically distributed masks can be relabelled accordingly. The selected input l is β u_m and the other input is (1+β)u_m. In addition to h, the following seven coordinates are mutually uniform on their respective spaces: A_h, A_(1+h), B, J_h, J_(1+h), P_h, C_(1+h). From them one recovers the original entire tape in order: subtract l and its opposite input, subtract v_m, recover R_e from J_e, retain P_h, and recover P_(1+h) from C_(1+h). The Lean native_free_frame theorem proves this triangular bijection, and even permits any function U×V→W at this step. The remaining coefficient word is forced by Y as C_h=Y+A_h B+J_h+P_h. Thus sampling the free coordinates and this one forced word simulates the complete jointly visible function key and packet exactly. Bijective charts make equality on authorized outputs sufficient; this proof does not assume that correlated row coins are statistically close to independent row coins. Literal copying of one unstructured garbling across all possible row inputs is not justified by it.

### Three local issuers, including setup and all public records

Let F=U²×W²×V×W² in field order A₀,A₁,J₀,J₁,B,C₀,C₁. Its bit dimension is C=2u+b+4w. The x-only packet difference Δ_x=O(x,0,0)+O(0,0,0) has only A_e=(e+t)x_i, J_e=(e+t)x_i M_j. It belongs to a public subspace S_x with two arbitrary a-bit unary tables and two ab-bit pair tables. Define S_z similarly, of dimension 2c+2cb. Embed both by replicating over the missing index and inserting zeros in B,C_e. These two spaces may intersect. Sample independent uniform masks H_x in S_x and H_z in S_z as part of setup. Publish the following canonical records:
* X issuer at ordinal i emits its row of L_x=H_x+Δ_x. This costs 2+2b bits. The z issuer does the same for L_z=H_z+Δ_z using only z_k, with 2+2b bits per k.
* The middle issuer emits L_y=O(0,v,0)+ι_x H_x+ι_z H_z. Its 2u-bit header for both A functions is independent of every message and can be issued once. At row j it emits the two J slices, B(j), and the two C slices, costing 1+4u bits. These depend only on v_j and setup. This accounts for every byte needed to evaluate the packet. Public ordering is fixed. Headers must not contain the private underlying masks themselves.
* Retrieve the requested rows, add corresponding fields at (i,j,k), and open one selected native row with the key. Affineness of O in the three supplied data bits at fixed tape gives O=ι_x L_x+L_y+ι_z L_z identically. The anchors permit each U/W evaluation from at most two bits in canonical storage.

Conditioned on the full base tape and all three data batches, (L_x,L_z) is uniform on S_x×S_z. For a simulated base key and O, choose these shares uniformly and set L_y=O+ι_x L_x+ι_z L_z. All public rows and header are deterministic canonical slices of that view; there is no separate release of raw masks. The Lean private_subspace_shares theorem proves the normalization with arbitrary additive embeddings even when their images overlap. The two bijections give a single exact batch simulator for key, header and all three parties' rows. Any quantum algorithm on identical classical distributions has identical acceptance probability. A view restricted to an arbitrary subset can inherit this proof when both worlds admit a common valid full-batch output extension. If only a smaller set is authorized with unrelated unissued rows, recompute reachable charts, shapes and simulator or allocate fresh slots. Return identical bytes on same-slot exact replay, with fresh setup for incompatible data or selections. Revealing the setup or a second choice under the same setup invalidates the game.

The public count is (1+w)+C+S, with S=2(a+c)(1+b). Compare the literal rank-three eager native control with three seven-bit shares and a two-bit leaf key per Cartesian tuple, or 23abc bits overall. At (2,2,2), key/three-issuer records are 7/56 bits versus 16/168. At (4,4,4) they are 29/210 versus 128/1344. The three middle-header and row records are all included. The setup samples 1+C+S independent bits. The two side issuers together use at most (a+c)(4+4b) binary AND/XOR operations plus reading and writing 2(a+c)(1+b) bits, permitting free indexing only in this algebraic ledger. For the middle header and each J slice, embedding a z table adds its k₀ value into a i-coordinates and subtracts that value from each of c−1 remaining entries; adding both embedded masks to the corresponding base array costs at most 3u XORs per function/slice. All four of these updates cost ≤6u+6w XORs over the full frame. Computing B takes b XORs and both C's at most 2w AND and 4w XOR operations. KeyGen selects one of two w-bit arrays, writes 1+w bits and computes one orientation XOR. At one address the decoder can ignore the inactive row in each object: from each side row read its chosen A and J, from the middle read the chosen A,J,B,C (two coefficients per A,J,C in the worst case), and from the key h and up to two coefficients for P_h. This is at most 14 data bits, plus address/order/seek overhead and bit operations. Setup, separate offline copies and noncontiguous tape accesses are charged in the actual model; these counts are not a registered TM clock.

The specialized relation itself has an easy public decision algorithm when every underlying input table is available to one public solver. The present result is about *distributed private issuance* and joint exposure constraints. Arbitrary 4,096-gate NAND templates have no known three-space description of comparable size. For example an arbitrary i×k interaction cannot be a member of W at fixed j, as its four-corner XOR can be nonzero. Sampling the original independent tapes from a short PRG seed still requires computing or transporting every eager correction if their exact bytes are returned. A basis chosen from secret tapes must itself be hidden or jointly simulated.

### Further boundaries

A related finite optimization applies to a public family of degree-d masks on binary addresses. Conditional on revealing the restriction of a uniform multilinear mask to the entire plane x_i=s, its remaining variation is exactly (x_i+s)Q with Q of degree ≤d−1 in the other coordinates. Split P=P₀+x_i P₁ to see this from coefficient uniqueness. The remaining entropy on any requested inactive point set is the binary rank of its evaluation matrix on monomials of degree ≤d−1, not the number of queried points. On a t-dimensional affine subcube the rank is Σ_{j≤min(t,d−1)} binom(t,j). A single hidden bit does not give independent masks at all remaining coordinates. Pointwise multiplication in a NAND gate adds degree bounds before Boolean reduction; repeated products can exhaust the full address dimension. This conditional calculation does not prove a generic garbling simulator.

Boyle, Couteau, Gilboa, Ishai, Kohl and Scholl, FOCS 2020, Definition 4.3 and Figure 2 give a selected insider *one* PCF key and opposite-side values at random inputs. Definition 4.4 changes to chosen queries, and Theorem 4.5 obtains this stronger variant in the programmable random-oracle model. In Section 5, Figure 6/Theorem 5.3 use function secret sharing for scalar multiples of a weak PRF for VOLE. Neither key-only insider game guarantees simulability when publishing both correlated evaluation programs and all our additional fields. Their efficient candidate relies on variable-density LPN. The discussion in Sections 1.1 and 1.7 also describes a generic FSS/FHE-based LWE route and analyzes ring-LWE with an exponential modulus for exponentially small error; this does not map concrete parameters, distributions, error or reduction cost to the registry of this goal. Neither PCF route is used in our positive template. [Primary paper](https://eprint.iacr.org/2020/1417).

A possible wider compiler would sum hidden products sharing a common space W. Before opening term packets one could add secret uniform W-valued pads summing to zero to both C rows of each term; otherwise a zero sum may reveal the individual nonzero terms. Such a compiler must factor the actual public NAND template, implement all owner-local contributions, count masks/coordinates and prove the whole joint distribution. No arbitrary-circuit under-2^100 WE, exploratory under-2^32 clock, or concrete registered post-quantum reduction is claimed.
