Fix a public branch address v of k bits so that after v is fixed the residual conditions f_i(v,w)=0 are affine functions of the remaining witness w over F2. A general finite compiler processes NAND gates topologically. Track affine forms in the witness, replace constants directly, and for a genuinely nonlinear pair choose the value of the first operand as a branch bit. Constrain this guess to equal its affine form before using the fixed bit in 1+v_j times the other operand, meaning 1+(v_j * other). Add the condition that the output is one. On an accepting witness all guesses come from that same forward computation. Conversely satisfying residual equations force each guessed value and the output by induction. Use registered defaults for missing wires and resolve a repeated parent as NOT. A fixed branch list can include redundant guesses; variable-length decision trees require a declared address/coverage convention.

A useful alternative guesses the parity of both operands. For bits x,y one has xy=(1+x+y)x, as certified in Lean. A common guessed parity can linearize many pairs. More generally a fixed space of branch linear forms suffices for a layer of affine operands when its row space intersects the binary span of each linearly independent pair nontrivially. One of x,y,x+y is then fixed on that layer (including affine offsets). Parsing a syntactically nontrivial XOR as affine requires a sound recognition step; unrelated later gates still need handling.

Choose a finite public vector space D of functions on v for each residual row (different spaces are allowed). Independently sample r_i in the declared spaces, and transmit the canonical coefficient vector of

    P(v,w) = h + sum_i r_i(v) f_i(v,w).

Its nonconstant part is the image of a public binary linear map L and its constant direction is E. If on each NO there are allowed multipliers proving sum_i lambda_i f_i=1 as an identity, then E=L lambda. For any phase bit h, mask translation r -> r+h lambda is a bijection. This holds pointwise conditional on the complete lattice challenge and every other variable determining h, as long as the r remain independent and uniform. The new transport lemma states the conditional finite-sum identity; the underlying image criterion and dual separator are already formalized by CertDual. Since the entire canonical public representation is simulated, any number of adaptive public evaluations, including inconsistent mixtures of spurious witnesses, is automatically covered. The simulator needs neither the secret phase nor a certificate. Symbolic expression trees exposing their secret coefficients separately need not have the same law.

Taking all functions of v gives a sufficient space whenever every residual affine system on a false statement is inconsistent. Each leaf then has an affine linear combination equal to the constant one, so choose these coefficients independently as functions of v. Dense serialization charges B=(1+n_free)2^k bits per output, omitting framing and auxiliary descriptions. A straightforward uniform issuer at every leaf traces the gates through n_free+1 bit coefficients per affine form, emits the residuals and adds the selected forms into an accumulator. With k guess constraints, one output condition, and G gates, dense word/bit-array work is O(2^k(G+k+1)(n_free+1)) before tape indexing and moving the statement; sampling costs (k+1)2^k bits. Decoder traces the actual W, determines v and evaluates its affine row; an ordinary sequential output tape may need to scan all B bits. For this unrestricted-table subclass, checking each residual system by binary elimination also decides its SAT problem. No small k or cheap general shared certificate basis follows for arbitrary circuits.

A registered-size example uses inputs a,x_1,...,x_127. Compute X as their 127-variable parity excluding a via 126 recognized four-NAND XOR macros. The remaining seven gates form na=NOT(a), u=NAND(a,X), v=NAND(na,X), then the AND of NOT(u) and NOT(v). Prepend 3585 unused NAND(1,1) gates to reach 4096. This is a false reconvergent circuit. In its true control use v=NAND(a,X); its output is aX and all 128 inputs influence the output. Recognition of the two final AND conditions gives 1+aX=0 and 1+(1+a)X=0, or the first condition twice on the control. Only a and X occur in the residual; the ciphertext stores constant and X coefficients in each of two leaves (four raw bits total). On NO the certificate (1+a,a) proves one; each separate condition has witnesses. Constant-only multipliers fail, as neither single row nor their sum is one. Enumerating the whole four-bit ciphertext gives 16 equally likely views in both worlds with affine multipliers. With constant multipliers supports are disjoint. The 4096-gate control and false circuits were replayed at all four (a,X) pairs. Independently, all 576 three-ordered-NAND networks on two bits had a refutation at every enumerated leaf exactly for the four false circuits. The 4096-gate example is a restricted recognized family in which SAT is already easy.

To actually deliver all 1024 source parity bits, repeat with independent masks for every anchor. On YES each polynomial opens its specified bit, including on overlapping evaluations of the same witness. On NO their joint law conditional on all challenge data and the anchor is a product of independent L(r_j), enabling exact simulation from a single fixed source challenge. This original full-lock option costs 1024B raw helper bits. The companion note reduces repetitions for the WE message by opening only the phase needed by a different terminal. Full-lock reconstruction and phase-only recovery are different guarantees.
