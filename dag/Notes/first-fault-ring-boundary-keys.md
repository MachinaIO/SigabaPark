## Issuing a shifted clean value without printing it

Take two public finite directed evaluation graphs, with public start vertices, edge-choice rules, and class-typed terminals. Run an authorized input along edges to obtain its class. A missing or invalid input may have a reject terminal. All edges, all terminal rows, both start keys, and every explicitly declared public graph description are in the adversary's view. A valid WE witness must traverse each graph to the same class. On a NO statement require that the two sets of classes **graph reachable from the starts** are disjoint. Including a shifted default terminal is safe even if the issuer cannot or does not decide whether it is reached: its value is sent in a protected row exactly like any other terminal. Standard reachability computes the sets in the proof. The instance-dependent algorithm that builds these graphs must be public, and its construction and auxiliary data must be identical in both bit worlds.

Use the registered rank-one Ring-LWE problem with R=(Z/16)[X]/(X^N+1), uniform ring secret, uniform ring header and fresh independent CBD(1) error coefficients in {-1,0,1}. Select independent uniform node keys k_v in R and independent uniform single-bit class masks p_i. Output both start keys. For **every edge** u→v issue two independent rows

    (A_d, B_d=A_d k_u+e_d+d k_v),   d=4,1.

For **every terminal** u of class i issue one row with B=A k_u+e+8m in R, encoding a bit in the constant coefficient only. Here m=p_i on the front and m=p_i xor beta on the tail. Intermediate and terminal headers are all independent uniform ring elements. Repeated destinations and coincident starts across the two sides should use explicitly separate graph-key domains; class masks are shared precisely by class identity.

A holder of k_u subtracts the noisy product. For each destination coefficient z first receives 4z+e0 modulo 16. Nearest-multiple-of-four rounding gives z mod 4. Next subtract that low digit from z+e1 and round to a multiple of four to obtain its high base-four digit. The Lean modular decoding theorem includes wraparound, either error endpoint and all residues. Thus recovery is exact with bounded CBD(1) noise at each hop and errors never accumulate. The terminal's two possible phases are 0 and 8 with disjoint error windows; comparing the closest one gives its bit. XOR of the two matching terminal bits is beta on every authorized witness.

## Full public-view reduction, including directed cycles

Fix a false instance and a bit. Compute the union of the publicly reachable vertices in the two graphs. Start keys and all live keys can be sampled honestly. There is no edge from a live source to a dead destination. For each dead vertex choose an independent uniform public-to-the-*reduction* shift t_v, never included in the view. In the **real branch of the one challenge** define k_v=s+t_v for the common unknown challenge secret s. Conditional on any s the entire family is independent uniform, including self-loops, repeated children and arbitrary shared directed paths.

Take a separate challenge row (alpha,r) for every issued row with a dead source, from one ordinary multi-row Ring-LWE instance. With a dead destination choose A=alpha−d (the scalar is a constant polynomial) and B=r+A t_u+d t_v. If r=alpha s+e, this is exactly A k_u+e+d k_v. With a live destination choose A=alpha, B=r+A t_u+d k_v; for terminal output replace the last term by its known phase. Live-source rows are generated with their honest keys and errors. The public headers are independently uniform even conditional on all shifts, since each is an independently translated uniform header. An ideal challenge makes every dead-source B independent uniform after these translations, even conditional on every header, shift, live key, class mask and remaining randomness. This argument uses one classical fixed-distribution challenge for the entire dead subgraph. It applies to cycles and requires neither a circular-security premise nor a hop for each vertex. Pad the challenge to a fixed row cap independent of the statement, use the necessary subset and ignore the rest. The decision game supplies these rows in its registered encoding; unpacking, modular arithmetic and repacking are costs of the reduction. The algebraic postprocessing also works for quantum distinguishers on ordinary classical samples if the underlying assumption covers their class; the registered model is classical.

When all dead-source rows are uniform, the only class outputs that influence real terminal bodies are those on reachable terminals. For front-live classes choose independent fair bits; for tail-live classes do the same. Disjointness ensures this is the exact idealized joint law for either beta, including repeated occurrences of the same class. Generate terminal bodies at live nodes using those effective bits. One comparison per fixed bit proves table gap at most twice the single comparison advantage. Equivalently use a uniformly random beta and a success test against the common ideal, with the convention for success bias stated explicitly. Auxiliary functions of this table are free of any new security premise but their runtime is charged. Graphs with reachable intersecting classes have no such authorization: anyone who can choose and combine arbitrary edge traversals can recover the bit. The absence of an overlap among **semantically consistent** inputs alone is insufficient.

## Capped first-fault instance and costs

Use 42 three-bit blocks. The front maps each (x,y,z) to (x,y AND (x OR z),z), hence its output always has no 010 block and it has the identity opening on each clean word. Mask class zero is the all-clean default; classes 1 through 42 are the first index of a 010 fault, i.e. products of local indicators and all earlier complements. The class-zero bit can be given by a front root terminal. For the tail, a public width-two one-pass parser on clean blocks keeps one state bit, branching on the next triple. At the first fault expose the corresponding tail fault-class value immediately; it may be exposed even on inputs the original tail would subsequently reject, since this extra class never occurs on the front. At end expose class zero only on the accepting parser state, with an actual terminal row present independent of whether any clean input reaches that state. Read-once disjoint triples guarantee every root-to-terminal choice of realized triple transitions can be combined into an input. Include only local transitions that exist for at least one of the seven clean symbols or the fault symbol; computing these at one parser state costs checking eight public symbols, with no global SAT oracle.

A concrete parameterized parser has next state p xor h_i(triple), starts at zero, and accepts clean inputs at state one; it also accepts every faulty input. With h_i=0 on the seven clean triples the NO instance is precisely the 42-block comparator control (585 raw NAND gates before padding to 4096). Allowing a nonzero clean symbol in one table while keeping all other tables zero gives a YES neighbor. The graph issuer has the same algorithm for either. Deduplicate identical next states per parent: at most two clean destinations and one fault terminal. Thus at most 84 parser states, 252 edges, 42 fault terminals and one clean terminal on each side (44 terminal rows including front). The public symbol-to-edge map remains present and is independent of masks. A witness follows at most 42 edges, plus two terminal reads.

At this cap take the **actual registered** RingLWE.Params m=548, q=16, secret uniform and error CBD(1). The pinned core returns H=87, 138, 233, 409 at N=256,512,1024,2048 respectively. These are estimator outputs for this sample count, not measured attacks or a QPT certificate. Raw row fields cost 548·8N bits, plus 8N bits for two start keys, routing, class IDs and framing. At N=1024 rows occupy 4,489,216 bits. Up to 548 N^2 coefficient-pair visits in naive negacyclic issuer products mean 574,619,648 visits at that N, excluding coefficient arithmetic, noise sampling, movement and serialization. At most 86 ring products decrypt the paths (2 per traversed edge and 2 terminal products). A reduction simulates all live-row products and may need a product A t_u for each challenged row. No verified native clock bound follows from these counts. Tested all 144 scalar residue/noise triples, 393,216 scalar header transports, and 2,500 edges over small negacyclic rings including cycles and self-loops.

The public graph also gives a cheaper direct decision algorithm for this subclass: traverse starts, compute reachable classes, and compare their sets. For this clean interval example, an overlap provides a consistent common clean boundary because the front accepts every clean word; for a general compiler the YES and NO promises together would suffice to decide the language. The cryptographic result supplies an actual whole-key issuer and a restriction theorem, not a general SAT compiler. A read-many tail can admit fictitious paths after public labels are pooled. The recursive issuer for the general case must enforce those consistency constraints or supply another sound representation with charged cost. Compare the earlier [changed-chart task](https://github.com/MachinaIO/SigabaPark/pull/219), [CDS shared completion](https://github.com/MachinaIO/SigabaPark/pull/227), and the topological one-pad-per-incidence key router: the present simultaneous ordinary-ring reduction covers cycles as well as the two correlated output vocabularies. The earlier oracle-only degree-five parity test and degree-six uniform-mask coin lower bound do not apply to these full ring-noise descriptions.

## What public sampling still tests

Ciphertexts here have fresh random headers and noisy products of two sampled ring elements. They are not justified as uniform on an affine support by the linear terminal-mask semantics. For example CBD(1) at modulus 16 has probabilities 1/4,1/2,1/4, rather than uniform coefficient noise. Even a nonlinear final lock would not rescue an independent affine auxiliary-key design automatically: if public encryption can self-sample a low-dimensional uniform affine pair (helper, secret) by retaining its own private issuer coins, Gaussian elimination on these augmented samples learns the dimension of the secret fiber over the helper. Fixed-witness recovery of the *entire secret from the helper alone* with error below one half forces a singleton fiber, since every nontrivial affine fiber is uniform on at least two points. Information-theoretic hiding of any residual secret dimension forces a positive-dimensional fiber. This yields a public decision test under those two extra premises, even when the final anchor itself is nonlinear; it is not a learning claim for general noisy product transcripts.

## Scalar cross-check at a fixed secret type

A second route uses ordinary scalar LWE with CBD(1) secret and error, issuing fixed-Hamming-weight signed ternary labels. On the designated secret type, independent random signed permutations of a common secret are independent uniform keys of that type. Reindex the challenge row and absorb each linear destination coordinate into its header; SignedRow verifies the sign cancellation after permutation. Unknown weight cannot be tested from the challenge. Instead use two independent row banks with the same secret, compare each bit of an adversary against a freshly generated ideal view, and use the product of the two signed differences. Conditional on weight the expectation is the squared conditional gap, never negative. A fair coding of the product and a shared fair payload give a decision-LWE gap at least Pr[weight=floor(n/2)]·(real payload gap)^2/8. PairedDifference, TypeGap and RetainType verify the averaging components. Uniform signed permutations require bounding finite-coin approximation by e.g. Fisher–Yates with cutoff and a collision/error budget. At the scalar interface m=2(252n+44), q=16 with both laws CBD(1), actual H for n=256,512,768,1024 equals 96,138,184,233. This route pays a squared-gap loss and per-coordinate rows; the primary ring construction above avoids both using exact uniform shifts and radix recovery. Neither route establishes the registered full-language SubmissionProp.
