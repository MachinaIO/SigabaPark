The small-score guard has a nonzero modular signal even on inconsistent paths. Here the signal on such paths is an entire random share. The construction below gives a bounded-query ideal interface and a concrete limit on using it in reusable ciphertexts.

Fix an occurrence string x of length h. Let f(x) in {0,1} be the verifier on independently chosen occurrence bits and let Hx be the vector of first-versus-later parity discrepancies, of length s. Embed this vector injectively and linearly over F2 in a fixed binary extension field F of degree at least max(1,s). Write z(x)=sum_i x_i h_i using the embedded columns of H. On a false instance every path with f(x)=1 has z(x) nonzero. Choose one field-element message mu. For a target Q>=1 sample independent uniform coefficients c_1,...,c_t with t=2Q and set

    p(z) = mu + sum_(j=1)^t c_j z^j,     O(x)= f(x) p(z(x)).

A valid accepting path recovers mu exactly. Consider coherent XOR access to O, with all coefficients private. At any d<=t distinct nonzero field points the p-values are independent uniform: the first d columns of the evaluation matrix form a Vandermonde matrix times a nonsingular diagonal of the points. Consequently on a false instance any at most t named path outputs have precisely the joint law of the function assigning zero to rejecting paths and a fresh common random field value to each distinct accepted syndrome. Repeated syndromes agree in both experiments. A Q-query quantum algorithm then has exactly the same average final state: after Q XOR queries each density-matrix entry is a sum of terms depending on at most 2Q point values, by expanding the query unitaries on both sides of the density matrix. This uses the bounded-independence principle of [Zhandry](https://eccc.weizmann.ac.il/report/2012/140/). It holds with arbitrary public f,H and unrestricted offline computation, for the specified oracle-only interface.

**Matrix-program cost.** Maintain the row (1,z,...,z^t), initially (1,0,...,0). The transition on bit b at position i is the (t+1)-square upper triangular matrix whose entry at row j and column k for 0<=j<=k<=t is binom(k,j)(b h_i)^(k-j), with zeroth powers equal to one. The binomial theorem propagates the full row under z -> z+b h_i in characteristic two. The terminal column is (mu,c_1,...,c_t). Tensor with a width-w field matrix program for the Boolean output f in the same read order to get width w(t+1). A Boolean branching program with deterministic transitions is one compatible frontend. Public verifier size and field representation are charged separately. Direct syndrome accumulation followed by Horner evaluation needs O(h+t) field additions or multiplications on a selected path, besides computing f. The hidden coefficient bank has (t+1) field elements. The field and its arithmetic are part of this candidate; the dyadic integer LWE encoding of earlier layers does not automatically implement extension-field multiplication.

**Why the access restriction matters.** For the always-false statement that some variable disagrees with itself, the relaxed verifier can accept precisely when two separately chosen copies of a vector differ. Every nonzero discrepancy is then available by choosing first copy zero and second copy equal to that vector. With field degree equal to the discrepancy length and |F|-1>=t+1, t+1 classical evaluations at distinct nonzero points recover p(0)=mu by Lagrange interpolation. A public ciphertext supporting arbitrarily many such path evaluations therefore fails even if its internal coefficient bank is completely hidden. Publishing that terminal column directly also reveals its first coordinate. The bounded-query result handles polynomially many joint low-consistency evaluations only for a preselected budget; choosing polynomial t leaves a polynomial interpolation procedure.

Replacing p by mu+F_k(z)-F_k(0) for a quantum-secure PRF removes that interpolation limit in the hidden-oracle model. On false instances the random-function hybrid evaluated at nonzero syndromes is exactly independent of mu, since the independent value at zero is a common pad. A reduction computes F_k(0) once and implements the coherent path oracle with a constant number of challenge queries per path query. This replacement requires a way to publish the composed evaluator while preventing evaluation of its keyed internals on arbitrary field inputs. The polynomial matrix program above does not implement that replacement and ordinary PRF security gives no such public evaluator.

**Factoring each read.** Translation by a nonzero a=h_i on degree-at-most-t polynomials has transition difference from identity of rank exactly floor((t+1)/2). Indeed v=z²+a z is translation invariant, and v^j and z v^j of degrees 2j and 2j+1 form a monic triangular basis through degree t. The difference kills each v^j and sends each z v^j to a v^j. One can also apply a translation to the monomial row without storing a dense matrix: for each binary position i of exponents up to t, add a^(2^i) times coordinate k-2^i to coordinate k for each k<=t with that bit set. The source lacks this bit, allowing in-place updates at the same stage; paths through the stages give exactly the odd binomial coefficients by (z+a)^(2^i)=z^(2^i)+a^(2^i). This costs O(t log(t+1)) field operations per full row and O(t) storage. The compact factors improve honest evaluation and leave the interpolation bound unchanged.
