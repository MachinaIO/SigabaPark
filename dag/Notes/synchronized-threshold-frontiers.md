## Shared trace addresses

For 128 witness bits and 4096 NAND gates, address a trace by the witness and 4095 nonterminal outputs in topological order. Force terminal output one and use the registered constant-one convention. Each NAND z=NAND(x,y) is the conjunction of (not x or not y or not z), (x or z), (y or z). Repeated literals or constants can be simplified. On NO, fix the witness. Classify each trace by its first wrong nonterminal bit, or by having no wrong internal bit. Each wrong-bit prefix fixes both parent values and the incorrect output, hence falsifies one specified clause on every extension. The honest internal leaf falsifies a terminal clause. These 4096 blocks partition all extensions. In lexicographic order the siblings preceding the honest path occur in increasing depth, the honest leaf follows, and the remaining siblings occur in decreasing depth. The partition has 2^140 blocks across witnesses. Its indexed member needs one circuit evaluation and this ordering; its rank is proof bookkeeping, not an issuer loop.

For m additive parties, a literal key authorizes its clause party's same share at addresses satisfying that literal. Enforcing the same address for all parties gives correct decoding on a genuine trace. To use the partition, changing one block requires its clause party's joint restricted bank together with every other party's view. Ordinary privacy against m-1 full parties alone does not give this. A witness-PRF masked-evaluator interface and a static garbled-label table address different public descriptions; neither cited DAG note supplies this threshold-key simulation.

## Concrete two-party threshold

Let T_t(x)=[x<t] for the integer address in [0,2^n), including endpoints t=0 and t=2^n. This variant of the two-party correction-word tree dedicates a separate seed correction to each child. It is designed to terminate the live path at an internal dyadic boundary without leaking that depth. For the baseline two-party point-function construction and its correction words see Boyle, Gilboa and Ishai, *Function Secret Sharing: Improvements and Extensions*, CCS 2016, [full version dated July 24, 2018](https://eprint.iacr.org/2018/707).

Each party starts with an independent uniform k-bit seed, known control j for party j, and accumulator zero. The public deterministic generator G expands a uniform k-bit seed to two independent-looking triples (k-bit seed, one control bit, one value bit). A local state is (s,tau,a). At a child, first obtain raw (u,v,w) from G(s), then output (u xor tau U, v xor tau V, a xor w xor tau W) using that depth and side's public correction (U,V,W). All additions below are XOR. Correctness holds for every G.

At the root start the dealer live even for a constant threshold. At each live node the controls differ. For each child independently, call it live if its address interval strictly straddles the cut. On a live child choose U uniformly; on a dead child set U=u0+u1. Set V=v0+v1+isLive. Set W=a0+a1+w0+w1+c, where c=0 for a live child and is the constant threshold value on a dead child. If there is a live child, continue down it. If neither child is live, choose all subsequent correction strings independently uniformly. Always publish both corrections at every depth, even after termination. There is no need to know a circuit in the generator game.

At every live child the controls differ and the accumulators sum to zero. At every first constant child seeds and controls agree, and accumulators sum to the known threshold constant. At every descendant of this child the same generator input and same control add identical increments, hence retain the difference. The depth-n accumulator is a share of the desired threshold. A root key includes its party index and seed; the correction bank is shared once.

## Restricted keys as a common function of one full key

A restriction to a public union of proper prefix subtrees consists of the party's state at each named root, a common copy of the correction bank, and the public prefix labels (these can be implicit in the declared order). Any prefix disjoint from B=[l,h) is in a constant region for both T_l and T_h, with the *same* known value there. The missing party's honest state there is exactly the known party's state, with the accumulator toggled by that value. This also reconstructs repeated or overlapping restrictions with precisely the real correlations. A single adapter, independent of the challenged threshold choice, takes a full known-party key and constructs the joint view of every such missing-party restriction and all required known-party keys. Arbitrary overlap among the held party's restrictions is allowed. The Lean theorem verifies the path-extension and whole-description equality after synchronization. The generator hybrid and the NAND application in this note are paper arguments.

Ordinary two-party point DPFs already give this external-frontier simulation for a *single public active point*, comparing two hidden payloads there: the corrected states agree after the first deviation and both sides see the same final common correction. For threshold switches involving an entire block, representing both endpoints canonically matters. An exclusive cut at the first address outside B can have a point-tree spine inside an external subtree. Here the spine is exactly the sequence of mixed intervals; it stops as soon as both children are constant. A single shared seed-correction string cannot in general synchronize both children at such a stop: it would have to equal both independent raw seed differences. For uniform raw pairs this necessary equality has probability 2^-k. This observation concerns exact state reconstruction with that encoding.

## Fixed generator reduction

The only computational game used in this lemma supplies either G(U_k) or a uniform 2(k+2)-bit string. Use ordinary post-quantum distinguishing security for classical samples against the downstream observer. Replace the missing party's expansion at successive live-parent levels, including the terminating level, by independent uniform strings. In the randomized prefix, its next live seed is uniform independent of the known party's root, previous public corrections and known active path. For the dead sibling, its raw hidden seed masks the published U; for a live child the independent fresh U leaves the hidden raw seed unused in the public transcript. Both V and W are masked by independent corresponding hidden raw bits. Even when the hidden control is one and U modifies its next seed, conditioning on that public U preserves uniformity. At a stop, the raw hidden seed masks U on both sides. The hidden control along the live path is the opposite of the known control, and its accumulator is the known accumulator. Therefore the adapter can sample the ideal prefix without knowing the challenged seed, insert the challenge expansion at its designated level, compute the actual hidden child state from its raw outputs and continue the suffix normally. This is an equality of distributions at each boundary. The generator need not take a statement, target, position or offset. The fully randomized view consists of the known root and uniformly independent correction words, regardless of t. A one-key comparison of two cuts loses at most 2n generator distinguishing advantages. Indicator outcomes under any deterministic joint adapter give the same bound evaluated at the adapter's actual cost. No hidden-key PRF oracle or random address guess is used. A public input XOR pad would preserve dyadic subcubes but is unnecessary here.

The full common public bank uses 2n(k+2) bits; one root seed costs k bits. With L missing roots in an explicit prefix bank, it takes L(k+2) additional bits, plus any labels or directory. Producing them costs at most nL traversals measured in single generator expansions, with shared prefixes reducing the count. Decryption from two covering roots costs at most 2n expansions plus lookup. These count fields and generator invocations only. A reduction for an observer on a materialized key bank must pay for producing it. Guessing one among the 2^140 adjacent hybrids, then one of at most 2n generator steps, cannot by itself certify a concrete cost/gain statement. The RNG game here is a conventional premise for this auxiliary result; no new assumed-hard family, estimator or parameter strength is proposed.

## Two-party domain compiler and cost boundary

One way to use just two roles is to give every gate its own three pins and include 129 source pins. For each of P=12417 pins expose two address bits (x_j,y_j). Let A require x=y, the prescribed true source and terminal, and the local NANDs on disjoint triples. Let B require x_j=y_pred(j) for the cyclic predecessor of pin j on its wire. Each wire's occurrences form a single cycle. Hence A and B together enforce the registered trace. A valid witness deterministically generates one common address in both. Read the 128 distinct input source x bits first and then all remaining bits in physical pin order, x before y. A wrong source constant or y twin falsifies A as soon as it appears; a wrong input to a gate violates its earlier predecessor equality in B (the source or output occurrence starts that wire), and a wrong gate output violates A's local NAND. Cyclic closure imposes the consistency of the final copy too. On NO the fully honest trace falsifies the forced terminal condition. The first-fault partition therefore contains at most 24707 times 2^128 blocks, below 2^143. A flat compiler emits role 0 restricted to A and role 1 restricted to B for the constant threshold endpoints. For each block one role's entire domain misses it, so the adapter recovers that role while deriving the other's authentic restrictions from its full root key. This gives an uncapped finite conditional two-role release whenever the domains have explicit prefix covers; resource and security claims must account for the covers.

In the original bit coordinates the B-domain is a Cartesian product of P independent equalities on distinct pairs. It contains exactly 2^P points. Flipping any single coordinate in a member violates its matched pair. Consequently every nonempty ordinary subcube contained in B is a singleton, even with arbitrary variable ordering or adaptive literal splits. Its explicit prefix frontier needs 2^12417 root states. Public XOR offsets and permutations do not change this count. This excludes a 2^100-bit honest endpoint using this encoding. A linear coordinate change can straighten B using parity coordinates; simultaneously obtaining compact restrictions and efficient joint simulation for A and B in a shared model remains open. For a single late literal at coordinate j (counting from one), an ordinary ordered tree needs 2^(j-1) prefix roots. Moving a given clause's at most three guard bits first makes each literal cheap and maps an original prefix into at most eight prefixes in that clause's reordered coordinates. Independently instantiating these trees does not ensure that the different roles sum to the same common-address function. A compact restriction for a product of constraints would need its own proof of the complete joint description.

The tree identities were also tested at all thresholds for depths one through six with five independent key generations per threshold and every constant-subtree prefix. With one-bit seeds the root-level randomized expansion gives each of the 64 correction banks once at depth one for every threshold. These are finite algebra checks, not computational security tests. The clause partition was exhaustively tested on all addresses in 30 small false circuits, and the pin construction on 16 single-gate examples including malformed references interpreted as the true wire.
