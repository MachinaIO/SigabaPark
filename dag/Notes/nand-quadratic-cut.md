**Exact implicit propagation.** For k independent NAND tuples, choose their 2k free pins v and replace the output of factor i by 1+x_i y_i. Absorb the constant terms into the target b. All affine linking, terminal and constant-pin equations now have the form Av+Bp(v)=b over F2, where p_i=x_i y_i. Repeated original input occurrences remain linked by those equations. The usual star-of-pins translation handles arbitrary NAND circuits after normalizing self and forward references to the default true constant. One can also insert a verified affine transformation between local pin blocks directly. Set d=rank B, not the rank of [A B], the number of gates or the number of prefix syndromes.

Eliminate rows against the product columns. The rows with no remaining product constrain v linearly. Solve those equations and parametrize all their solutions once by v=v0+Lt with f free coordinates. If they are inconsistent return zero. The other d rows become Boolean quadratics q_j(t)=0 modulo t_i²=t_i. This is row reduction on one shared assignment. In coordinates adapted to the image of B, reduction in the DAG states the exact equivalence for every assignment, retaining both the quotient test and the residual equation. No approximation to the set of jointly reachable tuples is made.

The number of consistent assignments is

    2^(-d) sum_{J subset [d]} sum_{t in F2^f} (-1)^(sum_{j in J} q_j(t)).

The count theorem proves this identity as an equality of integers after multiplication by 2^d; for each t every nonzero residual cancels. Each inner quadratic sum has a polynomial-time exact algorithm. If a cross term xy is present, write its exponent as xy+xL+yM+R, where L and M are affine in the remaining variables. Summing x and y gives 2 times the sign with exponent R+LM. This is the pivot theorem. The new exponent is still quadratic. When no cross term remains, a nonconstant linear phase sums to zero by a coordinate flip, and a constant phase sums to plus or minus 2 raised to the number of remaining coordinates. At most f/2 pivots occur per character. For a dense coefficient representation each pivot takes O(f²) bit operations; 2^d characters suffice, plus polynomial preprocessing, integer additions on O(f+d) bits and the final exact division. The executable enumerates characters in Gray order. To obtain a witness, fix one original free pin to zero if the count stays positive and otherwise fix it to one. Such conditioning adds only linear rows and never raises d. Count refers to local assignments, with a one-to-one lift through the solved linear system. Unused original primary inputs may extend a given tuple assignment in more than one way.

**A 128-bit frontier with only one quadratic equation.** Split the 128 input pins into x and y of length 64. The first half of the factor presentation takes the 64 products x_i y_i. The second half takes 64 fresh independent pairs u_i,v_i. Impose the affine link u=Ux+a, v=U^{-T}y+b and one target parity for the sum of all 128 NAND bits. U is block diagonal with a 2-by-2 shear (x0,x1)↦(x0+x1,x1); the dual shear sends (y0,y1)↦(y0,y0+y1). Their dot product agrees with the original. For a=b=0 the parity is always zero. For any nonzero offset pair the remaining affine phase is nonconstant and balanced; for example the linear terms of x and y have coefficients U^T b and U^{-1}a. The exact counts are therefore 0 or 2^128 at zero offsets and 2^127 at nonzero offsets, for either target. The companion generates eight literal 4096-gate statements, checks the counts and recovers a satisfying witness where one exists.

The prefix syndrome contains an invertible image of all 128 input bits from the linking rows. Thus at the middle cut there are exactly 2^128 distinct prefix contributions. With zero offsets and target zero, each has one actual compatible suffix. For target one, keeping only the affine span of the suffix still leaves the middle states: the lifted graph (u,v,dot(u,v)) has full affine span (the zero vector, all units and an active cross term give the parity direction). The quadratic algorithm has d=1 in both cases. In contrast, enforcing every physical XOR gate with an additional independent NAND tuple can increase d. Providing or finding a good semantic factorization is part of implementing the general algorithm.

**A limitation for short additive ring phases.** Take the accepting zero-offset, target-zero endpoint and ask the stronger question of exact two-sided *opening validity* on all independently supplied prefix and suffix tuples. Relabeling suffixes by the inverse shear, their compatibility matrix is the 2^128 by 2^128 identity support. Over any field, any factorization P Q that vanishes off-diagonal and stays nonzero on the diagonal has width at least 2^128 (dimension theorem). Prefix and suffix encodings themselves may be nonlinear. This covers a linear weighted automaton with an exact zero/nonzero terminal across this ordered cut.

More generally suppose each prefix i has some encoding p_i in a finite additive commutative monoid G and each suffix j provides an additive homomorphism h_j. If h_j(p_i)=0 off-diagonal and h_i(p_i) is nonzero, then all subset sums of the p_i are distinct: test an index in the symmetric difference. The subgroup theorem formally yields |G|≥2^(number of prefixes), with no field or nonzero-divisor assumption. A vector of h degree-n ring words mod 2^w thus needs h*n*w≥2^128 bits for this terminal. A fixed affine offset can be handled by subtracting a common neutral baseline or adjoining a constant slot when the resulting model is additive. The argument uses exact simultaneous isolation for a fixed public setup. An equality test whose *zero* phase means valid, threshold rounding, a collision-resistant nonlinear hash, probabilistic per-query error and an issuer that only decides existence are different models. In particular this bound neither refutes ordinary RingLWE nor rules out a more general witness-dependent release. A live RingLWE encryption of a running syndrome can hide its value, but remains linear under accumulation; handing out tests for all terminal coefficients or using several independently chosen openings supplies no proof that one complete witness opened the required target.

**Native role at the registered input format.** A second concrete family uses the same invertible shear and a fixed target parity one. At each of 128 input pins of the 64 transformed NANDs, the binary encoding may contain either the prescribed wire or the public true constant at address zero. The output XORs all initial and transformed NAND bits. With no replacement it is identically false. On a defective pair (u,v) its residual is uv+(l OR u)(r OR v), with l and r recording which pins were replaced. Each nonempty choice gives a nonconstant quadratic on that pair. Distinct pairs use independent coordinates in the transformed basis, so for any nonempty fault set both target parities are attainable. The local truth tables are checked by shear and fault. All 2^128 syntax variants read the same number of gates; padding uses dead NANDs before the terminal gate.

ShearCutRole.enc is a zero-work-tape registered machine. It checks the full 1,031-bit parameter frame, every physical gate token, the statement terminator and one-bit message framing. An intact (a,b) has physical chunk 1^(8a+3)0 1^(4b+1)0. Only at the 128 expected switch sites can the zero-wire short run replace that token; the finite control skips that run's unused template positions and records that a replacement occurred. A binary search on fixed token starts defines the canonical table entries, with a closed form for long repeated padding; the state count prices the entire transition table. A malformed input or the intact NO emits framed zero, a valid nonempty fault set emits the framed message. The decoder skips parameters, statement and witness and copies the framed ciphertext. A maximum 4,685,687 template positions give 9,371,390 states and a 4,685,699-tick clock. The encoder table costs 1,574,393,520 bits. Decoder clock 210,000,000 and table length 294 give total 1,789,079,513, below 2^32. The costs theorem evaluates these exact native role objects. The sampled words include one byte-compared to the actual core paramsWord, relation.encStmt and encodeTuple. A full Lean bisimulation of the finite controls and the NAND semantics remains open.

For the native family, success is publicly recognizable and the terminating issuer supplies exact NO hiding without a cryptographic assumption. For general circuits d and the useful affine factorization are uncontrolled; neither the issuer's present correctness class nor its priced role implements a general WE. No complete post-quantum reduction is asserted.
