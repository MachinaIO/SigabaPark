## An assignment-bound merge interface

An earlier branch-tag attempt let a gate combine parent values reached on incompatible assignments. Consider binding the whole derivation to a context derived from the original input. For a concrete feature generator use the prime field of order 2²⁵⁵−19. Interpret the 128 witness bits as a little-endian unsigned integer t and compute H(t)=(t,t²) in the field. The map uses fixed public parameters and the evaluator needs only its witness. For a wire whose support is restricted, pack its support coordinates in their original order. The example below uses a wire whose function depends on all inputs.

Here is the candidate interface tested. For each wire and value, Gen chooses a syndrome offset s and an additive embedding J of the two feature coordinates in a syndrome group G. Fix a public additive map A from integer vectors to G, for example matrix multiplication followed by reduction. A handle for that value at t is a vector X with A(X)=s+J(H(t)). A merge must consume two handles at the matching context, derive a NAND output handle, and propagate the bound context. Suppose every valid pair under the stated norm thresholds enables the transition, with no other authentication. Honest evaluation reveals the intermediate handles on chosen witnesses. A terminal algorithm would recover the common pad from any valid accepting handle. This describes the input to a necessary test. Construction of the public transition descriptors and endpoint under a registry assumption remains open. The quadratic feature is public and supplies no hiding by itself.

## Which combinations survive

Consider integer coefficients with sum exactly one, so the unknown offset is preserved. Their weight is the sum of their absolute values. A new context means one absent from the source contexts. With an injective J the minimum weight permitting a new context for this generator is **five**.

* Weight one copies an existing tag. Weight three has the form H(a)+H(b)−H(c). Equality to H(d) means the unordered pairs (a,b) and (c,d) agree. Indeed the linear and quadratic coordinate equations imply 2(a−c)(b−c)=0. The theorem quadratic_tag_pair_unique establishes this in every integral domain with nonzero two, including coincident points. Thus d was already among the positive sources. Integer coefficients of sum one have odd weight.
* The matching upper example is H(4)=H(0)+2H(3)−2H(1). Both coordinates agree already over the integers, and all four contexts are distinct in the fixed field. For *any* three valid preimages X₀,X₁,X₃ of norm at most B, the vector X₀+2X₃−2X₁ has the target syndrome and norm at most 5B. The theorem quadratic_syndrome_lift proves both claims for an additive map, an arbitrary quadratic sequence of syndromes and a seminormed additive commutative source. It permits different random preimages of the same legal syndrome. Its existence conclusion requires no trapdoor, Gaussian model, or extraction from ciphertext noise.

The parabola's pair-sum property is classical. The application here is the exact coefficient threshold for the proposed tag and its effect on a NAND merge. A plain affine packed tag already satisfies H(2)=2H(1)−H(0) at weight three. For the quadratic case the pair-sum calculation and the five-term witness were also checked for every source triple at primes 5, 7, 11, 17 and 257. ## A false circuit that tests the claimed operation

Let u be the predicate t≠4, let v=NAND(u,u), let r=NAND(u,v) and let z=NAND(r,r). Every assignment gives z=0. Equality to the fixed bit string 4 can be computed by negating selected input bits and using 127 binary ANDs, each realized by two NANDs. One more NAND complements equality to obtain u. With the last three gates this uses at most 386 gates. Put unused constant gates first, and adjust indices to make z the last of the 4,096 gates. All variables are in the support of u.

Run honest wire evaluation at t=0,1,3 to get u=1 handles. At t=4, honest evaluation supplies v=1. The five-term lift supplies a u=1 handle at the *same* t=4. If the merge into r accepts all syndrome preimages through radius 5B for u and propagates valid outputs, the (1,1) row yields r=0. Duplicating that handle gives z=1. Under the terminal contract this releases the pad on a false circuit. The argument assumes the transition is functional on those off-trace valid handles. It also assumes the honest handles meet B and their thresholds on the same ciphertext. With randomized correctness these joint events require their own probability bound. The primitive's correctness on satisfying statements alone does not imply them. No claim about the registered security game follows without instantiating those hypotheses and accounting for costs.

## Improving the tag and what remains

One more feature coordinate already removes the displayed relation: at degree three the integer discrepancy is 4³−(2·3³−2)=12, nonzero in the chosen field. More generally use (t,t²,…,tʰ) when the characteristic exceeds h. If a coefficient combination of weight at most 2h−1 and sum one yields a fresh context, move its negative terms and the new context to the other side. Both sides then contain the same number m≤h of terms, counted with multiplicity. Their first m power sums agree. Newton identities recover all elementary symmetric polynomials, so the corresponding monic polynomials and multisets coincide. This excludes such a fresh context. The higher-moment extension is a paper argument. It relies on an injective feature embedding into the syndrome. Truncation and arbitrary ring quotients can destroy this property.

Coefficient weight is **not** a lower bound on the norm of a resulting preimage. Even an acceptance threshold below 5B might admit the computed vector through cancellation. A usable reduction must handle short combinations of large weight, arbitrary new preimages and any correlated public helper data. A concrete next target is to derive a new short kernel vector from any off-trace accepted merge despite the public ability to obtain honest handles for arbitrarily many contexts, and to connect that event to a fixed entry of the existing decision registry. A standalone collision-resistance assumption would change the registry. Even authenticated merges still need a terminal conversion whose complete false-statement ciphertext hides the message from quantum distinguishers.

With literal fixed-width field coordinates, one pair has 510 bits and four pairs per gate at 4,096 gates have 8,355,840 bits. Three coordinates give 12,533,760 bits at the same replication. Either can instead be computed from a witness where the interface permits it. These are feature sizes. Matrix descriptions, handles, input access, arithmetic, sampling, other output fields and both machine descriptions still need pricing against the strict 4,294,967,295-step aggregate. There is no total upper bound for a complete scheme here.
