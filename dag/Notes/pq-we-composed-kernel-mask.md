Take h binary layers of the masked-correction construction. Indices below run from 1 at the root to h at the terminal key. Fix common public transitions S_i0 and S_i1=S_i0+U_i V_i, root projection P0, and a common efficiently sampled law for basis errors independent of keys and LWE coins. Each intermediate key is initially independent uniform in the forward experiment; the terminal key may have any efficiently sampled law independent of the other coins. The only extra key exposure is the published P0 A0. All arithmetic is over Z/(2^k).

**Choosing masks jointly.** Let P_i generate the row module of the stack of P_(i-1) S_i0 and P_(i-1) S_i1. Retain public reconstruction coefficients for this stack. Choose the columns of Z_i to generate the entire modular kernel of M_i=P_(i-1) U_i. These choices are computable by integer normal forms, including torsion at composite modulus. For example a diagonal coefficient 2^j in Smith coordinates admits kernel generator 2^(k-j) when 0<j<k; a zero diagonal gives a free generator. Row modules need at most as many generators as ambient coordinates by the same diagonalization. The two projected transitions give both P_(i-1) S_i0 and M_i V_i by subtraction.

**A simulator for the whole chain.** Its only terminal-key input is P_h A_h. Repeat from layer h down toward the root. With P_i A_i available, compute P_(i-1) S_i0 A_i and M_i V_i A_i. To generate the reconstructed value inside W_i, solve M_i X=M_i V_i A_i and add Z_i times an independent uniform matrix of compatible shape to any solution. This is exactly uniform in the required column cosets because image(Z_i)=ker(M_i). Draw the public B_i independently and take canonical digits for W_i. Sample the three concatenated integer preimage banks from their ambient Gaussian laws with the usual pivot abort. Now generate P_(i-1) A_(i-1) from the three projected targets as in the local lemma. Even if P_(i-1) is not surjective, free columns are obtained by multiplying fresh uniform columns by P_(i-1); solve for the pivot columns using the common invertible minor. This is the projection of a uniform parent completion. Save the emitted banks and continue with the simulated projection. Finally emit the root projection and banks in wire order.

For encryption performed by the full reverse sampler, the distinguishing advantage from this simulator is at most sum_i a_i epsilon_i, where a_i is the number of mask generators and epsilon_i bounds a fixed single-secret decisional LWE challenge for the public dimensions at layer i. Charge implementation and truncation errors separately. For the forward sampler also add the sum of uniform reversal errors. For the computational hybrids replace layers from root to terminal. At hop i generate the deeper real suffix by efficient full reversal, including its child key. The already replaced ancestor kernels use the current parent only via P_(i-1) A_(i-1). The compensation target projects to P_(i-1) Q_i since M_i Z_i=0; hence the projected parent completion at this hop needs no challenge secret. Its W_i rows before multiplication by Z_i can be replaced by the usual a_i shared-public-matrix LWE hybrids. Abort on a missing pivot and propagate that flag throughout. This gives the claimed sequential simulator, including dependence among public banks. In particular for two terminal-key distributions with common public parameters, their terminal sketch distinguishing advantage plus twice the hybrid bound suffices. This theorem does not handle message-dependent public transitions with different simulator inputs. Correctness still charges the actual integer norm of U_i Z_i times LWE noise, which can be large for a modular kernel basis.

**Which terminal information survived?** By induction the rows of P_h span precisely all P0 S_1b1 ... S_hbh with the b_i chosen independently. Equality of two fixed terminal sketches is thus equivalent to equality on every unrestricted branch string. This includes inconsistent choices when two layers query the same witness bit. For instance take P0=[1], first transitions [1,0],[0,1] and second transitions [0,1]^T,[1,0]^T. When the same witness bit is used twice, both legal products are zero, yet either inconsistent string has product one. The terminal sketch is then the entire one-row key. This is a failure of the sufficient sketch criterion for a repeated-variable verifier. It does not show that noisy public ciphertexts reveal the full sketch. The open construction issue is to enforce consistency of witness choices without exposing a terminal distinguishing direction through the simulation, while bounding the mask lifts for correctness.

There is a concrete endpoint consequence beyond the sketch criterion. Suppose these two layers encode the always-false predicate that a bit differs from itself, and the candidate encodes messages by a zero versus independent uniform terminal entry. If for the fixed inconsistent string (0,1) the actual public path product is within centered error B of its ideal value except with probability beta in each experiment (including abort), thresholding that product at B distinguishes the two messages with acceptance-probability gap at least 1-2 beta-(4B+1)/q for 4B<q. The ideal inconsistent product copies the terminal entry; on a good uniform sample acceptance requires the entry to lie within distance 2B of zero. This argument needs no independence of error and entry. The additive-width error bounds, when available for every fixed branch string, also apply to this inconsistent product, which uses the ordinary public branch matrices. A decoder-side check for consistency alone cannot protect that endpoint encoding.
