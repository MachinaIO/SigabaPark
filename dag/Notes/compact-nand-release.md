The fixed decision experiment has 512 uniform-secret coordinates, 1025 rows, q=257, and independent CBD(1) errors. Encrypt a bit by shifting only the last response by 128 times that bit. The terminal issuer emits the **native** degree-one `ModuleLWE.encodeSample` matrix and response vector. The decoder takes the 512 recovered secret residues in fixed nine-bit **big-endian** order followed by the complete native packet. The public coefficients use little-first `Nat.bits`, including the empty digit string for zero. These conventions differ deliberately. Gate `field_frames` checks both native per-residue emission schedules at every residue using the core `frame`. The matrix numeric-frame bits are lifted twice, each row adds `(true,false)`, the outer matrix adds `false`, then every response uses its ordinary numeric frame. Independent small paired replays compare actual machine transitions against the core encoder, and full-size replays compare every bit against a separate streaming formatter.

### All honest lengths

Let L be the physical bit length of the native matrix and responses, n=512 and m=1025. A phase count gives **L+120354372** issuer transitions and **L+23051** decoder transitions for any valid run, including all supported errors and operand values. Data-dependent numeric-output loops account for L. The issuer's nonemitting count is 229nm+220n+61m+7: secret/row initialization and initial rewinds, n rounds of 192 ticks and nine writes, m left rewinds of 9n+1, nm checks and 192-tick draws, 27 arithmetic ticks per coefficient, both error phases (one also emits the row delimiter), nine accumulator-clear and nine response-write ticks per row, the final row-buffer rewind and nine response-read ticks per body. `idleIssue` itemizes the nonemitting visits; `issue_count` proves the simplification. For decoding, 9n writes, 9n+2 rewind/control ticks, 27n final-row arithmetic ticks and nine final-subtraction ticks are in addition to L. Every physical control path goes through either a fixed-depth binary tree or a monotone scan to the adjacent blank. Initialized data cells are always present bits, even when zero; there are no internal blanks. Recycled arithmetic scratch is cleared after every row. The format bound L≤39906326 gives 160260698 and 39929377 worst-case upper bounds, both inside the clocks. `budget_all_lengths` checks the numeric inequalities. This phase-count proof is on paper; the entire native `Machine.run` distribution has not been replayed in the kernel.

Two full native fixtures, one with endpoint input bit zero and varied data and one with bit one and every coefficient equal to 256, respectively emit 31541168 and 39904956 bits. Both original and packed tables take exactly 151895540/160259328 issuer and 31564219/39928007 decoder ticks. These measurements corroborate the formulas for two coin sequences.

### A full role envelope for a stated class of registered circuits

`CompactNandRelease201.roles` has the author's `Impl WE.sig` type; the decoder is deterministic. On the registered input `encodeTuple [params, encCircuit(C), [b]]`, the encoder consumes the full parameter frame and evaluates every registered gate on three simultaneous assignments: all zero, all one, and alternating starting with one. Before LWE setup it reuses the later secret, sum and response work tapes as these three wire banks. For each assignment the wires start with the true constant and its 128 input bits. The first blank after the computed bank stands for all forward references (each reads true). Its head saturates at that blank. Each gate's output is appended at that address. One pass over the user statement determines whether a tested assignment satisfies it. No test of circuit satisfiability is charged as an oracle.

With the outer role frame included, `single_gate_code` proves that one gate with addresses (a,b) is exactly `1^(8a+3) 0 1^(4b+1) 0`. The final outer false terminates the circuit. The two modulo counters therefore move the shared heads to addresses a and b; `all_gate_payloads` checks pointwise bitwise NAND for all pairs of three-lane words. The parser rewinds before each lookup and seeks the append position. On exit it erases all three temporary banks and retains the recognition bit at the head of tape one. It then consumes the encoded message tag and leaves the physical input head on b, as required by the original issuer.

The logical ciphertext is a **4608-bit prefix followed by the complete native packet**. While writing the freshly generated secret the machine outputs each bit when recognition succeeded and emits zero otherwise. Before computing matrix products it resets the recognition cell. A set of extra states for precisely the emitting native states, including secret writes, adds one `true` per physical output bit and terminates the whole field with `false`. These are actual registered outputs. Dec skips three complete input fields (`params`, the original circuit, and the supplied witness), unframes the ciphertext, feeds the prefix and native sample to the recovered-secret decoder, and emits the registered encoding of one bit. A valid original witness may differ from the recognized probe because all accepted ciphertexts open the same LWE secret.

The same three encoder tapes and two decoder tapes suffice. Including the dense transition descriptions, the encoder costs **2238116730** with clock 465000000 and the decoder **844271444** with clock 290000000. Their total is **3082388174 < 2^32**, as `role_cost` checks against `WE.cost`. For 4096 gates, each of the at most three head sweeps per gate spans at most 4225 cells. The registered circuit field has length at most 2·4096·(6·4224+3)+1. Counting this field once, initialization, final erase, the original issuer, an additional tag per native bit and one per secret bit fits the encoder clock. Counting the three leading fields, the original decoder and a tag for every secret/native bit plus final output fits the decoder clock. The maximum statement, forward addresses and independent tape widths enter these bounds. Output length is charged physically.

### Correctness and false-view simulation

On every YES circuit accepted by a probe, the prefix is the actual secret, the last residual is in {256,0,1} or {127,128,129}, and every valid witness recovers the message. This includes every satisfiable predicate depending on at most one input bit, and satisfiable monotone-increasing or monotone-decreasing predicates, regardless of the syntactic circuit computing it. On **every NO circuit** all three probes reject. The complete secret-release portion of the ciphertext then consists of 4608 deterministically zero bits. There is no conditional issuance failure or extra visible branch record. Given the single fixed 1025-row decision challenge, a reduction hardwires the public circuit, chooses a fair private message, shifts the final response natively, and inserts the 4608 zeros. On uniform input translation of the final response preserves the full framed law; on real input the honest capped-source variation costs at most twice 525312/2^192 in the two-branch gap. Matching the adversary's accept indicator with the private bit gives half the signed gap. Full registered `Machine` security still needs an exact simulation of the adversary clock and arbitrary output plus its certified complete cost ratio. A separate successor wrapper can hardwire the literal source prefix (at most 207643656+9216 bits <2^28 here), hide the mixed bit and implement the output/timeout test. No assumption from an unrelated search game is used. Registry H=166 is a classical estimator result, and no quantum hardness or quantum gate cost is certified.

This is a genuine scoped role implementation, not correctness for every registered YES. For example, the predicate `not w1 AND w2` rejects all three probes even though it has witnesses. Use gates `(1,1),(129,2)` followed by 4094 copies of `(130,130)` to realize it with the exact 4096-gate convention. On that circuit Dec uses zero as the secret regardless of witness. For exact uniform nonzero x the last dot product with an independent uniform row is uniform, hence for bit zero the probability of correct decoding is only 128/257, up to the probability 257^-512 of zero x and the stated joint sampling error. A general non-poolable witness-dependent supplier, its complete correlated NO simulation, and a composed full `Machine.run` security theorem remain open.
