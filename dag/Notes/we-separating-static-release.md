For the local static relation, a statement is 12672 authorization bits (all A indices, then all C, then all J; 4224 positions each). An authorized witness names an A and a C index different from its J index, with all three flags set. The new oracle-free machines use the registered field order: Enc reads encodeTuple [params, flags, [beta]] and emits encodeTuple [packet]. Dec reads encodeTuple [params, flags, witness, packet] and emits encodeTuple [[bit]]. It can scan for any full term, so the witness field is skipped. The dimensions below charge a three-index, 39-bit witness and a parameter word of at most 515 bits. This is a complete local implementation for public fixed opening sets. A registered Circuit-SAT statement has different semantics.

The encoder first materializes each equality bit word(i,x)=v in lexicographic (x,v), then i order on a work tape, using the actual F9 function from SeparatingTerminalMachine.allow with role J. There are 266112 bits, one blank delimiter per term, and two reserved blanks at the left. Each position in this initialization is a paid transition-table state. It runs before reading beta. Per term the same 4224 bits are scanned three times; for A and C the eligibility bit is complemented and for J it is taken directly. Relative to the preceding abstract sampler, there is no supplied zero template or private operand string. After reading the actual flags onto tape 2 and copying them to the public packet, the encoder samples two independent term shares from its transition coins. It samples a new pad and stores it on tape 3 at *every* incidence, including dense dummy positions. Exactly 798462 designated fair coins are consumed for logical sampling. For valid fixed-size flags the clock times of these designated samples depend only on the input field lengths and schedule, so these bits have the independent uniform product law.

The raw packet is the original 12672 flags followed by one triple per term, role and index: the conjunction of the open flag and eligibility, the old public correction (share XOR pad if eligible, zero otherwise), and the sampled pad when its source flag is set (zero otherwise). The lemma slot_emissions checks the actual three data-output states for all eligible-bit, flag, role and register values. This serialization is 2407680 logical bits and 4815361 bits on the encoded one-field output tape. Ineligible pads disclosed at opened addresses are independent dense dummy coins; they are held fixed under the existing losing-mask involution. Every previously available true opening remains extractable from the packet. Eligibility markers and the opening mask depend only on the fixed statement.

The decoder scans the three framed fields preceding the ciphertext and skips its fixed flag prefix. Within each term it retains the first active share in each role by XORing its correction and the real released pad. On a term containing all roles these three shares recover beta; all complete terms recover the same beta. If it reaches the end without a complete term it returns zero. The existing finite-field separation theorem is precisely the equivalence between a valid triple and such a complete term. On a losing static statement the previous termwise involution flips one missing role, leaves all opened pads/corrections unchanged and hence matches every output bit. Extra authorization/eligibility fields are deterministic under that coupling. This yields perfect message hiding for static flags and quantum postprocessing of the resulting classical packet. The flagged format does not restrict a party endowed with a different source oracle.

The actual machines encMachine and decMachine have respectively 3 and 0 work tapes, 267281 and 1241865 states, dense descriptions 1515483270 and 186279750 bits, and clocks 2^24 and 2^23. Their costs sum to **1726928844**, strictly below 2^31 (full_static_local_budget). The clock fields are not measurements. Counting the state paths for valid input gives 1581n+704+2p encoder steps for n indices and p parameter bits: one ROM construction/initial rewind, loading the flags and beta, one flag rewind per term, two ROM rewinds per term and six local output steps per incidence. The longest losing decode takes 1140n+2p+4 plus the framed lengths of the skipped input flag and witness fields. For n=4224, p≤515, and a 39-bit witness, both fit the declared clocks. The mathematical termwise correctness argument, the previously established sampler laws and the finite-state output identity are distinct from a single Lean theorem about the full Machine.run PMF; such a composed mechanization is still open.

Tape 3 is an internal record of the generated pads. The trusted Machine.run returns only the encoded output, not this work tape. The implemented static issuer consumes that record's values immediately when authorized. Persistent/adaptive private service would require a continuation or an explicit service with its own access law. A witness-conditioned, non-poolable supplier for all registered NAND statements, and a reduction for its complete false auxiliary view including any coherent access, remain open. The static decoder's ability to locate a winning triple by itself is why the public fixed-flag interface cannot stand in for an unrestricted circuit supplier.
