### Terminal and wire image

For `LWE.decision` (registry index zero), take 512 independently uniform secret residues, 1025 rows, modulus 257 and independent coefficient errors CBD(1). The first 1024 rows are the prefix. On the last row add 128 times the message bit to the response, modulo 257. An authorized supplier delivers the **same** 512-residue secret to decryption. The residual is in {256,0,1} or {127,128,129}, so the test for the latter set is exact. This uses the existing statement-independent assumption. Core revision `640702122226` evaluates its estimator `LWE.H` to 166 for these parameters; at dimension 32 with 65 rows it yields 24. A classical estimator output gives no quantitative quantum security certificate.

The concrete problem maps its laws with `Cslib.Crypto.ModuleLWE.encodeSample`. In degree one `expandModuleMatrix` has the original row and column order. Write `f(w)=(true,w[0]),(true,w[1]),… ,false` and `lift` for the same expansion without the terminal false. The complete encoded sample is `f(concat_i f(concat_j f(Nat.bits(Aij))))` (one outer frame on the matrix, one frame per row, one per coordinate), followed by the concatenated `f(Nat.bits(zi))`. Here and below `Nat.bits` is low-first and is empty for zero. Equivalently every physical numeric-frame bit in the matrix is transmitted as `(true,true,true,bit)`, each row ends with `(true,false)`, and the matrix ends with `false`. Responses have only the numeric frame. This is not the asymptotic `LWE.encodePub` transposed format. Nine bits per residue gives the fixed-width comparison figures of 4617 bits for one additional row and 4732425 for all rows; the native encoded packet actually occupies **2102276 through 39906326 bits**. These are format extrema across all legal residue packets, not assertions that both extrema have positive mass under each real bit law.

### A machine that issues the entire matrix

The two-work-tape `issuer` takes a single message bit. It generates the 512 secret values onto the first tape in nine low-first bits each, scans that tape once per row, emits every generated coefficient in the native matrix format and accumulates the dot product modulo 257. Each row takes two fresh coin flips and adds the first minus the second, exactly CBD(1) with probabilities 1/4,1/2,1/4. Only the final response is shifted. The second tape buffers the 1025 responses in fixed width while the matrix is being emitted. It is rewound once and copied with native numeric framing. Neither errors nor secret are outputs. The first tape retains the privately generated secret for a future supplier; `Machine.run` returns only the public word, so connecting an honest issuer that needs the secret requires internal composition before halt.

For each secret or matrix coefficient read a 16-bit integer, retry 65535, and otherwise return the remainder modulo 257. There are exactly 255 accepted values for every residue: `257*i+r` for `0≤i<255`. On the twelfth rejection return zero. Couple to unlimited sampling by identical bits up to the first fully rejected block. The 525312 draws jointly have TV error at most `ε=525312/2^192 < 2^-172`, including the retained secret and all published fields under subsequent identical processing. The bounded variable-length reads preserve the independent fair suffix after each stopping point (equivalently expose independent 12-trial tapes and discard unused trials); the two row-error coins are always separate. Correctness of the residual is exact even on fallback. All ranks are issued with the original distribution. No test or resampling conditions the LWE challenge on a full-rank event.

`decoder` takes precisely the nine-bit-per-coordinate recovered secret followed by the entire native packet. Its single work tape holds those 4608 secret bits. It parses the complete matrix, computes the last dot product, skips the first 1024 response frames, and returns the one recovered bit. This is a terminal interface, before the outer registered algorithm framing or any NAND witness decoding. The issuer uses phase-specific state codes for rejection counters, partial words and accumulator, with 2^52 states, a 2^28 clock and dense description 15807634692070440960. The decoder has 2^33 states, a 2^27 clock and description 6493990551552. The combined charged cost is **15807641186463645696**, below 2^64. `cost_local` proves the machine cost inequality. A direct count on valid inputs bounds issuer transitions by 150245942 and decoder transitions by 39920151 (`count_budget` checks the arithmetic). For issue the count budgets 192 sampling ticks per coefficient, 9 reads and at most 76 emission ticks per matrix coefficient, secret rewinds of 4608 per row, both error ticks, fixed-width secret/response writes, the final response rewind and scan. Decryption scans each native symbol once plus initial writes/rewind and nine secret reads per last-row coordinate. This is a phase-count argument and physical transition implementation; there is no kernel theorem yet about the full issuer `Machine.run` law.

### One fixed decision challenge for the complete false view

Specify the interface for each false circuit C. Let P be the first 1024 pairs and (a,z) the remaining unshifted pair. A simulator `S(C,P;u)` with fresh coins must produce the entire gate/header/advice record jointly with P and (a,z), up to error ε_H per branch. If conditioned on the fixed secret and prefix the real header has this simulator law and the last-row randomness is fresh, this stronger sufficient condition implies the required joint law. We only need joint simulation of publicly observable data, including correlated rows and all exposed descriptions. The simulator receives no error or secret. On YES assume a valid witness recovers x from the honest header with its stated error. The terminal then adds zero decoding error. Knowledge of the unshifted last response, a precursor secretly correlated with its noise, or leaked simulator coins is not a free auxiliary input. For example a header giving the unshifted last response allows perfect decoding by subtraction even when that response has the correct marginal.

On a single native 1025-row decision challenge, privately draw fair b, extract P, sample H=S(C,P;u), shift only z and present **exactly** the WE adversary's public input with its ordinary statement and parameter framing. Accept when its accept indicator agrees with b. This includes complementing the probability of acceptance on the b=0 branch, including malformed output/timeout according to the original acceptance convention. On uniform input, the last response is uniform independently of P, a and H; translation permutes its values, so after *all* re-encoding the two inputs have identical law. `ideal_shift` proves the finite permutation equality for every real acceptance function; `mixture_gap` checks the signed factor of two. On real input the simulated gap is within `e=2ε_H+2ε` of the signed honest gap, in absolute-value form `|g| ≤ 2|d|+e`. For a computational hybrid, replace TV by an acceptance error for the full distinguisher class. A nonempty simulator does not get to use the mixed branch bit to program the uniform response.

There are two additional executable converters. The zero-tape `nativePrefix` filters the entire last row and final response, including their framing, producing the exact native 1024-row packet. `mixedPacket` emits a **private** control bit and the complete canonically shifted 1025-row packet, re-encoding the possibly different length of the final natural. It reads the terminal word into a sentinel-coded register. Its private first bit must be consumed by the reduction and hidden from the adversary. Their respective fully charged individual costs are 67741264 and 68188864, with clocks 2^26 each. A replay checked every one of the 257 possible terminal responses for both branches against core `encodeSample`, and checked the prefix output on those inputs. Twelve small complete physical replays (including an all-rejection tape) checked the retained secret, resulting dot products, native packet and recovered bit against an independent reference built with core `encodeSample`.

### Cost and post-quantum scope

Write C_A for adversary cost and C_B for the **entire** fixed-decision reduction, including challenge copies/rewinds, both native conversions, S, C-specific advice/serialization and all outer framing, the private branch administration, one call to A, its timeout, and output normalization/complement. `transfer` gives an exact sufficient condition for the classical ratio in the registered primitive: C_A≥1, C_B≤2^35 C_A, e≤2^-67, and 2^166 d²≤C_B imply 2^128 g²≤C_A. The proof uses (2|d|+e)²≤6d²+3e². The converter costs are only components. For example, charging the core generic `andThenLin` upper bound of `500000 * first.cost * second.cost` to a converter of cost 68188864 already gives a factor above 2^44, so that coarse composition estimate alone is insufficient to certify the 2^35 inequality. The issuer need not be run by the reduction.

For a quantum distinguisher on a classical challenge the same construction is a single-invocation reduction with one fresh classical bit, the same two deterministic streaming passes (the mixed transducer takes the private coin), one full simulator, and one final Boolean measurement/complement. There is no rewinding of a quantum adversary or guessing of its workspace. Under a quantum machine model admitting measured classical input, classical side computation can be charged as exactly the specified converter machines, at most 2^27 physical transitions for those two passes, plus a sequential challenge copy and rewind (at most twice 39906326 symbols plus endpoint overhead) if only one input head is provided. Additionally charge S, wrapping and delivering the entire adversary input, one actual run of the quantum adversary and its output operation. Other quantum gate models require an explicit cost for classical control, memory, circuit conversion and compilation. The verified `Machine.cost` is classical, and neither a quantum hardness exponent nor a quantum gate-count ratio for unspecified S is asserted. A coherent secret-dependent oracle in the public interface would require a simulator for its complete joint oracle, beyond this classical-packet theorem.

A concrete correlated header satisfying the interface works for explicit undirected path authorization. Take distinct s,t, set the potential of s to 0 and that of t to the 4608-bit fixed-width x, and sample independent uniform 4608-bit strings at the other vertices. Publish the XOR of the endpoint potentials on every edge. A witness path telescopes to x. When disconnected, XOR x into every potential of the t component. This bijection preserves every edge label and sets both distinguished potentials to zero, even conditional on any fixed secret, LWE rows and errors. Thus S can sample the entire edge record with both potentials fixed to zero, without finding components. There are 4608(V−2) fair bits and 4608E published label bits before graph encoding and tape costs. This checks joint simulation in a nonempty header model. Compiling a succinct non-poolable authorization header for every registered NAND circuit, and certifying its end-to-end clocks, cost ratio and quantum hardness, remain open.
