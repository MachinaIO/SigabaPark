## The privacy game

Cheng and Goyal, *Collusion-Resistant Constrained PRFs for Compute-&-Compare Predicates from LWE*, ePrint 2026/1874 (September 2, 2026), Section 7, Definition 7.1 and Theorems 7.2 and 7.11, is the source used here. The reduction below uses the algorithms in that section. The constrained-hiding experiment fixes the common per-world compute functions before setup. It requires distinct comparison targets within each world and rejection in both worlds at each master-evaluation query. Theorem 7.2 assumes the indicated decisional GLWE game with the published sample parameters. Its asymptotic PPT theorem does not assert a concrete registry strength or quantify the cost of simulating the public profile at the registered instance. [Paper](https://eprint.iacr.org/2026/1874)

The two-key proposal that constrains to [C=1] and [C=b] under the same master repeats target 1 at b=1. An empty support on NO does not remove the syntactic restriction. The actual key includes a noisy linear image of the target under the same secret vector; regenerating a key refreshes error but keeps this center. Encrypted descriptions of the fixed compute function also reuse Setup randomness. Adding a role prefix to the target keeps different targets mutually exclusive at one common input. Adding a role prefix to the PRF input changes the master argument. In an ideal function model, at most one authorized role per master/input, together with independent memoized off-domain values per key/input and no master reference, gives independent uniform output labels: distinct authorized labels draw distinct master coordinates and the other labels use disjoint independent coins. Adaptive repeated evaluations preserve this law. It need not describe the full concrete key distribution.

The original private CPRF notion of Boneh, Lewi and Wu, Definitions 2.9 and 2.10, instead compares supports of pairwise intersections and requires both sides to agree at master evaluation queries. The support check can hold for repeated unreachable comparisons on NO with no master queries. Their general multi-key circuit instantiation in Section 3 uses subexponential iO and puncturable PRFs. It does not instantiate the registered lattice route. [Original paper](https://www.cs.utexas.edu/~dwu4/papers/PrivatePRFs.pdf)

## One constrained key and genuine public master evaluations

Write a witness as (u,z) with k retained and 128-k eliminated bits. Build the two-bit-valued function J(z) that equals 1 if some u makes C(u,z) true and equals 0 otherwise. Value 2 is permanently unreachable. Use one master. Sample the public parameters and one constrained key comparing J to target 1 for message one or target 2 for message zero. Publish the constrained key and the reference table of actual Eval(master,z) for every z in a fixed, public order along with pp. A receiver extracts z from its witness and outputs one iff the reference row matches CEval(key,z). The reduction uses a single master. It never assumes equality of PRF values at distinct inputs.

On NO the value of J is identically zero. Both candidate constraints reject every table lookup, distinctness within each world holds vacuously, and (J,J) can be fixed before setup. One challenge Constrain and exactly 2^k master Eval queries return the entire honest header under either bit; the resulting advantage is that of this specific admissible attacker in the Section 7.2 game. The construction also works with a public fixed table domain S and map into S, provided every valid witness maps to an authorized index and all queried indices on NO reject both targets. If this coverage is randomized, with coins independent of the master, charge the witness miss probability. A small public S and a public cheap J satisfying these properties give a decision procedure via enumeration: its evaluation work is |S| times the cost of J.

On YES fix a particular valid witness (u,z). For bit one, single-key correctness at z bounds the error. For bit zero, the key compares to unreachable 2. A predictor in the semi-adaptive pseudorandomness game requests this single key and checks the challenge at the prescribed z against CEval there. Its random-output acceptance is 1/M for uniform output alphabet of size M. If its event probability gap is eta then the false match probability is at most 1/M+eta. The predicate, witness and target are fixed at the times required by the game. This particular marginal needs no reference queries at other inputs. A sufficiently large output space, or costed independent repetitions, is required. For the actual primitive, the concrete correctness failure including the gap must meet the registered target. A binary coordinate alone does not give 128-bit correctness. The single-challenge construction is an asymptotic theorem application only when both the projection circuit and the number of reference queries are polynomial in the running security parameter. Fixed finite exponents demand a concrete cost/gain reduction at those sizes.

A second variant uses only ordinary single-key constrained pseudorandomness. Give the fixed constraint [J=1] and publish a table whose z-th bit is b XOR a designated uniform output bit of Eval(master,z). An authorized receiver unmasks one row. On NO replace each distinct evaluated pad in order with an independent random bit; for the changed coordinate one may use the fixed unauthorized key, true Eval for the remaining real coordinates, and private fresh coins for idealized coordinates. Endpoints have advantage at most twice the sum of the individual event gaps. This dispenses with constraint hiding and wrong-key collision arguments. A KP-ABE analogue encrypts the same bit in an independent ciphertext at every attribute z, giving the single secret key for J. Neither variant uses a new hardness assumption. With a primitive whose row cost a is independent of the projection circuit and cost b per instantiated cofactor, the two explicit workloads have the form a 2^k + b 2^(128-k), plus other costs. The arithmetic-geometric mean bound is 2^65 sqrt(ab), so ab at most 2^70 is necessary to fit these two workloads alone under 2^100. This cost decomposition must be proved for the chosen primitive, particularly for any universal circuit invoked at every evaluation.

## Public-profile compression

For an adaptive preprocessor and evaluator allowed only membership queries to a uniform Boolean table, fix the address x. Condition on x never being queried. Flipping just the bit at x preserves the entire query transcript, the produced description, and the predicted bit. Thus exactly half the functions in this event are predicted correctly, whenever it is nonempty. The Lean solution proves equality of the good and bad counts for every deterministic branching tree, including identical repeated queries. Randomized rules follow by fixing their coins. If the preprocessing phase is independent of a uniform test x, uses at most Q calls in a domain of size D, and its resulting predictor uses no additional oracle access, success at that random x is at most 1/2+Q/(2D). For the finite PRF version, an emulator with oracle access that produces a universally correct public prediction code would turn into a PRF distinguisher using its actual synthesis and testing time. If the purported emulator is accurate only on authorized witnesses, receives auxiliary secret-dependent data, or can use an additional challenge-dependent oracle during prediction, the universal bound is inapplicable. Deterministically compressing a table after making every allowed query preserves admissibility but does not save those queries.

## Related masters and rounding

In the paper, Eval is linear in the vector secret before rounding, with a public address-dependent matrix. This permits checking pre-round addition if the masters use a common parameter bank. Nearest rounding does not in general preserve sums exactly: mod 16 rounded to mod 2, the residues 3 and 3 each round to 0, while 6 rounds to 1. In a one-coordinate threshold test either account for the exact carry distribution or use a correctly justified reconciliation radius. Comparing two independent off-domain values and one related value is a different experiment from Theorem 7.2. Its other master secret fields and all shared public parameters require a joint argument too.

The actual key contains a core block b_ij = s_i^T(B_j - psi_ij G)+e_ij for a publicly known ciphertext description bit psi_ij. In a binary gadget block with consecutive columns proportional to 1 and 2, take the public combination v=(2,-1) on those columns. Then Gv=0 and each core leaks precisely the noisy projected sample s_i^T B_j v+e_ij v. This is independent of the target and of the encrypted program bits. For three keys with a common public B_j, the signed sum of these samples has no secret term when s_2=s_0+s_1. If the independent error entries lie in [-E,E], its circular magnitude is at most 9E. For independent uniform secrets modulo a power of two, their signed difference is uniform; except with probability 2^-n it has an odd coordinate. Since B_j v is uniform (one coefficient is a unit) and independent of the secrets, its inner product with that difference is then uniform. Independent additive row errors preserve uniformity. A centered window of radius 9E has probability at most 2^-n+(18E+1)/q in this independent case; add any error-tail probability in the related case. This calculation rules out encoding the bit by switching between these two shared-bank relations when the window is small. It does not distinguish two worlds that both keep the same relation, or apply across independent public matrices. Almost key-homomorphism alone supplies no hiding theorem for the latter design choices.

## Explicit size audit

In Section 7 let t be the bit width of a q-residue (for the displayed power-of-two modulus, log2(q)). The example uses m=nt and L=ell_f (n+1)^2 t^2 for an ell_f-bit program. The L explicit B_j matrices alone use ell_f n(n+1)^3 t^4 bits, before keys, table, algorithms or evaluation. This counts the full public setup created in the ciphertext, as required absent an independent provision for it. One explicitly written encrypted program bit already takes (n+1)(m+t)t bits. Seeded or shared parameters change these calculations and require evidence of their own.

For lambda=128, epsilon<1/2 and the example n=2 lambda(d+k+ell')/epsilon. Implementing J by a balanced OR of all 2^(128-k) literal cofactor circuits gives d at least 128-k on that unsimplified template, hence n>2^16. For k at most 92, even one program bit per literal cofactor gives ell_f >= 2^36 and the public matrices alone exceed 2^100 bits. For k at least 93, all numerical instantiations satisfying the explicit weaker correctness requirement q>=m^k have t>=k log2(m)>2^10, so the same matrices exceed 2^104 bits even for ell_f=1. The separate q>=m^k condition here is drawn from the positive term m^k in the displayed correctness/smudging inequality; the paper's asymptotic constants do not supply a finite security estimate at 128. These are limits on a particular explicit bank and template. Hardwiring the statement in a smaller template may shorten the encrypted program, but the per-row work of applying that template and any dependence in the reduction must still be charged. This does not rule out more efficient single-key CPRFs, KP-ABE, different public evaluation profiles, or statement simplification.

The projection and admissibility conditions were checked on every Boolean two-input truth table. An adaptive four-address predictor and finite odd-coordinate projection counts modulo eight were independently enumerated. These small tests check the finite identities. The Lean theorem covers the unseen-address identity at every finite size. The quantitative GLWE reduction, actual role machines and a capped instantiation remain open.
