## Exact recognized family

The registered circuit has 128 primary inputs, constant true at index 0, and exactly 4096 gates. Each of its first sixteen consecutive 200-gate blocks may compute *any* NAND straight-line program on its own eight inputs, constant true, and outputs of earlier gates in that same block. The four final block outputs in increasing wire order are a four-bit tag, least significant bit first. The remaining 896 gates are the fixed equality combiner from the witness-indexed bucket construction: compare each of the other fifteen tags to the first in each bit by XOR then NOT, conjoin the 60 results, and pad with pairs of negations. The function suffixPair generates the actual 896 pairs by arithmetic. This is a syntactic promise and admits variable tag maps for every role, including role zero. It does not require a trusted bitmap, a fixed witness lookup, a list of template circuits, or a separate circuit-specific machine.

In this family an accepting witness exists iff one tag occurs in every block's table. Given a common tag choose an eight-bit preimage in each role and concatenate; disjoint wire supports make every chosen table entry agree with the original circuit. Conversely any accepted 128-bit input supplies its sixteen preimages. TagWitness proves the finite choice step. Since the compiler itself computes all reachability flags it could publicly decide this family. The significance of the result is calibrated honest interface and cost; no hard SAT family is being deduced from this example.

## Native implementation

The three-tape encoder takes the original frame of the public parameters, gate list and payload. It matches the parameter encoding and counts the physical runs of the canonical nested gate frames: 8a+3 ones then zero for the left operand, 4b+1 then zero for the right. Each operand is range checked. A local primary maps to 1 through 8 and a local computed wire to 9 through 208. The unspent role is verified against the unary role marker on the third tape. A forward gate reference encounters the blank end of the current truth array and rejects. The first tape stores 400 eight-bit addresses, least-significant bits first. It is reused across roles. The second tape holds one scalar evaluation consisting of constant one, eight bits of the current assignment, and up to 200 computed gate bits. For each of 256 assignments the machine replays the parsed operands. It rewinds to the truth-array origin, seeks each selected bit, appends NAND of the pair, and explicitly clears the truth array when collecting the last four bits. The third tape keeps the nine-bit next-assignment counter, with 256 as its sentinel, and the unary role marker in the other direction. The negative part of the first tape stores the 256 tag-major flags. All addresses and head movements are explicit finite control.

For role zero the encoder also prints its public directory in assignment order: four little-endian tag bits for each of 256 possible local witnesses. Every data bit, including this directory, is serialized as [true,value]. After verifying the fixed suffix, the machine checks the final [true,payload,false] frame and end of input. It erases the suffix-check workspace, reuses the three tapes for the 753-row, n=1024, q=64 CBD(1) bank and reads its bitmap from the negative first tape. The virtual payload is read at the parked physical input head. The generator uses fresh fair coins at the same meaningful source operations as its component, ignoring all parser and framing coins. The outputs are one ciphertext frame containing the 1024-bit directory followed by the usual 4,631,046 bank bits, then the final false terminator. The directory is computable from the statement, including in the uniform-challenge simulation. On invalid syntax all bits emitted before detection are independent of the payload. The native encoder closes the possibly partial public frame and halts. Correctness on satisfiable circuits outside the syntactic family is open.

The zero-tape decoder skips the original parameters and statement frames, reconstructs the first eight little-endian witness bits, looks up their tag in the ciphertext's first 1024 data bits, and scans to the end of the frame. Its backwards search then evaluates just the selected 96-bit bucket. An accepting witness has all sixteen roles reachable in its tag and its share sum is exactly 32β modulo 64 for every bank tape. The decoder prints the registered one-bit result frame. The parser and issuer are fused as explicit transitions rather than charging a generic composition lemma with a large simulation overhead.

## Registered cost and clocks

The actual encoder has 229000 states, three work tapes, a clock of 1,342,177,280 and description length 1,261,332,000, for cost 2,603,509,280. The original-frame decoder costs 270,570,448. Their total is **2,874,079,728 < 2^32**. NativeCosts evaluates the two Machine objects. This arithmetic does not itself establish semantic correctness. The following accounting explains the assigned clocks.

At gate j there are at most 208 populated scalar truth cells before its append. Two eight-step address decodes, four rewind/seek traversals, a seek to the append location and the end checks together cost at most 1100 steps, even for a failing forward lookup. One assignment needs under 5000 additional ticks: 3200 for the descriptor rewind, at most 209 to clear values, two traversals of at most 256 for the selected flag, and the assignment counter, role markers, tag collection and optional 8-symbol directory entry. There are 16*256*200 gate evaluations. Reading the source consumes fewer than 208,000,000 raw physical bits since no permitted parent exceeds 4224 and counted runs abort on their limit. Three million extra ticks cover the per-parent role checks, descriptors, 30481 suffix-template cells, suffix comparisons and resets. The bank and extra output-marker cycles take under 11,000,000 ticks. ReplayBudget verifies the resulting arithmetic bound against the actual declared clock. The original decoder's unary source plus directory and framed packet, endpoint scan, reverse traversal and tag read stay below 2^28. A proof of every tape invariant and the complete clocked Machine.run law is not included.

## Positive and negative control replays

Two distinct 4096-gate examples were generated with PRNG seeds 258 and 257. Each role has 195 variable-parent gates, a constant-false NAND, and four output inversions of selected primary or constant values. The first two role tag images can be made equal or disjoint in their most significant bit. The other roles reach all sixteen tags. Independent scalar enumeration and 256-way bit-parallel NAND columns agreed on all 4096 local tags in each example. Encoder memory matched every one of the resulting 256 flags. The YES case has shared tags 0 through 7; the NO case has none. A modified cross-role reference rejected after 8022 steps and a forward reference after 390118.

The fixed transitions were replayed with homogeneous head-seek scans, counted input runs, and eight-bit descriptor reads batched in the host harness. It advances the model tick count by each exact scalar distance. Cleared scalar cells are represented by a logical extent in that replay. The first five assignments were also run without those shortcuts: both paths agreed at 755043 native ticks, including tape positions, raw input position and all 40 emitted symbols. The complete accelerated run on YES used 395,987,550 ticks; NO used 395,673,570. Both emitted 9,264,141 physical frame symbols. Independent arithmetic reproduced all matrix entries, training bodies and masked shares after verifying the entire directory, using a deterministic bank coin replay; that tape is only a test, not the security coin distribution. The static clock is a worst-case allowance rather than either fixture's execution time.

The previous source reduction and ideal translation remain confined to the registered fixed LWE bank and actual reachable role sets. Instantiating its full reduction as clocked machines with a formally checked simulation, and a correct universal compiler for general shared-input circuits, are open. A bounded-support separator can reuse local truth-table evaluation after verified local renaming; a wire shared across roles breaks the independent choice argument without a separate consistency mechanism. No new assumption is used.
