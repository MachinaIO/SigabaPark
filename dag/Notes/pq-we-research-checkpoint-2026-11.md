The goal is witness encryption for general CircuitSAT with polynomial ciphertext length, encryption time and witness decryption time, and security against a quantum polynomial-time observer of the whole ciphertext on every false statement. The desired hardness challenge is efficiently testable and independent of the statement. The constructions considered here avoid iO and intermediates implying iO. **No candidate at this checkpoint satisfies the full goal.** The strongest positive result is a polynomial-size code-based candidate with witness correctness and a restricted observation bound. The independent-noise version has a concrete failure on the actual matrix family. The comparison below uses the final revision of the [research branch in PR 109](https://github.com/MachinaIO/SigabaPark/pull/109).

### Circuit compilation and lattice encodings

The compiler transport theorem transfers a backend correctness and security bound across a public relation map under explicit simulation and cost hypotheses. The port-projection results give checkable linear identities and a constructive witness lift. These Lean results address the registered adversary model. A quantum-secure backend and its honest machine costs remain separate obligations. [Compiler theorem and scope](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-compiler-transport.md)

For thin projected layers, sampling the public preimages first and then completing their shared parent gives a statistical simulation. Encoding the difference between binary transitions as a gadget correction changes the width recurrence from multiplicative to additive. A fixed decisional-LWE challenge hides certain kernel components of the corrections. Across layers, the resulting simulation retains a projection spanning all independently selected branch strings. When a verifier reads a witness bit twice, these strings include inconsistent answers. A two-read example distinguishes a zero-versus-uniform endpoint. [Width and costs](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-additive-width-branch-corrections.md), [composed reduction and counterexample](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-composed-kernel-mask.md)

An exact consistency guard can have exponential width in the number of variables live at a cut. A polynomial-width parity test separates scores approximately, but a small nonzero score can expose the terminal key modulo a power of two. A field-polynomial mask gives perfect hiding for a preset budget of quantum queries to a hidden evaluator; polynomially many classical evaluations can interpolate its constant term once that budget is exceeded. Reusable public evaluation remains unresolved. [Consistency guard](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-consistency-guard-gap.md), [syndrome masks](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-polynomial-syndrome-mask.md)

### Code-based constructions

A Fourier mask for bounded-weight syndrome decoding gives identical public distributions on false statements. A linear program optimizes common cutoff noise, and public kernel checks improve witness decoding on some matrices. For sparse growing thresholds, worst-case bias bounds preclude efficient repetition in the analyzed regimes. Removing forced witness weight helps on structured statements. [Cutoff optimization](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-optimal-cutoff-noise.md), [full-header decoding](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-syndrome-header-decoder.md), [weighted preprocessing](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-weighted-syndrome-quotient.md)

The binary linear system in Fenzi and Weissenberg's Theorem 4.8 gives a fixed matrix per size class. A satisfying assignment lifts efficiently to a vector of weight at most D. On false statements every representation of the target has weight greater than Gamma D. Polynomial Gamma keeps the compiler and matrix size polynomial. This supplies the distance gap required by the Bernoulli parity candidate. Worst-case gap hardness alone gives no noisy-secret recovery assumption. A separate conditional orbit/list-decoding reduction specifies sufficient symmetries; their realization and hardness on the compiled family are unproved. [Frontend and parameters](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-fixed-gap-frontend.md), [fixed search game](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-orbit-list-decoding.md), [source paper](https://eprint.iacr.org/2026/2634)

**Independent noise.** Quotienting out public row masks yields a payload of m-rank(H)+1 bits per repetition for an augmented matrix with m columns. But each clean header block lies in a Reed-Muller code. For the analyzed fixed tradeoff parameter, linear gap in the security parameter and sufficiently large verifier lengths, polynomial-time block decoding recovers the noise with overwhelming probability. On linearly consistent targets this removes the pad without a short witness. Quotient compression preserves the failure. [Wire quotient](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-honest-table-quotient.md), [decoding-radius audit](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-table-noise-radius.md)

**Correlated noise, final variant.** Random affine-flat indicators place both the clean and noisy blocks in the ambient Reed-Muller code. Decoding that ambient code returns the received word. The one-label-per-block witness still recovers a bit with probability at least 3/4 in one repetition. At security parameter lambda, 8(lambda+1) independent repetitions give error below 2^(-lambda). For D blocks of local code dimension k_C the quotient payload is D k_C-rank(H)+1 bits per repetition. Encryption, ciphertext size and witness decryption are polynomial; these are asymptotic bounds. The affine-flat test gives negligible distinguishing advantage for classical tests reading at most lambda adaptively chosen affine parities at the specified polynomial gap. A distinguisher can instead inspect the entire ciphertext and the clean subcode may be smaller than the ambient code. **Full-view quantum hiding of the target parity from a fixed falsifiable assumption is open.** [Sampler, reduction scope and cost](https://github.com/MachinaIO/SigabaPark/blob/660eea090e8fe8223c22c04a596f4b14a7c92544/dag/Notes/pq-we-flat-table-noise.md)

The research notes contain mathematical derivations and small finite checks. The compiler theorems are separate Lean artifacts. DAG note validation checks the submission format; the bounded-observation argument is not a machine-checked full WE security proof.
