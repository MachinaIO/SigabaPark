### What a public terminal key exposes

Split the witness into a private-table front p and a b-bit public tail u chosen after the ciphertext. The front and the statement are public to the evaluator. The source construction has *private* encryption at every slot. Its last slot repeatedly calls the encryption algorithm at the last slot of the shared inner master. Beginning with u, each descent wraps the previous value as (previous, dummy, tau, dummy, dummy), with fresh tau in the original algorithm. At the bottom one ordinary single-input ciphertext encrypts the nested record. First-slot master generation, its PRF key, first-slot aggregator issuance and the outer issuer key are absent from this chain. Other slots leave the chain earlier and may issue private aggregator keys along it. The starred master generated at each first row is independent of the shared inner master. Publishing either full master would authorize more than terminal encryption.

A proposed public generator can expose a purpose-specific terminal encryption key and take only an exact b-bit string, returning rejection for malformed raw encodings. Every keyed function that consumes the terminal data must perform the public parser itself. Client-side checks can be bypassed by directly running the public encryption algorithm. Derive level-specific tags injectively from the context and raw u (including slot and op, with enough bits for that encoding); do not let the caller supply the tag, alternative value, mode or override. Ordinary outer public-encryption coins may be fresh without entering the plaintext. This changes the original randomized-tag encoding and must be built into both sides of the modified proof; an A.10/A.12 comparison using a PRF needs the resulting actual query count, independent keys and disjoint domains. Encryption of the same raw u consistently uses the same internal tag, even when its public encryption is freshly randomized. Revealing a public key for this innermost role gives no entitlement to reveal a secret issuer or an independent starred child's master. [BKS, ePrint 2015/158, Appendix A.2, Figures 5 and 6 and Claims A.8–A.14](https://eprint.iacr.org/2015/158.pdf).

### Where the original transition breaks

For a false statement, the final gated functions agree on all private queried tuples and all public u. An intermediate AGG produces *child ciphertext bytes*, not the final payload. In the A.8 hide step the ordinary target key under the shared inner master evaluates the fallback. Its switched key uses a dummy master/PRF, expects the target identifier in every suffix slot, and returns the programmed tuple of gamma values. A public raw input is identical on both sides; a canonical parser that writes only dummy override fields has supplied no gamma for the switched leaf. Even for a single public unsigned bit, choose the original terminal output to contain that bit and make the dummy fallback return a fixed zero: outputs already differ on raw one. A caller able to encrypt arbitrary internal record fields could additionally select unintended modes. Strong message privacy for correctly generated private ciphertexts does not imply either equality. Private A.8 message pairs formerly changed the *same tail row* from ordinary to overridden, which a public generator does not do.

Here is a repair of the **comparison**, conditional on an FE game that supports this restricted public raw slot while comparing the issued keys. Sample the starred master and its seed for the hide step. For each raw u compute its deterministic fallback terminal ciphertext gamma_j(u) with the real child encryption algorithm and exactly the same tag-derived coins, including slot-2 pairing with the fixed first value when the child has rank one. Put the dictionary D_j[u]=gamma_j(u) inside the target right function key. Send the ordinary private-suffix override components through their original left/right ciphertext queries; they do not depend on u. On the right, the target key routes those finite components and obtains the terminal component from D_j[u]. With no private suffix, enable this route for the target key explicitly. Use unique first-row identifiers plus a mode scoped to that key so the empty private-tag conjunction activates no other key. Nontargeted keys use the original fallback on both sides. All keys reject malformed raw inputs in exactly the same way. The dictionary_criterion theorem characterizes exact equality for all private row choices and all raw strings; coverage of valid tails is essential. This repair is valid when the fallback splits into the private tuple and the terminal component as in Figure 6. Figure 5's issuer and all independently issued starred keys still require their own comparisons.

In the fresh-coin A.11 step the corrected challenger uses one starred child master. It can precommit the complete finite list of 2^b terminal pairs, the n_i other-slot pairs and q function pairs as in [task 142](https://github.com/MachinaIO/SigabaPark/pull/142). Build the challenger-side dictionary from all its returned ciphertexts; keep its entries fixed across every later evaluation, including repetitions. For the WE specialization the raw labels agree; at rank two they are fused with the fixed first value in the child message. The local wrapper can then request an independently generated shared-inner key containing the returned dictionary. Committing these lists is compatible with a fixed finite b, but an asymptotic PPT reduction needs an explicit polynomial bound on 2^b. Finite security must charge all queries, their replies, dictionary construction and the large key query. No honest tail table cost is implied by the simulator's clock *alone*. The real-key issue is whether left and right keys support compatible visible lengths and functions. A plain public FE whose key reveals f cannot supply this function-privacy step. Padded encodings revealing circuit length have to cover the programmed circuit in the honest world, unless a separately justified compression removes that dependence.

The scope of this obstacle is exact return bytes. A permissible child encryption interface may append an independent uniform h-bit marker that its own decryption ignores. Conditional on independent fixed public context, reproducing an arbitrary dictionary of such markers on all 2^b tails requires at least h 2^b token bits in a fixed-width public decoder (include all table-dependent auxiliary words in the token). This is the marker_capacity pigeonhole lemma. On a uniform random dictionary exact joint success is at most 2^(k−h 2^b) for k-bit tokens; fix independent evaluation tapes and average if needed. Per-point correctness error eta gives simultaneous correctness at least 1−2^b eta by union bound. This capacity test concerns a public path returning the child bytes for an issued private tuple, as in AGG evaluation; it does not lower-bound the information in a final one-bit WE answer. It is conditional on the indicated information in the child's returned bytes, not a lower bound for every child FE scheme.

A public Norm can strip this example's redundant marker on *both* sides. To repair A.8 more generally, its normalized output on the whole issued private cross-product and every raw u must be byte-identical to the corresponding normalized override; A.11 must reconstruct the joint distribution of normalized challenger replies with its other keys, and all future computations must accept that representation. Standard rerandomization usually samples new bytes; equality of decryptions or equality of marginal distributions cannot substitute for equality of **function outputs** in ordinary private-FE admissibility. A common canonical map with all these properties could change the counting result. Publishing a seed for a pseudorandom dictionary cannot by itself reproduce an already sampled independent table. Giving the starred adversary a public generator for the required scoped messages and randomness would be a different child game requiring a base and an induction. A conditional, distinct fallback is explicit canonical function tables on a tiny raw domain, with preprocessing and output length paid where the keys are generated.

### An exact construction with a raw final tail and no public MIFE premise

There is a way to put u outside every FE interface. Form the Boolean cofactor predicate E(p)=OR_v phi(p,v) over all b-bit v. Apply the ordinary private front-table compiler (including its finite prefix optimization if desired) to the one-bit output function f_beta(p)=beta AND E(p). Preserve all its allocated private slots and prepare the public description of E. The raw terminal generator is the identity on exactly b bits. If an exact gated result for all well-formed p,u is desired, Dec first checks the public phi(p,u); it returns zero when the check fails and otherwise decrypts the front result. Supply phi in the ciphertext when the underlying WE signature does not supply it to Dec. The cofactor_gate lemma checks the equality for *all* inputs. For the registered WE correctness obligation alone, Dec may skip the check and simply use the front result: every genuine witness satisfies E(p), and the definition imposes no correctness condition on invalid witnesses.

For every false public phi, E(p)=0 for every private front, so both function queries agree on every Cartesian product of the private tables. The ordinary private-game reduction generates the same public statement data and schedule and forwards the unchanged private package to the observer. This wrapper has the same ordinary gap with one execution and no challenge query for u. No new public capability exists at any A.8 or A.11 step, nor is a new hiding assumption about function equivalence needed beyond the original **private** compiler's obligations. For a valid witness the inherited private correctness error stays unchanged by the deterministic construction. This modular result is conditional on a realized private front compiler and its finite assumptions.

The generic cofactor construction really pays for its existential predicate. A simple fixed NAND compiler copies the 4096-gate input circuit 2^b times, wires v as constants, combines the outputs with three NAND gates per binary OR and uses two gates for payload AND. The emitted program has g=4099·2^b−1 gates. A shared tail-independent cone of g0 gates can be produced once: with g1=4096−g0 the corresponding displayed count is g0+2^b g1+3(2^b−1)+2. Further cofactor sharing or a circuit-specific existential projection must be exhibited. A uniform loop may save circuit-description bytes but still executes its iterations if used in this manner. BKS keys and nested evaluators must support this function's dimensions and the costs of its dynamic generation or evaluation at its actual use sites. If even one ordinary four-row garbling physically emits a full 129-bit label for each of the g gates, 516g bits fit strictly below 2^32 only for b≤10 (literal_projection_horizon). This is an implementation condition. A vector truth table followed by arbitrary indexing would also produce a full-domain solution but would return 2^b private function-output bits per front; existential gating uses only one.

For rank four after projection, write t for the still-private terminal width and balance the remaining bits across an explicit prefix and three nonterminal slots. Let (v,s)=divmod(128−b−t,4). A necessary field-only ledger with front entries of K bits and terminal entries of L bits is K(4+s)2^v+L2^t. Balancing minimizes the four power terms by discrete exchange. For the idealized 2z+1 accounting in [task 146](https://github.com/MachinaIO/SigabaPark/pull/146), L=255 at rank four for one bit. With K=64 its minimum at b=10 is 5,364,514,816 (t=22), already over the cap; smaller b cannot improve it. For the four-cell terminal layout in [task 145](https://github.com/MachinaIO/SigabaPark/pull/145), L=4^7=16,384. At K=64 its minimum is 5,368,709,120 at b=16 (t=16), and first fits at b=19 with 3,758,096,384 (t=15). At K=90 it first fits at b=20 and at K=128 at b=23. These examples omit every dynamic key, shape, generator and Turing-machine cost outside the named fields; adding a separate garbling size is legitimate only if not already counted in those field bits. The naïve cofactor implementation faces an expense even at a surviving field-only partition. No under-cap parameter row for general NAND follows.

### Literature boundary

The 2013/774 preprint is by Gordon, Katz, Liu, Shi and Zhou; their work and Goldwasser, Goyal, Jain and Sahai's 2013/727 were merged in the nine-author EUROCRYPT paper. Partial public-key multi-input FE explicitly allows a specified subset of encryption keys to be known. Its public slots range over inputs chosen after the transcript. The general constructions based on obfuscation do not give this task the required ordinary registry reduction. In particular, for an unrestricted private circuit-description slot and public raw input slot, a fixed universal evaluation key together with an encryption of C and the public input key evaluates C on all inputs. Message privacy for equally sized equivalent C then yields iO under the usual efficient uniform family and correctness hypotheses. This argument does not establish that a fixed finite WE-specific family implies general iO. Restricted inner-product schemes must still realize the actual wrapper and recursive randomized encryption/key algorithms; the ability to evaluate an inner product alone supplies no such compiler. Public-prefix ABE enumeration issues finite records in advance and cannot automatically delegate this post-publication tail evaluation. [Gordon et al., ePrint 2013/774](https://eprint.iacr.org/2013/774), [Goldwasser et al., EUROCRYPT 2014](https://www.iacr.org/archive/eurocrypt2014/84410299/84410299.pdf), [Abdalla et al., multi-input inner-product FE](https://eprint.iacr.org/2016/425).

The remaining practical branch is a small, uniformly constructed circuit for existential projection on the actual residual instances, or a restricted public tail implementation whose normalized complete intermediate outputs have an independent security proof. All finite private FE reductions, clocks and descriptions must still fit the registered assumptions and cost bounds.
