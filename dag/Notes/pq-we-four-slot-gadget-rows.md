### Which two-block header is shared

With scalar headers identical across a 2×2 grid, mixed subtraction of the left lanes yields B_Lᵀ Δs + Gᵀ(s₁₁−s₁₀) plus the mixed error. The right lane uses s₁₁−s₀₁ instead. MixedLane is the scalar identity underlying each coordinate. The additive secret s_ij=u_i+v_j removes the first term on every rectangle. Even a visibly variable product s_ij=p_i q_j s with known unit multipliers can be reduced to a shared secret by dividing every cell by its multiplier; noise after division must be bounded separately. This note instead realizes an independent interaction in four evaluation slots of one module sample. The physical header is a single polynomial matrix per input lane. Its scalar projections at the four slots are different public matrices. This changes the scalar-header condition and does not compress four independent scalar secrets into the entropy of one scalar secret.

### Four robust slots, including for composite q

Fix an even a≥2, q=a⁴+1 and R=(Z/q)[X]/(X⁴+1). Use four evaluation points ω=a,a³,−a,−a³ in that order. Every prime dividing q is odd, and a has order exactly eight modulo that prime because a⁴=−1. Root differences are therefore units modulo q. Equivalently, FourSlotInverse gives the explicit inverse up to the factor four, itself a unit. Evaluation is a ring isomorphism R→(Z/q)^4. Every uniform ring coefficient vector induces four jointly independent uniform scalar evaluations, and this extends to independent entries of vectors and matrices. Thus for uniform module secret s∈R^r, the mixed difference of its four evaluations is uniform in (Z/q)^r, equaling zero with probability q^(−r).

For a coefficient error polynomial with centered coefficients bounded by E, **all four** scalar projections have a centered representative of magnitude at most EW, where W=1+a+a²+a³. At each root the four signed powers reduce modulo q to a signed permutation of 1,a,a²,a³. NoiseGeometry gives (a−1)W=q−2. This bound is relative to q; it does not assert four independent scalar errors. Use uniform module secrets, coefficientwise CBD(1) (thus E=1), ring degree four, module rank r, and the number of samples specified below in the existing registered ModuleLWE.decision. There is no new assumption. The value of its estimator and any assumed hardness at this large odd modulus must be checked separately for a proposed parameter set.

### Honest parameter generation and Boolean evaluation

Let k be the number of witness input lanes and assign four publicly specified addresses z⁽⁰⁾,...,z⁽³⁾ to the slots, for example varying two designated bits. Constants use the registered true/default convention. Let X_i∈R interpolate the four bits at input i. Put t=ceil(log₂ q), choose m≥rt, and use a coefficientwise constant gadget G with r blocks 1,2,...,2^(t−1), padding remaining columns by zero. For any target matrix M, define BD_slot(M) by taking the ordinary binary gadget decomposition independently at each slot and interpolating its entries. Then G BD_slot(M)=M in R. Its entries may be large in the coefficient basis; their four evaluations are all bits. This distinction prevents hidden noise growth in the slot argument.

Choose independent uniform public B_i∈R^(r×m) and d∈R^r. For this group choose fresh uniform s∈R^r. Release each c_i=(B_i+X_iG)ᵀs+e_i with independent coefficientwise registered errors. For a constant x use B_x=−xG and c_x=0. For NAND(x,y), form D=BD_slot(−B_x), B_g=−B_y D−G and c_g=−Dᵀ c_y−y c_x, with y the four clear gate values packed in R. The usual bilinear expansion gives c_g=(B_g+(1−xy)G)ᵀs+e_g with e_g=−Dᵀe_y−y e_x. SlotNand checks the single-coordinate multiplicative identity. All clear arithmetic on a chosen slot can be performed using the input circuit and its public address; the honest decoder can just evaluate the projected matrices, without computing any other slot's witness values. At depth h the slot infinity norm of e_C is at most H E W, H=(m+1)^h. Public matrices B_C depend on the circuit and B_i, and are shared across the packed addresses and across groups reusing B_i.

Take the single projected column p=BD_slot(d), so Gp=d. Release one pure reference c_R=(B_C p)ᵀs+U and body v=dᵀs+e_D+floor(q/2)β. The error e_D is registered coefficient noise. Draw the four U slots independently and uniformly from the integer interval [−F,F] and interpolate them. This chosen reference-flood law is separate from the registered challenge errors. The stipulated interval sampler must be implemented, or choose an exactly power-of-two-length interval with its corresponding endpoints and TV denominator. At an accepting slot, subtract (pᵀ c_C−c_R) from v and decode the nearer of zero and floor(q/2). BooleanBookend checks the signed error formula, e_D−pᵀe_C+U at this slot. A sufficient deterministic condition is (1+mH)EW+F < (q−1)/4. The terminal handles a Boolean value, so no gadget-vector reference, inversion of a cofactor count, or prime modulus is required.

### Joint NO hybrid

For a selected four-address batch, start with **one** fixed registered decision Module-LWE challenge containing km+1 uniform module columns and their bodies under one secret (or independent uniform bodies). Use the first km columns as A_i and the last as d. Set B_i=A_i−X_iG. These matrices are exactly independent uniform even given d. Use the first km responses directly as the input ciphertexts and add the message shift to the last response. All input rows, slots and their linear combinations are present at once. In particular the simulator never chooses four independent surrogate **scalar** errors and it needs no leftover-hash header approximation or input smudging.

Using the supplied inputs and the four known addresses, the simulator evaluates c_C and issues pᵀc_C+U as reference. On a NO statement all four real outputs are zero. Conditioned on the matrices, secret, and registered errors, this reference has the honest center shifted by pᵀe_C. TV across four independently flooded coordinates is bounded by δ≤4mHEW/(2F+1), using interval translations followed by reduction and CRT. The real inputs are otherwise exactly honest. On an ideal challenge the withheld last body is uniform independent of every input response and reference, so adding either message gives the same whole-view law. Other batches under the programmed public B_i may be sampled honestly with independent ring secrets. A sequence of L batches therefore gives message gap at most 2L times a one-challenge bound plus 2Lδ, at the cost of simulating all other rows and the selected circuit. This is a mathematical reduction with classical challenge strings, not a claimed verified HardAt transfer or a quantum hardness certificate.

One can instead set the honest reference error to pᵀe_C exactly. Then the NO simulator needs no flood and the Boolean output subtraction has only the bookend error. Issuance must compute the selected clear outputs or the complete corresponding error recurrence. Algebraically this publishes a masked input body accompanied by the exact product Y·dᵀs, where Y is the packed acceptance vector. This variant does not eliminate truth-table work or hide a hard decision inside an efficient general issuer.

### Quantitative scope and replay

In the independent-reference variant a group transmits km ring input components, one ring reference and one ring body, or 4(km+2)t raw bits apart from the common header, codes and framing. Sending all B_i and d once uses 4(krm+r)t bits. For 128 retained witness bits, four slots still require 2^126 batches. Even one bit per batch exceeds the target. More generally packing N power-of-two slots by q=a^N+1 similarly gives bounded evaluation by the geometric sum at every odd power of a; direct storage still costs N·ceil(log₂ q) bits per ring component. Uniform secrets in the N slots have N independent scalar coordinates. These are batching results, not general ciphertext compression.

There is also an obstruction within the sufficient small-TV ledger even on the four-slot experiment. Since EW/q is roughly 1/a, obtaining negligible shift error this way requires a large a and therefore a large gadget width. For example, if one chooses a≥2^128, then t≥513. With r≥64 and m≥rt, one literal public input matrix already takes 4rmt≥4·64²·513²>2^32 bits. This counts a particular dense encoder and parameter choice. Costs also include reading unary circuit wires, bit decomposition, transforms, ring arithmetic, sampling and both role descriptions. No general capped machine is established.

An independent replay used a=2^64 (q has 257 bits), rank one only to test identities, and m=257. It sampled all four secret coefficients and actual coefficientwise CBD(1) errors, formed physical four-coefficient products, generated both 2×2 input lanes, and checked a NAND YES family and the false circuit NOT(NAND(x,NOT(x))). It compared full reference shifts on all four NO slots and decoded both message bits on every accepting slot. The sampled secret had nonzero mixed difference. These experiments are not a hardness assessment. The earlier independent-row projected-count construction in task 2bc12cd7-4def-48df-8c47-e3df1077f40c additionally supports positive cofactor counts; our scalar reference uses Boolean output and does not inherit count decoding.
