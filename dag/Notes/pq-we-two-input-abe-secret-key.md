Design-AI sub-task (ee) on `Def_WE_CircuitSAT` (`m = 128` witness bits, `2^12` NAND gates). The
2-split XWE of Brakerski–Jain–Komargodski–Passelègue–Wichs (ePrint 2017/874, "BJKPW", Thm 3.2,
Appendix A) issues `2^a` KP-ABE keys for `φ(w1, ·)` and `2^b` ciphertexts. A 3-way split needs
one more slot: keys for `w1`, slot-1 objects for `w2`, slot-2 objects for `w3`, and decryption of
any triple that satisfies `φ`. The literature status (open PRs #74 and #80): 2-input ABE exists
from LWE plus pairings in the GGM (Agrawal–Yadav–Yamada, CRYPTO 2022) and from evasive plus tensor LWE
(Agrawal–Rossi–Yadav–Yamada, ePrint 2023/941, "ARYY"). From plain LWE it exists only for
conjunctions of one-slot predicates (Francati–Friolo–Malavolta–Venturi, ePrint 2022/806), which are
decidable slot by slot. Allowed here: plain or Ring LWE, succinct or decomposed LWE, TLWE. Excluded:
iO, evasive LWE, local mixing, statement-dependent assumptions, pairings.

The three theorem nodes named below (`AdvancedEncryption.WE.TwoInput.*`) have complete proofs in
the same PR. They are not in `refs` because they are not merged yet.

## Summary

| Route | Verdict |
| --- | --- |
| (1a) per-slot secrets combined additively (key switching, `r = a_x + b_y`) | **Broken**: every 2×2 rectangle of slot values leaks `(b_y − b_y')·G` (`rect_leak`) |
| (1b) bilinear pair secret `r = s_x·T_y` via a two-level GGH15 with per-bit channels (candidate C2, §2) | **No attack found, no plain-LWE proof**. Same family as ARYY's "Attempt 1". The gap is a trapdoor circularity (§3) |
| (2) secret-key / correlated randomness, "lockable" tags | **Gives nothing**: in WE every slot combination is a legitimate witness, so a lock that blocks any pair breaks correctness. Pair randomness for `2^{86}` pairs from `2^{44}` objects must be publicly derivable, so it is a low-degree function of the slot objects, which is case (1a) or (1b) |
| (3) TLWE public trapdoor at the last step | **Breaks correctness**: TLWE needs `σ_e·σ_t ≳ q/√m`, so any preimage that the honest decryptor applies to a TLWE sample has error `≳ q`. TLWE can host a decoding step, not a traversed preimage |
| (4) streaming chain + circuit restructuring (Tseitin / CNF / bounded width) | **No generic gain**: a width-`s` decomposition lets the encryptor *decide* SAT by reachable-state DP at the cost of the chain's middle layers (`dp_reach`). The chain only saves the last cut, about `s/k` bits, and worst-case circuits have `s ≈` prefix length |

**Cost, if the gap in §3 were closed** (per-item costs as in PR #83, ring BGG+ at depth about
2048): balanced items `K_f ≈ 2^{76}` (key), `K_x ≈ 2^{77}` (slot-1 ciphertext), `K_y ≈ 2^{83}`
(slot-2 key, `2ℓ + 3` ring-matrix preimages). `split3_frontier` gives the best exponent
`E = ⌈(128 + 76 + 77 + 83)/3⌉ = 122`, so total encryption is about `3·2^{122} ≈ 2^{123.6}`, compared with `2^{147.7}` for
the 2-split of PR #83 and `2^{188}` for the baseline. This is still far above `2^{97}`. The count
`2^{43}` alone is misleading: per-item cost dominates. **Status: open.** No construction from allowed
assumptions beats the 2-split.

## 1. What the 3-way split actually needs

BJKPW's transform with a collusion-resistant scheme needs `(k−1)`-input ABE for a `k`-way split.
For `k = 3`:

* `2^a` function keys `sk_{w1}` for `f_{w1}(x, y) = φ(w1, x, y)`, all generated by the encryptor;
* `2^b` slot-1 objects `ct_x` (all `x = w2`), `2^c` slot-2 objects `key_y` (all `y = w3`);
* security only when `φ` is unsatisfiable, i.e. **every** `(w1, x, y)` is unauthorized. There are no
  adaptive queries and no adversarially chosen attributes; the published attribute sets are the
  **entire** domains.

Two remarks fix what "weaker object" can mean.

* **Mix-and-match is not a weakness to exclude.** In multi-input ABE, mixing ciphertexts from
  different sessions is an attack to be blocked. In WE every pair `(x, y)` is a candidate witness
  part. For the point-function statement `φ = [w = w*]` (about 400 gates) each triple must decrypt,
  so a scheme that blocks any pair by tags, locks or correlated randomness is incorrect on some
  statement in the family. The restricted object therefore has the **full** mix-and-match
  requirement of secret-key 2-input ABE over exponentially many ciphertexts per slot. The only
  real relaxations are the fixed function family, the non-adaptive game and the full-domain
  attribute sets. ARYY (§1.2, "Perspective") observe that WE permits correlated randomness across
  slots. The next point shows that this does not escape the problem.
* **Pair randomness must be derived.** The encryptor publishes `2^{44}` objects, and `2^{86}` pairs need
  distinct BGG+ secrets (one secret with two attribute values leaks; see `mix_leak` in PR #80). So
  the pair secret `r_{x,y}` is a fixed, publicly evaluable function of `(ct_x, key_y)`. With lattice
  operations (products of short matrices with LWE vectors) this function has low degree in the slot
  secrets. Degree 1 is §2.1; degree 2 is §2.2.

## 2. Route (1): per-slot fresh secrets joined by key switching

### 2.1 Additive joining is broken (`rect_leak`, proved)

Suppose the decryptor can derive the BGG+ block `(a_x + b_y)(A − p_x G) + e` from the slot objects,
as any key switching from `a_x` to `a_x + b_y` gives. For two values `x, x'` of slot 1 and `y, y'`
of slot 2, the alternating sum over the rectangle is exactly

`(p_x' − p_x)·(b_y − b_y')·G + (e1 − e2 − e3 + e4)`

(`AdvancedEncryption.WE.TwoInput.rect_leak`, over any commutative ring). The `A`-part cancels. With
`G`'s public trapdoor this decodes `b_y − b_y'` whenever `p_x ≠ p_x'` at some bit. Subtracting
`(b_y − b_y')(A − p G)`-type terms then moves an encoding of attribute `(x, y)` to the secret of
`(x, y')`, and `mix_leak` recovers that secret. Any **linear** (affine) secret combination loses
in four combinations. The same holds for `r = a_x + b_y + c` and for any combination that is
affine in each slot separately and additive across slots.

### 2.2 Bilinear joining: candidate C2 (two-level GGH15 with per-bit channels)

Public: BGG+ matrices `A0, A1 = (A1_i)_{i ≤ ℓ}, A2, u`. Encryptor-private matrices with trapdoors:
`B_{i,β}` (bit `i`, value `β ∈ {0,1}`), `B0`, `B_u = [B_u' | b]`.

* `ct_x` (fresh short `s_x`, row): `s_x B_{i,x_i} + e_i` for every bit `i`, `s_x B0 + e`, and
  `s_x B_u + e + μ·(0,…,0,⌊q/2⌋)`.
* `key_y` (fresh short `T_y`, `n×n`): `D_{y,i,β} = B_{i,β}^{−1}(T_y (A1_i − βG) + E)` for both `β`,
  `D_{y,0} = B0^{−1}(T_y [A0 | A2 − y⊗G] + E)`, and `D_{y,u} = (B_u'^{−1}(T_y u − b + E); 1)`.
* `sk_{w1}`: a short `k` with `[A0 | A_{f_{w1}}] k = u` (BGG+, decrypting when `f = 0`).
* `Dec(w1, x, y)`: compute `(s_x B_{i,x_i} + e_i) D_{y,i,x_i}` and `(s_x B0 + e) D_{y,0}`. This is a
  BGG+ ciphertext for attribute `(x, y)` under the pair secret `r_{x,y} = s_x T_y`. Then BGG+
  evaluation, `sk_{w1}`, and comparison with `(s_x B_u + …)·D_{y,u} ≈ r u + μ⌊q/2⌋`.

Correctness needs short `s_x` and short `T_y` (else `s_x E` is not small). The extra level costs one
factor `m·σ_D` in noise, about 30 bits of `log q` against `log q ≈ 2.9·10^5`.

**Attacks checked.**

* Channel crossing `(s_x B_{i,x_i})·D_{y,i,1−x_i}` gives a product of unrelated matrices, which is
  garbage. A ciphertext carries one channel per bit, so `mix_leak` inside one pair does not apply.
* Rectangle sums: `Σ± s_x T_y = (s_x − s_x')(T_y − T_y') ≠ 0`, so there is no linear cancellation.
  Short integer relations `Σ λ_{xy} s_x T_y = 0` require short dependencies among hidden vectors
  (an SIS instance with unknown matrix), which the decryptor cannot compute.
* Zeroizing (GGH15 rank attacks) needs many small zero-test values. Here small values arise only
  from authorized decryptions, and for a false statement there are none. Small values from
  `B·D` would need `B`, which is never published.
* If the separate channels are dropped and `key_y` carries `T_y·A1_i` and `T_y·G` as separate
  preimages, the decryptor computes `x_i s_x T_y G` alone and decodes `r_{x,y}`. The channel
  structure is necessary.

This is ARYY's "Attempt 1" family (right tensoring `⊗ r_y` there, a left secret `T_y` here). ARYY
state that it has no apparent attack but could not prove it even from evasive LWE (§1.3).

## 3. The precise gap: trapdoor circularity

A plain-LWE proof must, in some hybrid, replace an LWE sample by uniform. In C2 there are two
candidate levels, and both are blocked.

* **Left level (secret `s_x`, matrices `B`).** The `key_y` are preimages under every `B_{i,β}`
  and `B0`, and all `2^c` of them are published. So `s_x B + e` cannot be an LWE challenge unless
  the preimages can be simulated without `B`'s trapdoor. This is exactly the evasive-LWE step
  ("`B^{−1}(P)` reveals only `s·P`") with structured targets `P = T_y(A1_i − βG) + E`.
* **Right level (secret `T_y`, public matrices).** The targets `T_y(A1_i − 0·G) + E` and
  `T_y(A1_i − G) + E'` are both present, and their difference is about `T_y G`, so they are not
  jointly pseudorandom. Hence there is no CVW18-style right-to-left proof. Both channels are
  needed because `key_y` must serve all `2^b` values of `x`. A key carrying channel sets
  `C_i ⊆ {0,1}` serves `∏|C_i|` values, so one channel per bit means `2^{b+c}` keys, which is the
  1-input cost.
* **BGG+ puncturing does not rescue either level.** Selective BGG+ sets `A1_i = A0R_i + x*_i G`.
  This cancels the `G`-terms only at one `x*`, while `key_{y*}` publishes `T_{y*}`-encodings for every
  `x`. Puncturing at `x = 0` does give a trapdoor for `[A0 | A_{f(·,y*)}]`, since `f(0, y*) = 1` on a false
  statement. But the reduction must then write `T(A0R_i − G)`, which contains `T G` with `T`
  the LWE secret.
* **Hybrid granularity.** A hop must kill all pairs `(x*, ·)` or all pairs `(·, y*)` at once, since
  pair-level hybrids have no representation by slot objects. Each such hop is a 1-input ABE
  statement with all attributes of the other slot live, which is the circularity above.
  Exponential hop counts are allowed (`pq-we-hybrid-count-barrier`), but they do not help here.

**Open lemma (stated, not proved).** For short `s_x` (`x ∈ {0,1}^b`) and short `T_y`
(`y ∈ {0,1}^c`), the joint view `{s_x B_{i,x_i} + e}, {B_{i,β}^{−1}(T_y(A1_i − βG) + E)}`, plus the
`B0`/`B_u` parts and the keys `sk_{w1}` for a function family unauthorized on every `(x, y)`, hides
`μ` under plain LWE. Its weakest known proof uses evasive LWE (ARYY's final scheme modifies the
key and also needs tensor LWE for P). A proof for the WE-restricted family (fixed `φ`, full domains)
would give the costs in the summary.

## 4. Route (3): TLWE public trapdoors (AJLW, ePrint 2026/2927)

TLWE keeps `sA + e` pseudorandom next to a public trapdoor `T` of `A` only if `σ_e·σ_t ≥ q/√m`
(below that, `eT mod q = eT` over `Z` breaks it). A preimage that is sampled with `T`, or is
indistinguishable from one, has width `σ_D ≥ σ_t`. The honest error after applying it is then
`≈ √m·σ_e·σ_D ≥ q`. So TLWE cannot let the reduction simulate the `B`-preimages of §3 (the honest
decryptor traverses them), nor the BGG+ keys (applied to evaluated ciphertexts). Using TLWE only
for a final *decoding* step (TDRE style) does not touch the circularity, which lies in the
preimages. Open PR #78 analyses TLWE for WE in general.

## 5. Route (4): bounded-width verifiers and circuit restructuring

The layered chain of PR #80 streams `V` as `σ_i = h_i(σ_{i−1}, w_i)` with `s`-bit states and pays
`2^{ℓ_i + s}` ciphertexts in each middle layer. `AdvancedEncryption.WE.TwoInput.dp_reach` shows that
the reachable state sets `R_{n+1} = h(R_n × B)` are exactly the states reached by some witness
prefix, with at most `|S|·|B|` step evaluations per layer. So **the same decomposition lets the
encryptor decide SAT** at cost `Σ_i 2^{s+ℓ_i}`, the same as the chain's middle layers, and then
encrypt trivially. The chain differs from this DP only at the last cut, where a 1-input ABE
replaces `2^{s+ℓ_k}` with `2^{max(s, ℓ_k)}`. With PR #80's frontier, the DP over the same blocks
needs `m + (k−1)s ≤ k·e`, against `m + (k−2)s ≤ k·e` for the chain. The chain gains `s/k` bits.
For `k = 3, s = 16` that is 54 against 48. If the verifier is narrow at every bit (`ℓ_i = 1`), the DP
costs `m·2^{s+1}` while the chain costs at least `2^s`, a gain of at most `log2(2m) = 8` bits.

**Restructuring.** Tseitin/CNF adds the cut wires as witness bits, and the chain or DP enumerates
them, so `m` grows by the cut size. A re-encoding with a narrower verifier is a decomposition with
smaller `s`, and that makes the statement *easier to decide* at the same rate. For worst-case
`2^{12}`-gate circuits, for example `[h1(w1) ⊕ h2(w2) ⊕ h3(w3) = y]` with 128-bit `h_i`, every
order has `s ≈` prefix length, and then `e ≥ 64`. **Verdict:** narrowness is easiness. Route (4)
cannot beat the 2-split on the worst case, and on narrow instances it beats deciding by only
`s/k` bits.

## 6. Pricing a 3-way split by per-item cost

`AdvancedEncryption.WE.TwoInput.split3_frontier`: tables of `2^a, 2^b, 2^c` items with per-item
cost `2^{K1}, 2^{K2}, 2^{K3}` (`a + b + c = m`) all stay `≤ 2^E` iff
`m + K1 + K2 + K3 ≤ 3E` and every `K_i ≤ E`. The 2-split analogue is `m + K1 + K2 ≤ 2E`. With PR #83's
`K ≈ 2^{76}` the 2-split gives `E ≈ 140`, compared with PR #83's measured `2^{147.7}` total. A 3-way
split gains `(m + ΣK)/2 − (m + ΣK)/3` bits only if the slot-2 object costs about as much as the
others. In C2 it is about `2ℓ` preimages (`K_y ≈ K + 6.5`), which gives `E = 122` (summary). A 3-way split reaches `2^{97}` only if
`ΣK ≤ 3·97 − 128 = 163`, i.e. per-item costs averaging `2^{54}`. That needs depth reduction far
beyond the worst case `d ≈ 2048`, so it is out of reach for BGG+-type items.

## 7. Remaining gap and next steps

1. The open lemma of §3 (bilinear GGH15 with per-bit channels, keys unauthorized on all pairs)
   from plain LWE. Equivalently, an evasive-LWE-free simulation of `B^{−1}(T_y(A1_i − βG) + E)`.
   This is the single missing step, and it is the known open problem of plain-LWE multi-input ABE
   in its smallest form.
2. Even if it is closed, the 3-way split is at about `2^{123.6}`, not `2^{97}`. A further gain needs
   cheaper per-item BGG+ costs (depth), not more slots.

## A cut-rank test for exact many-slot field masks

Splitting n witness bits into r blocks of at most ceil(n/r) bits uses at most r*2^ceil(n/r) individual menu entries. For r=ceil(n/log2 n) this part is polynomial. This count by itself makes no guarantee about joint security, evaluator width, or key generation. To test one concrete route, suppose the *observable* pad at a tuple is the exact scalar product of the prefix and suffix state at a slot cut, over a finite field F_q. This includes a chain of arbitrarily sampled slot matrices with cut dimension d and scalar endpoints: even dependent matrices yield F(u,v)=A(u)B(v), where the row and column have length d. Suppose the observable output on the false instance is V_b(u,v)=F(u,v)+b at every tested tuple. All statements below concern this output interface.

On a fixed s-by-s grid of distinct prefix and suffix choices the pad table has rank at most d. Thus a hybrid replacing it by independent field values fails on s=d+1 as soon as each side has that many choices. The ideal square matrix is invertible with probability product_(i=1)^s (1-q^(-i)), by counting successively independent columns. This is bounded away from zero even for q=2. Computing this test takes s^2 evaluations and polynomial field time. It applies without any independence hypothesis on the real slot secrets. Failure of this hybrid alone does not establish plaintext leakage for every low-rank table.

There is a stronger conclusion for the natural control where the s prefix rows and s suffix columns are independent uniform vectors in F_q^d. Set s=d+h, h>=1. Write J=11^T. If the augmented s-by-(d+1) matrices [A,1] and [B^T,1] both have full column rank then AB+J has rank d+1 by factorization through the identity. AB always has rank at most d. Modulo the known line spanned by 1, each projected random column is uniform in dimension s-1, so full augmented rank has probability product_(i=0)^(d-1) (1-q^(i-(s-1))). Square this for the independent sides. This gives a lower bound on the difference of the probabilities that V_b has rank greater than d. For q=2, h=4 it is at least (1-1/8)^2 by a union bound on nonzero coefficient vectors in the projected kernel. Even access only to emitted values suffices. Forced inclusion of the constant vector among state coordinates invalidates this particular random-factor message bound; it does not invalidate the rank obstruction to independent pads.

Consequently an r-way compiler cannot justify security by replacing an exact polynomial-width field matrix product with independent tuple masks on an exponentially large balanced cut. A wide enough cut on just one side, or modifying the observable output via a nonlinear map with its own proof, changes the test's premises. Ordinary WE only needs hiding of b. No impossibility for general multi-input ABE, rounded encodings or quantum-secure PRFs follows. The joint security proof, not the polynomial menu count, is what remains necessary.

~~~python
from itertools import product
from fractions import Fraction
def rank2(columns):
    basis={}
    for v in columns:
        while v:
            i=v.bit_length()-1
            if i not in basis:
                basis[i]=v
                break
            v ^= basis[i]
    return len(basis)
s,d=3,2
one=(1<<s)-1
factors=list(product(range(1<<s),repeat=d))
large=0
for A in factors:
    for B in factors:
        cols=[(A[0] if B[0]>>i&1 else 0)^(A[1] if B[1]>>i&1 else 0) for i in range(s)]
        assert rank2(cols)<=d
        big=rank2([x^one for x in cols])>d
        assert big==(rank2((*A,one))==rank2((*B,one))==d+1)
        large+=big
assert Fraction(large,len(factors)**2)==Fraction(9,64)
print("4096 factor pairs; exact message-test gap 9/64")
~~~

## Fixed LPN and the exact offset condition for correlated tuple values

Consider a value-only alternative to the exact product test. Sample a uniform binary m-by-d matrix A, d-by-l uniform S and independent Bernoulli noise E of shape m-by-l; put Y=AS+E. Keep a fixed, statement-independent parameter family with quantum-hard decisional LPN for one m-sample column. Publish A. For each query tuple z the public circuit computes an m-by-l binary feature matrix T_x(z) and an offset bit g_x(z) without using S,E or b. The evaluator returns the bit <T_x(z),Y> + b*g_x(z), using the entrywise inner product. Reuse of cells of Y is intentional.

With Y replaced by uniform U the *whole* value function is a uniform element of the image of the linear map D -> (<T_x(z),D>)_z translated by b*g_x. Thus the two message laws are identical exactly when there exists D with <T_x(z),D>=g_x(z) for every z. This does not demand an independent random function on tuples. For statement-only features, a nonuniform proof may establish this existence without an efficient algorithm for finding D. Replacing columns one by one costs at most l fixed LPN advantages per message, since given the challenge A the reduction can generate the other columns with fresh secrets and noise. It can implement coherent evaluations reversibly using its full challenge column; budget their circuit cost. The resulting bound for the value interface on a false x satisfying the offset condition is twice the sum of the column advantages. See the binary decisional experiment in [Non-Interactive Zero-Knowledge from LPN and MQ, Definition 4.2](https://eprint.iacr.org/2024/1254.pdf).

If the condition fails, some at most m*l+1 tuples have feature matrices summing to zero but offset bits summing to one. Indeed select a basis among the flattened rows; interpolating their offsets defines a consistent functional there, so one additional row contradicts it. XORing these responses returns b exactly, for every Y and every noise draw. This gives a polynomial-size nonuniform distinguisher for a fixed offending x even if the tuple domain is exponential; efficient uniform discovery of the tuples is a separate issue. For features that depend on random A, a certificate hardwired before seeing A need not suffice. In particular the small-test statement here uses statement-only features.

For an interface example take one nonzero fixed coefficient feature when C_x(z)=0 and zero otherwise, with g_x(z)=1. Every true witness reads b. On NO the offset condition holds and the functions are constant across tuples with a hidden random shift in the ideal game. Publishing Y as well as any response on a known tuple instead exposes b by subtraction. Trying to encode the offset by sending only (A,Y+bD) for an efficiently computed public D does not repair this: for *every* fixed x and D independent of Y given A, the two buffer distributions are computationally indistinguishable by the same column hybrids, including on YES. An efficient decoder with a hardwired valid witness would contradict this. Thus the fixed assumption can justify correlated masks and avoid the earlier rank objection at the value interface, but an explicit representation giving the witness these evaluations without exposing the seed buffer and offset separately remains necessary. No general public WE ciphertext follows.

~~~python
from itertools import product
from collections import Counter
for rows in product(range(4),repeat=3):
    for g in range(8):
        images = [sum(((row & d).bit_count()%2)<<i for i,row in enumerate(rows))
                  for d in range(4)]
        law = Counter(images)
        same = law == Counter(y^g for y in images)
        assert same == (g in images)
        if not same:
            assert any(all((h&y).bit_count()%2==0 for y in images)
                       and (h&g).bit_count()%2 and h.bit_count()<=3
                       for h in range(1,8))
print("512 feature/offset systems; exact image criterion and short separating parities")
~~~

## An explicit response basis, and when its generation decides the source language

Flatten the public augmented row f(z)=(T_x(z),g_x(z)) into p+1 bits. If the sender can find representative tuples z_1,...,z_s whose rows span all query rows, it can publish just V_b(z_i) for i=1,...,s. Use a uniform p-bit mask in this construction: LPN is unnecessary. A receiver expresses f(z) in the representative basis by public elimination and XORs the indicated response bits. Correctness is exact for every query, because the full response is the evaluation of a linear functional on f(z). On NO the offset condition from above makes the joint responses perfectly hiding by translating the mask. Representatives must be chosen independently of mask and message. If both parties deterministically generate the representatives from x, the response payload is at most p+1 bits and no tuples need be transmitted. Otherwise include the polynomial-size list or its public seed. Enumeration of the whole tuple domain would give a short payload but can make Enc exponential.

One constructive case is an ordered read-once matrix product for the *augmented features*. Suppose f(z)=u M_1(z_1)...M_r(z_r)H, with polynomial layer widths and polynomially enumerable symbols per layer, each admissible tuple drawn from their Cartesian product. At layer zero retain the starting row if nonzero. At each subsequent layer extend every retained row by every allowed symbol, then keep a maximal independent subset of the resulting rows. Save a prefix realizing each retained row. Inductively these rows span all realizable prefix rows: right multiplication by the same next matrix preserves every prior linear dependence. Apply H and remove redundant projected rows at the end. This produces actual representative tuples in deterministic polynomial time, with at most the layer width many live prefixes and at most rank(H) final tuples. The argument needs the common reading order and the ability to extend every prefix by each symbol; repeated-variable consistency cannot simply be dropped. Dense binary elimination and matrix multiplication at each layer suffice for a polynomial sender and receiver. This provides a public ciphertext implementation of the specified linear evaluation interface on this structured family.

There is a sharp diagnostic for the proposed witness decoder f(w)=(0,1). With the complete basis, test if e_last belongs to its span. On YES, any accepting witness forces membership. On NO, (D,1) annihilates the basis by the offset condition but evaluates to one on e_last, so membership is impossible. Thus polynomial-time basis construction under these two promises already gives a polynomial-time source decider and hence a one-bit direct encryption. The same test works if the representatives span just e_last on YES and are all genuine on NO. Random discovery with a bounded two-sided error gives a BPP decider. This identifies a concrete cost overlooked by merely counting p+1 representatives. For the previous one-feature example with a unique accepting n-bit tuple, any list of Q independent uniform tuples spans e_last only if it samples that witness, with probability 1-(1-2^-n)^Q. This is a limitation of that sampling strategy, not a lower bound on other compilers. ## Two passes: a structured positive case and an NP-complete ordering

The same witness bits may be read in two different orders. For a block I contiguous in both orders, let P_I and Q_I be its matrix products in the first and second passes. Keep a basis of the vectors vec(P_I) tensor vec(Q_I), with one realizing assignment per basis element. For width w the dimension is at most w^4 (pad smaller matrices). Start at singletons by trying each possible bit. Suppose two disjoint children J,K partition I in first-pass order, and in the second pass occur either as J,K or as K,J. In the first case combine two representatives by (P_J P_K, Q_J Q_K); in the second by (P_J P_K, Q_K Q_J). On the tensor vectors this operation extends bilinearly, because each input pair occurs once in each tensor monomial of the result. Disjoint child assignments can be chosen independently. Consequently combining only basis representatives, at most w^8 pairs per node, and taking a basis again spans *all* attainable parent vectors. At the root the desired u P Q H is a linear contraction of the retained tensors. The earlier response-basis compiler applies to the projected augmented rows. A supplied binary common-interval decomposition is easy to check; alternatively recursively try interval splits with memoization to find one in polynomial time. This includes same-order and reverse-order passes and recursively swapped blocks. There is no need to remember all first-pass witness bits at the middle cut.

In contrast, polynomial WE for unrestricted two-pass orders would already suffice for ordinary NP, even at width three. Given a nonempty CNF with nonempty clauses, introduce one bit for each *literal occurrence*, storing the variable value before applying its literal sign. Read all occurrence bits once in clause order. At any position the live states record whether this clause is satisfied so far, plus an absorbing failure state. Apply the sign, at the end of each clause fail if unsatisfied, otherwise reset. In the second pass group the *same occurrence bits* by variable. On the first bit of each group store its value; on every later bit keep it on agreement and go to the absorbing failure state on disagreement. A new group overwrites the stored value without reviving failure. At the end accept either live state. Position-dependent transitions are public deterministic three-by-three binary matrices (one 1 per row); every Boolean assignment is evaluated exactly even over F_2. Empty clauses or an empty conjunction can be handled directly. Each input bit is read exactly twice. For l literal occurrences this uses 2l transitions on a run and O(l) small matrix pairs, plus the read order. Tseitin conversion gives polynomial size for CircuitSAT. A satisfying original witness supplies all occurrence bits including auxiliary gate values; any accepting occurrence string recovers a consistent satisfying assignment. Hence an ordinary WE for this public read-order family with polynomial costs and a fixed-assumption proof transports to general NP with the same assumption and no obfuscation intermediary. This is a reduction target, not an instantiation.

For the previous mask example compute f=(1-C,1) by a final linear map of the one-hot states. Reject maps to (1,1), accept to (0,1). On NO the offset condition holds, and a satisfying witness evaluates to the target. Thus polynomial generation of the genuine response basis for arbitrary second-pass permutations would decide SAT, by testing membership of (0,1). Width, layer size and number of reads are already constant per position here; the unmet cryptographic requirement is to enforce the same choices across the two orders without making reachability for all assignments publicly decidable. This concerns the augmented feature language of the preceding sections and does not give the missing public-encoding hybrid of PR 111.

~~~python
from itertools import product
~~~

## Two live states admit a linear scan even with arbitrary rereads

For the deterministic, *oblivious* model used in the preceding reduction, width two has a direct decision algorithm. Each position i queries a public bit index v_i shared by both states, possibly repeated arbitrarily. For a fixed answer a, its map on the state bit is either constant (a reset) or s -> s XOR b_i(a), where b_i(a) is the image of zero. A particular execution therefore has a last reset, or uses only permutations. Its final state depends on one constant and the parity of all later permutation flips. This is specific to a single input index per layer; state-dependent choices of the queried variable are outside the argument. For a broader width-two SAT model see [Makita et al.](https://www.jstage.jst.go.jp/article/transfun/E105.A/9/E105.A_2021EAP1120/_article).

Scan right to left. For each variable maintain its allowed answers from the suffix requirement that *all* later maps are permutations. Also maintain the XOR coefficients of the suffix flips, using b_i(x)=b_i(0) XOR ((b_i(0) XOR b_i(1)) AND x). This affine extension is valid on the allowed domain even when the other answer resets. To test a reset at i, try its at most two constant-map answers a compatible with the suffix, temporarily pin v_i=a, and test if the reset value XOR suffix parity can equal the desired terminal state. With a product of unary domains, an affine bit takes both values iff some free variable has nonzero coefficient. Otherwise it takes only its fixed value. Then extend the permanent suffix by requiring a permutation at i and adding its flip. Stop extending if a domain becomes empty. Finally test the initial state as the no-reset case. Conversely each passing test yields an assignment: choose allowed answers meeting that parity; the unconstrained earlier prefix cannot affect the result after the reset. Thus this computes exact satisfiability without enumerating assignments or assuming independent occurrences.

With indexed arrays the scan uses O(L+n) word operations for L positions and n bit variables and O(n) working words (besides the stored read schedule). Maintain the parity for the least allowed answer of every variable and a count of free variables with nonzero coefficient. Only one variable changes per step; temporarily pinning it also costs O(1). A public single-tape implementation must charge for addressing and parsing; a straightforward scan-based simulation remains polynomial. For either accepting terminal this gives an unconditional one-bit ciphertext: emit the plaintext if acceptance is attainable and zero otherwise. Both accepting terminals or no accepting terminals are immediate. The previous width-three construction already embeds ordinary NP with two reads per variable. Thus in this precise model a third state can record permanent failure across multiple local checks, whereas at width two a later reset erases all earlier state information. This delineates the structured subclass and does not provide security for the three-state construction.

~~~python
from itertools import product
from random import Random
def attainable(n,layers,start,want):
    domain = [3]*n   # low and high bits permit answers zero and one
    coeff = [0]*n
    parity = free = 0
    for i,table in reversed(layers):
        old, c = domain[i],coeff[i]
        least = int(old==2)
        for a,(zero,one) in enumerate(table):
            if zero==one and old & (1<<a):
                fixed = parity ^ (c & (least^a))
                if free-int(old==3 and c==1)>0 or zero^fixed==want:
                    return True
        new = old & sum(1<<a for a,(z,o) in enumerate(table) if z!=o)
        if new==0:
            return False
        cnew = c ^ table[0][0] ^ table[1][0]
        parity ^= (c & least) ^ table[0][0] ^ (cnew & int(new==2))
        free += int(new==3 and cnew==1)-int(old==3 and c==1)
        coeff[i],domain[i] = cnew,new
    return free>0 or start^parity==want
~~~

## Which three-state transitions are needed?

Identify the states with F_3. Every permutation of the three states is s -> a s+c with a=1 or -1; there are exactly six such affine permutations. Constant maps are resets. Suppose each fixed input answer at each layer selects either a permutation or a constant. There is a polynomial test for acceptance even when the public schedule rereads variables arbitrarily. This is a statement about final-state acceptance. Related complexity questions for programs over monoids are studied in [Barrington, McKenzie, Moore, Tesson and Therien](https://sfi-edu.s3.amazonaws.com/sfi-edu/production/uploads/sfi-com/dev/uploads/filer/aa/b3/aab31b7d-bc95-4394-9d6b-21460c31e6aa/00-04-026.pdf).

Enumerate the last reset position and answer, or the no-reset case. Pin the reset answer and require a permutation at every later position. These are unary restrictions on actual bit variables; intersect all domains and skip inconsistent branches. The start of the suffix has a known state. Eliminate pinned variables. On this subcube the suffix consists entirely of affine permutations. Write chi_S(x)=(-1)^(sum_(j in S) x_j) over F_3. Every slope depending on one free bit is a signed character, while each intercept has at most two character coefficients (since 2 is invertible). The final state is the initial state times the product of slopes, plus one term per layer consisting of its intercept times the slopes of all later layers. Products of signed characters stay single signed characters, with supports combined by symmetric difference. A suffix of length L thus gives at most 2L+1 terms before combining equal supports, regardless of rereads.

For terminal t form the character dictionary of 1-(s_final-t)^2. It equals one exactly on the assignments ending at t. It is nonzero somewhere iff some coefficient is nonzero: the binary character matrix has orthogonal rows of squared norm 2^f, invertible in F_3 for f free bits. Squaring uses at most O((L+1)^2) term pairs per last-reset branch. There are at most 2L+1 branches; support bitsets, dictionary operations, coefficient addition mod three and unary-domain checks all have polynomial bit cost. Test the accepting terminals separately. As previously, a positive decision lets Enc output the bit and a negative decision gives a constant one-bit ciphertext. There is no hardness premise. This gives no comparable algorithm if a transition merges two states while preserving a distinct third image: such a map has image size two and is not affine on F_3. The NP-complete clause/equality program uses those partial mergers, for example sending both live states to the satisfying live state and keeping failure absorbing.

More generally, for k positions that may contain a partial merger, guess an answer bit and an entering state for each of these positions (at most 6^k choices), impose consistent pins, and compute the corresponding outgoing states. The k+1 intervening segments enforce specified terminal states on the *same* assignment. Enumerate last resets in each segment, intersect all the unary restrictions, and multiply their terminal-indicator dictionaries before the nonzero test. Testing each segment for feasibility separately would be unsound. This takes (L+1)^O(k+1) times polynomial bit overhead, allowing all constant k. This bound applies to the number of exceptional positions, not the number of different transition tables. No polynomial bound for arbitrary k or fixed-assumption general WE follows.

~~~python
from itertools import product
from random import Random
def possible(n, layers, start, target):
    cases=[(-1,0,start)]
    for i,(v,ab) in enumerate(layers):
        cases.extend((i,b,c) for b,(a,c) in enumerate(ab) if a==0)
    for i,b,s in cases:
        dom=[3]*n
        if i>=0: dom[layers[i][0]]=1<<b
        for v,ab in layers[i+1:]:
            dom[v]&=sum(1<<j for j,(a,c) in enumerate(ab) if a)
        if 0 in dom: continue
        coeff={0:(-target)%3}
        mask,sign=0,1
        def add(m,c):
            coeff[m]=(coeff.get(m,0)+c)%3
        for v,ab in reversed(layers[i+1:]):
            (a,c),(aa,cc)=ab if dom[v]==3 else [ab[int(dom[v]==2)]]*2
            add(mask,sign*2*(c+cc))
            add(mask^(1<<v),sign*2*(c-cc))
            sign=sign*a%3
            if a!=aa: mask^=1<<v
        add(mask,sign*s)
        ind={0:1}
        for u,cu in coeff.items():
            for v,cv in coeff.items():
                ind[u^v]=(ind.get(u^v,0)-cu*cv)%3
        if any(ind.values()): return True
    return False

            for _ in range(rng.randrange(16))]

        ends=set()
        for x in product(range(2),repeat=n):
            s=start
            for v,ab in layers:
                a,c=ab[x[v]]
                s=(a*s+c)%3
            ends.add(s)
~~~

## Parameter cost of partial mergers when rereads are unrestricted

The exponent depending on the number of exceptional positions in the preceding decision baseline cannot in general be replaced by a fixed polynomial exponent unless parameterized CLIQUE is fixed-parameter tractable. Here is an explicit witness-preserving reduction. For a simple graph on N vertices and requested clique size h>=2, give the witness h vertex addresses of ceil(log2 N) bits each. Use isolated padding vertices to fill the address domain. For each pair of addresses test the badness bit f, one for a nonedge (including the diagonal), zero for an edge. A witness passes all pair tests iff its addresses form an ordered clique.

A Boolean truth table on u bits has a character expansion over F_3 with at most 2^u terms. The coefficient for support S is 2^(-u) times the sum of f(x) chi_S(x) over the Boolean cube, in F_3. Implement translation of a ternary state by one term c chi_S(x) using only permutations: negate the state conditionally on each selected input bit, translate by c, then repeat the conditional negations. The total map is s -> s+c chi_S(x). Concatenating terms yields the permutation program P_f(s)=s+f(x); its inverse is obtained by reversing and inverting its steps. Constants can be implemented at an arbitrary bit position with both transitions equal. Pair predicates have u=2 ceil(log2 N), so at most 4N^2 terms and O(N^2 log N) instructions per pair. Coefficients can be computed in polynomial time independently of h's value in the exponent.

Let M send 1 to 2 and fix 0 and 2. Compile each pair check as P_f, M, P_f inverse, M in execution order. Starting in 0, a good pair leaves 0 and a bad pair leaves 2. Starting in 2, either case leaves 2 (for a bad pair the intermediate states are 0,0,2,2). Thus the accumulated rejection bit persists at the *boundaries* even though it need not persist inside a permutation block. Start at 0 and accept only 0. There are exactly k=2 binom(h,2) designated merger positions, all using the same input-independent M. All other instructions are permutations. Total length is O(h^2 N^2 log N) for N>=2. This proves the parameterized implication by direct substitution: an f(k) poly(L) decision procedure here gives an f'(h) poly(N) CLIQUE procedure. Under the usual parameterized clique time hypothesis excluding g(h) N^o(h), it also rules out g'(k) L^o(sqrt(k)); see [Chen, Huang, Kanj and Xia](https://www.sciencedirect.com/science/article/pii/S0022000006000675) for parameterized clique lower bounds. Neither claim proves the preceding L^O(k) upper bound optimal.

This uses arbitrary repeated reads for the character terms. It does not strengthen the parameter lower bound for schedules reading each bit only twice. It does show that sharing a single public partial merger and allowing arbitrary efficiently listed ternary permutations already gives a nontrivial WE target. A hypothetical polynomial-cost secure WE for these schedules would transport to CLIQUE, hence all NP by witness-preserving reductions such as the literal-selection reduction from 3SAT. The complexity obstruction applies to the strategy of publicly deciding the statement; it does not exclude computational WE.

~~~python
from itertools import combinations, product
def terms(table):
    n=len(table)
    return [(s,(pow(n,-1,3)*sum(v*(-1)**((s&x).bit_count()%2)
                                 for x,v in enumerate(table)))%3) for s in range(n)]

        for j in range(4):
            if (mask & x) >> j & 1: s=-s%3
        s=(s+direction*c)%3
        for j in reversed(range(4)):
            if (mask & x) >> j & 1: s=-s%3
    return s

            s=apply(s,z,reversed(coeffs),-1)
            s=2 if s==1 else s
~~~

## One fixed merger per clause with at most eight controlled permutations

There is a shorter boundary update than the two-merger construction above. Encode live as 0 and failed as 2 in F_3. For any Boolean badness bit f, first translate by -f, then apply the fixed M=(0,2,2). If f=0 both boundary states are unchanged. If f=1, the two boundary states 0 and 2 become 2 and 1 respectively; M sends both to 2. Thus no inverse translation is needed. For the clique construction this halves the merger count to binom(h,2). The invariant is needed only between checks.

For a nonempty clause with u<=3 literals, use local query bits x_j equal to one when literal j is false. Its badness bit is f(x)=product_j x_j, including if occurrences happen to read the same original variable. Expand -f in F_3 characters chi_S. The coefficient c_S is -2^(-u)*(-1)^|S| since f is supported on the all-ones tuple. To implement the translation by sum_S c_S chi_S, visit the 2^u supports in cyclic binary reflected Gray order starting at the empty set. At each support translate by c_S and then conditionally negate on the unique bit toggled to the next support (including the final return to empty). For any assignment, induction gives a state after moving to support R equal to chi_R times the initial state plus accumulated character translations inside the same parentheses. Explicitly it is chi_R(x)*(s_initial + sum_{S visited} c_S chi_S(x)). Closing the tour therefore gives s_initial-f(x).

All constant translations can be compiled away. Maintain the offset d in the invariant logical state = physical state + d, initially zero. A constant translation adds to d. A conditional negation becomes identity when its bit is zero and the reflection s -> -s-2d when its bit is one; d stays fixed. After the tour d=sum_S c_S=-f(0)=0. Negated literal inputs are handled by swapping the two public transitions. Thus only 2^u controlled permutations, each choosing between identity and a transposition, and exactly one input-independent M are emitted. Constants are compiled into the reflection tables. Reject an empty clause directly.

An m-clause 3-CNF therefore takes at most 9m instructions with unrestricted rereads, accepting exactly its satisfying witnesses. More specifically the usual NAND Tseitin encoding with two binary clauses and one ternary clause per gate, and one output unit, needs at most 19g+3 instructions for g gates before simplification. A decryptor extends an original witness by the honest gate values. Conversely acceptance enforces each gate equation and the output pin. These are counts of verifier instructions, not cryptographic operations or ciphertext bytes. Schedules of this form suffice as a general-NP target for fixed-assumption WE. The same occurrence control must remain consistent across repeated reads; publishing both choices as freely composable paths drops that requirement. No hiding theorem for the compiled ciphertext is obtained.

~~~python
from itertools import product
def program(u):
    size=1<<u
    d=0
    steps=[]
    for i in range(size):
        gray=i^(i>>1)
        j=(i+1)%size
        next_gray=j^(j>>1)
        d=(d-pow(size,-1,3)*(-1)**gray.bit_count())%3
        steps.append(((gray^next_gray).bit_length()-1,(-2*d)%3))
    assert d==0
    return steps

def run(s,bits,steps):
    for j,c in steps:
        if bits[j]: s=(c-s)%3
    return (0,2,2)[s]

checked=0
for u in range(1,4):
    steps=program(u)
    for pins in product(range(3),repeat=u):
        for signs in product(range(2),repeat=u):
            for data in product(range(2),repeat=3):
                bits=[data[j]^a for j,a in zip(pins,signs)]
                for start in (0,2):
                    assert run(start,bits,steps)==(2 if all(bits) else start)
                    checked+=1
print(checked,"signed/repeated-input boundary checks; clause lengths 3, 5 and 9")
~~~

## A direct five-instruction NAND check with a matching local lower bound

Let p be the product of controlled permutations before the fixed merger M=(0,2,2), in execution order. It suffices to realize p^{-1}(0)=f, where f is the Boolean violation indicator. Indeed on a good trace only starting state 0 reaches 0; on a bad trace only starting state 1 could reach 0, and state 1 is never a boundary state. M maps both other outcomes to failure. Conversely these two required boundary behaviors force exactly this preimage in either case. This relaxes the previous requirement to implement an entire translation by -f.

Let a,b be the NAND inputs, c the proposed output, and t=1-c. The violation indicator is f=t XOR (ab), with f(0,0,0)=0 in local coordinates (a,b,t). Write R_j(s)=j-s mod 3. Use the following four instructions, each applying its reflection if its named local bit is one and identity otherwise, in the displayed execution order:

    (t, R_1), (a, R_2), (b, R_0), (a, R_2), M.

For verification, the prefix character supports of the control sequence form the open walk empty, t, ta, tab, tb (concatenation means set union here). In the inverse product applied to zero, a controlled reflection R_j with prefix supports U before and V after contributes (j/2)(chi_U-chi_V), since it is involutive. Summing the four contributions gives the F_3 character coefficients (2,2,2,1,2) in that walk order. These are the coefficients of f: expand (1-chi_t*(1-2ab))/2 using a=(1-chi_a)/2 and likewise for b. The listed support has size five. In any word of l such controlled reflections, including controls with reversed polarity, the inverse image of zero has character support at most l+1: each term lies on its two adjacent prefix supports, with signs allowed. Hence three instructions cannot implement this boundary behavior before M on three independent local bits. This proves optimality among single-bit-controlled identity/transposition words with one final fixed M and the stated boundary encoding. It does not bound other gate encodings or joint optimization across gates.

A unit pin uses one conditional R_1 on its violation bit, followed by M. Conjoining g native NAND checks and the output pin gives at most 5g+2 instructions, with g+1 fixed mergers. Constants and complemented controls can be resolved publicly; tied inputs remain correct by specialization. The certificate is the original witness extended by honest gate values. In the reverse direction all accepted checks force exactly those values. For g=4096 this gives 20482 instructions versus the preceding clause-by-clause upper bound 77827, under the same reread model. Each native gate contributes four witness-controlled reads rather than reading arbitrary independent occurrence labels. This reduction sharpens the concrete fixed-assumption WE target; it is not a public-key encoding of the transitions that enforces witness consistency.

## Binding repeated reads in the binary matrix-chain interface

The public evaluator of the matrix-chain benchmark in [PR 99](https://github.com/MachinaIO/SigabaPark/pull/99) permits one independent branch choice per encrypted level. Using the five-instruction NAND word verbatim there would allow inconsistent reads. The following compiler enforces consistency *inside the product* for every level string and avoids expanding the ternary permutations. As in the benchmark, use a source coordinate initialized to one, a failure counter initialized to zero, and the backend's message coordinate. All transitions have entries zero or one and row vectors act from the left.

For each NAND check read its proposed inputs a,b and output c in three binary levels. Use two scratch coordinates. After a put the source into slot a (index zero or one). On b=0 route both slots to slot zero; on b=1 keep both. Thus exactly slot ab is live. On c send slot c to the failure counter and clear both slots, since c=ab is exactly a NAND violation. An additional read pins the circuit output by adding the source to the counter if it reads zero. Keep the counter and message by identity. A known constant port hardwires its two matrices to the same effective choice, with no consistency slot; for the empty-gate convention use the direct true case.

Concurrently, for each trace wire with at least two occurrences, save its *first* bit in two one-hot slots. On every later read of bit v add its saved slot 1-v to the counter. Discard the slots immediately after the last comparison. Store by routing the source, with other source entries allowed; on intermediate levels carry both slots by identity. Allocate pairs by interval coloring of the closed first-to-last occurrence intervals; F is their maximum overlap. The additional source, counter, message and two scratch coordinates give width at most 2F+5 and length 3g+1. Multiple additions to the counter come from distinct old coordinates (scratch, saved slot, or pin source). Hence no matrix entry of value two is required. Project the terminal row to failure and message as in PR 99. Under the designated initial row the counter is exactly the number of locally false gate/pin checks plus the number of disagreements with first occurrences, at most (g+1)+(3g+1). A modulus above 4g+2 suffices for this no-wrap argument; the backend's other modulus/noise conditions remain necessary. A zero counter defines a consistent trace and every gate equation holds. Conversely a valid witness extends by honest gate values and yields zero. This proves the mixed-string invariant, not just correctness on honest paths.

This is an actual polynomial-size binary plaintext matrix frontend; both level choices are safe to expose *through a backend whose security applies to that frontend*. For 4096 gates it needs 12289 levels and at most 16386 failure counts as an upper bound on the counter value. The width is schedule-dependent and may outweigh the shorter ternary instruction sequence. Compare H, width, prefix-product growth, preimage dimension and noise with the live-clause frontend before selecting parameters. This supplies neither a new fixed-assumption hiding theorem nor a claim that PR 99's modified frontend is automatically covered by every published theorem.

~~~python
from itertools import product
# Leaves a,b and internal z=NAND(a,b), o=NAND(z,a), then output o.
ports=(0,1,2,2,0,3,3)
~~~

## Computing the gate output inside the chain

At a binary level the branch bit may select a linear map of the *entire old state*. This lets one gate operand select the map and the other arrive through saved coordinates. Keep a permanent unit source, discrepancy counter and message coordinate, and a pair of indicator coordinates per live wire. Process gates topologically. For a NAND choose a previously unseen primary operand as selector if present, otherwise choose either operand. If both operands are distinct unseen primaries, insert one preceding level to initialize the other from its branch bit. This extra level consumes one new input and the ensuing gate level consumes the other. If operands coincide there is no extra level. Constants and unavailable references are resolved to the specified public value at the read site.

At the gate level with branch bit v, initialize an unseen selector to v or, for a known selector, add its stored indicator for 1-v to the counter. For a public constant selector charge a mismatch directly from the unit source, or hardwire its effective choice and ignore the branch. If v=0, set the output pair to the public one encoding true. If v=1, copy the other operand's two rails in reverse order. A tied operand uses v as its other value. All output sources are from the old layer (or the permanent unit), so the compiler needs no within-level nonlinear operation. Carry only wires with future uses, including the terminal result. At the final projection add its false rail to the counter and retain the message. A fixed final level with identical branches suffices. Equality checks are never subtracted. Thus on every independent branch string a zero final counter forces all selector rereads to agree, each computed output is the correct NAND, and the final output is true. The converse follows by reading the chosen operand from an honest evaluation. Incorrect choices may propagate incorrect internal values, but an earlier discrepancy remains in the counter.

For g>=1 gates and n used primary variables this has H<=g+floor(n/2)+1 binary levels: extra preloads correspond to disjoint pairs of first-seen inputs. At each layer pack its live wires in pairs, reusing indices between different layers, and pad to the common width 2F+3 for maximum live wire count F at a cut. A conservative unoptimized bound uses F<=n+g. Each non-counter column receives at most one incoming unit, including when a rail is copied to several destinations. The counter column carries itself and at most one additional unit at a level. Consequently for *any* contiguous product of h selected matrices, starting with any basis row, every non-counter entry is at most one and the counter entry at most h+1. The maximal row sum is at most width+h. This bounds plaintext product growth before lattice encoding, not the noise of the sampled preimages. From the designated source the terminal failure count is at most g+1, so the prime-base unit-pivot choice of the live-clause benchmark can use p>max(g+1,2) for this part. The remaining backend requirements persist.

For the 128-primary, 4096-gate cap this gives at most 4161 levels including the pin, versus the preceding 12289. Live width must be measured for the actual gate order before claiming a ciphertext-size improvement. All additions and copies above are binary matrix entries; this is a frontend improvement with no proof of fixed-assumption hiding for the backend.

~~~python
from itertools import product

            pair.append(edges)
~~~

## Contracting a block after fixing one selector

A single binary matrix pair can execute many consecutive NAND gates. Choose a selector z and simulate the block twice symbolically, fixing z to 0 and 1. Each incoming live wire starts as a distinct literal. For each simulated wire allow constants, literals and their complements. NAND with zero gives one; NAND with one negates its other argument; equal operands negate that operand and complementary operands give one. Stop before any operation outside those cases, or before using a second uninitialized primary. Thus neither simulation assumes unproved correlations among incoming wires. Any matched public block needs only polynomial preprocessing (two passes for a given candidate). Shorter unmatched portions can use the preceding gate compiler. Retain the original order, trace semantics and live-wire accounting at all block boundaries.

For each outgoing live wire, under each branch, a constant routes the source to one of its rails, and a literal copies the corresponding incoming pair in the appropriate order. A selector that is a known wire adds its old opposite rail to the discrepancy counter once; a new primary requires no comparison and is stored if live on exit. Internal uses of z share that one branch choice. Other inputs are taken from stored rails. Hence each non-counter column still has at most one incoming unit, and at most one mismatch per block can enter the counter. A zero terminal counter still certifies an honest execution. With B compiled branch levels (including preloads and counting uncontracted gate levels) and one pin, H=B+1 and width is at most 2F+3 using maximum boundary liveness F. This changes the actual pair of matrices for a gate block rather than sampling and multiplying independent lattice encodings of the levels afterwards.

On the 128-segment streaming control above, fix the unique new primary z of each segment. Its incoming gate value s is the only other input. Simulating the actual 32 NAND instructions gives output zero for z=0 and s for z=1. Thus all 32 instructions contract to the single map (s,z) -> s AND z. Only the running wire crosses each segment boundary. The general counter layout has H=129, width 5 and geometric coefficient (129-2)*25=3175, compared with 200655 before contraction. This input has no cryptographically hard core: its initial state is one, so its full predicate is the conjunction of its 128 primary bits and is satisfiable. A public decider on this instance emits the one-bit plaintext. The 3175 figure measures the matrix fallback alone.

There is also an exact way to remove such a suffix from an otherwise arbitrary hard instance. Suppose the only incoming data is a single state bit, each block has a fresh private selector, and no eliminated bit occurs in the retained verifier or in another block. Compute backwards from the accepting set A={1}, replacing A at each block by {s: T(s,0) in A or T(s,1) in A}. This takes four table lookups per block. The residual verifier checks whether its computed boundary bit lies in the resulting two-element-domain subset. A valid full witness restricts to a valid residual one. Conversely extend any accepting residual trace by choosing a good outgoing branch at each block using the stored backward sets. No hardness assumption is changed, and an arbitrary retained circuit may still be hard. For the example suffix, every accepting residual witness lifts by setting its fresh bits to one. If a selector is shared across blocks this elimination can introduce incompatible choices and is not justified by this recurrence.

~~~python
from itertools import product
def segment(s,z):
    for i in range(32):
~~~

## Projecting a two-state suffix with repeated and shared affine queries

Keep arbitrary prefix witness data y, including any derived port bits checked by the retained verifier. Let s be its outgoing state bit. Let z be bits private to the suffix, unused by the prefix. Layer i of an oblivious two-state suffix selects its public state map using l_i(y,z), an affine Boolean form. It may read the same private or shared data at many positions. There is an explicit polynomial-size predicate on (y,s) equivalent to existence of a single z taking the suffix to target t. The previous independent-selector recurrence did not cover this case.

Take the at most 2L+1 last-reset cases as in the two-state decision algorithm, but keep y and s symbolic. In a reset case impose l_i=a and start the remaining parity at the specified reset value. In the no-reset case start at s. For each later layer restrict l_j to the answers giving a permutation. This restriction is vacuous, contradictory, or one affine equation. Its flip bit on the allowed assignments is the image of state zero, an affine function of the single bit l_j (use its table value on both answers to extend it). XOR all these flips with the starting bit and set the result equal to t. Each branch is now one affine system in (y,s,z); no constraint on states or queries before the last reset is needed. In particular two contradictory answers to a repeated linear query cannot survive as independent choices.

Eliminate z in each branch by putting its columns first in Gaussian elimination, discarding pivot rows for z and retaining all residual equations, including a possible 0=1. This is exact: any solution of the remaining rows extends by back substitution with free private bits set to zero. Publish or recompute the OR of the surviving affine systems on (y,s) as part of the residual verifier. Each consistent disjunct needs at most dim(y)+1 independent equations. A dense implementation with L positions and N total coordinates needs O((L+1)(L+N+1)^3) binary operations for elimination; constructing the affine rows and compiling their tests are polynomial too. Every full satisfying witness restricts to an accepting residual witness; every accepted residual witness lifts by one affine solve in a passing branch. The core can compute y and s by arbitrary polynomial-size circuits on its own witness; no requirement of affine dependence *inside* the core is imposed. Thus this removes all private suffix bits before a WE backend even when suffix queries share them extensively. The new verifier's size and depth must be charged. It inherits the chosen backend's assumptions and does not solve an arbitrary three-state suffix or an arbitrary retained core.

For example start at zero and flip on z, then on z XOR y. Reaching one is possible exactly when y=1. Independent per-position choices would also admit y=0. More generally private bits can cancel from the residual predicate even if they appear at every query.

~~~python
from itertools import product
from random import Random
rng=Random(677)
# Low two positions private; next two shared; bit 4 incoming state; bit 5 constant.
one=32
def project(rows):
    rows=list(rows)
    for bit in (1,2):
        j=next((j for j,r in enumerate(rows) if r&bit),None)
        if j is not None:
            pivot=rows.pop(j)
            rows=[r^pivot if r&bit else r for r in rows]
    return rows
def parts(layers,target):
    cases=[(-1,0,16)]+[(i,a,one*lo) for i,(_,maps) in enumerate(layers)
                         for a,(lo,hi) in enumerate(maps) if lo==hi]
    out=[]
    for i,a,par in cases:
        rows=[] if i<0 else [layers[i][0]^(a*one)]
        for form,maps in layers[i+1:]:
            allowed=[b for b,(lo,hi) in enumerate(maps) if lo!=hi]
            if not allowed: rows.append(one)
            if len(allowed)==1: rows.append(form^(allowed[0]*one))
            par ^= maps[0][0]*one
            if maps[0][0]!=maps[1][0]: par ^= form
        out.append(project(rows+[par^(target*one)]))
    return out
def val(row,x): return (row&x).bit_count()%2
for _ in range(150):

            for i in range(rng.randrange(12))]
    for target in (0,1):
        disj=parts(layers,target)
        for y,s in product(range(4),range(2)):
            shared=one+4*y+16*s
            got=any(all(val(row,shared)==0 for row in system) for system in disj)
            ends=set()
            for z in range(4):
                state=s
                for form,maps in layers: state=maps[val(form,shared+z)][state]
                ends.add(state)
            assert got==(target in ends)
~~~

## Removing private bits from a three-state suffix by sparse character support

Allow all three-state maps, including partial mergers. Write y for the shared Boolean ports, z for the private Boolean bits, and s for the incoming ternary state supplied by the retained verifier. Each layer has an affine Boolean query l(y,z) and two deterministic maps on the three states. Compute the exact acceptance indicator backwards for each entering state as a dictionary of binary characters over F_3. Initialize the three terminal indicators to their constant acceptance bits. If G_0 and G_1 are the two successor dictionaries for a given state, update to (G_0+G_1)/2 + chi_l*(G_0-G_1)/2. Here chi_l=(-1)^l; its affine constant contributes a sign, and multiplication by its linear part XORs the support indices. Combine equal indices modulo three and delete zeros. This is just the two cases of a Boolean selector and preserves the zero/one values of the indicator. It works across arbitrary rereads; there is no enumeration of reset positions or merger states. With maximum intermediate dictionary size D per state this takes O(L D) dictionary insertions up to constant factors, plus polynomial costs for bitsets, key lookup and coefficient arithmetic. A budgeted compiler can abort before a large intermediate table and use the original backend. Final sparsity alone does not certify that cost.

For each possible start state, split the final supports by their private part U. The resulting polynomial is sum_U a_U(y) chi_U(z). At fixed y it is identically zero in z iff every a_U(y) vanishes: the binary character matrix is invertible in F_3. Compile the residual acceptance predicate as the OR of nonzero coefficient tests for the state selected by the retained verifier. Each a_U is evaluated by parities of the shared ports and addition modulo three. This projects every private suffix bit without treating distinct occurrences as independent. It also works if the shared ports are arbitrary outputs computed by the core from its own witness. This yields a polynomial construction whenever intermediate dictionary sizes are polynomial, regardless of the number of partial mergers.

There is a constructive, shared-input-independent witness list. Take the union of the distinct private supports over the three initial states, of size r. Build a basis among the realizable evaluation rows (chi_U(z))_U, starting with all ones and processing private bits in order. For each bit extend every retained row both ways by either identity or flipping the signs in the coordinates containing that bit; retain independent rows and one realizing prefix per row. Linear dependence survives a common sign update, so induction preserves the full evaluation span. At the end its dimension is r by character independence, yielding r actual private strings, even when their domain is exponential. For any shared ports and start state with a nonzero coefficient vector, at least one listed string has nonzero evaluation and hence accepts. A zero dictionary needs no strings. Basis generation is polynomial in r and the private bit length; one may instead just use the coefficient test if only decision is needed. Unlike summing accepting multiplicities in F_3, it remains correct when the number of accepting completions is divisible by three. The projection transports WE to the residual verifier and adds no assumption. It does not bound D for general CircuitSAT, or provide the residual cryptographic backend.

## Projecting private parities by their intersection across a cut

For queries of the form a_i z + b_i y + c_i over F_2 the preceding character dictionaries can be dense even in a simple suffix. There is a different exact compiler whose exponential factor depends only on private parities shared across each cut. Put P_i=span(a_1,...,a_i), Q_i=span(a_(i+1),...,a_L), and I_i=P_i intersect Q_i. Write h=max_i dim I_i. This uses the linear trellis principle also described in the separator note, now compiling an *ordinary residual Boolean verifier on symbolic shared inputs y*. No enumeration of shared inputs or Fourier expansion is needed.

At cut i index Boolean reachability gates by machine state and a functional on I_i (one bit per basis vector). Start with the incoming machine state and the unique empty assignment. Given a cut entry, extend to the private query value d=a_(i+1) z. If a_(i+1) is in I_i its value is already forced, otherwise try both bits. For each option the next boundary assignment is unique: every v in I_(i+1) has form p+e a_(i+1) with p in P_i, and both v and a_(i+1) belong to Q_i, hence p is in I_i. Compute the new values from these public basis coordinates. Drive the actual successor state using d+b_(i+1)y+c_(i+1), and OR all incoming contributions at the destination. Build the shared parity once per layer. A circuit may implement each edge by two Boolean guards, one per possible shared parity value.

For soundness maintain that each reachable entry is realized by a single prefix functional on P_i leading to its machine state and matching its recorded values. Since a_(i+1) lies in Q_i, membership in P_i is equivalent to membership in I_i. Thus a free choice extends *any* prefix realizing that entry. The next boundary agrees with the extended functional by the containment just proved. At the end every functional on P_L extends to the ambient space and is evaluation against some z. Conversely every z follows a realizing path. This proves the existential projection for every fixed y and incoming state. To construct z one can backtrack a successful path, then solve the resulting linear equations. The base case and final acceptance allow empty suffixes and zero/private-free query rows.

Elimination to find bases and coordinate maps is polynomial in the input dimensions. With w states there are at most 2*w*2^h private transitions per layer, before the two shared-bit guards. Enumerating them also costs polynomially many bit operations per transition for basis arithmetic. Thus the residual circuit is polynomial for h logarithmic in input size, including arbitrary numbers of three-state partial mergers and arbitrary affine shared ports computed by a retained hard core. It need not materialize a universal list of accepting private assignments. For example the two-state suffix checking z_i=y_i by successive discrepancy queries and accumulating an OR of failures always has a unique accepting private assignment z=y for target no-failure. Here h=0 in coordinate order, yet a fixed witness list covering all y would need 2^n entries. The projection removes the private bits exactly. Worst-case intersection dimension is still linear (e.g. two full passes over an independent basis), and the remaining backend's cryptographic obligations are unchanged.

~~~python
from random import Random
~~~

## A tunable witness budget for high private-parity cuts

Rather than paying the full trellis width or enumerating the whole private witness, leave selected private linear coordinates in the residual witness. Form the binary code C of length L consisting of attainable private answer streams (a_i z)_i, temporarily omitting the shared offsets. Compute a generator basis of this image in minimal-span form: basis strings have distinct first nonzero positions and distinct last nonzero positions. Start with echelon rows with distinct starts. If two ends coincide, add the later-starting row to the earlier-starting row. Its start stays fixed and its end decreases, so this procedure terminates in polynomial time. Keep coefficient transformations or solve in the generator basis to map an honest z to its coefficients. Every coefficient vector gives an attainable stream by definition of the image. See [Forney, chapter 10](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/1b67ae9f5c124c3bd56c8649afa5af47_chap10.pdf) for trellis-oriented bases.

A basis row with endpoints l,r crosses exactly the cuts l<=i<r. For any subset of rows the first and last endpoints remain distinct. Thus the dimension of its prefix projection is the number of rows starting by i, and the suffix projection dimension is the number ending after i (distinct pivots). Subtracting the dimension of the whole subcode gives exactly the number of crossing rows as the cut dimension used above. Choose some coefficients as new shared witness bits. XOR their generator contributions into the public query forms on the shared inputs and apply the preceding projection to the remaining subcode. This operation moves actual stream coefficients, not arbitrarily chosen parity constraints that could introduce new dependencies. Even a malicious choice of the retained coefficients extends to an original private input whenever the residual trellis accepts. Honest encryption computes the layout from the statement alone.

For a prescribed cut-width cap b, scan cuts left to right. Whenever more than b remaining intervals cross a cut, remove one with farthest right endpoint and retain its coefficient in the witness. Singleton rows cross no cut and never need removal. This minimizes the number k of retained bits *among subsets of this fixed generator basis*. For an exchange proof, take an optimal deletion set containing earlier greedy deletions. At a violation it must delete an additional interval crossing that cut. Exchange that interval for the greedy choice if necessary. Earlier cuts were already feasible after the earlier greedy deletions alone, and at every later cut the exchanged-out shorter interval cannot outlast the greedy one. This preserves feasibility and size. The minimum need not hold over nonlinear encodings or all choices of generator basis.

If the core witness uses s bits (shared ports can be derived from it), the new split-ABE verifier takes s+k bits instead of s+dim(C). It uses at most O(L*w*2^b) guarded trellis transitions for w states plus polynomial bit arithmetic and the core verifier. Balanced splitting needs 2^floor((s+k)/2) keys and 2^ceil((s+k)/2) attribute ciphertexts. These counts inherit the original split backend's assumptions, concrete losses, and policy-depth dependence. Enumerate the at most dim(C)+1 width caps and charge actual verifier and key costs before choosing one. At cap zero the construction can still eliminate all singleton rows. For a repeated full basis of d independent private coordinates in the same order, its natural minimal-span rows all cross the middle. The tradeoff there is exactly k=max(0,d-b) for that basis. For general NP this tradeoff does not guarantee both small k and small b.

~~~python
from itertools import combinations
from random import Random
rng=Random(292)
def minimal(rows):
    starts={}
    for x in rows:
        while x:
            lo=x&-x
            if lo not in starts:
                starts[lo]=x
                break
            x^=starts[lo]
    ends={}
    for lo,x in sorted(starts.items(),reverse=True):
        while x.bit_length() in ends: x^=ends[x.bit_length()]
        assert x&-x==lo
        ends[x.bit_length()]=x
    return list(ends.values())
def span(rows):
    s={0}
    for x in rows: s|={v^x for v in s}
    return s
for trial in range(100):

    rows=minimal(raw)
    assert span(rows)==span(raw)
    crossing=[{j for j,x in enumerate(rows) if (x&((1<<i)-1)) and (x>>i)} for i in range(9)]
    for b in range(len(rows)+1):
        keep=set()
        for cut in crossing:
            while len(cut-keep)>b:
                keep.add(max(cut-keep,key=lambda j:rows[j].bit_length()))
        opt=next(k for k in range(len(rows)+1)
                 if any(all(len(cut-set(p))<=b for cut in crossing)
                        for p in combinations(range(len(rows)),k)))
        assert len(keep)==opt
        sub=[x for j,x in enumerate(rows) if j not in keep]
        for i,cut in enumerate(crossing):
            left=span(x&((1<<i)-1) for x in sub)
            right=span(x>>i for x in sub)
            assert len(left)*len(right)==1<<(len(sub)+len(cut-keep))
print("100 stream codes; all caps, cuts and exact subset optima checked")
~~~

## Optimality over all linear bits of the private stream

The previous greedy bound in fact holds for any choice of linear measurements of the stream, at the same fixed read order and with the same exact private-parity trellis width. Let G be the minimal-span basis already computed for C, and take any residual subcode U of C. Choose a minimal-span basis H of U. Express each h in H in the basis G. Among the rows used for h, select the one starting earliest. Distinct starts in G imply that its first nonzero coordinate survives in h. Likewise the last coordinate of h is the maximum end among its constituent rows, since ends in G are distinct. Thus the selected G-row interval lies within the interval of h. The selected rows are distinct because H has distinct starts. They form a subset of G of size dim U and their crossing counts are at most those of H *simultaneously at every cut*. By the cut-dimension identity in the previous section these counts are exactly the linear trellis width exponents of the respective subcodes.

In particular, revealing k independent linear measurements on C leaves an affine translate of a codimension-k subcode U. The translate adds known offsets and does not change cut dimensions. Whenever such measurements meet a cap b, the subset above leaves at most the same width using the same k. Conversely deleting k rows is realized by revealing their k coefficients. The preceding greedy algorithm therefore minimizes k over all linear measurements on C, even if the alternative first changes basis. This strengthens the scope of the previous fixed-basis statement. It does not optimize the read order, nonlinear summaries, or smaller semantic automata for a particular acceptance predicate.

The following check uses minimal() and span() in the preceding listing. It enumerates every subspace of four coefficient bits and compares its entire cut profile to that of the selected rows, including the zero and full subcodes.
~~~python
from random import Random
~~~

## Exact cost even for nonlinear finite-state covers of the stream code

Keep the binary linear stream code C, fixed order, and a cap of 2^b states at each internal cut. Consider any family of layered trellises whose *union of accepted stream languages is exactly C*. Each row of the family may be a different nonlinear nondeterministic recognizer. Reading is one symbol per layer and only its state passes to the next layer; a retained k-bit certificate can select at most 2^k such recognizers. For this interface the minimum number of recognizers is exactly 2^kstar, where kstar is the greedy interval deletion count above. The upper bound uses the cosets of the retained subcode. This equality also handles non-power-of-two family sizes.

For the lower bound pick a set J of internal cuts; let hit(J) count the minimal-span basis intervals crossing at least one of them. The cuts partition the stream into disjoint consecutive segments. Let C_j be the subcode supported entirely on segment j. Its dimension equals the number of basis rows contained there, since distinct starts and ends prevent a combination from cancelling its extreme positions. Thus sum_j dim C_j = dim C - hit(J). Fix a recognizer and all its states on J. Accepted streams through these states form a Cartesian product of segment languages, since segment paths concatenate at their boundaries. For a nonempty such rectangle, fix a word in it. Vary one segment at a time: the differences from that fixed word are supported there and belong to C by linearity. The rectangle therefore has size at most 2^(sum_j dim C_j). This also holds if several accepting paths realize a word. At most 2^(b |J|) boundary tuples per recognizer are possible. Covering |C| words requires at least 2^(hit(J)-b |J|) recognizers.

The strongest such multicut bound equals the achievable value. Write d=dim C and A for the cuts-by-intervals incidence matrix. Maximizing the number of retained rows is the packing LP max sum x subject to Ax<=b and 0<=x<=1. Its dual minimizes b sum y+sum z with A^T y+z>=1 and nonnegative variables. The consecutive-ones matrix A is totally unimodular, as are its transpose and identity extensions; with integer data the two optima are integral. For the consecutive-ones fact see [the interval-matrix integrality argument](https://num.math.uni-goettingen.de/bibi/preprintserie/preprints/schoebel/paper.pdf). Truncate the dual weights to zero or one and choose z to cover precisely intervals missed by J={i:y_i=1}. The dual objective becomes b |J|+d-hit(J). Subtracting the optimum from d proves kstar=max_J(hit(J)-b |J|). For two disjoint successive blocks each reading d0 independent bits twice, the two middle cuts together require 2(d0-b) selector bits for b<=d0, twice what either cut alone certifies.

This lower bound concerns enforcing exactly the language of consistent private streams for every trace. A WE compiler may only need correct existential acceptance of a particular verifier, and computational hiding does not require an exact language cover. Thus the result identifies a reason to move consistency into the cryptographic proof or exploit the predicate when this multicut certificate is large; it is not a lower bound for general WE.

~~~python

            all(sum(i in r for j,r in enumerate(intervals) if j not in skip)<=b for i in range(8))
            for skip in combinations(range(d),k)))

                  for mask in range(256))

print("600 interval families/caps: every exact multicut optimum equals enumeration")
~~~

## Relaxing consistency by all global XOR periods of a narrow verifier

Let f on L binary level choices be acceptance of the public deterministic layered verifier from a designated start, *before* enforcing private stream consistency. Compute its translation periods K={d: for all x, f(x+d)=f(x)}, a binary linear space. If the honest level choices are o(y)+C, replace C by C+K in the projection compiler. A relaxed accepting word has form o(y)+c+d; the word o(y)+c is accepted by the period identity. Conversely any honest accepting word remains available. Gaussian elimination splits a relaxed codeword into c and d and lifts c to the private witness. This works for arbitrary shared offsets. For several possible incoming states compute a space valid for each (intersect the period spaces, or compile per state). This is a predicate-dependent relaxation of the previous exact-stream model. It need not minimize the trellis width: compare against the original or any certified period subspace.

The following deterministic algorithm finds the full global period space for fixed state width w, without enumerating words. First discard unreachable states at each layer, then merge states with identical accepting suffix functions by the backwards ordered pair of successor classes (at the end use the output bit). In each resulting layer enumerate permutations of its at most w residual classes. Start with the identity. Add an edge from permutation p to permutation q with label e at layer i exactly if q(delta(s,b))=delta(p(s),b XOR e) for every state and both input bits. End at the identity on terminal classes. Any successful path maps every run on x to the run on x+d while preserving the terminal output. Conversely a period d induces the permutation mapping the residual of each prefix to that of its prefix shifted by d: equal residuals stay equal because shifting every possible suffix by the same remaining bits is bijective and f is invariant. Translation by d is its own inverse, so the induced map is a permutation. It respects the transition equations. Thus the graph recognizes exactly K.

At each permutation compute a basis for the span of reachable augmented prefix labels (1,prefix). Appending a fixed edge bit is linear on augmented vectors, using their first coordinate to append that bit. Taking the span across incoming edges is exact for this calculation. At the final identity project away the leading coordinate; the resulting span is K because the actual accepting labels already form a space. The graph has at most 2L(w!)^2 candidate edges, each checked on at most 2w transitions; label-space propagation adds polynomial factors in L. In particular w=3 suffices for the target automata and entails at most six permutations per layer. This does not imply that every such target has useful periods.

For example let C={(z,z)} with n private bits read twice in the same order. Its middle-cut dimension is n. If the verifier tests even parity, K is the even-parity code, and C+K=K. Its middle-cut dimension is one for nonempty halves, independent of n. The residual predicate is simply even parity of the shared offset. In contrast any singleton accepting language has zero period space. Efficiency gain depends on the predicate and does not supply a cryptographic hiding theorem.

~~~python
from itertools import permutations
from random import Random
rng=Random(981)
def basis(xs):
    piv={}
    for x in xs:
        while x:
            j=x.bit_length()
            if j not in piv:
                piv[j]=x
                break
            x^=piv[j]
    return list(piv.values())
def periods(tables):
    reached=[{0}]
    for tab in tables:
        reached.append({t for s in reached[-1] for t in tab[s]})
    classes={s:int(s==0) for s in reached[-1]}
    layers=[]
    for i in reversed(range(len(tables))):
        pairs={s:tuple(classes[t] for t in tables[i][s]) for s in reached[i]}
        table=sorted(set(pairs.values()))
        # Terminal output classes may consist of 1 alone. Renumber the targets densely.
        target=sorted({t for pair in table for t in pair})
        layers.append([tuple(target.index(t) for t in pair) for pair in table])
        classes={s:table.index(v) for s,v in pairs.items()}
    live={(0,):[1]}
    for i,tab in enumerate(reversed(layers)):
        n=max(max(row) for row in tab)+1
        dest={}
        for q in permutations(range(n)):
            xs=[]
            for p,vs in live.items():
                for e in (0,1):
                    if all(q[row[b]]==tab[p[s]][b^e] for s,row in enumerate(tab) for b in (0,1)):
                        xs.extend(v^((v&1)*e<<(i+1)) for v in vs)
            if xs: dest[q]=basis(xs)
        live=dest
    vs=next(v for p,v in live.items() if tuple(range(len(p)))==p)
    K={0}
    for v in vs: K|={x^(v>>1) for x in K}
    return K
for _ in range(150):
    L=rng.randrange(1,8)
    tabs=[[[rng.randrange(3) for b in range(2)] for s in range(3)] for i in range(L)]
    def accept(x):
        s=0
        for i,tab in enumerate(tabs): s=tab[s][(x>>i)&1]
        return s==0
    f=[accept(x) for x in range(1<<L)]
    assert periods(tabs)=={d for d in range(1<<L) if all(a==f[x^d] for x,a in enumerate(f))}
print("150 width-three schedules: full computed period spaces equal truth-table stabilizers")
~~~

## Projecting existential acceptance by counting holes in an affine hull

A verifier can have trivial translation stabilizer but accept enough words that private consistency need not be routed explicitly. For a fixed incoming state let A be the accepting language over unrestricted binary level choices of length L. The actual streams for a shared input y are o(y)+C with the public offset o(y) and binary private code C as above. First handle empty A by rejecting. Compute its affine hull H=h+V, its size |A|, the number of holes e=2^dim(V)-|A|, and r=dim(V intersect C). Whenever e<2^r the exact residual predicate is

    there exists a private accepting completion  iff  o(y)+h belongs to C+V.

Indeed the right side is exactly nonempty intersection of the two affine spaces. Every nonempty intersection has 2^r points, and the e missing words cannot cover it. In particular a parity-check matrix for C+V supplies ordinary Boolean parity tests on the offset bits. The residual predicate needs no new private bits. Every accepting original witness restricts to a valid residual witness. For false-instance WE the reverse implication requires only existence: the count proves it without handing the decryptor a private completion. If a reverse witness is required for another application, sampling uniform points of a nonempty intersection succeeds with probability at least 1-e/2^r; a tiny gap in absolute counts alone does not guarantee efficient sampling. More generally at most floor(e/2^r) of the C-cosets meeting H can be completely empty of A, because their intersections are disjoint. Guessing how the holes are distributed when the strict test fails is unsound. Equality can already fail for A equal to a full affine space of dimension at least two minus one word and C=0.

These inputs to the test are available without enumerating A. On the public deterministic layered verifier propagate, per state, the count of distinct reaching prefixes and a basis for the span of their augmented vectors (1,prefix). Appending an answer bit acts linearly on augmented vectors. Sum counts over incoming labeled edges, including both answers when they reach the same state; determinism gives each word one path. Merge bases by Gaussian elimination. Combine accepting terminal states; taking the first-coordinate-one slice of their augmented span gives H. Counts require at most L+1 bits. This yields polynomial preprocessing in L, the explicit verifier size and the private code dimensions. The same calculation can be restricted to paths visiting a given state at an internal cut, testing its language separately. The OR of the resulting projected systems is exact if all nonempty components pass their tests; uncertified components need exact residual verification or a fallback. Costs and correctness of the retained core WE are unchanged except for the new residual predicates and preprocessing.

For example take L>=3 and let A consist of words with first bit zero except the all-zero word. Its affine hull is the whole first-bit-zero hyperplane and its global period space is zero. If C is any nonzero subcode of that hyperplane, e=1<|C|. For every shared offset, the residual check is precisely that its first bit is zero, even if C contains long-range repeated-bit dependencies. This is a predicate-sensitive simplification outside the global-period method. No comparable density guarantee holds for arbitrary CircuitSAT.

~~~python
from itertools import combinations
def span(vs):
    out={0}
    for v in vs: out|={x^v for x in out}
    return frozenset(out)
codes={span(chosen) for i in range(4) for chosen in combinations(range(1,8),i)}
passed=exceptional=0

    holes=len(H)-len(A)
    for C in codes:
        size=len(V&C)
        missing=set()
        for o in range(8):
            coset=frozenset(o^c for c in C)
            actual=bool(A&coset)
            projected=bool(H&coset)
            if projected and not actual: missing.add(coset)
            if holes<size:
                assert actual==projected
                passed+=1
        assert len(missing)<=holes//size
        exceptional+=bool(missing)
print(passed,"certified offset tests;",exceptional,"language/code pairs with a missing coset")
~~~

## Isolating the few possibly empty fibers before splitting WE

Continue with A, H, C and the shared offset o(y) above, for one designated incoming state. Write m=2^r for the size of a nonempty H intersection and e=|H|-|A|. When e>=m but B=floor(e/m) is polynomially bounded, the density test alone leaves exceptions. There is a randomized compiler that handles them with separate WE calls on the core and on a fixed fiber. It requires no uniform sampler for accepting witnesses and has correctness even on YES fibers with a unique accepting word.

Sample Q independent holes from H minus A, recording distinct C-coset labels in a public set T (use a parity-check matrix for labels). Sample by lexicographic unranking: for a prefix p, the number of holes below it is |H_p|-|A_p|. The former is zero or a power of two by linear elimination; the latter is a suffix-path count of the deterministic verifier. Their difference is exact because A is contained in H. For bounded-time coins and failure parameter lambda, map a uniform integer with ceil(log2 e)+lambda+ceil(log2 Q)+2 bits modulo e to the rank. The total variation error over all Q ranks is at most 2^-lambda. Every completely empty fiber meeting H comprises m holes in one coset; there are at most B such cosets. With Q=ceil(e/m)*(lambda+ceil(log2(max(1,B)))+1), the probability of missing *any* completely empty fiber is at most B exp(-Qm/e)+2^-lambda <= 2^(1-lambda). This controls even a shared offset chosen from exponentially many possibilities after the list is seen. Partial fibers may also appear in T.

Encrypt the same payload independently for the following OR of branches. The first WE instance checks only the core witness y, the public hull test o(y)+h in C+V, and that its coset label is absent from T. For each label t in T take a representative hole h_t from the sample. Make two WE instances: the first checks the core and the equality of its offset label to t; the second checks f(h_t+D u)=1, where the columns of D span C intersect V and u has exactly r bits. Encrypt independent XOR shares of the payload across this pair (fresh mask for each pair). On a satisfying witness whose label was sampled, its actual accepted stream a gives u by solving D u=a+h_t. Both a and h_t belong to H and the same coset. Conversely a passing pair gives an accepted stream and its difference from o(y) lies in C, hence lifts to an original private witness. Use a canonical label order and transmit sufficient data to identify the two instances. A decryptor only opens its own branch. The construction handles e<m by the earlier deterministic rule and empty A directly.

On a false original instance, except on the stated sampling failure, the first branch is false and every pair has at least one false instance. For each pair a true or unknown other share can be freshly encrypted with public coins, and changing the payload complements the share under the false instance. A hybrid over the first branch and all pairs bounds total distinguishing advantage by the sampling failure plus (1+|T|) times the worst applicable pointwise backend advantage, with polynomial simulation overhead and independent encryption randomness. Selecting a false member of each pair may use the nonuniform convention. Correctness for original YES witnesses does not rely on sampling success; at most two backend decryptions are used. The compiler adds no instance-dependent hardness assumption. If the sampler's cost or branch count is excessive, use the original backend instead.

For a core with s witness bits, splitting each resulting WE relation into two halves using the existing ABE backend now takes O((1+Q)(2^ceil(s/2)+2^ceil(r/2))) cryptographic entries, before policy sizes and security-loss calibration. A single direct split of s+d private/core bits would scale as 2^ceil((s+d)/2), where d=dim C counts private stream coordinates. The improvement separates witness exponents on the stated density regime. Neither this entry count nor polynomial B ensures polynomial total complexity when s or r is large. Outside this regime the construction has no general security or complexity improvement over the existing fallback.
