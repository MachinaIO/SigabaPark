Design-AI sub-task (ee) on `Def_WE_CircuitSAT` (`m = 128` witness bits, `2^12` NAND gates). The
2-split XWE of Brakerski–Jain–Komargodski–Passelègue–Wichs (ePrint 2017/874, "BJKPW", Thm 3.2,
Appendix A) issues `2^a` KP-ABE keys for `φ(w1, ·)` and `2^b` ciphertexts. A 3-way split needs
one more slot: keys for `w1`, slot-1 objects for `w2`, slot-2 objects for `w3`, and decryption of
any triple that satisfies `φ`. The literature status (open PRs #74 and #80): 2-input ABE exists
from LWE plus pairings in the GGM (Agrawal–Yadav–Yamada, CRYPTO 2022) and from evasive plus tensor LWE
(Agrawal–Rossi–Yadav–Yamada, ePrint 2023/941, "ARYY"). From plain LWE it exists only for
conjunctions of one-slot predicates (Francati–Friolo–Malavolta–Venturi, ePrint 2022/806), which are
decidable slot by slot. Allowed here: plain or Ring LWE, succinct or decomposed LWE, TLWE. Excluded:
iO, evasive LWE, local mixing, statement-dependent assumptions, pairings.

The three theorem nodes named below (`AdvancedEncryption.WE.TwoInput.*`) have complete proofs in
the same PR. They are not in `refs` because they are not merged yet.

## Summary

| Route | Verdict |
| --- | --- |
| (1a) per-slot secrets combined additively (key switching, `r = a_x + b_y`) | **Broken**: every 2×2 rectangle of slot values leaks `(b_y − b_y')·G` (`rect_leak`) |
| (1b) bilinear pair secret `r = s_x·T_y` via a two-level GGH15 with per-bit channels (candidate C2, §2) | **No attack found, no plain-LWE proof**. Same family as ARYY's "Attempt 1". The gap is a trapdoor circularity (§3) |
| (2) secret-key / correlated randomness, "lockable" tags | **Gives nothing**: in WE every slot combination is a legitimate witness, so a lock that blocks any pair breaks correctness. Pair randomness for `2^{86}` pairs from `2^{44}` objects must be publicly derivable, so it is a low-degree function of the slot objects, which is case (1a) or (1b) |
| (3) TLWE public trapdoor at the last step | **Breaks correctness**: TLWE needs `σ_e·σ_t ≳ q/√m`, so any preimage that the honest decryptor applies to a TLWE sample has error `≳ q`. TLWE can host a decoding step, not a traversed preimage |
| (4) streaming chain + circuit restructuring (Tseitin / CNF / bounded width) | **No generic gain**: a width-`s` decomposition lets the encryptor *decide* SAT by reachable-state DP at the cost of the chain's middle layers (`dp_reach`). The chain only saves the last cut, about `s/k` bits, and worst-case circuits have `s ≈` prefix length |

**Cost, if the gap in §3 were closed** (per-item costs as in PR #83, ring BGG+ at depth about
2048): balanced items `K_f ≈ 2^{76}` (key), `K_x ≈ 2^{77}` (slot-1 ciphertext), `K_y ≈ 2^{83}`
(slot-2 key, `2ℓ + 3` ring-matrix preimages). `split3_frontier` gives the best exponent
`E = ⌈(128 + 76 + 77 + 83)/3⌉ = 122`, so total encryption is about `3·2^{122} ≈ 2^{123.6}`, compared with `2^{147.7}` for
the 2-split of PR #83 and `2^{188}` for the baseline. This is still far above `2^{97}`. The count
`2^{43}` alone is misleading: per-item cost dominates. **Status: open.** No construction from allowed
assumptions beats the 2-split.

## 1. What the 3-way split actually needs

BJKPW's transform with a collusion-resistant scheme needs `(k−1)`-input ABE for a `k`-way split.
For `k = 3`:

* `2^a` function keys `sk_{w1}` for `f_{w1}(x, y) = φ(w1, x, y)`, all generated by the encryptor;
* `2^b` slot-1 objects `ct_x` (all `x = w2`), `2^c` slot-2 objects `key_y` (all `y = w3`);
* security only when `φ` is unsatisfiable, i.e. **every** `(w1, x, y)` is unauthorized. There are no
  adaptive queries and no adversarially chosen attributes; the published attribute sets are the
  **entire** domains.

Two remarks fix what "weaker object" can mean.

* **Mix-and-match is not a weakness to exclude.** In multi-input ABE, mixing ciphertexts from
  different sessions is an attack to be blocked. In WE every pair `(x, y)` is a candidate witness
  part. For the point-function statement `φ = [w = w*]` (about 400 gates) each triple must decrypt,
  so a scheme that blocks any pair by tags, locks or correlated randomness is incorrect on some
  statement in the family. The restricted object therefore has the **full** mix-and-match
  requirement of secret-key 2-input ABE over exponentially many ciphertexts per slot. The only
  real relaxations are the fixed function family, the non-adaptive game and the full-domain
  attribute sets. ARYY (§1.2, "Perspective") observe that WE permits correlated randomness across
  slots. The next point shows that this does not escape the problem.
* **Pair randomness must be derived.** The encryptor publishes `2^{44}` objects, and `2^{86}` pairs need
  distinct BGG+ secrets (one secret with two attribute values leaks; see `mix_leak` in PR #80). So
  the pair secret `r_{x,y}` is a fixed, publicly evaluable function of `(ct_x, key_y)`. With lattice
  operations (products of short matrices with LWE vectors) this function has low degree in the slot
  secrets. Degree 1 is §2.1; degree 2 is §2.2.

## 2. Route (1): per-slot fresh secrets joined by key switching

### 2.1 Additive joining is broken (`rect_leak`, proved)

Suppose the decryptor can derive the BGG+ block `(a_x + b_y)(A − p_x G) + e` from the slot objects,
as any key switching from `a_x` to `a_x + b_y` gives. For two values `x, x'` of slot 1 and `y, y'`
of slot 2, the alternating sum over the rectangle is exactly

`(p_x' − p_x)·(b_y − b_y')·G + (e1 − e2 − e3 + e4)`

(`AdvancedEncryption.WE.TwoInput.rect_leak`, over any commutative ring). The `A`-part cancels. With
`G`'s public trapdoor this decodes `b_y − b_y'` whenever `p_x ≠ p_x'` at some bit. Subtracting
`(b_y − b_y')(A − p G)`-type terms then moves an encoding of attribute `(x, y)` to the secret of
`(x, y')`, and `mix_leak` recovers that secret. Any **linear** (affine) secret combination loses
in four combinations. The same holds for `r = a_x + b_y + c` and for any combination that is
affine in each slot separately and additive across slots.

### 2.2 Bilinear joining: candidate C2 (two-level GGH15 with per-bit channels)

Public: BGG+ matrices `A0, A1 = (A1_i)_{i ≤ ℓ}, A2, u`. Encryptor-private matrices with trapdoors:
`B_{i,β}` (bit `i`, value `β ∈ {0,1}`), `B0`, `B_u = [B_u' | b]`.

* `ct_x` (fresh short `s_x`, row): `s_x B_{i,x_i} + e_i` for every bit `i`, `s_x B0 + e`, and
  `s_x B_u + e + μ·(0,…,0,⌊q/2⌋)`.
* `key_y` (fresh short `T_y`, `n×n`): `D_{y,i,β} = B_{i,β}^{−1}(T_y (A1_i − βG) + E)` for both `β`,
  `D_{y,0} = B0^{−1}(T_y [A0 | A2 − y⊗G] + E)`, and `D_{y,u} = (B_u'^{−1}(T_y u − b + E); 1)`.
* `sk_{w1}`: a short `k` with `[A0 | A_{f_{w1}}] k = u` (BGG+, decrypting when `f = 0`).
* `Dec(w1, x, y)`: compute `(s_x B_{i,x_i} + e_i) D_{y,i,x_i}` and `(s_x B0 + e) D_{y,0}`. This is a
  BGG+ ciphertext for attribute `(x, y)` under the pair secret `r_{x,y} = s_x T_y`. Then BGG+
  evaluation, `sk_{w1}`, and comparison with `(s_x B_u + …)·D_{y,u} ≈ r u + μ⌊q/2⌋`.

Correctness needs short `s_x` and short `T_y` (else `s_x E` is not small). The extra level costs one
factor `m·σ_D` in noise, about 30 bits of `log q` against `log q ≈ 2.9·10^5`.

**Attacks checked.**

* Channel crossing `(s_x B_{i,x_i})·D_{y,i,1−x_i}` gives a product of unrelated matrices, which is
  garbage. A ciphertext carries one channel per bit, so `mix_leak` inside one pair does not apply.
* Rectangle sums: `Σ± s_x T_y = (s_x − s_x')(T_y − T_y') ≠ 0`, so there is no linear cancellation.
  Short integer relations `Σ λ_{xy} s_x T_y = 0` require short dependencies among hidden vectors
  (an SIS instance with unknown matrix), which the decryptor cannot compute.
* Zeroizing (GGH15 rank attacks) needs many small zero-test values. Here small values arise only
  from authorized decryptions, and for a false statement there are none. Small values from
  `B·D` would need `B`, which is never published.
* If the separate channels are dropped and `key_y` carries `T_y·A1_i` and `T_y·G` as separate
  preimages, the decryptor computes `x_i s_x T_y G` alone and decodes `r_{x,y}`. The channel
  structure is necessary.

This is ARYY's "Attempt 1" family (right tensoring `⊗ r_y` there, a left secret `T_y` here). ARYY
state that it has no apparent attack but could not prove it even from evasive LWE (§1.3).

## 3. The precise gap: trapdoor circularity

A plain-LWE proof must, in some hybrid, replace an LWE sample by uniform. In C2 there are two
candidate levels, and both are blocked.

* **Left level (secret `s_x`, matrices `B`).** The `key_y` are preimages under every `B_{i,β}`
  and `B0`, and all `2^c` of them are published. So `s_x B + e` cannot be an LWE challenge unless
  the preimages can be simulated without `B`'s trapdoor. This is exactly the evasive-LWE step
  ("`B^{−1}(P)` reveals only `s·P`") with structured targets `P = T_y(A1_i − βG) + E`.
* **Right level (secret `T_y`, public matrices).** The targets `T_y(A1_i − 0·G) + E` and
  `T_y(A1_i − G) + E'` are both present, and their difference is about `T_y G`, so they are not
  jointly pseudorandom. Hence there is no CVW18-style right-to-left proof. Both channels are
  needed because `key_y` must serve all `2^b` values of `x`. A key carrying channel sets
  `C_i ⊆ {0,1}` serves `∏|C_i|` values, so one channel per bit means `2^{b+c}` keys, which is the
  1-input cost.
* **BGG+ puncturing does not rescue either level.** Selective BGG+ sets `A1_i = A0R_i + x*_i G`.
  This cancels the `G`-terms only at one `x*`, while `key_{y*}` publishes `T_{y*}`-encodings for every
  `x`. Puncturing at `x = 0` does give a trapdoor for `[A0 | A_{f(·,y*)}]`, since `f(0, y*) = 1` on a false
  statement. But the reduction must then write `T(A0R_i − G)`, which contains `T G` with `T`
  the LWE secret.
* **Hybrid granularity.** A hop must kill all pairs `(x*, ·)` or all pairs `(·, y*)` at once, since
  pair-level hybrids have no representation by slot objects. Each such hop is a 1-input ABE
  statement with all attributes of the other slot live, which is the circularity above.
  Exponential hop counts are allowed (`pq-we-hybrid-count-barrier`), but they do not help here.

**Open lemma (stated, not proved).** For short `s_x` (`x ∈ {0,1}^b`) and short `T_y`
(`y ∈ {0,1}^c`), the joint view `{s_x B_{i,x_i} + e}, {B_{i,β}^{−1}(T_y(A1_i − βG) + E)}`, plus the
`B0`/`B_u` parts and the keys `sk_{w1}` for a function family unauthorized on every `(x, y)`, hides
`μ` under plain LWE. Its weakest known proof uses evasive LWE (ARYY's final scheme modifies the
key and also needs tensor LWE for P). A proof for the WE-restricted family (fixed `φ`, full domains)
would give the costs in the summary.

## 4. Route (3): TLWE public trapdoors (AJLW, ePrint 2026/2927)

TLWE keeps `sA + e` pseudorandom next to a public trapdoor `T` of `A` only if `σ_e·σ_t ≥ q/√m`
(below that, `eT mod q = eT` over `Z` breaks it). A preimage that is sampled with `T`, or is
indistinguishable from one, has width `σ_D ≥ σ_t`. The honest error after applying it is then
`≈ √m·σ_e·σ_D ≥ q`. So TLWE cannot let the reduction simulate the `B`-preimages of §3 (the honest
decryptor traverses them), nor the BGG+ keys (applied to evaluated ciphertexts). Using TLWE only
for a final *decoding* step (TDRE style) does not touch the circularity, which lies in the
preimages. Open PR #78 analyses TLWE for WE in general.

## 5. Route (4): bounded-width verifiers and circuit restructuring

The layered chain of PR #80 streams `V` as `σ_i = h_i(σ_{i−1}, w_i)` with `s`-bit states and pays
`2^{ℓ_i + s}` ciphertexts in each middle layer. `AdvancedEncryption.WE.TwoInput.dp_reach` shows that
the reachable state sets `R_{n+1} = h(R_n × B)` are exactly the states reached by some witness
prefix, with at most `|S|·|B|` step evaluations per layer. So **the same decomposition lets the
encryptor decide SAT** at cost `Σ_i 2^{s+ℓ_i}`, the same as the chain's middle layers, and then
encrypt trivially. The chain differs from this DP only at the last cut, where a 1-input ABE
replaces `2^{s+ℓ_k}` with `2^{max(s, ℓ_k)}`. With PR #80's frontier, the DP over the same blocks
needs `m + (k−1)s ≤ k·e`, against `m + (k−2)s ≤ k·e` for the chain. The chain gains `s/k` bits.
For `k = 3, s = 16` that is 54 against 48. If the verifier is narrow at every bit (`ℓ_i = 1`), the DP
costs `m·2^{s+1}` while the chain costs at least `2^s`, a gain of at most `log2(2m) = 8` bits.

**Restructuring.** Tseitin/CNF adds the cut wires as witness bits, and the chain or DP enumerates
them, so `m` grows by the cut size. A re-encoding with a narrower verifier is a decomposition with
smaller `s`, and that makes the statement *easier to decide* at the same rate. For worst-case
`2^{12}`-gate circuits, for example `[h1(w1) ⊕ h2(w2) ⊕ h3(w3) = y]` with 128-bit `h_i`, every
order has `s ≈` prefix length, and then `e ≥ 64`. **Verdict:** narrowness is easiness. Route (4)
cannot beat the 2-split on the worst case, and on narrow instances it beats deciding by only
`s/k` bits.

## 6. Pricing a 3-way split by per-item cost

`AdvancedEncryption.WE.TwoInput.split3_frontier`: tables of `2^a, 2^b, 2^c` items with per-item
cost `2^{K1}, 2^{K2}, 2^{K3}` (`a + b + c = m`) all stay `≤ 2^E` iff
`m + K1 + K2 + K3 ≤ 3E` and every `K_i ≤ E`. The 2-split analogue is `m + K1 + K2 ≤ 2E`. With PR #83's
`K ≈ 2^{76}` the 2-split gives `E ≈ 140`, compared with PR #83's measured `2^{147.7}` total. A 3-way
split gains `(m + ΣK)/2 − (m + ΣK)/3` bits only if the slot-2 object costs about as much as the
others. In C2 it is about `2ℓ` preimages (`K_y ≈ K + 6.5`), which gives `E = 122` (summary). A 3-way split reaches `2^{97}` only if
`ΣK ≤ 3·97 − 128 = 163`, i.e. per-item costs averaging `2^{54}`. That needs depth reduction far
beyond the worst case `d ≈ 2048`, so it is out of reach for BGG+-type items.

## 7. Remaining gap and next steps

1. The open lemma of §3 (bilinear GGH15 with per-bit channels, keys unauthorized on all pairs)
   from plain LWE. Equivalently, an evasive-LWE-free simulation of `B^{−1}(T_y(A1_i − βG) + E)`.
   This is the single missing step, and it is the known open problem of plain-LWE multi-input ABE
   in its smallest form.
2. Even if it is closed, the 3-way split is at about `2^{123.6}`, not `2^{97}`. A further gain needs
   cheaper per-item BGG+ costs (depth), not more slots.

## A cut-rank test for exact many-slot field masks

Splitting n witness bits into r blocks of at most ceil(n/r) bits uses at most r*2^ceil(n/r) individual menu entries. For r=ceil(n/log2 n) this part is polynomial. This count by itself makes no guarantee about joint security, evaluator width, or key generation. To test one concrete route, suppose the *observable* pad at a tuple is the exact scalar product of the prefix and suffix state at a slot cut, over a finite field F_q. This includes a chain of arbitrarily sampled slot matrices with cut dimension d and scalar endpoints: even dependent matrices yield F(u,v)=A(u)B(v), where the row and column have length d. Suppose the observable output on the false instance is V_b(u,v)=F(u,v)+b at every tested tuple. All statements below concern this output interface.

On a fixed s-by-s grid of distinct prefix and suffix choices the pad table has rank at most d. Thus a hybrid replacing it by independent field values fails on s=d+1 as soon as each side has that many choices. The ideal square matrix is invertible with probability product_(i=1)^s (1-q^(-i)), by counting successively independent columns. This is bounded away from zero even for q=2. Computing this test takes s^2 evaluations and polynomial field time. It applies without any independence hypothesis on the real slot secrets. Failure of this hybrid alone does not establish plaintext leakage for every low-rank table.

There is a stronger conclusion for the natural control where the s prefix rows and s suffix columns are independent uniform vectors in F_q^d. Set s=d+h, h>=1. Write J=11^T. If the augmented s-by-(d+1) matrices [A,1] and [B^T,1] both have full column rank then AB+J has rank d+1 by factorization through the identity. AB always has rank at most d. Modulo the known line spanned by 1, each projected random column is uniform in dimension s-1, so full augmented rank has probability product_(i=0)^(d-1) (1-q^(i-(s-1))). Square this for the independent sides. This gives a lower bound on the difference of the probabilities that V_b has rank greater than d. For q=2, h=4 it is at least (1-1/8)^2 by a union bound on nonzero coefficient vectors in the projected kernel. Even access only to emitted values suffices. Forced inclusion of the constant vector among state coordinates invalidates this particular random-factor message bound; it does not invalidate the rank obstruction to independent pads.

Consequently an r-way compiler cannot justify security by replacing an exact polynomial-width field matrix product with independent tuple masks on an exponentially large balanced cut. A wide enough cut on just one side, or modifying the observable output via a nonlinear map with its own proof, changes the test's premises. Ordinary WE only needs hiding of b. No impossibility for general multi-input ABE, rounded encodings or quantum-secure PRFs follows. The joint security proof, not the polynomial menu count, is what remains necessary.

~~~python
from itertools import product
from fractions import Fraction
def rank2(columns):
    basis={}
    for v in columns:
        while v:
            i=v.bit_length()-1
            if i not in basis:
                basis[i]=v
                break
            v ^= basis[i]
    return len(basis)
s,d=3,2
one=(1<<s)-1
factors=list(product(range(1<<s),repeat=d))
large=0
for A in factors:
    for B in factors:
        cols=[(A[0] if B[0]>>i&1 else 0)^(A[1] if B[1]>>i&1 else 0) for i in range(s)]
        assert rank2(cols)<=d
        big=rank2([x^one for x in cols])>d
        assert big==(rank2((*A,one))==rank2((*B,one))==d+1)
        large+=big
assert Fraction(large,len(factors)**2)==Fraction(9,64)
print("4096 factor pairs; exact message-test gap 9/64")
~~~

## Fixed LPN and the exact offset condition for correlated tuple values

Consider a value-only alternative to the exact product test. Sample a uniform binary m-by-d matrix A, d-by-l uniform S and independent Bernoulli noise E of shape m-by-l; put Y=AS+E. Keep a fixed, statement-independent parameter family with quantum-hard decisional LPN for one m-sample column. Publish A. For each query tuple z the public circuit computes an m-by-l binary feature matrix T_x(z) and an offset bit g_x(z) without using S,E or b. The evaluator returns the bit <T_x(z),Y> + b*g_x(z), using the entrywise inner product. Reuse of cells of Y is intentional.

With Y replaced by uniform U the *whole* value function is a uniform element of the image of the linear map D -> (<T_x(z),D>)_z translated by b*g_x. Thus the two message laws are identical exactly when there exists D with <T_x(z),D>=g_x(z) for every z. This does not demand an independent random function on tuples. For statement-only features, a nonuniform proof may establish this existence without an efficient algorithm for finding D. Replacing columns one by one costs at most l fixed LPN advantages per message, since given the challenge A the reduction can generate the other columns with fresh secrets and noise. It can implement coherent evaluations reversibly using its full challenge column; budget their circuit cost. The resulting bound for the value interface on a false x satisfying the offset condition is twice the sum of the column advantages. See the binary decisional experiment in [Non-Interactive Zero-Knowledge from LPN and MQ, Definition 4.2](https://eprint.iacr.org/2024/1254.pdf).

If the condition fails, some at most m*l+1 tuples have feature matrices summing to zero but offset bits summing to one. Indeed select a basis among the flattened rows; interpolating their offsets defines a consistent functional there, so one additional row contradicts it. XORing these responses returns b exactly, for every Y and every noise draw. This gives a polynomial-size nonuniform distinguisher for a fixed offending x even if the tuple domain is exponential; efficient uniform discovery of the tuples is a separate issue. For features that depend on random A, a certificate hardwired before seeing A need not suffice. In particular the small-test statement here uses statement-only features.

For an interface example take one nonzero fixed coefficient feature when C_x(z)=0 and zero otherwise, with g_x(z)=1. Every true witness reads b. On NO the offset condition holds and the functions are constant across tuples with a hidden random shift in the ideal game. Publishing Y as well as any response on a known tuple instead exposes b by subtraction. Trying to encode the offset by sending only (A,Y+bD) for an efficiently computed public D does not repair this: for *every* fixed x and D independent of Y given A, the two buffer distributions are computationally indistinguishable by the same column hybrids, including on YES. An efficient decoder with a hardwired valid witness would contradict this. Thus the fixed assumption can justify correlated masks and avoid the earlier rank objection at the value interface, but an explicit representation giving the witness these evaluations without exposing the seed buffer and offset separately remains necessary. No general public WE ciphertext follows.

~~~python
from itertools import product
from collections import Counter
for rows in product(range(4),repeat=3):
    for g in range(8):
        images = [sum(((row & d).bit_count()%2)<<i for i,row in enumerate(rows))
                  for d in range(4)]
        law = Counter(images)
        same = law == Counter(y^g for y in images)
        assert same == (g in images)
        if not same:
            assert any(all((h&y).bit_count()%2==0 for y in images)
                       and (h&g).bit_count()%2 and h.bit_count()<=3
                       for h in range(1,8))
print("512 feature/offset systems; exact image criterion and short separating parities")
~~~

## An explicit response basis, and when its generation decides the source language

Flatten the public augmented row f(z)=(T_x(z),g_x(z)) into p+1 bits. If the sender can find representative tuples z_1,...,z_s whose rows span all query rows, it can publish just V_b(z_i) for i=1,...,s. Use a uniform p-bit mask in this construction: LPN is unnecessary. A receiver expresses f(z) in the representative basis by public elimination and XORs the indicated response bits. Correctness is exact for every query, because the full response is the evaluation of a linear functional on f(z). On NO the offset condition from above makes the joint responses perfectly hiding by translating the mask. Representatives must be chosen independently of mask and message. If both parties deterministically generate the representatives from x, the response payload is at most p+1 bits and no tuples need be transmitted. Otherwise include the polynomial-size list or its public seed. Enumeration of the whole tuple domain would give a short payload but can make Enc exponential.

One constructive case is an ordered read-once matrix product for the *augmented features*. Suppose f(z)=u M_1(z_1)...M_r(z_r)H, with polynomial layer widths and polynomially enumerable symbols per layer, each admissible tuple drawn from their Cartesian product. At layer zero retain the starting row if nonzero. At each subsequent layer extend every retained row by every allowed symbol, then keep a maximal independent subset of the resulting rows. Save a prefix realizing each retained row. Inductively these rows span all realizable prefix rows: right multiplication by the same next matrix preserves every prior linear dependence. Apply H and remove redundant projected rows at the end. This produces actual representative tuples in deterministic polynomial time, with at most the layer width many live prefixes and at most rank(H) final tuples. The argument needs the common reading order and the ability to extend every prefix by each symbol; repeated-variable consistency cannot simply be dropped. Dense binary elimination and matrix multiplication at each layer suffice for a polynomial sender and receiver. This provides a public ciphertext implementation of the specified linear evaluation interface on this structured family.

There is a sharp diagnostic for the proposed witness decoder f(w)=(0,1). With the complete basis, test if e_last belongs to its span. On YES, any accepting witness forces membership. On NO, (D,1) annihilates the basis by the offset condition but evaluates to one on e_last, so membership is impossible. Thus polynomial-time basis construction under these two promises already gives a polynomial-time source decider and hence a one-bit direct encryption. The same test works if the representatives span just e_last on YES and are all genuine on NO. Random discovery with a bounded two-sided error gives a BPP decider. This identifies a concrete cost overlooked by merely counting p+1 representatives. For the previous one-feature example with a unique accepting n-bit tuple, any list of Q independent uniform tuples spans e_last only if it samples that witness, with probability 1-(1-2^-n)^Q. This is a limitation of that sampling strategy, not a lower bound on other compilers. To extend to general NP without the implied decision algorithm one must change either the decoding criterion or the NO security mechanism.

## Two passes: a structured positive case and an NP-complete ordering

The same witness bits may be read in two different orders. For a block I contiguous in both orders, let P_I and Q_I be its matrix products in the first and second passes. Keep a basis of the vectors vec(P_I) tensor vec(Q_I), with one realizing assignment per basis element. For width w the dimension is at most w^4 (pad smaller matrices). Start at singletons by trying each possible bit. Suppose two disjoint children J,K partition I in first-pass order, and in the second pass occur either as J,K or as K,J. In the first case combine two representatives by (P_J P_K, Q_J Q_K); in the second by (P_J P_K, Q_K Q_J). On the tensor vectors this operation extends bilinearly, because each input pair occurs once in each tensor monomial of the result. Disjoint child assignments can be chosen independently. Consequently combining only basis representatives, at most w^8 pairs per node, and taking a basis again spans *all* attainable parent vectors. At the root the desired u P Q H is a linear contraction of the retained tensors. The earlier response-basis compiler applies to the projected augmented rows. A supplied binary common-interval decomposition is easy to check; alternatively recursively try interval splits with memoization to find one in polynomial time. This includes same-order and reverse-order passes and recursively swapped blocks. There is no need to remember all first-pass witness bits at the middle cut.

In contrast, polynomial WE for unrestricted two-pass orders would already suffice for ordinary NP, even at width three. Given a nonempty CNF with nonempty clauses, introduce one bit for each *literal occurrence*, storing the variable value before applying its literal sign. Read all occurrence bits once in clause order. At any position the live states record whether this clause is satisfied so far, plus an absorbing failure state. Apply the sign, at the end of each clause fail if unsatisfied, otherwise reset. In the second pass group the *same occurrence bits* by variable. On the first bit of each group store its value; on every later bit keep it on agreement and go to the absorbing failure state on disagreement. A new group overwrites the stored value without reviving failure. At the end accept either live state. Position-dependent transitions are public deterministic three-by-three binary matrices (one 1 per row); every Boolean assignment is evaluated exactly even over F_2. Empty clauses or an empty conjunction can be handled directly. Each input bit is read exactly twice. For l literal occurrences this uses 2l transitions on a run and O(l) small matrix pairs, plus the read order. Tseitin conversion gives polynomial size for CircuitSAT. A satisfying original witness supplies all occurrence bits including auxiliary gate values; any accepting occurrence string recovers a consistent satisfying assignment. Hence an ordinary WE for this public read-order family with polynomial costs and a fixed-assumption proof transports to general NP with the same assumption and no obfuscation intermediary. This is a reduction target, not an instantiation.

For the previous mask example compute f=(1-C,1) by a final linear map of the one-hot states. Reject maps to (1,1), accept to (0,1). On NO the offset condition holds, and a satisfying witness evaluates to the target. Thus polynomial generation of the genuine response basis for arbitrary second-pass permutations would decide SAT, by testing membership of (0,1). Width, layer size and number of reads are already constant per position here; the unmet cryptographic requirement is to enforce the same choices across the two orders without making reachability for all assignments publicly decidable. This concerns the augmented feature language of the preceding sections and does not give the missing public-encoding hybrid of PR 111.

~~~python
from itertools import product
from random import Random
rng=Random(912)

for _ in range(50):
    clauses=[[rng.choice((-3,-2,-1,1,2,3)) for _ in range(rng.randint(1,3))]
             for _ in range(3)]
    occ=sum(clauses,[])
    order=sorted(range(len(occ)),key=lambda i:abs(occ[i]))
    def run(bits):
        state=0
        i=0
        for clause in clauses:
            for pos,lit in enumerate(clause):
                if state!=2:
                    state=int(bool(state or bits[i]^(lit<0)))
                    if pos+1==len(clause):
                        state=0 if state else 2
                i+=1

        for i in order:
            var=abs(occ[i])
            if state!=2:
                state=bits[i] if var!=old or state==bits[i] else 2
            old=var
        return state!=2

        return all(any(x[abs(v)-1]^(v<0) for v in c) for c in clauses)
~~~

## Two live states admit a linear scan even with arbitrary rereads

For the deterministic, *oblivious* model used in the preceding reduction, width two has a direct decision algorithm. Each position i queries a public bit index v_i shared by both states, possibly repeated arbitrarily. For a fixed answer a, its map on the state bit is either constant (a reset) or s -> s XOR b_i(a), where b_i(a) is the image of zero. A particular execution therefore has a last reset, or uses only permutations. Its final state depends on one constant and the parity of all later permutation flips. This is specific to a single input index per layer; state-dependent choices of the queried variable are outside the argument. For a broader width-two SAT model see [Makita et al.](https://www.jstage.jst.go.jp/article/transfun/E105.A/9/E105.A_2021EAP1120/_article).

Scan right to left. For each variable maintain its allowed answers from the suffix requirement that *all* later maps are permutations. Also maintain the XOR coefficients of the suffix flips, using b_i(x)=b_i(0) XOR ((b_i(0) XOR b_i(1)) AND x). This affine extension is valid on the allowed domain even when the other answer resets. To test a reset at i, try its at most two constant-map answers a compatible with the suffix, temporarily pin v_i=a, and test if the reset value XOR suffix parity can equal the desired terminal state. With a product of unary domains, an affine bit takes both values iff some free variable has nonzero coefficient. Otherwise it takes only its fixed value. Then extend the permanent suffix by requiring a permutation at i and adding its flip. Stop extending if a domain becomes empty. Finally test the initial state as the no-reset case. Conversely each passing test yields an assignment: choose allowed answers meeting that parity; the unconstrained earlier prefix cannot affect the result after the reset. Thus this computes exact satisfiability without enumerating assignments or assuming independent occurrences.

With indexed arrays the scan uses O(L+n) word operations for L positions and n bit variables and O(n) working words (besides the stored read schedule). Maintain the parity for the least allowed answer of every variable and a count of free variables with nonzero coefficient. Only one variable changes per step; temporarily pinning it also costs O(1). A public single-tape implementation must charge for addressing and parsing; a straightforward scan-based simulation remains polynomial. For either accepting terminal this gives an unconditional one-bit ciphertext: emit the plaintext if acceptance is attainable and zero otherwise. Both accepting terminals or no accepting terminals are immediate. The previous width-three construction already embeds ordinary NP with two reads per variable. Thus in this precise model a third state can record permanent failure across multiple local checks, whereas at width two a later reset erases all earlier state information. This delineates the structured subclass and does not provide security for the three-state construction.

~~~python
from itertools import product
from random import Random
def attainable(n,layers,start,want):
    domain = [3]*n   # low and high bits permit answers zero and one
    coeff = [0]*n
    parity = free = 0
    for i,table in reversed(layers):
        old, c = domain[i],coeff[i]
        least = int(old==2)
        for a,(zero,one) in enumerate(table):
            if zero==one and old & (1<<a):
                fixed = parity ^ (c & (least^a))
                if free-int(old==3 and c==1)>0 or zero^fixed==want:
                    return True
        new = old & sum(1<<a for a,(z,o) in enumerate(table) if z!=o)
        if new==0:
            return False
        cnew = c ^ table[0][0] ^ table[1][0]
        parity ^= (c & least) ^ table[0][0] ^ (cnew & int(new==2))
        free += int(new==3 and cnew==1)-int(old==3 and c==1)
        coeff[i],domain[i] = cnew,new
    return free>0 or start^parity==want

rng=Random(446)
for n in range(1,7):
    for _ in range(100):
        layers=[(rng.randrange(n),tuple((rng.randrange(2),rng.randrange(2)) for _ in range(2)))
                for _ in range(rng.randrange(21))]
        for start in (0,1):
            terminals=set()
            for x in product(range(2),repeat=n):
                s=start
                for i,tab in layers:
                    s=tab[x[i]][s]
                terminals.add(s)
            assert terminals=={t for t in (0,1) if attainable(n,layers,start,t)}
print("600 schedules; 2400 start/target decisions agree with exhaustive evaluation")
~~~

## Which three-state transitions are needed?

Identify the states with F_3. Every permutation of the three states is s -> a s+c with a=1 or -1; there are exactly six such affine permutations. Constant maps are resets. Suppose each fixed input answer at each layer selects either a permutation or a constant. There is a polynomial test for acceptance even when the public schedule rereads variables arbitrarily. This is a statement about final-state acceptance. Related complexity questions for programs over monoids are studied in [Barrington, McKenzie, Moore, Tesson and Therien](https://sfi-edu.s3.amazonaws.com/sfi-edu/production/uploads/sfi-com/dev/uploads/filer/aa/b3/aab31b7d-bc95-4394-9d6b-21460c31e6aa/00-04-026.pdf).

Enumerate the last reset position and answer, or the no-reset case. Pin the reset answer and require a permutation at every later position. These are unary restrictions on actual bit variables; intersect all domains and skip inconsistent branches. The start of the suffix has a known state. Eliminate pinned variables. On this subcube the suffix consists entirely of affine permutations. Write chi_S(x)=(-1)^(sum_(j in S) x_j) over F_3. Every slope depending on one free bit is a signed character, while each intercept has at most two character coefficients (since 2 is invertible). The final state is the initial state times the product of slopes, plus one term per layer consisting of its intercept times the slopes of all later layers. Products of signed characters stay single signed characters, with supports combined by symmetric difference. A suffix of length L thus gives at most 2L+1 terms before combining equal supports, regardless of rereads.

For terminal t form the character dictionary of 1-(s_final-t)^2. It equals one exactly on the assignments ending at t. It is nonzero somewhere iff some coefficient is nonzero: the binary character matrix has orthogonal rows of squared norm 2^f, invertible in F_3 for f free bits. Squaring uses at most O((L+1)^2) term pairs per last-reset branch. There are at most 2L+1 branches; support bitsets, dictionary operations, coefficient addition mod three and unary-domain checks all have polynomial bit cost. Test the accepting terminals separately. As previously, a positive decision lets Enc output the bit and a negative decision gives a constant one-bit ciphertext. There is no hardness premise. This gives no comparable algorithm if a transition merges two states while preserving a distinct third image: such a map has image size two and is not affine on F_3. The NP-complete clause/equality program uses those partial mergers, for example sending both live states to the satisfying live state and keeping failure absorbing.

More generally, for k positions that may contain a partial merger, guess an answer bit and an entering state for each of these positions (at most 6^k choices), impose consistent pins, and compute the corresponding outgoing states. The k+1 intervening segments enforce specified terminal states on the *same* assignment. Enumerate last resets in each segment, intersect all the unary restrictions, and multiply their terminal-indicator dictionaries before the nonzero test. Testing each segment for feasibility separately would be unsound. This takes (L+1)^O(k+1) times polynomial bit overhead, allowing all constant k. This bound applies to the number of exceptional positions, not the number of different transition tables. No polynomial bound for arbitrary k or fixed-assumption general WE follows.

~~~python
from itertools import product
from random import Random
def possible(n, layers, start, target):
    cases=[(-1,0,start)]
    for i,(v,ab) in enumerate(layers):
        cases.extend((i,b,c) for b,(a,c) in enumerate(ab) if a==0)
    for i,b,s in cases:
        dom=[3]*n
        if i>=0: dom[layers[i][0]]=1<<b
        for v,ab in layers[i+1:]:
            dom[v]&=sum(1<<j for j,(a,c) in enumerate(ab) if a)
        if 0 in dom: continue
        coeff={0:(-target)%3}
        mask,sign=0,1
        def add(m,c):
            coeff[m]=(coeff.get(m,0)+c)%3
        for v,ab in reversed(layers[i+1:]):
            (a,c),(aa,cc)=ab if dom[v]==3 else [ab[int(dom[v]==2)]]*2
            add(mask,sign*2*(c+cc))
            add(mask^(1<<v),sign*2*(c-cc))
            sign=sign*a%3
            if a!=aa: mask^=1<<v
        add(mask,sign*s)
        ind={0:1}
        for u,cu in coeff.items():
            for v,cv in coeff.items():
                ind[u^v]=(ind.get(u^v,0)-cu*cv)%3
        if any(ind.values()): return True
    return False

rng=Random(318)
for _ in range(250):
    n=rng.randrange(1,7)
    layers=[(rng.randrange(n),[(rng.choice((0,1,1,2,2)),rng.randrange(3)) for b in range(2)])
            for _ in range(rng.randrange(16))]
    for start in range(3):
        ends=set()
        for x in product(range(2),repeat=n):
            s=start
            for v,ab in layers:
                a,c=ab[x[v]]
                s=(a*s+c)%3
            ends.add(s)
        assert ends=={t for t in range(3) if possible(n,layers,start,t)}
print("2250 start/target tests on three-state schedules with repeats, permutations and resets")
~~~

## Parameter cost of partial mergers when rereads are unrestricted

The exponent depending on the number of exceptional positions in the preceding decision baseline cannot in general be replaced by a fixed polynomial exponent unless parameterized CLIQUE is fixed-parameter tractable. Here is an explicit witness-preserving reduction. For a simple graph on N vertices and requested clique size h>=2, give the witness h vertex addresses of ceil(log2 N) bits each. Use isolated padding vertices to fill the address domain. For each pair of addresses test the badness bit f, one for a nonedge (including the diagonal), zero for an edge. A witness passes all pair tests iff its addresses form an ordered clique.

A Boolean truth table on u bits has a character expansion over F_3 with at most 2^u terms. The coefficient for support S is 2^(-u) times the sum of f(x) chi_S(x) over the Boolean cube, in F_3. Implement translation of a ternary state by one term c chi_S(x) using only permutations: negate the state conditionally on each selected input bit, translate by c, then repeat the conditional negations. The total map is s -> s+c chi_S(x). Concatenating terms yields the permutation program P_f(s)=s+f(x); its inverse is obtained by reversing and inverting its steps. Constants can be implemented at an arbitrary bit position with both transitions equal. Pair predicates have u=2 ceil(log2 N), so at most 4N^2 terms and O(N^2 log N) instructions per pair. Coefficients can be computed in polynomial time independently of h's value in the exponent.

Let M send 1 to 2 and fix 0 and 2. Compile each pair check as P_f, M, P_f inverse, M in execution order. Starting in 0, a good pair leaves 0 and a bad pair leaves 2. Starting in 2, either case leaves 2 (for a bad pair the intermediate states are 0,0,2,2). Thus the accumulated rejection bit persists at the *boundaries* even though it need not persist inside a permutation block. Start at 0 and accept only 0. There are exactly k=2 binom(h,2) designated merger positions, all using the same input-independent M. All other instructions are permutations. Total length is O(h^2 N^2 log N) for N>=2. This proves the parameterized implication by direct substitution: an f(k) poly(L) decision procedure here gives an f'(h) poly(N) CLIQUE procedure. Under the usual parameterized clique time hypothesis excluding g(h) N^o(h), it also rules out g'(k) L^o(sqrt(k)); see [Chen, Huang, Kanj and Xia](https://www.sciencedirect.com/science/article/pii/S0022000006000675) for parameterized clique lower bounds. Neither claim proves the preceding L^O(k) upper bound optimal.

This uses arbitrary repeated reads for the character terms. It does not strengthen the parameter lower bound for schedules reading each bit only twice. It does show that sharing a single public partial merger and allowing arbitrary efficiently listed ternary permutations already gives a nontrivial WE target. A hypothetical polynomial-cost secure WE for these schedules would transport to CLIQUE, hence all NP by witness-preserving reductions such as the literal-selection reduction from 3SAT. The complexity obstruction applies to the strategy of publicly deciding the statement; it does not exclude computational WE.

~~~python
from itertools import combinations, product
def terms(table):
    n=len(table)
    return [(s,(pow(n,-1,3)*sum(v*(-1)**((s&x).bit_count()%2)
                                 for x,v in enumerate(table)))%3) for s in range(n)]
def apply(s,x,coeffs,direction):
    for mask,c in coeffs:
        for j in range(4):
            if (mask & x) >> j & 1: s=-s%3
        s=(s+direction*c)%3
        for j in reversed(range(4)):
            if (mask & x) >> j & 1: s=-s%3
    return s
edges=list(combinations(range(4),2))
for graph in range(64):
    E={e for j,e in enumerate(edges) if graph>>j&1}
    bad=[int(tuple(sorted((z>>2,z&3))) not in E) for z in range(16)]
    coeffs=terms(bad)
    for picks in product(range(4),repeat=3):
        s=0
        for a,b in combinations(picks,2):
            z=4*a+b
            s=apply(s,z,coeffs,1)
            s=2 if s==1 else s
            s=apply(s,z,reversed(coeffs),-1)
            s=2 if s==1 else s
        assert (s==0)==all(tuple(sorted(pair)) in E for pair in combinations(picks,2))
print("4096 graph/address triples; emitted ternary permutation and merger steps agree with CLIQUE")
~~~

## One fixed merger per clause with at most eight controlled permutations

There is a shorter boundary update than the two-merger construction above. Encode live as 0 and failed as 2 in F_3. For any Boolean badness bit f, first translate by -f, then apply the fixed M=(0,2,2). If f=0 both boundary states are unchanged. If f=1, the two boundary states 0 and 2 become 2 and 1 respectively; M sends both to 2. Thus no inverse translation is needed. For the clique construction this halves the merger count to binom(h,2). The invariant is needed only between checks.

For a nonempty clause with u<=3 literals, use local query bits x_j equal to one when literal j is false. Its badness bit is f(x)=product_j x_j, including if occurrences happen to read the same original variable. Expand -f in F_3 characters chi_S. The coefficient c_S is -2^(-u)*(-1)^|S| since f is supported on the all-ones tuple. To implement the translation by sum_S c_S chi_S, visit the 2^u supports in cyclic binary reflected Gray order starting at the empty set. At each support translate by c_S and then conditionally negate on the unique bit toggled to the next support (including the final return to empty). For any assignment, induction gives a state after moving to support R equal to chi_R times the initial state plus accumulated character translations inside the same parentheses. Explicitly it is chi_R(x)*(s_initial + sum_{S visited} c_S chi_S(x)). Closing the tour therefore gives s_initial-f(x).

All constant translations can be compiled away. Maintain the offset d in the invariant logical state = physical state + d, initially zero. A constant translation adds to d. A conditional negation becomes identity when its bit is zero and the reflection s -> -s-2d when its bit is one; d stays fixed. After the tour d=sum_S c_S=-f(0)=0. Negated literal inputs are handled by swapping the two public transitions. Thus only 2^u controlled permutations, each choosing between identity and a transposition, and exactly one input-independent M are emitted. Constants are compiled into the reflection tables. Reject an empty clause directly.

An m-clause 3-CNF therefore takes at most 9m instructions with unrestricted rereads, accepting exactly its satisfying witnesses. More specifically the usual NAND Tseitin encoding with two binary clauses and one ternary clause per gate, and one output unit, needs at most 19g+3 instructions for g gates before simplification. A decryptor extends an original witness by the honest gate values. Conversely acceptance enforces each gate equation and the output pin. These are counts of verifier instructions, not cryptographic operations or ciphertext bytes. Schedules of this form suffice as a general-NP target for fixed-assumption WE. The same occurrence control must remain consistent across repeated reads; publishing both choices as freely composable paths drops that requirement. No hiding theorem for the compiled ciphertext is obtained.

~~~python
from itertools import product
def program(u):
    size=1<<u
    d=0
    steps=[]
    for i in range(size):
        gray=i^(i>>1)
        j=(i+1)%size
        next_gray=j^(j>>1)
        d=(d-pow(size,-1,3)*(-1)**gray.bit_count())%3
        steps.append(((gray^next_gray).bit_length()-1,(-2*d)%3))
    assert d==0
    return steps

def run(s,bits,steps):
    for j,c in steps:
        if bits[j]: s=(c-s)%3
    return (0,2,2)[s]

checked=0
for u in range(1,4):
    steps=program(u)
    for pins in product(range(3),repeat=u):
        for signs in product(range(2),repeat=u):
            for data in product(range(2),repeat=3):
                bits=[data[j]^a for j,a in zip(pins,signs)]
                for start in (0,2):
                    assert run(start,bits,steps)==(2 if all(bits) else start)
                    checked+=1
print(checked,"signed/repeated-input boundary checks; clause lengths 3, 5 and 9")
~~~
