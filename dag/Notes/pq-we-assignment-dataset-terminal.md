A signature can authenticate a terminal bit for a dataset signed by its issuer. Its raw lattice opening can do more: when the bit is one it yields a short preimage for a dual encryption under a particular matrix. Publicly serving that encryption for every witness with the same hidden message is an additional operation. Below is an explicit assignment-indexed construction that reaches the preimage, followed by a failure of its literal terminal encryption. The result is an interface separation, with no WE submission or new hardness premise.

### Which dataset can the verifier trust?

[PR 133](https://github.com/MachinaIO/SigabaPark/pull/133) characterizes agreement on overlapping input supports. Its three-gate circuit computes the constant zero via u=NAND(x,x), v=NAND(x,u), o=NAND(v,v). A free combination of two individually obtainable labels fabricates v=0. Our interface uses the full 128-bit assignment as an injective identifier τ=x, scoped to the current ciphertext and statement. A merge refers to the specified ordered parent wires under the same header; the verifier checks the circuit named by the ciphertext. Constant wire zero and all reads of future wires evaluate to true as in the registered relation. Fan-out copies a derivation. The local-signature quotient note uses a signature in the sense of a Boolean equivalence class. The proof-system note considers unrestricted linear solvability. Here the certificate is for a named dataset, and the norm of a preimage matters.

For the GVW multi-dataset scheme, Enc can generate a fresh master verification/signing key pair. The holder of the master secret authorizes each dataset key. Its holder signs the 128 bits under that key. In §5.2 a regular signature binds the dataset key, tag and length. Verification checks it and the evaluated signature for the named circuit. A false value on a previously issued admissible dataset gives a type-II forgery. A valid signature at a fresh tag gives a type-I forgery even when the value is correct. Thus a public initializer with only ordinary verification data that outputs all labels for an unqueried τ immediately wins the fresh-tag game by submitting the first projection. A signer-created auxiliary program for constrained issuance would change the game and needs its own proof. Publishing the master signing key permits signing a different vector under the chosen name. Merely testing equality of two caller-supplied names cannot prevent this. Checking x itself against the public name and recomputing the trace is an available alternative source of semantic soundness.

The encryptor lacks the eventual witness. Issuing once for a known assignment covers only that assignment. Issuing a literal header for every assignment costs at least 2^128 writes even at one bit per record. Letting the evaluator generate its own key permits honest self-signing, but also lets it sign arbitrary data. Further, its trapdoor allows short preimages of arbitrary targets under its own A, including on a false circuit. The paper's issuer authentication and claw game concern secret keys retained by the signer. A publicly verifiable commitment with public commitment creation likewise permits the evaluator to commit to x, which identifies a dataset if the verifier checks the opening. Its binding game alone says nothing about an encryptor's secret. [Gorbunov, Vaikuntanathan and Wichs, *Leveled Fully Homomorphic Signatures from Standard Lattices*, ePrint 2014/897, §§4.2, 5.1–5.2, Theorems 4.1 and 5.1, pp. 17–18, 22–25](https://eprint.iacr.org/2014/897.pdf)

### NAND and a concrete setup-free initializer

Work over Z/q. Take a gadget G of shape n by k with binary decomposition D satisfying G D(V)=V. If V_j=A U_j+b_j G for parent j, set

    R = D(V_l)
    b_o = 1 - b_l b_r
    U_o = -(b_r U_l + U_r R)
    V_o = G - V_r R.

Here A is n by r, the U matrices are r by k, and R is k by k. Expanding the right side proves V_o=A U_o+b_o G. The sign convention matters: using G R=-V_l with these same update formulas failed the modular check. We use the positive decomposition of GVW Lemma 2.2(3). The theorem nand_opening is the pointwise additive identity, valid also when the two parents coincide. The signed branch scalar is only zero or one, so the entry norm grows by at most k+1 per gate of depth. The paper's square secret-key construction obtains its input signatures by trapdoor inversion. [GVW, §§3.2–3.3, Theorem 3.1 and the NAND growth calculation, pp. 11–14](https://eprint.iacr.org/2014/897.pdf)

Here is a different, public issuer that avoids enumerating assignments. Enc chooses public V_1,...,V_128 of shape n by k. Anyone given x builds the implicit n by 128k matrix

    A_x = [ V_1 - x_1 G | ... | V_128 - x_128 G ].

The label for input i is the public block insertion U_i=E_i, where E_i embeds a k-vector in block i. Indeed A_x E_i+x_i G=V_i. The constant true has U=0,V=G. All 128 labels for a chosen identifier are issued by the evaluator, with no private key or setup. This is a rectangular algebraic compiler derived here, not an instantiation of GVW unforgeability. For sound public verification, check τ=x and recompute C(x) against the claimed bit, using the registered wire semantics. Alternatively one may verify a complete deterministic trace against x. Every accepting verified claim then has a common assignment by construction. Checking only a short matrix equation under the adaptively derived A_x would require its own short-opening soundness theorem. A malicious party can omit public checks when processing the raw ciphertext.

The terminal public V_C depends on C and the common V_i only. For a public n-vector z take h=D(z). At b_C=1, t=(-U_C h,h) satisfies [A_x | V_C]t=z. At b_C=0, any (p,r') with [A_x | V_C](p,r')=z gives A_x(p+U_C r')=z. These are the two parts of terminal_preimage. The latter is an algebraic reduction; its use as a hardness reduction would need a norm bound, an appropriate random instance and the selector's whole joint distribution. GVW Lemma 6.4 gives a randomized short-preimage algorithm in the nonzero-gadget case. Our explicit choice makes Dec deterministic.

One can compute U_C h without ever storing a rectangular U. Compute V and the bits forward. Set a vector accumulator at the last wire to h and all other accumulators to zero. Process gates in reverse order: for current accumulator t add -b_r t to the left parent and -R t to the right parent. Accumulate both contributions for a repeated parent. The leaf accumulators are the 128 consecutive blocks of U_C h. This follows by distributivity from the displayed NAND update. Work modulo q and finally center coefficients. The true integer lift is recovered whenever its predicted norm is below q/2. A check over q=13, n=1, k=4, two Boolean inputs, five gates, a true constant, repeated parents and fan-out gave identical projected and explicit matrix openings on all four assignments and all thirteen targets.

### Terminal release and its joint view

For one fixed x, encryption can put the same ephemeral row s on both blocks and publish c_x=s A_x+e_x, c_C=s V_C+e_C, and d=s z+e_d+β q/2 for even q. On a satisfying witness subtract (c_x,c_C)t from d and round to the nearest of 0,q/2. Correctness requires the absolute induced error to be strictly below q/4. This derives a specific terminal bit release. Fresh per-assignment secrets would require matching headers and masks; a single common d cannot be paired arbitrarily with them. In the original GVW basic core the V_i can be common while the HTDF key A varies per dataset. Keeping V_C common does not make the left samples common. The adaptive signature wrapper can introduce further per-dataset data.

For the public selector, the literal way to provide c_x is to publish for each i both rows c_i^b=s(V_i-bG)+e_i^b. Then c_i^0-c_i^1=sG+e_i^0-e_i^1. Multiplying by h gives s z plus error at most 2kη if each noise coefficient has magnitude at most η. Thus direct rounding of d-(c_i^0-c_i^1)h recovers β on *every* circuit if (2k+1)η<q/4. This uses only one input position and no proof, signing oracle or witness. The theorem cross_header_pad proves the cancellation, including unequal noise. The registered false circuit with every gate NAND(1,1) suffices. A compact public algorithm returning those same raw block samples on demand has the same problem, even if different assignment identifiers are authenticated. Two distinct assignments suffice. If instead both bit openings are issued at the same fixed A and V_i, their difference composed with h gives a short A-preimage of z with coordinate bound 2kβ_init (shared_openings). Both failures rely on exactly the common targets and correlated observations displayed here.

The missing interface is a compact, witness-independent ciphertext constructor serving only the contracted terminal value needed by a coherent accepting evaluation. Equivalently, in the row above it must supply the action of a common dual secret on the accepting preimage with small rounding error while keeping the two raw input projections inaccessible together. Its false-statement experiment gives the adversary the entire header, masked bit, all initialization data and public algorithms, with unrestricted offline evaluation on arbitrarily many assignments. Any claim must show the registered cost/advantage-squared inequality for this view. A secrecy hybrid to an independent uniform pad suffices if it includes all those components, both challenge bits, and its concrete loss. GVW authenticates the output of computations over previously issued data under SIS. Its §6 context-hiding guarantee concerns information about that data. Neither game compares two encryptions of β. SIS is not a named entry of the goal's decision-LWE registry; any use via LWE would need the actual parameter translation and concrete loss. BGG+ FKHE evaluates ciphertext data for the attribute fixed at encryption; its LWE theorem does not supply both attribute choices under one ephemeral row. [GVW, §§2.1, 6.1, Lemma 6.4 and Theorem 6.5](https://eprint.iacr.org/2014/897.pdf) · [Boneh et al., *Fully Key-Homomorphic Encryption, Arithmetic Circuit ABE and Compact Garbled Circuits*, ePrint 2014/356, §4, Definition 4.1 and Theorem 4.2](https://eprint.iacr.org/2014/356.pdf)

A separate exact interface test (certificate_fibers) fixes C, encryptor coins ρ, a view v(ρ) and a publicly computed certificate π(v,x). An exact decoder of K(ρ) given (v,x,π) for every satisfying x exists iff, whenever C is satisfiable, K is constant on each fiber of v. Equal views give the very same certificate for the same x. Conversely one may choose a representative of the fiber. The converse is information-theoretic and supplies no efficient decoder. In particular, a verifier recomputing C(x) with τ=x has perfect consistency even if two choices of a hidden fair bit give identical views and all the same certificates. Then any decoder for a fixed satisfying x succeeds exactly half the time averaged over that bit. This countermodel concerns the public certificate API with no correlated payload. Real WE may put suitable correlated information in its header. Publishing β itself gives the converse caution: correctness and identical verification behavior can coexist with complete disclosure on false statements.

### A 4,096-gate resource row

Price the rectangular selector with binary G, n=128, w=98,304 bits per residue, q=2^w, k=nw=12,582,912, r=128k=1,610,612,736. This power-of-two row is an arithmetic test for the public construction; GVW's SIS theorem chooses a prime. No concrete lattice strength is attributed to this row. Take independent uniform V_i, s and z, and errors independently in {-1,+1}. The ciphertext contains the dense V_i, 256 dual rows, the terminal dual row, z and d in that order. U_i are implicit. No external parameters or signing service are charged to the user. The worst-case depth is 4,096; treating it as 12 would change the relation.

The integer lift of U_C is entrywise bounded by B=(k+1)^4096. For h binary, the noise in honest rounding is at most 1 + r k B + k. In this row k+1 < 2^23.59 (for example, (k+1)^100 < 2^2359 by integer exponentiation), so log2(r k B) < 31+24+4096·23.59 < 96,680. This is below w−2 with ample room. The lift is unique. The two-row cancellation also rounds correctly with probability one. Thus the concrete row achieves honest recovery and publicly discloses the bit even for the registered all-false circuit. The latter calculation can be implemented by sequentially scanning the ciphertext, accumulating two row products against the binary decomposition of z and rounding one word. Buffer the first pair until z is read. Its cost need not approach the security threshold: even rescanning the full encoded payload once for each of the 128 coordinates of z, followed by sequential word additions, takes far below 2^128 with conventional binary counters. The algebraic recovery and this costing argument are distinct from a registered Machine distinguisher proof.

These counts price fixed-width schoolbook evaluation. H counts inspected bit positions in the inner loops, not TM cycles. Ciphertext output is a separate mandatory write floor. All 4,096 forward matrices occupy 648,518,346,341,351,424 bits in Dec's workspace. The reverse pass reads decompositions of the stored left-parent matrices directly. The remaining operations include gate parsing and parent selection, indicator additions, repeated head moves, key and noise generation, the initial dual products, the final dot products and rounding. In particular, the terminal inner product on r entries uses full w-bit products, not merely r bit operations.

For oracle-free machines with t work tapes and a control states, each description is exactly 6a·3^t·(4+4t+Nat.size(a)) bits. An example implementation budget of eight tapes and 1,024 states for each machine consumes 3,789,213,696 bits for the pair. Even optimistic clocks then give a whole-machine floor of 20,584,098,424,442,880. The theorem selector_cost_row checks the conditional floor and the product H. This row fails PR 133's separate 2^32 screen already from its writes; that screen is stricter than the registered 2^100 cap. Under a roomier budget of 28 tapes and at most 2^24 states per machine, both descriptions together cost at most 649,404,639,179,654,238,830,592. If all costs outside the three inner loops fit in 2^90 steps, the remaining cap allows approximately 77,000 TM steps per counted inner bit position. This is a break-even budget and requires an actual implementation to certify.

A conservative whole-machine upper estimate is possible for the **disclosing** row without assuming fast memory access. Use a fixed Boolean circuit for each algorithm, including its bounded input and coins. A size allowance S=2^96 gates and input/output bits per algorithm suffices by the following paper accounting.

* Represent conditional word addition by bit selection and a ripple adder, under 64 NANDs per bit (a full adder can use two XORs, two ANDs and one OR). The two forward and one reverse matrix passes together use under 64H < 2^90 NANDs for those inner additions. At each gate, selecting two parent matrices from at most 4,225 by a binary multiplexer tree takes under 2·4225·4nk w NANDs. Repeated for both forward passes and also for the left matrix in reverse, this costs less than 2^77. Demultiplexing updates to at most 4,225 parent vectors of k entries in reverse, including addition of both contributions, fits in 2^75 by the same bound with 64 NANDs per bit.
* For dual products one may multiply twice for both choices of each block. At most (256+1)nk + 128k + k + n full scalar products of two w-bit words suffice counting individual multiplications (input banks, terminal row, opening and masked word). Schoolbook multiplication plus accumulation costs at most 128w² NANDs each, below 2^81 in aggregate. Generating bounded errors requires one coin each. Negations, gadget subtractions and carry-outs fit in another 2^81. Framing and routing do not require scanning the entire ciphertext for each of its bits. The statement has length at most 4096(6·4224+3) before tuple framing. A quadratic-size sequential counter simulation on even 2^30 statement-prefix bits fits in 2^70 with binary counters. Align the large fixed payload once by a shift network controlled by that prefix length, then unframe it. Fewer than 2^60 framed input/output positions with fewer than 64 shifts each fit well inside the allowance. All fields have fixed sizes apart from this small prefix; malformed inputs can be cut off by the clocks.
* For a loose nonuniform implementation, place all input, fair coin and gate-result bits consecutively on one work tape. For each circuit gate unroll fixed head movements to its two arguments and back to the next result cell; the remembered arguments occupy at most four control variants. The input copy and scattered output reads fit the same bound. With S bounding the total positions, both the clock and number of states per machine are below 100S² < 2^199 (at most three traversals of S cells per gate and one per output, allowing for read/write steps). Padding to 2^199 states would cost 6·2^199·3·(8+200) < 2^211 description bits per machine. Even this deliberately slow implementation has aggregate clock plus both descriptions below 2^213. This constructive upper estimate and the exact payload floor bracket a failed construction. The smaller practical cap requires a streamed implementation and a different terminal primitive. No secure runtime or machine description can yet be assigned to that missing operation.

For comparison, even literal one-dataset-per-assignment GVW input openings alone, at a hypothetical square width m=128w+256 and 24 bits per signed starting entry, occupy 2^128·128m²·24, about 2^186.75 bits. This prices that serialization before any signature headers, gate evaluation or machine descriptions. It does not assume the displayed sampler width attains the paper's strength.

The Lean nodes cover the NAND invariant, the two terminal identities, the two common-target cancellations, the public-certificate fiber criterion and conditional cost arithmetic. The selector compiler, small-instance experiment, noise estimates, issuance-game application, implementation estimates and full-view discussion are paper results. The remaining design question is whether a decision-LWE registry primitive can deliver the accepting contraction for all identifiers in one ciphertext without exposing opposite projections. A solution needs a reduction covering adaptive reuse of that ciphertext and a bounded Machine implementation.
